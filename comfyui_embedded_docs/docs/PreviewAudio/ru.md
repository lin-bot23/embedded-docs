# Предварительное прослушивание аудио

Узел Preview Audio позволяет прослушивать аудио прямо в интерфейсе ComfyUI, не сохраняя его в выходную директорию. Он принимает аудиоданные на вход, проверяет их наличие и пропускает их без изменений, отображая временный аудиоплеер, чтобы вы могли услышать результат.

## Входные параметры

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `audio` | Аудиоданные для предпросмотра. Узел вызывает ValueError, если вход равен None — это может произойти, когда в исходном видео отсутствует аудиодорожка. | AUDIO | Да | - |

## Выходные параметры

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `audio` | Аудиоданные, переданные без изменений со входа. | AUDIO |
| `ui` | Отображает виджет аудиоплеера в интерфейсе для предпросмотра аудио. | UI |
