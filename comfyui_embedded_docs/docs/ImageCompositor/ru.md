# Создать многослойное изображение

Этот узел объединяет несколько слоёв изображения в одно итоговое композитное изображение. Он принимает стек слоёв, созданный с помощью узла Add Layer, и при необходимости применяет сохранённые настройки композиции из редактора композитинга, смешивая слои в соответствии с их положением, размером, поворотом, непрозрачностью и режимом наложения.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `layers` | Стек слоёв для сведения; создайте его с помощью узла Add Layer. Элементы располагаются по значению z_index; пакетные кадры внутри элемента разворачиваются в последовательные слои. Размещение, непрозрачность и режим наложения элемента задают исходную композицию. При отсутствии явного холста документа размер по возможности принимается равным максимальному охвату размещённых слоёв. Сохранённая композиция, соответствующая текущим входам, имеет приоритет. | LAYERS | Да | Максимум 50 слоёв |
| `compositor` | Многослойная композиция, сохранённая редактором композитинга. | COMPOSITOR | Нет | — |

**Примечания об ограничениях:**

- Стек слоёв поддерживает не более 50 слоёв (расширенных кадров); если указать больше, возникнет ошибка.
- В настоящее время поддерживаются только растровые слои; другие типы элементов слоёв вызывают ошибку.
- Версия документа `layers` должна быть 1; другие версии вызывают ошибку.
- Сохранённое состояние `compositor` применяется только при совпадении записанных в нём сигнатур входных данных с текущим стеком слоёв. При несовпадении узел возвращается к сведению на основе свойств слоёв и помечает сохранённое состояние как устаревшее.
- Непрозрачность слоя ограничивается диапазоном от 0.0 до 1.0.
- Горизонтальное и вертикальное положение слоя (`x`, `y`) ограничивается максимальным пределом разрешения.
- Если ширина и высота слоя заданы равными нулю или меньше, используются естественные размеры изображения; при этом они ограничены максимальным пределом разрешения.
- Размер холста после сведения не должен превышать максимальный предел разрешения.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сведённое изображение. Содержит альфа-канал, если композиция имеет прозрачные области (например, скрытый фон), в противном случае — обычное RGB. | IMAGE |
| `MASK` | Прозрачность композиции (1 = полностью прозрачно). Все нули, когда композиция непрозрачна. | MASK |
