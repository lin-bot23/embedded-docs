# 建立分層影像

此節點可將多個影像圖層合併為單一合成影像。它接收以 Add Layer 節點建立的圖層堆疊，並可選擇套用合成器編輯器所儲存的合成設定，根據圖層的放置位置、大小、旋轉、不透明度與混合模式進行混合。

## 輸入

| 參數 | 說明 | 資料型別 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `layers` | 要合成的圖層堆疊；請使用 Add Layer 建立。項目依 z_index 堆疊，項目內的批次影格會展開為連續圖層，而項目的放置位置、不透明度與混合模式則定義初始合成。若沒有明確的文件畫布，畫布尺寸會盡可能取已放置圖層的最大範圍。與目前輸入相符的已儲存合成會優先套用。 | LAYERS | 是 | 最多 50 層 |
| `compositor` | 由合成器編輯器儲存的圖層合成。 | COMPOSITOR | 否 | 無 |

**限制說明：**

- 圖層堆疊最多支援 50 個圖層（展開後的影格）；若提供更多圖層將回報錯誤。
- 目前僅支援點陣圖層；其他圖層項目類型會回報錯誤。
- `layers` 文件版本必須為 1；其他版本會回報錯誤。
- 已儲存的 `compositor` 狀態只有在記錄的輸入指紋與目前圖層堆疊相符時才會重播。若不相符，節點會改為依照圖層屬性進行合成，並將已儲存狀態標記為過期。
- 圖層不透明度會被限制在 0.0 到 1.0 之間。
- 圖層的水平/垂直放置位置（`x`、`y`）會被限制在最大解析度限制內。
- 圖層的寬度與高度若設為 0 或以下，會回退為影像原始尺寸，且上限為最大解析度限制。
- 合成畫布尺寸不得超過最大解析度限制。

## 輸出

| 輸出名 | 說明 | 資料型別 |
|-------------|-------------|-----------|
| `IMAGE` | 合成後的影像。當合成結果具有透明區域（例如隱藏背景）時會帶有 Alpha 色版，否則為一般 RGB。 | IMAGE |
| `MASK` | 合成結果的透明度（1 代表完全透明）。若合成結果不透明，則全為 0。 | MASK |
