# ایجاد تصویر لایه‌ای

این گره چندین لایه تصویر را به یک تصویر ترکیبی واحد تبدیل می‌کند. این گره یک پشته لایه ساخته شده با گره Add Layer را دریافت می‌کند و به‌صورت اختیاری تنظیمات ترکیب ذخیره‌شده از ویرایشگر compositor را اعمال می‌کند و لایه‌ها را بر اساس مکان، اندازه، چرخش، شفافیت و حالت ترکیب آن‌ها با هم می‌آمیزد.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `لایه‌ها` | پشته لایه برای ترکیب؛ آن را با Add Layer بسازید. آیتم‌ها بر اساس z_index پشته می‌شوند، فریم‌های دسته‌ای داخل یک آیتم به لایه‌های متوالی بسط می‌یابند، و مکان، شفافیت و حالت ترکیب آیتم، ترکیب اولیه را تعریف می‌کنند. بدون بوم سند صریح، اندازه به‌صورت بهترین تلاش برای حداکثر گستردگی لایه‌های قرار گرفته تعیین می‌شود. یک ترکیب ذخیره‌شده که با ورودی‌های فعلی مطابقت داشته باشد، اولویت دارد. | LAYERS | بله | حداکثر ۵۰ لایه |
| `ترکیب‌کننده` | ترکیب لایه‌ای ذخیره‌شده توسط ویرایشگر compositor. | COMPOSITOR | خیر | None |

**یادداشت‌هایی درباره محدودیت‌ها:**

- پشته لایه حداکثر از ۵۰ لایه (فریم‌های بسط‌یافته) پشتیبانی می‌کند؛ ارائه بیشتر باعث خطا می‌شود.
- در حال حاضر فقط لایه‌های رستری پشتیبانی می‌شوند؛ سایر انواع آیتم لایه باعث خطا می‌شوند.
- نسخه سند `layers` باید ۱ باشد؛ نسخه‌های دیگر باعث خطا می‌شوند.
- وضعیت ذخیره‌شده `compositor` تنها زمانی بازپخش می‌شود که اثرانگشت‌های ورودی ثبت‌شده آن با پشته لایه فعلی مطابقت داشته باشد. اگر مطابقت نداشته باشند، گره به ترکیب از ویژگی‌های لایه باز می‌گردد و وضعیت ذخیره‌شده را به‌صورت منقضی شده علامت‌گذاری می‌کند.
- شفافیت لایه به محدوده ۰.۰ تا ۱.۰ محدود می‌شود.
- مکان افقی/عمودی لایه (`x`, `y`) به حد حداکثر رزولوشن محدود می‌شود.
- عرض و ارتفاع لایه هنگامی که روی صفر یا کمتر تنظیم شوند، به اندازه طبیعی تصویر باز می‌گردند و در حد حداکثر رزولوشن سقف‌گذاری می‌شوند.
- اندازه بوم ترکیبی نباید از حد حداکثر رزولوشن فراتر رود.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `IMAGE` | تصویر ترکیبی. هنگامی که ترکیب دارای نواحی شفاف است (مثلاً پس‌زمینه پنهان)، کانال آلفا را حمل می‌کند، در غیر این صورت RGB ساده. | IMAGE |
| `MASK` | شفافیت ترکیب (۱ = کاملاً شفاف). هنگامی که ترکیب کدر است، همه صفر. | MASK |
