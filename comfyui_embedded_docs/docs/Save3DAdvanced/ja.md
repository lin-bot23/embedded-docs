# 3Dを保存（詳細）

Save3DAdvanced は、ComfyUI の出力ディレクトリに 3D モデルをファイルとして保存し、保存したシーンのプレビューを作成します。また、3D モデル、シーン内での配置、カメラ情報、ビューポートの寸法を後続ノードに渡します。モデルの配置またはカメラ情報が接続されていない場合、ノードはビューポート状態に保存されている値を使用します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | 上流の3Dノードからの3Dモデルファイルです。 | FILE3D | はい | GLB<br>GLTF<br>FBX<br>OBJ<br>STL<br>USDZ<br>Any |
| `filename_prefix` | 保存ファイル名に使用されるプレフィックスです（デフォルト: "3d/ComfyUI"）。 | STRING | はい | Free text |
| `viewport_state` | カメラとモデルの配置情報を含むビューポート状態です。通常は Load 3D ノードから取得されます。 | LOAD3D | はい | - |
| `model_3d_info` | シーン内の各モデルの配置（位置、回転、スケール）です。Y-up ワールド空間で表されます。接続すると、`viewport_state` に保存されているモデル配置を上書きします。 | LOAD3DMODELINFO | いいえ | - |
| `camera_info` | ビューポートのカメラ情報（位置、注視ターゲット、ズーム、タイプ）です。接続すると、`viewport_state` に保存されているカメラ情報を上書きします。 | LOAD3DCAMERA | いいえ | - |
| `width` | ビューポートのレンダリング幅（ピクセル単位）です（デフォルト: 1024）。 | INT | はい | 1 to 4096 |
| `height` | ビューポートのレンダリング高さ（ピクセル単位）です（デフォルト: 1024）。 | INT | はい | 1 to 4096 |

注: `model_3d_info` と `camera_info` はオプションです。どちらかの入力が接続されていない場合、ノードは `viewport_state` に保存されている対応する値にフォールバックします。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 入力から渡された3Dモデルファイルです。 | FILE3D |
| `model_3d_info` | シーン内の各モデルの配置（位置、回転、スケール）です。Y-up ワールド空間で表されます。 | LOAD3DMODELINFO |
| `camera_info` | ビューポートのカメラ情報（位置、注視ターゲット、ズーム、タイプ）です。 | LOAD3DCAMERA |
| `width` | 入力から渡されたレンダリング幅の値です。 | INT |
| `height` | 入力から渡されたレンダリング高さの値です。 | INT |
