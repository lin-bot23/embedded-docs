# Сохранить 3D (расширенно)

Save3DAdvanced сохраняет 3D-модель в файл в выходном каталоге ComfyUI и создает предварительный просмотр сохраненной сцены. Он также передает 3D-модель, ее размещение в сцене, информацию о камере и размеры окна просмотра последующим узлам. Если размещение модели или информация о камере не подключены, узел использует значения, хранящиеся в состоянии окна просмотра.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Файл 3D-модели из вышестоящего 3D-узла. | FILE3D | Да | GLB<br>GLTF<br>FBX<br>OBJ<br>STL<br>USDZ<br>Any |
| `filename_prefix` | Префикс для имени сохраняемого файла (по умолчанию: "3d/ComfyUI"). | STRING | Да | Free text |
| `viewport_state` | Состояние окна просмотра, содержащее информацию о камере и размещении модели, обычно от узла Load 3D. | LOAD3D | Да | - |
| `model_3d_info` | Размещение каждой модели в сцене: позиция, поворот и масштаб (мировое пространство с осью Y вверх). При подключении переопределяет размещение модели, сохраненное в `viewport_state`. | LOAD3DMODELINFO | Нет | - |
| `camera_info` | Информация о камере окна просмотра: позиция, цель (точка взгляда), масштаб и тип. При подключении переопределяет информацию о камере, сохраненную в `viewport_state`. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина рендеринга окна просмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |
| `height` | Высота рендеринга окна просмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |

Примечание: `model_3d_info` и `camera_info` являются необязательными. Если какой-либо из этих входов не подключен, узел использует соответствующие значения, сохраненные в `viewport_state`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Файл 3D-модели, переданный со входа. | FILE3D |
| `model_3d_info` | Размещение каждой модели в сцене: позиция, поворот и масштаб (мировое пространство с осью Y вверх). | LOAD3DMODELINFO |
| `camera_info` | Информация о камере окна просмотра: позиция, цель (точка взгляда), масштаб и тип. | LOAD3DCAMERA |
| `width` | Значение ширины рендеринга, переданное со входа. | INT |
| `height` | Значение высоты рендеринга, переданное со входа. | INT |
