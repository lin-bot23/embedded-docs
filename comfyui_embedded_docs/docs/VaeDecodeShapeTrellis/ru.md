# VaeDecodeShapeTrellis

Этот узел декодирует скрытые представления формы Trellis2 в 3D-сетку. Он использует VAE для преобразования разреженных скрытых данных формы в геометрию сетки, а также выводит данные подразделения формы, сгенерированные в процессе декодирования. Узел поддерживает как одиночные, так и пакетные скрытые входы и автоматически корректирует ориентацию сетки в соответствии с ожидаемой системой координат.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `samples` | Скрытые сэмплы для декодирования, включающие тензор сэмплов и разреженные координатные данные. Словарь скрытого пространства также может содержать необязательные поля: `coord_counts` для пакетных фигур, `coord_resolution` для управления разрешением сетки и `model_frame` для ориентации координат. | LATENT | Да | None |
| `vae` | Модель VAE, используемая для декодирования скрытого представления формы в сетку. | VAE | Да | None |

### Примечания по параметру `samples`

- Вход `samples` представляет собой словарь скрытого пространства, который должен содержать тензор `samples` и разреженные координаты `coords`.
- Если присутствует `coord_counts`, он должен быть одномерным тензором целых неотрицательных чисел, и сумма всех значений счётчика должна равняться общему количеству строк координат. Каждое значение счётчика представляет одну фигуру в пакете.
- Если задан `coord_resolution`, разрешение сетки вычисляется как `coord_resolution * 16`. В противном случае используется встроенный буфер разрешения VAE (значение по умолчанию: 1024).
- Если для `model_frame` задано значение `"z_up"`, вершины декодированной сетки поворачиваются из системы координат с осью Z вверх в соглашение с осью Y вверх, используемое в glTF. Значение по умолчанию: `"y_up"`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Декодированная 3D-сетка, содержащая позиции вершин и индексы граней. При декодировании нескольких фигур сетки возвращаются в виде одного объединённого тензора, если все они имеют одинаковую форму, или в виде упакованного пакета переменного размера в противном случае. | MESH |
| `shape_subdivides` | Данные подразделения формы, формируемые на каждом этапе процесса декодирования. | SHAPE_SUBDIVIDES |
