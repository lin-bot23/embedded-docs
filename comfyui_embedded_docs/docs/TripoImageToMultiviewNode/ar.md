# Tripo: من صورة إلى مناظر متعددة

يولّد المناظر الأمامية واليسرى والخلفية واليمنى للموضوع من صورة إدخال واحدة باستخدام Tripo API. يتم رفع الصورة، وبدء مهمة توليد متعدد المناظر، ثم الاستعلام عنها بشكل دوري حتى تكتمل، وتُعاد المناظر الأربعة الناتجة مع معرّف المهمة. هذه مهمة مدفوعة تُحتسب بتكلفة تقارب 0.10 دولار أمريكي.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | الصورة المصدر للموضوع التي يولّد منها Tripo المناظر الأمامية واليسرى والخلفية واليمنى. تُستخدم صورة واحدة فقط للطلب، حتى إذا تم توفير دفعة. | IMAGE | نعم | صورة واحدة |

ملاحظة: تستدعي العقدة واجهة Tripo السحابية وتنتظر انتهاء مهمة التوليد. تستغرق المهمة النموذجية حوالي 25 ثانية. تتم المصادقة تلقائيًا عبر المدخلات المخفية للعقدة، لذا لا حاجة لتوفير مفتاح Tripo API في سير العمل. تتطلب العقدة توفر جميع روابط المناظر الأربعة في استجابة Tripo (`front_view_url`، `left_view_url`، `back_view_url`، `right_view_url`)؛ إذا كان أي منظر مفقودًا، يفشل التنفيذ مع خطأ.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `معرّف مهمة المناظر المتعددة task_id` | معرّف المهمة الذي يعيده Tripo لطلب توليد صورة متعددة المناظر. يمكن استخدامه للإشارة إلى المهمة المكتملة، على سبيل المثال عند تحسين المناظر باستخدام Tripo: Edit Multiview. | MULTIVIEW_TASK_ID |
| `أمام` | المنظر الأمامي المولّد للموضوع. | IMAGE |
| `يسار` | المنظر الجانبي الأيسر المولّد للموضوع. | IMAGE |
| `خلف` | المنظر الخلفي المولّد للموضوع. | IMAGE |
| `يمين` | المنظر الجانبي الأيمن المولّد للموضوع. | IMAGE |
