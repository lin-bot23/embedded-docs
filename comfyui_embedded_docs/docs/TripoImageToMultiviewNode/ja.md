# Tripo: 画像からマルチビュー

単一の入力画像から、Tripo API を使用して被写体の正面、左、背面、右のビューを生成します。画像がアップロードされ、マルチビュー生成タスクが開始されて完了するまでポーリングされ、得られた 4 つのビューがタスク ID とともに返されます。これは有料タスクで、約 0.10 USD が課金されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | Tripo が正面、左、背面、右のビューを生成する元となる被写体のソース画像です。バッチが指定された場合でも、リクエストには 1 つの画像のみが使用されます。 | IMAGE | はい | 単一画像 |

注: このノードは Tripo のクラウド API を呼び出し、生成タスクが完了するまで待機します。一般的なタスクは約 25 秒かかります。認証はノードの非表示入力によって自動的に処理されるため、ワークフローで Tripo API キーを指定する必要はありません。このノードは Tripo の応答内の 4 つのビュー URL（`front_view_url`、`left_view_url`、`back_view_url`、`right_view_url`）をすべて必要とします。いずれかのビューが欠けている場合、実行はエラーで失敗します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `multiview task_id` | Tripo がマルチビュー画像生成リクエストに対して返すタスク識別子です。完了したタスクを参照するために使用できます。たとえば、Tripo: Edit Multiview でビューを調整する場合などです。 | MULTIVIEW_TASK_ID |
| `正面` | 生成された被写体の正面ビュー。 | IMAGE |
| `左` | 生成された被写体の左側ビュー。 | IMAGE |
| `背面` | 生成された被写体の背面ビュー。 | IMAGE |
| `右` | 生成された被写体の右側ビュー。 | IMAGE |
