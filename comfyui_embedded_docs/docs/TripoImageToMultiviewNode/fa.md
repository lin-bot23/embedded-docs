# Tripo: تصویر به چندنما

تولید نماهای جلو، چپ، پشت و راست سوژه را از یک تصویر ورودی واحد با استفاده از API Tripo انجام می‌دهد. تصویر بارگذاری می‌شود، یک وظیفه تولید چندنمایی آغاز شده و به‌صورت دوره‌ای بررسی می‌شود تا تکمیل شود، و چهار نمای به‌دست‌آمده همراه با شناسه وظیفه بازگردانده می‌شوند. این یک وظیفه پرداختی است و هزینه آن تقریباً ۰.۱۰ دلار آمریکا محاسبه می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر مبدأ سوژه که Tripo از آن نماهای جلو، چپ، پشت و راست را تولید می‌کند. برای درخواست فقط از یک تصویر استفاده می‌شود، حتی اگر یک دسته تصویر ارائه شده باشد. | IMAGE | بله | تک تصویر |

نکته: این گره API ابری Tripo را فراخوانی می‌کند و منتظر می‌ماند تا وظیفه تولید به پایان برسد. یک وظیفه معمولی حدود ۲۵ ثانیه طول می‌کشد. احراز هویت به‌طور خودکار از طریق ورودی‌های پنهان گره انجام می‌شود، بنابراین نیازی نیست کلید API Tripo در گردش کار ارائه شود. این گره به هر چهار URL نمای موجود در پاسخ Tripo نیاز دارد (`front_view_url`، `left_view_url`، `back_view_url`، `right_view_url`)؛ اگر هر یک از نماها موجود نباشد، اجرا با خطا شکست می‌خورد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `task_id چندنما` | شناسه وظیفه‌ای که Tripo برای درخواست تولید تصویر چندنمایی بازمی‌گرداند. می‌توان از آن برای ارجاع به وظیفه تکمیل‌شده استفاده کرد، برای مثال هنگام پالایش نماها با Tripo: Edit Multiview. | MULTIVIEW_TASK_ID |
| `جلو` | نمای جلوی تولیدشده سوژه. | IMAGE |
| `چپ` | نمای سمت چپ تولیدشده سوژه. | IMAGE |
| `پشت` | نمای پشت تولیدشده سوژه. | IMAGE |
| `راست` | نمای سمت راست تولیدشده سوژه. | IMAGE |
