# Tripo: Из изображения в мультиракурс

Создаёт виды спереди, слева, сзади и справа для объекта из одного входного изображения с помощью API Tripo. Изображение загружается, запускается задача многовидовой генерации и опрашивается до завершения, а четыре полученных вида возвращаются вместе с ID задачи. Это платная задача стоимостью примерно 0,10 USD.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Исходное изображение объекта, из которого Tripo создаёт виды спереди, слева, сзади и справа. Для запроса используется только одно изображение, даже если передан пакет. | IMAGE | Да | Одно изображение |

Примечание: Узел обращается к облачному API Tripo и ожидает завершения задачи генерации. Типичная задача занимает около 25 секунд. Аутентификация выполняется автоматически через скрытые входы узла, поэтому в рабочем процессе не нужно указывать ключ API Tripo. Узел требует наличия всех четырёх URL видов в ответе Tripo (`front_view_url`, `left_view_url`, `back_view_url`, `right_view_url`); если какой-либо вид отсутствует, выполнение завершается ошибкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `task_id мультиракурса` | Идентификатор задачи, возвращённый Tripo для запроса генерации многовидового изображения. Его можно использовать для ссылки на завершённую задачу, например при уточнении видов с помощью Tripo: Edit Multiview. | MULTIVIEW_TASK_ID |
| `спереди` | Сгенерированный вид объекта спереди. | IMAGE |
| `слева` | Сгенерированный вид объекта слева. | IMAGE |
| `сзади` | Сгенерированный вид объекта сзади. | IMAGE |
| `справа` | Сгенерированный вид объекта справа. | IMAGE |
