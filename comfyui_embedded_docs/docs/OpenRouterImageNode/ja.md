# OpenRouter Image

このノードは、Microsoft の MAI-Image-2.6 モデルを使用して、OpenRouter 経由で画像を生成または編集します。テキストからの画像生成に加えて、最大 5 枚の参照画像を使用した画像ガイド付き編集をサポートし、7 種類のアスペクト比で 1K または 1.5K の解像度を選択できます。

## 入力

### 共通入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `モデル` | 画像の生成に使用する OpenRouter の画像モデルです。モデルを選択すると、以下に示すモデル固有のオプションが表示されます。 | DYNAMIC_COMBO | Yes | `microsoft/mai-image-2.6`<br>`microsoft/mai-image-2.6-flash` |

### Mai Image 2.6 および Mai Image 2.6 Flash 入力

両方のモデルオプション（`microsoft/mai-image-2.6` および `microsoft/mai-image-2.6-flash`）で共通であり、同じパラメータセットを公開します。

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 生成する画像、または参照画像に適用する編集内容を記述します。最大 20000 文字です。デフォルト：`""`（空）。前後の空白を除去した後に少なくとも 1 文字が必要です。 | STRING | Yes | 1 to 20000 characters |
| `aspect_ratio` | 生成される画像のアスペクト比です。参照画像が接続されている場合にも適用されます。デフォルト：`"1:1"`。`"auto"` を指定すると、テキストからの画像生成ではモデルが比率を選択し（1.5K サイズでレンダリングされます）、編集時には最初の参照画像のアスペクト比が維持されます。 | COMBO | Yes | `"1:1"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"auto"` |
| `resolution` | 出力サイズの階層です。1K は約 1 メガピクセル（1:1 は 1024x1024、16:9 は 1360x768）、1.5K は約 2.3 メガピクセル（1:1 は 1536x1536、16:9 は 2048x1152）です。デフォルト：`"1K"`。`aspect_ratio` が `"auto"` の場合、この設定は無視されます。 | COMBO | Yes | `"1K"`<br>`"1.5K"` |
| `seed` | ノードを再実行するかどうかを決定するシードです。API にはシードが存在しないため、この値に関わらず実際の結果は非決定的になります。デフォルト：`42`。 | INT | Yes | 0 to 2147483647 |

### 参照入力

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image_1` ... `image_5` | 拡張可能なスロットです。画像ガイド付き編集のために 1 ～ 5 枚の参照画像を接続します。バッチ入力は画像 1 枚につき 1 回としてカウントされます。スロットは任意であり、空のままにできます（最小接続数は 0）。 | IMAGE | No | 0 to 5 images |

**注意事項：**

- 接続されたすべてのスロットを通じて、合計最大 5 枚の参照画像がサポートされます。バッチ入力は画像 1 枚につき 1 回としてカウントされます。
- `prompt` は、前後の空白を除去した後に少なくとも 1 文字を含む必要があり、20000 文字を超えることはできません。
- 参照画像は PNG データとして送信され、合計 2048 x 2048 ピクセルに制限されます。
- `aspect_ratio` の設定は、参照画像が接続されている場合でも出力に適用されます。
- `aspect_ratio` が `"auto"` の場合、`resolution` の設定は無視されます。参照画像がない場合は、モデルがテキストからの画像生成用の比率を選択し、1.5K サイズでレンダリングします。参照画像が接続されている場合は、最初の参照画像のアスペクト比が維持されます。
- シード値は API の結果には影響しません。ノードを再実行するかどうかを決定するだけです。
