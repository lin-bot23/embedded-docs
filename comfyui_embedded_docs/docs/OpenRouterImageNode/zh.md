# OpenRouter 图像

此节点通过 OpenRouter 使用 Microsoft 的 MAI-Image-2.6 模型生成或编辑图像。它支持文生图以及使用最多五张参考图像进行图像引导编辑，提供七种宽高比，分辨率为 1K 或 1.5K。

## 输入

### 通用输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用于生成图像的 OpenRouter 图像模型。选择模型后会显示下方列出的模型特定选项。 | DYNAMIC_COMBO | 是 | `microsoft/mai-image-2.6`<br>`microsoft/mai-image-2.6-flash` |

### Mai Image 2.6 和 Mai Image 2.6 Flash 输入

由两个模型选项（`microsoft/mai-image-2.6` 和 `microsoft/mai-image-2.6-flash`）共享，它们暴露相同的参数集。

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述要生成的图像，或要应用于参考图像的编辑。最多 20000 个字符。默认：`""`（空）。去除首尾空白后至少需要 1 个字符。 | STRING | 是 | 1 to 20000 characters |
| `aspect_ratio` | 生成图像的宽高比，当连接参考图像时也会应用。默认：`"1:1"`。`"auto"` 让模型为文生图选择比例（以 1.5K 尺寸渲染），并在编辑时保持第一张参考图像的宽高比。 | COMBO | 是 | `"1:1"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"auto"` |
| `resolution` | 输出尺寸层级。1K 约为 1 百万像素（1:1 为 1024x1024，16:9 为 1360x768）；1.5K 约为 2.3 百万像素（1:1 为 1536x1536，16:9 为 2048x1152）。默认：`"1K"`。当 `aspect_ratio` 为 `"auto"` 时忽略。 | COMBO | 是 | `"1K"`<br>`"1.5K"` |
| `seed` | 用于确定节点是否应重新运行的种子；API 没有种子，因此无论此值如何，实际结果都是不确定的。默认：`42`。 | INT | 是 | 0 to 2147483647 |

### 参考输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image_1` ... `image_5` | 可扩展插槽：连接 1 到 5 张参考图像以进行图像引导编辑；批处理输入每张图像计为一次。插槽是可选的，可以留空（最少连接 0 个）。 | IMAGE | 否 | 0 to 5 images |

**注意：**

- 所有连接的插槽总共最多支持 5 张参考图像；批处理输入每张图像计为一次。
- 去除首尾空白后，`prompt` 必须至少包含 1 个字符，且不能超过 20000 个字符。
- 参考图像以 PNG 数据发送，总计限制为 2048 x 2048 像素。
- 即使连接了参考图像，`aspect_ratio` 设置也会应用于输出。
- 当 `aspect_ratio` 为 `"auto"` 时，`resolution` 设置会被忽略。没有参考图像时，模型会为文生图选择比例并以 1.5K 尺寸渲染；连接参考图像时，会保持第一张参考图像的宽高比。
- 种子值不影响 API 结果；它只决定节点是否重新运行。
