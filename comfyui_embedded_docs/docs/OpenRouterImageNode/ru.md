# Изображение OpenRouter

Этот узел генерирует или редактирует изображения через OpenRouter с использованием моделей Microsoft MAI-Image-2.6. Он поддерживает генерацию изображений по текстовому описанию, а также редактирование с опорой на изображения с использованием до пяти эталонных изображений, в семи соотношениях сторон при разрешении 1K или 1.5K.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель изображений OpenRouter, используемая для генерации изображения. При выборе модели отображаются параметры, специфичные для этой модели, перечисленные ниже. | DYNAMIC_COMBO | Да | `microsoft/mai-image-2.6`<br>`microsoft/mai-image-2.6-flash` |

### Входы Mai Image 2.6 и Mai Image 2.6 Flash

Общие для обоих вариантов модели (`microsoft/mai-image-2.6` и `microsoft/mai-image-2.6-flash`), которые предоставляют один и тот же набор параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `prompt` | Описывает изображение для генерации или правку, которую нужно применить к эталонным изображениям. До 20000 символов. По умолчанию: `""` (пустая строка). После удаления окружающих пробелов требуется не менее 1 символа. | STRING | Да | от 1 до 20000 символов |
| `aspect_ratio` | Соотношение сторон генерируемого изображения; также применяется, когда подключены эталонные изображения. По умолчанию: `"1:1"`. `"auto"` позволяет модели выбрать соотношение для генерации по тексту (рендерится в размере 1.5K) и сохраняет соотношение сторон первого эталонного изображения при редактировании. | COMBO | Да | `"1:1"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"auto"` |
| `resolution` | Уровень размера выходного изображения. 1K — это примерно 1 мегапиксель (1:1 — 1024x1024, 16:9 — 1360x768); 1.5K — примерно 2,3 мегапикселя (1:1 — 1536x1536, 16:9 — 2048x1152). По умолчанию: `"1K"`. Игнорируется, когда `aspect_ratio` имеет значение `"auto"`. | COMBO | Да | `"1K"`<br>`"1.5K"` |
| `seed` | Сид для определения, должен ли узел перезапуститься; в API нет сида, поэтому фактические результаты недетерминированы независимо от этого значения. По умолчанию: `42`. | INT | Да | от 0 до 2147483647 |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_1` ... `image_5` | Расширяемый слот: подключите от 1 до 5 эталонных изображений для редактирования с опорой на изображения; пакетный вход считается один раз за изображение. Слоты необязательны, их можно оставить пустыми (минимум 0 подключённых). | IMAGE | Нет | от 0 до 5 изображений |

**Примечания:**

- Всего поддерживается максимум 5 эталонных изображений по всем подключённым слотам; пакетный вход считается один раз за изображение.
- `prompt` должен содержать не менее 1 символа после удаления окружающих пробелов и не может превышать 20000 символов.
- Эталонные изображения передаются как данные PNG и ограничены общим размером 2048 x 2048 пикселей.
- Настройка `aspect_ratio` применяется к выходному изображению, даже когда подключены эталонные изображения.
- Когда `aspect_ratio` имеет значение `"auto"`, настройка `resolution` игнорируется. Без эталонных изображений модель выбирает соотношение для генерации по тексту и рендерит в размере 1.5K; при подключённых эталонных изображениях сохраняется соотношение сторон первого эталонного изображения.
- Значение `seed` не влияет на результат API; оно только определяет, будет ли узел перезапущен.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `IMAGE` | Сгенерированное или отредактированное изображение. Если сервис возвращает несколько изображений, они объединяются в один пакетный выход IMAGE. Возникает ошибка, если изображение не возвращено или если возвращённое изображение не удаётся декодировать. | IMAGE |
