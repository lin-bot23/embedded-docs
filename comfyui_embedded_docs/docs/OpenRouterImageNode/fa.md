# تصویر OpenRouter

این گره تصاویر را از طریق OpenRouter و با استفاده از مدل‌های MAI-Image-2.6 مایکروسافت تولید یا ویرایش می‌کند. از تولید متن‌به‌تصویر و همچنین ویرایش مبتنی بر تصویر با حداکثر پنج تصویر مرجع، در هفت نسبت ابعاد و با تفکیک‌پذیری 1K یا 1.5K پشتیبانی می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل تصویر OpenRouter برای تولید تصویر. با انتخاب یک مدل، گزینه‌های مخصوص آن مدل که در ادامه فهرست شده‌اند نمایان می‌شوند. | DYNAMIC_COMBO | بله | `microsoft/mai-image-2.6`<br>`microsoft/mai-image-2.6-flash` |

### ورودی‌های Mai Image 2.6 و Mai Image 2.6 Flash

مشترک بین هر دو گزینه مدل (`microsoft/mai-image-2.6` و `microsoft/mai-image-2.6-flash`) که مجموعه پارامترهای یکسانی را ارائه می‌دهند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | تصویر موردنظر برای تولید، یا ویرایشی که باید روی تصاویر مرجع اعمال شود را توصیف می‌کند. حداکثر 20000 کاراکتر. پیش‌فرض: `""` (خالی). پس از حذف فاصله‌های ابتدا و انتها، حداقل 1 کاراکتر لازم است. | STRING | بله | 1 تا 20000 کاراکتر |
| `aspect_ratio` | نسبت ابعاد تصویر تولیدشده؛ هنگام اتصال تصاویر مرجع نیز اعمال می‌شود. پیش‌فرض: `"1:1"`. مقدار `"auto"` اجازه می‌دهد مدل نسبت را برای متن‌به‌تصویر انتخاب کند (با اندازه 1.5K رندر می‌شود) و هنگام ویرایش، نسبت ابعاد نخستین تصویر مرجع را حفظ می‌کند. | COMBO | بله | `"1:1"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"auto"` |
| `resolution` | سطح اندازه خروجی. 1K حدود 1 مگاپیکسل است (1:1 برابر 1024x1024، 16:9 برابر 1360x768)؛ 1.5K حدود 2.3 مگاپیکسل است (1:1 برابر 1536x1536، 16:9 برابر 2048x1152). پیش‌فرض: `"1K"`. زمانی که `aspect_ratio` برابر `"auto"` باشد نادیده گرفته می‌شود. | COMBO | بله | `"1K"`<br>`"1.5K"` |
| `seed` | بذری که تعیین می‌کند آیا گره باید دوباره اجرا شود؛ API بذر ندارد، بنابراین نتایج واقعی صرف‌نظر از این مقدار غیرقطعی هستند. پیش‌فرض: `42`. | INT | بله | 0 تا 2147483647 |

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image_1` ... `image_5` | جایگاه قابل‌گسترش: 1 تا 5 تصویر مرجع را برای ویرایش مبتنی بر تصویر متصل کنید؛ یک ورودی دسته‌ای هر تصویر یک بار شمرده می‌شود. جایگاه‌ها اختیاری‌اند و می‌توانند خالی بمانند (حداقل 0 اتصال). | IMAGE | خیر | 0 تا 5 تصویر |

**یادداشت‌ها:**

- حداکثر 5 تصویر مرجع در مجموع میان همه جایگاه‌های متصل پشتیبانی می‌شود؛ یک ورودی دسته‌ای هر تصویر یک بار شمرده می‌شود.
- `prompt` پس از حذف فاصله‌های ابتدا و انتها باید حداقل 1 کاراکتر داشته باشد و نمی‌تواند از 20000 کاراکتر فراتر رود.
- تصاویر مرجع به‌صورت داده PNG ارسال می‌شوند و به مجموع 2048 x 2048 پیکسل محدود هستند.
- تنظیم `aspect_ratio` حتی زمانی که تصاویر مرجع متصل هستند نیز روی خروجی اعمال می‌شود.
- وقتی `aspect_ratio` برابر `"auto"` باشد، تنظیم `resolution` نادیده گرفته می‌شود. بدون تصاویر مرجع، مدل نسبت را برای متن‌به‌تصویر انتخاب می‌کند و با اندازه 1.5K رندر می‌کند؛ با اتصال تصاویر مرجع، نسبت ابعاد نخستین تصویر مرجع حفظ می‌شود.
- مقدار بذر بر نتیجه API تأثیر نمی‌گذارد؛ فقط تعیین می‌کند که آیا گره دوباره اجرا می‌شود.
