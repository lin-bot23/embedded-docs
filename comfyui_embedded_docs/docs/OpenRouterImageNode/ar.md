# صورة OpenRouter

تولّد هذه العقدة الصور أو تحرّرها عبر OpenRouter باستخدام نماذج MAI-Image-2.6 من Microsoft. وهي تدعم التوليد من النص إلى الصورة وكذلك التحرير الموجّه بالصور مع ما يصل إلى خمس صور مرجعية، بسبع نسب عرض إلى ارتفاع وبدقة 1K أو 1.5K.

## المدخلات

### المدخلات العامة

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الصور من OpenRouter المستخدم لتوليد الصورة. يؤدي اختيار نموذج إلى إظهار الخيارات الخاصة بذلك النموذج والمدرجة أدناه. | DYNAMIC_COMBO | نعم | `microsoft/mai-image-2.6`<br>`microsoft/mai-image-2.6-flash` |

### مدخلات Mai Image 2.6 و Mai Image 2.6 Flash

مشترك بين خياري النموذج (`microsoft/mai-image-2.6` و`microsoft/mai-image-2.6-flash`)، اللذين يعرضان المجموعة نفسها من المعاملات.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | يصف الصورة المطلوب توليدها، أو التعديل المطلوب تطبيقه على الصور المرجعية. حتى 20000 حرف. القيمة الافتراضية: `""` (فارغة). يلزم حرف واحد على الأقل بعد إزالة المسافات البيضاء المحيطة. | STRING | نعم | 1 إلى 20000 حرف |
| `aspect_ratio` | نسبة العرض إلى الارتفاع للصورة المولّدة، وتُطبَّق أيضًا عند توصيل صور مرجعية. القيمة الافتراضية: `"1:1"`. يتيح `"auto"` للنموذج اختيار النسبة في وضع النص إلى الصورة (تُعرض بحجم 1.5K) ويحافظ على نسبة العرض إلى الارتفاع للصورة المرجعية الأولى عند التحرير. | COMBO | نعم | `"1:1"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"auto"` |
| `resolution` | فئة حجم الإخراج. 1K نحو 1 ميغابكسل (1:1 هو 1024x1024، و16:9 هو 1360x768)؛ 1.5K نحو 2.3 ميغابكسل (1:1 هو 1536x1536، و16:9 هو 2048x1152). القيمة الافتراضية: `"1K"`. يتم تجاهله عندما تكون قيمة `aspect_ratio` هي `"auto"`. | COMBO | نعم | `"1K"`<br>`"1.5K"` |
| `seed` | البذرة لتحديد ما إذا كان ينبغي إعادة تشغيل العقدة؛ لا تحتوي واجهة API على بذرة، لذا تكون النتائج الفعلية غير حتمية بغض النظر عن هذه القيمة. القيمة الافتراضية: `42`. | INT | نعم | 0 إلى 2147483647 |

### المدخلات المرجعية

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image_1` ... `image_5` | فتحة قابلة للتوسّع: صِل من 1 إلى 5 صور مرجعية للتحرير الموجّه بالصور؛ يُحتسب الإدخال المجمّع مرة واحدة لكل صورة. الفتحات اختيارية ويمكن تركها فارغة (الحد الأدنى 0 متصلة). | IMAGE | لا | 0 إلى 5 صور |

**ملاحظات:**

- يُدعم حد أقصى إجمالي قدره 5 صور مرجعية عبر جميع الفتحات المتصلة؛ ويُحتسب الإدخال المجمّع مرة واحدة لكل صورة.
- يجب أن يحتوي `prompt` على حرف واحد على الأقل بعد إزالة المسافات البيضاء المحيطة، ولا يمكن أن يتجاوز 20000 حرف.
- تُرسَل الصور المرجعية كبيانات PNG وتقتصر على إجمالي 2048 x 2048 بكسل.
- يُطبَّق إعداد `aspect_ratio` على الإخراج حتى عند توصيل صور مرجعية.
- عندما تكون قيمة `aspect_ratio` هي `"auto"`، يتم تجاهل إعداد `resolution`. في حال عدم وجود صور مرجعية، يختار النموذج النسبة في وضع النص إلى الصورة ويعرض بحجم 1.5K؛ وعند توصيل صور مرجعية، يتم الحفاظ على نسبة العرض إلى الارتفاع للصورة المرجعية الأولى.
- لا تؤثر قيمة البذرة في نتيجة API؛ فهي تحدد فقط ما إذا كانت العقدة ستُعاد تشغيلها.
