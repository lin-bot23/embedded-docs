# OpenRouter 圖像

此節點透過 OpenRouter 使用 Microsoft 的 MAI-Image-2.6 模型來生成或編輯圖像。它支援文字轉圖像生成，以及使用最多五張參考圖像進行圖像引導編輯，並提供七種長寬比，解析度可為 1K 或 1.5K。

## 輸入

### 通用輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `模型` | 用於生成圖像的 OpenRouter 圖像模型。選擇模型後會顯示下方列出的模型特定選項。 | DYNAMIC_COMBO | 是 | `microsoft/mai-image-2.6`<br>`microsoft/mai-image-2.6-flash` |

### Mai Image 2.6 與 Mai Image 2.6 Flash 輸入

兩個模型選項（`microsoft/mai-image-2.6` 與 `microsoft/mai-image-2.6-flash`）共用這些輸入，且兩者提供相同的參數集。

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `prompt` | 描述要生成的圖像，或要套用至參考圖像的編輯。最多 20000 個字元。預設值：`""`（空）。移除前後空白後至少需要 1 個字元。 | STRING | 是 | 1 至 20000 characters |
| `aspect_ratio` | 生成圖像的長寬比；連接參考圖像時也會套用。預設值：`"1:1"`。`"auto"` 會讓模型為文字轉圖像選擇長寬比（以 1.5K 尺寸渲染），並在編輯時保留第一張參考圖像的長寬比。 | COMBO | 是 | `"1:1"`<br>`"16:9"`<br>`"9:16"`<br>`"3:2"`<br>`"2:3"`<br>`"4:3"`<br>`"3:4"`<br>`"auto"` |
| `resolution` | 輸出尺寸等級。1K 約為 1 百萬像素（1:1 為 1024x1024，16:9 為 1360x768）；1.5K 約為 2.3 百萬像素（1:1 為 1536x1536，16:9 為 2048x1152）。預設值：`"1K"`。當 `aspect_ratio` 為 `"auto"` 時忽略此設定。 | COMBO | 是 | `"1K"`<br>`"1.5K"` |
| `seed` | 用於決定節點是否應重新執行的種子；API 沒有種子，因此無論此值為何，實際結果都不具確定性。預設值：`42`。 | INT | 是 | 0 至 2147483647 |

### 參考輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `image_1` ... `image_5` | 可擴充插槽：連接 1 到 5 張參考圖像以進行圖像引導編輯；批次輸入中的每張圖像各計為一張。插槽為選用，可留空（最少可連接 0 個）。 | IMAGE | 否 | 0 至 5 images |

**備註：**

- 所有已連接插槽合計最多支援 5 張參考圖像；批次輸入中的每張圖像各計為一張。
- `prompt` 在移除前後空白後必須至少包含 1 個字元，且不得超過 20000 個字元。
- 參考圖像會以 PNG 資料傳送，且總計限制為 2048 x 2048 像素。
- 即使連接了參考圖像，輸出一樣會套用 `aspect_ratio` 設定。
- 當 `aspect_ratio` 為 `"auto"` 時，會忽略 `resolution` 設定。在沒有參考圖像時，模型會為文字轉圖像選擇長寬比，並以 1.5K 尺寸渲染；連接參考圖像時，則會保留第一張參考圖像的長寬比。
- `seed` 值不會影響 API 結果；它只會決定節點是否重新執行。
