# پیش‌نمایش سه‌بعدی (پیشرفته)

این گره پیش‌نمایش یک مدل سه‌بعدی را در رابط کاربری نمایش می‌دهد، بدون اینکه فایل را در پوشه خروجی ComfyUI ذخیره کند. مدل را در یک فایل موقت ذخیره می‌کند و داده‌های مدل، اطلاعات مدل، اطلاعات دوربین و ابعاد پیش‌نمایش را برای پردازش بیشتر در ادامه مسیر عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `مدل ۳بعدی` | فایل مدل سه‌بعدی از یک گره سه‌بعدی بالادستی. | FILE3D | بله | GLB، GLTF، FBX، OBJ، STL، USDZ یا هر قالب سه‌بعدی پشتیبانی‌شده |
| `اطلاعات مدل سه‌بعدی` | جای‌گیری هر مدل در صحنه: موقعیت، چرخش و مقیاس (فضای جهانی با محور Y رو به بالا). اختیاری. گزینه پیشرفته. | LOAD3DMODELINFO | خیر | - |
| `وضعیت نمای دید` | وضعیت فعلی viewport شامل اطلاعات دوربین و مدل. | LOAD3D | بله | - |
| `اطلاعات دوربین` | اطلاعات دوربین viewport: موقعیت، هدف نگاه، بزرگ‌نمایی و نوع. اختیاری. گزینه پیشرفته. | LOAD3DCAMERA | خیر | - |
| `عرض` | عرض رندر viewport بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 1 تا 4096 |
| `ارتفاع` | ارتفاع رندر viewport بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 1 تا 4096 |

توجه: هنگامی که `camera_info` یا `model_3d_info` متصل نیستند، مقادیر آن‌ها در صورت موجود بودن از `viewport_state` گرفته می‌شود. اگر `viewport_state` هیچ اطلاعات دوربینی نداشته باشد، `camera_info` برابر None است. اگر `viewport_state` اطلاعات مدل نداشته باشد، `model_3d_info` به‌صورت پیش‌فرض یک لیست خالی می‌شود. اگر `viewport_state` یک دیکشنری نباشد، به‌عنوان خالی در نظر گرفته می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل سه‌بعدی (glb/obj/stl/etc.) از یک گره سه‌بعدی بالادستی، بدون تغییر عبور داده می‌شود. | FILE3D |
| `اطلاعات دوربین` | جای‌گیری هر مدل در صحنه: موقعیت، چرخش و مقیاس (فضای جهانی با محور Y رو به بالا). از مقدار ورودی استفاده می‌کند، یا در غیر این صورت از مقدار ذخیره‌شده در `viewport_state` استفاده می‌کند. | LOAD3DMODELINFO |
| `اطلاعات مدل سه‌بعدی` | اطلاعات دوربین viewport: موقعیت، هدف نگاه، بزرگ‌نمایی و نوع. از مقدار ورودی استفاده می‌کند، یا در غیر این صورت از مقدار ذخیره‌شده در `viewport_state` استفاده می‌کند. | LOAD3DCAMERA |
| `عرض` | عرض رندر viewport بر حسب پیکسل. | INT |
| `ارتفاع` | ارتفاع رندر viewport بر حسب پیکسل. | INT |
