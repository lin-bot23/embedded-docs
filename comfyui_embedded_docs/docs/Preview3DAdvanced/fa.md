# پیش‌نمایش سه‌بعدی (پیشرفته)

این گره یک پیش‌نمایش مدل سه‌بعدی را در رابط کاربری نمایش می‌دهد بدون اینکه فایل را در پوشه خروجی ComfyUI ذخیره کند. مدل را در یک فایل موقت ذخیره می‌کند و داده‌های مدل، اطلاعات مدل، اطلاعات دوربین و ابعاد پیش‌نمایش را برای پردازش‌های بعدی عبور می‌دهد.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `مدل ۳بعدی` | فایل مدل سه‌بعدی از یک گره سه‌بعدی بالادستی. | FILE3D | بله | GLB, GLTF, FBX, OBJ, STL, USDZ، یا هر فرمت سه‌بعدی پشتیبانی‌شده دیگر |
| `اطلاعات مدل سه‌بعدی` | فراداده‌های اطلاعات مدل اختیاری. گزینه پیشرفته. | LOAD3DMODELINFO | خیر | - |
| `وضعیت نمای دید` | وضعیت فعلی viewport که شامل اطلاعات دوربین و مدل است. | LOAD3D | بله | - |
| `اطلاعات دوربین` | پیکربندی اختیاری دوربین برای نمای سه‌بعدی. گزینه پیشرفته. | LOAD3DCAMERA | خیر | - |
| `عرض` | عرض پیش‌نمایش بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 1 تا 4096 |
| `ارتفاع` | ارتفاع پیش‌نمایش بر حسب پیکسل. پیش‌فرض: 1024. | INT | بله | 1 تا 4096 |

نکته: زمانی که `camera_info` یا `model_3d_info` متصل نیستند، مقادیر آن‌ها در صورت موجود بودن از `viewport_state` گرفته می‌شود. اگر `viewport_state` حاوی اطلاعات دوربین نباشد، `camera_info` برابر None است. اگر `viewport_state` اطلاعات مدل نداشته باشد، `model_3d_info` به صورت پیش‌فرض یک لیست خالی در نظر گرفته می‌شود. اگر `viewport_state` یک دیکشنری نباشد، به عنوان خالی در نظر گرفته می‌شود.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل سه‌بعدی عبور داده‌شده از ورودی. | FILE3D |
| `اطلاعات دوربین` | فراداده‌های اطلاعات مدل، είτε از ورودی یا از وضعیت viewport. | LOAD3DMODELINFO |
| `اطلاعات مدل سه‌بعدی` | پیکربندی دوربین، είτε از ورودی یا از وضعیت viewport. | LOAD3DCAMERA |
| `عرض` | عرض پیش‌نمایش بر حسب پیکسل. | INT |
| `ارتفاع` | ارتفاع پیش‌نمایش بر حسب پیکسل. | INT |
