# Просмотр 3D (расширенный)

Этот узел отображает предварительный просмотр 3D-модели в интерфейсе без сохранения файла в выходной каталог ComfyUI. Он сохраняет модель во временный файл и передаёт данные модели, информацию о модели, информацию о камере и размеры предварительного просмотра для дальнейшей обработки в конвейере.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `3D-модель` | Файл 3D-модели от предыдущего 3D-узла. | FILE3D | Да | GLB, GLTF, FBX, OBJ, STL, USDZ или любой поддерживаемый 3D-формат |
| `model_3d_info` | Необязательные метаданные информации о модели. Расширенная опция. | LOAD3DMODELINFO | Нет | - |
| `состояние области просмотра` | Текущее состояние области просмотра, содержащее информацию о камере и модели. | LOAD3D | Да | - |
| `camera_info` | Необязательная конфигурация камеры для 3D-вида. Расширенная опция. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина предварительного просмотра в пикселях. По умолчанию: 1024. | INT | Да | 1 до 4096 |
| `height` | Высота предварительного просмотра в пикселях. По умолчанию: 1024. | INT | Да | 1 до 4096 |

Примечание: Если `camera_info` или `model_3d_info` не подключены, их значения берутся из `viewport_state`, когда они доступны. Если `viewport_state` не содержит информации о камере, `camera_info` принимает значение None. Если `viewport_state` не содержит информации о модели, `model_3d_info` по умолчанию принимает пустой список. Если `viewport_state` не является словарём, он обрабатывается как пустой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Файл 3D-модели, переданный со входа. | FILE3D |
| `camera_info` | Метаданные информации о модели: либо из входа, либо из состояния области просмотра. | LOAD3DMODELINFO |
| `model_3d_info` | Конфигурация камеры: либо из входа, либо из состояния области просмотра. | LOAD3DCAMERA |
| `width` | Ширина предварительного просмотра в пикселях. | INT |
| `height` | Высота предварительного просмотра в пикселях. | INT |
