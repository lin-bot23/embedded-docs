# Просмотр 3D (расширенный)

Этот узел отображает предварительный просмотр 3D-модели в интерфейсе, не сохраняя файл в выходной каталог ComfyUI. Модель сохраняется во временный файл, а данные модели, информация о модели, информация о камере и размеры предварительного просмотра передаются дальше для последующей обработки в цепочке узлов.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `3D-модель` | Файл 3D-модели из вышестоящего 3D-узла. | FILE3D | Да | GLB, GLTF, FBX, OBJ, STL, USDZ или любой поддерживаемый 3D-формат |
| `model_3d_info` | Размещение каждой модели в сцене: положение, поворот и масштаб (мировое пространство с осью Y вверх). Необязательно. Расширенная опция. | LOAD3DMODELINFO | Нет | - |
| `состояние области просмотра` | Текущее состояние области просмотра, содержащее информацию о камере и модели. | LOAD3D | Да | - |
| `camera_info` | Информация о камере области просмотра: положение, целевая точка взгляда, масштаб и тип. Необязательно. Расширенная опция. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина рендеринга области просмотра в пикселях. По умолчанию: 1024. | INT | Да | 1 до 4096 |
| `height` | Высота рендеринга области просмотра в пикселях. По умолчанию: 1024. | INT | Да | 1 до 4096 |

Примечание: Если `camera_info` или `model_3d_info` не подключены, их значения берутся из `viewport_state`, когда они доступны. Если `viewport_state` не содержит информации о камере, `camera_info` принимает значение None. Если в `viewport_state` нет информации о модели, `model_3d_info` по умолчанию принимает пустой список. Если `viewport_state` не является словарём, он считается пустым.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Файл 3D-модели (glb/obj/stl и т. д.) из вышестоящего 3D-узла, переданный без изменений. | FILE3D |
| `camera_info` | Размещение каждой модели в сцене: положение, поворот и масштаб (мировое пространство с осью Y вверх). Использует входное значение или, при его отсутствии, значение, сохранённое в `viewport_state`. | LOAD3DMODELINFO |
| `model_3d_info` | Информация о камере области просмотра: положение, целевая точка взгляда, масштаб и тип. Использует входное значение или, при его отсутствии, значение, сохранённое в `viewport_state`. | LOAD3DCAMERA |
| `width` | Ширина рендеринга области просмотра в пикселях. | INT |
| `height` | Высота рендеринга области просмотра в пикселях. | INT |
