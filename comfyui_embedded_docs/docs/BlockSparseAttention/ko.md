# 모델 희소 어텐션

## 개요

블록 스파르스 어텐션 노드는 ComfyUI 모델에 블록 스파르스 어텐션 기제를 적용하도록 변경합니다. 이 기제는 각 쿼리 블록이 모든 가능한 블록 대신 일부 키 블록에만 집중할 수 있도록 하여 계산 부담을 줄입니다. 이는 특히 장순열에 매우 유익합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `model` | 블록 스파르스 어텐션을 적용할 ComfyUI 모델. | MODEL | 예 | N/A |
| `selection` | 어느 키 블록을 어텐션할지 결정하는 방법. | 다이나믹 콤보 | 예 | 옵션: sol-attn (적응형 tau), sla (top-k), vsa (비디오 스파르스 어텐션) |
| `tau` | sol-attn 방법에서 스코어 분포의 스케일에서의 임계값. | FLOAT | 아님 | 기본: 1.3, 최소: 0.0, 최대: 4.0, 단위: 0.05 |
| `keep_percent` | sla 방법에서 각 쿼리 블록이 정확히 유지할 키 블록의 비율. | FLOAT | 아님 | 기본: 10.0, 최소: 0.5, 최대: 95.0, 단위: 0.5 |
| `start_percent` | 스파르스 어텐션이 시작할 비율 점. | FLOAT | 아님 | 기본: 0.2, 최소: 0.0, 최대: 1.0, 단위: 0.01 |
| `end_percent` | 스파르스 어텐션이 끝날 비율 점. | FLOAT | 아님 | 기본: 1.0, 최소: 0.0, 최대: 1.0, 단위: 0.01 |
| `dense_blocks` | 항상 밀집 어텐션을 사용할 트랜스포머 블록을 나타내는 문자열. | STRING | 아님 | 기본: "" |
| `min_tokens` | 모델이 밀집 어텐션을 사용할 순서의 토큰 수의 최소값. | INT | 아님 | 기본: 12288, 최소: 0, 최대: 1 << 20, 단위: 512 |
| `extra_tokens` | 각 쿼리 블록이 선택된 블록 이상으로 어텐션할 최상급 토큰 수. | INT | 아님 | 기본: 256, 최소: 0, 최대: 256, 단위: 64 |
| `sink_conditioning` | 사용할 MiniMax-H3 조건 행을 나타내는 MiniMax-H3 조건. | COMBO | 아님 | 옵션: exact_kv, exact_kv_and_rows, off |
| `verbose` | 상세 로깅을 활성화합니다. | BOOLEAN | 아님 | 기본: False |

### 주의사항

- `selection` 매개변수는 다른 키 블록 선택 방법 중 하나를 선택할 수 있습니다:
  - `sol-attn`: 스코어 분포에 기반하여 적응형 임계값을 사용하여 키 블록을 선택합니다.
  - `sla`: 가장 높은 점수를 가진 키 블록의 일정 비율을 유지합니다.
  - `vsa`: 비디오 스파르스 어텐션을 적용하며, 3D 비디오-큐브 타일링과 학습된 대략적인 어텐션 브랜치를 사용합니다.
- `dense_blocks` 매개변수는 항상 밀집 어텐션을 사용할 트랜스포머 블록을 지정할 수 있습니다.
- `min_tokens` 매개변수는 밀집 어텐션을 사용할 순서의 토큰 수의 최소값을 설정합니다.
- `extra_tokens` 매개변수는 각 쿼리 블록이 선택된 블록 이상으로 어텐션할 추가적인 최상급 토큰 수를 지정합니다.
- `sink_conditioning` 매개변수는 MiniMax-H3 모델에만 관련이 있으며, 조건 행을 처리하는 방법을 결정합니다.
- `verbose` 매개변수는 상세 로깅을 활성화하여 디버깅에 유용할 수 있습니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `model` | 블록 스파르스 어텐션을 적용한 ComfyUI 모델. | MODEL |

### 제약 사항 및 제한 사항

- `sol-attn` 방법은 0.0과 4.0 사이의 `tau` 값을 요구합니다.
- `sla` 방법은 0.5과 95.0 사이의 `keep_percent` 값을 요구합니다.
- `vsa` 방법은 MiniMax-H3 모델과 호환되며, 모델이 `to_gate_compress` 레이어를 가지고 있어야 합니다.
- `min_tokens` 매개변수는 0 이상의 정수여야 합니다 (0이면 모든 어텐션이 밀집 상태로 유지됩니다).
- `extra_tokens` 매개변수는 음수여야 합니다.
- `sink_conditioning` 옵션은 MiniMax-H3 모델에만 적용됩니다.
