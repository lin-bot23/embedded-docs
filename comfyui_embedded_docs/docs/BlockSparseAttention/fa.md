# توجه تنک مدل

## مقدمه

گره توجه ناپیوسته بلوک مدل ComfyUI را تغییر می‌دهد تا مکانیزم توجه ناپیوسته بلوک را اعمال کند. این مکانیزم بار محاسباتی را کاهش می‌دهد زیرا به هر بلوک پرسش اجازه می‌دهد تا بر روی یک زیرگروه از بلوک‌های کلید تمرکز کند، به جای توجه به تمام بلوک‌های ممکن، که برای توالی‌های بلند بسیار مفید است.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل ComfyUI که باید به آن توجه ناپیوسته بلوک اعمال شود. | MODEL | بله | N/A |
| `selection` | روشی که برای تعیین بلوک‌های کلیدی که باید به آن‌ها توجه شود استفاده می‌شود. | DYNAMIC_COMBO | بله | گزینه‌ها: sol-attn (tau تطبیقی)، sla (top-k)، vsa (Video Sparse Attention) |
| `tau` | محدوده‌ی پارامتر در sigmas توزیع نمره برای روش sol-attn. | FLOAT | خیر | پیش‌فرض: 1.3، حداقل: 0.0، حداکثر: 4.0، قدم: 0.05 |
| `keep_percent` | درصدی از بلوک‌های کلیدی که هر بلوک پرسش دقیقاً نگه می‌دارد برای روش sla. | FLOAT | خیر | پیش‌فرض: 10.0، حداقل: 0.5، حداکثر: 95.0، قدم: 0.5 |
| `start_percent` | نقطه‌ی درصدی که توجه ناپیوسته شروع می‌شود. | FLOAT | خیر | پیش‌فرض: 0.2، حداقل: 0.0، حداکثر: 1.0، قدم: 0.01 |
| `end_percent` | نقطه‌ی درصدی که توجه ناپیوسته پایان می‌یابد. | FLOAT | خیر | پیش‌فرض: 1.0، حداقل: 0.0، حداکثر: 1.0، قدم: 0.01 |
| `dense_blocks` | رشته‌ای که بلوک‌های ترانسفورمر که همیشه باید از توجه چگال استفاده کنند را نشان می‌دهد. | STRING | خیر | پیش‌فرض: "" |
| `min_tokens` | تعداد حداقلی توکن‌ها در یک توالی که مدل از توجه چگال استفاده می‌کند. | INT | خیر | پیش‌فرض: 12288، حداقل: 0، حداکثر: 1 << 20، قدم: 512 |
| `extra_tokens` | تعداد توکن‌های اضافی برجسته که هر بلوک پرسش به آن‌ها توجه می‌کند. | INT | خیر | پیش‌فرض: 256، حداقل: 0، حداکثر: 256، قدم: 64 |
| `sink_conditioning` | ردیف‌های MiniMax-H3 برای استفاده در توجه نزولی. | COMBO | خیر | گزینه‌ها: exact_kv، exact_kv_and_rows، off |
| `verbose` | فعال‌سازی لاگ‌های دقیق. | BOOLEAN | خیر | پیش‌فرض: False |

### یادداشت‌ها

- پارامتر `selection` به شما اجازه می‌دهد تا بین روش‌های مختلف برای انتخاب بلوک‌های کلیدی انتخاب کنید:
  - `sol-attn`: از یک محدوده تطبیقی برای انتخاب بلوک‌های کلیدی بر اساس توزیع نمره استفاده می‌کند.
  - `sla`: یک درصد ثابت از بلوک‌های کلیدی برجسته را نگه می‌دارد.
  - `vsa`: توجه ناپیوسته ویدیویی (Video Sparse Attention) را اعمال می‌کند که از کاشی‌بندی کره ویدئویی 3D و یک شاخه توجه خشناب شده یاد گرفته شده استفاده می‌کند.
- پارامتر `dense_blocks` می‌تواند برای مشخص کردن بلوک‌های ترانسفورمر که همیشه باید از توجه چگال استفاده کنند استفاده شود.
- پارامتر `min_tokens` تعداد حداقلی توکن‌ها در یک توالی را برای استفاده از توجه چگال تنظیم می‌کند.
- پارامتر `extra_tokens` به شما اجازه می‌دهد تعداد توکن‌های اضافی برجسته که هر بلوک پرسش به آن‌ها توجه می‌کند را مشخص کنید.
- پارامتر `sink_conditioning` تنها برای مدل‌های MiniMax-H3 مرتبط است و تعیین می‌کند که چگونه ردیف‌های توجه نزولی پردازش می‌شوند.
- پارامتر `verbose` لاگ‌های دقیق را فعال می‌کند که می‌تواند برای اشکال‌زدایی مفید باشد.

### محدودیت‌ها و محدودیت‌ها

- روش `sol-attn` نیاز به یک مقدار `tau` بین 0.0 و 4.0 دارد.
- روش `sla` نیاز به یک مقدار `keep_percent` بین 0.5 و 95.0 دارد.
- روش `vsa` تنها با مدل‌های MiniMax-H3 سازگار است و نیاز به داشتن لایه `to_gate_compress` در مدل دارد.
- پارامتر `min_tokens` باید یک عدد صحیح نامنفی باشد (با مقدار 0، تمام توجه‌ها متراکم باقی می‌مانند).
- پارامتر `extra_tokens` باید یک عدد غیرمنفی باشد.
- گزینه‌های `sink_conditioning` تنها برای مدل‌های MiniMax-H3 قابل اعمال هستند.
