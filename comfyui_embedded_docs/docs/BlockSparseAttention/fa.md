# Block Sparse Attention

## بررسی کلی

نود Block Sparse Attention از مکانیزم توجه بلوک-سبک (block-sparse attention) استفاده می‌کند و آن را به مدل ComfyUI اعمال می‌نماید. این مکانیزم توجه محاسبات توجه را کاهش می‌دهد تا هر بلوک جستجو (query block) فقط به یک زیر مجموعه انتخاب شده از بلوک‌های کلید (key blocks) توجه کند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدل ComfyUI که باید بلوک-سبک توجه به آن اعمال شود. | MODEL | بله | N/A |
| `selection` | روش انتخاب بلوک‌های کلیدی که باید به آن‌ها توجه شود. | DYNAMIC_COMBO | بله | گزینه‌ها: Sol-Attn (自适应 tau)، top-k (SLA)، VSA (FastVideo) |
| `tau` | محدوده‌ی پارامتر score-distribution sigmas برای انتخاب Sol-Attn (自适应 tau). | FLOAT | خیر | پیش‌فرض: 1.3، حداقل: 0.0، حداکثر: 4.0، قدم: 0.05 |
| `keep_percent` | درصد بلوک‌های کلیدی که هر بلوک جستجو دقیقاً نگه می‌دارد برای top-k (SLA). | FLOAT | خیر | پیش‌فرض: 10.0، حداقل: 0.5، حداکثر: 95.0، قدم: 0.5 |
| `start_percent` | درصد برنامه قبل از آن که مدل از توجه چگال (dense attention) استفاده کند. | FLOAT | خیر | پیش‌فرض: 0.2، حداقل: 0.0، حداکثر: 1.0، قدم: 0.01 |
| `end_percent` | درصد برنامه بعد از آن که مدل از توجه چگال استفاده کند. | FLOAT | خیر | پیش‌فرض: 1.0، حداقل: 0.0، حداکثر: 1.0، قدم: 0.01 |
| `dense_blocks` | رشته‌ای که بلوک‌های ترانسفورمر که همیشه از توجه چگال استفاده می‌کنند را نشان می‌دهد. | STRING | خیر | پیش‌فرض: "" |
| `min_tokens` | تعداد حداقلی توکن‌ها در یک توالی برای آن که مدل از توجه چگال استفاده کند. | INT | خیر | پیش‌فرض: 12288، حداقل: 0، حداکثر: 1 << 20، قدم: 512 |
| `extra_tokens` | تعداد توکن‌های اضافی که هر بلوک جستجو به آن‌ها توجه می‌کند و فراتر از بلوک‌های انتخاب شده خود است. | INT | خیر | پیش‌فرض: 256، حداقل: 0، حداکثر: 256، قدم: 64 |
| `sink_conditioning` | ردیف‌های MiniMax-H3 برای استفاده در conditionining sink. | COMBO | خیر | گزینه‌ها: exact_kv، exact_kv_and_rows، off |
| `verbose` | اینکه آیا گزارش‌دهی دقیق (verbose logging) را فعال کنید یا خیر. | BOOLEAN | خیر | پیش‌فرض: False |

### یادداشت‌ها

- پارامتر `selection` روش انتخاب بلوک‌های کلیدی را تعیین می‌کند. گزینه‌ها عبارتند از:
  - Sol-Attn (自适应 tau): هر بلوک جستجو به یک زیر مجموعه انتخاب شده از بلوک‌های کلیدی بر اساس یک محدوده‌ی自适应 توجه می‌کند.
  - top-k (SLA): هر بلوک جستجو دقیقاً یک درصد ثابت از بلوک‌های کلیدی را نگه می‌دارد.
  - VSA (FastVideo): هر بلوک جستجو دقیقاً یک درصد ثابت از بلوک‌های ویدیویی را نگه می‌دارد، از تiling و شاخه‌ی خشن FastH3-VSA استفاده می‌کند.
- پارامتر `dense_blocks` به شما اجازه می‌دهد تا بلوک‌های ترانسفورمر که همیشه از توجه چگال استفاده می‌کنند را مشخص کنید.
- پارامتر `min_tokens` تعداد حداقلی توکن‌ها در یک توالی را برای استفاده از توجه چگال تنظیم می‌کند.
- پارامتر `extra_tokens` تعداد توکن‌های اضافی را که هر بلوک جستجو به آن‌ها توجه می‌کند و فراتر از بلوک‌های انتخاب شده خود است، مشخص می‌کند.
- پارامتر `sink_conditioning` ردیف‌های MiniMax-H3 برای استفاده در conditionining sink را تعیین می‌کند.
- پارامتر `verbose` گزارش‌دهی دقیق (verbose logging) را فعال می‌کند.
