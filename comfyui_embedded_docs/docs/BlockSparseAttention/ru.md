# Block Sparse Attention

## Обзор

Узел Block Sparse Attention applies блок-спарсинговую механизму внимания к модели ComfyUI, что уменьшает вычисления внимания, позволяя каждому блоку запроса attending только выбранному подмножеству блоков ключей точно.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель ComfyUI, к которой applies блок-спарсинговую механизму внимания. | МОДЕЛЬ | Да | N/A |
| `selection` | Метод выбора, который используется для выбора, какие блоки ключей attending. | ДИНАМИЧЕСКАЯ КОМБО | Да | Опции: Sol-Attn (адаптивный tau), top-k (SLA), VSA (FastVideo) |
| `tau` | Порог в сигмах распределения оценок для Sol-Attn (адаптивный tau) выбора. | ФЛОАТ | Нет | по умолчанию: 1.3, мин: 0.0, макс: 4.0, шаг: 0.05 |
| `keep_percent` | Процент блоков ключей, которые каждый блок запроса сохраняет точно для top-k (SLA) выбора. | ФЛОАТ | Нет | по умолчанию: 10.0, мин: 0.5, макс: 95.0, шаг: 0.5 |
| `start_percent` | Процент расписания до которого модель использует сплошное внимание. | ФЛОАТ | Нет | по умолчанию: 0.2, мин: 0.0, макс: 1.0, шаг: 0.01 |
| `end_percent` | Процент расписания после которого модель использует сплошное внимание. | ФЛОАТ | Нет | по умолчанию: 1.0, мин: 0.0, макс: 1.0, шаг: 0.01 |
| `dense_blocks` | Строка, представляющая трансформаторные блоки, которые всегда выполняют сплошное внимание. | СТРОКА | Нет | по умолчанию: "", |
| `min_tokens` | Минимальное количество токенов в последовательности, для которой модель использует сплошное внимание. | ИНТ | Нет | по умолчанию: 12288, мин: 0, макс: 1 << 20, шаг: 512 |
| `extra_tokens` | Количество дополнительных топ-оценочных токенов, которые каждый блок запроса attends за пределами своих выбранных блоков. | ИНТ | Нет | по умолчанию: 256, мин: 0, макс: 256, шаг: 64 |
| `sink_conditioning` | Строки MiniMax-H3 для использования в sink conditioning. | КОМБО | Нет | Опции: exact_kv, exact_kv_and_rows, off |
| `verbose` | Включить ли verbose logging. | БОЛЕЕ-МЕНЕЕ | Нет | по умолчанию: False |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Модель ComfyUI с applied блок-спарсинговой механизму внимания. | МОДЕЛЬ |

### Замечания

- Параметр `selection` определяет, как выбираются блоки ключей. Опции:
  - Sol-Attn (адаптивный tau): Каждый блок запроса attends выбранный подмножество блоков ключей на основе адаптивного порога.
  - top-k (SLA): Каждый блок запроса сохраняет фиксированный процент блоков ключей точно.
  - VSA (FastVideo): Каждый блок запроса сохраняет фиксированный процент кубов видео точно, используя тiling cube и грубый ветвь FastH3-VSA.
- Параметр `dense_blocks` позволяет вам specify трансформаторные блоки, которые всегда выполняют сплошное внимание.
- Параметр `min_tokens` устанавливает минимальное количество токенов в последовательности, для которой модель использует сплошное внимание.
- Параметр `extra_tokens` позволяет specify количество дополнительных топ-оценочных токенов, которые каждый блок запроса attends за пределами своих выбранных блоков.
- Параметр `sink_conditioning` определяет строки MiniMax-H3 для использования в sink conditioning.
- Параметр `verbose` включает verbose logging.
