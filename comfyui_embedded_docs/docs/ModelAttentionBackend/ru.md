# Бэкенд внимания модели

```markdown
# ModelAttentionBackend

## Обзор

Узел ModelAttentionBackend позволяет вам выбрать реализацию сплошного внимания для модели. Этот узел исправляет модель с выбранным бэком внимания, который может быть как PyTorch внимание, так и Comfy Kitchen внимание, если оно доступно. Этот узел особенно полезен, когда сплошное внимание неактивно или не поддерживается, обеспечивая работу модели с указанным механизмом сплошного внимания.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, которая будет исправлена с выбранным бэком внимания. | МОДЕЛЬ | Да |  |
| `attention` | Сплошный бэкенд внимания, который будет применен к модели. Доступные опции: "pytorch attention" и "comfy kitchen attention", если последнее доступно в среде. | STRING | Да | "pytorch attention"<br> "comfy kitchen attention" (при наличии) |

- Опция "comfy kitchen attention" использует квантифицированное внимание INT8 и поддерживается только на GPU Nvidia и AMD.

## Выходы

| Название выходного параметра | Описание | Тип данных |
|-------------|-------------|-----------|
| `model` | Входная модель с примененным выбранным бэком внимания. | МОДЕЛЬ |

## Примечание

- Если выбранный бэкенд внимания недоступен, узел автоматически перейдет к использованию PyTorch внимания и выведет предупреждение.
- Узел ModelAttentionBackend является экспериментальным и может быть изменен в будущих выпусках.
```
