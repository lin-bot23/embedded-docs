# Бэкенд внимания модели

Этот узел выбирает бэкенд плотного внимания, который модель использует для своих вычислений. Он клонирует заданную модель, применяет выбранный бэкенд и возвращает пропатченный клон. При использовании с блочным разреженным вниманием этот бэкенд используется, когда разреженное внимание неактивно или не поддерживается. Если выбранный бэкенд недоступен, узел автоматически переключается на внимание PyTorch.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель для патчинга. | MODEL | Да |  |
| `attention` | Применяемый бэкенд плотного внимания (по умолчанию: "pytorch attention"). Внимание Comfy Kitchen использует квантованное внимание INT8 и доступно только на GPU Nvidia и AMD. Если выбранный бэкенд недоступен, используется внимание PyTorch. | COMBO | Да | "pytorch attention"<br>"comfy kitchen attention" |

Примечание: опция "comfy kitchen attention" отображается только в том случае, если модуль внимания Comfy Kitchen INT8 доступен в текущем окружении.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `model` | Клон входной модели с применённым выбранным бэкендом внимания. | MODEL |
