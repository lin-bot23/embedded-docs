# بک‌اند توجه مدل

این گره بک‌اند توجه متراکمی را انتخاب می‌کند که یک مدل برای محاسبات توجه خود استفاده می‌کند. مدل داده‌شده را کلون می‌کند، بک‌اند انتخاب‌شده را اعمال می‌کند و کلون وصله‌شده را برمی‌گرداند. هنگام استفاده همراه با Block Sparse Attention، این بک‌اند هر زمان که توجه پراکنده غیرفعال یا پشتیبانی‌نشده باشد استفاده می‌شود. اگر بک‌اند انتخاب‌شده در دسترس نباشد، گره به‌طور خودکار به توجه PyTorch بازمی‌گردد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که باید وصله شود. | MODEL | بله |  |
| `attention` | بک‌اند توجه متراکم برای اعمال (پیش‌فرض: "pytorch attention"). توجه Comfy Kitchen از توجه کوانتیزه INT8 استفاده می‌کند و فقط روی GPUهای Nvidia و AMD در دسترس است. اگر بک‌اند انتخاب‌شده در دسترس نباشد، از توجه PyTorch به‌عنوان جایگزین استفاده می‌شود. | COMBO | بله | "pytorch attention"<br>"comfy kitchen attention" |

توجه: گزینه "comfy kitchen attention" تنها زمانی فهرست می‌شود که ماژول توجه INT8 مربوط به Comfy Kitchen در محیط فعلی در دسترس باشد.
