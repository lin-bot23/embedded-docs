# بک‌اند توجه مدل

```markdown
# ModelAttentionBackend

## مقدمه

گره ModelAttentionBackend به شما امکان می‌دهد تا یک پیاده‌سازی توجه چگال (dense attention) برای مدل خود انتخاب کنید. این گره مدل را با پس‌زمینه توجه انتخاب شده اصلاح می‌کند، که می‌تواند توجه PyTorch یا توجه Comfy Kitchen باشد، اگر آن در محیط موجود باشد. این گره به ویژه در مواقعی که توجه پراکنده (sparse attention) غیرفعال یا پشتیبانی نمی‌شود، بسیار مفید است و اطمینان حاصل می‌کند که مدل با مکانیزم توجه چگال مشخصی عمل می‌کند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که با پس‌زمینه توجه انتخاب شده اصلاح خواهد شد. | MODEL | بله |  |
| `attention` | پس‌زمینه توجه چگال برای اعمال به مدل. گزینه‌های موجود "attention pytorch" و "attention comfy kitchen" است، اگر "attention comfy kitchen" در محیط موجود باشد. | STRING | بله | "attention pytorch"<br> "attention comfy kitchen" (در صورت موجودیت) |

- گزینه "attention comfy kitchen" از توجه INT8 کوچک‌شده استفاده می‌کند و تنها روی کارت‌های گرافیک Nvidia و AMD پشتیبانی می‌شود.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `model` | مدلی که با پس‌زمینه توجه انتخاب شده اعمال شده است. | MODEL |

## یادداشت

- اگر پس‌زمینه توجه انتخاب شده موجود نباشد، گره به طور خودکار به استفاده از توجه PyTorch بازمی‌گردد و یک هشدار ثبت می‌کند.
- گره ModelAttentionBackend تجربی است و ممکن است در نسخه‌های آینده تغییر کند.
```
