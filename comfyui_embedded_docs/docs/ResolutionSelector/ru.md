# Выбор разрешения

Узел Resolution Selector вычисляет ширину и высоту в пикселях на основе выбранного соотношения сторон и целевого общего разрешения в мегапикселях. Он полезен для генерации согласованных размеров для других узлов, таких как узел Empty Latent Image.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `aspect_ratio` | Соотношение сторон для выходных размеров (по умолчанию: `"1:1 (Square)"`). | COMBO | Да | `"1:1 (Square)"`<br>`"2:3 (Portrait Photo)"`<br>`"3:2 (Photo)"`<br>`"3:4 (Portrait Standard)"`<br>`"4:3 (Standard)"`<br>`"9:16 (Portrait Widescreen)"`<br>`"16:9 (Widescreen)"`<br>`"21:9 (Ultrawide)"` |
| `megapixels` | Целевое общее количество мегапикселей. 1.0 Мп ≈ 1024x1024 для квадрата (по умолчанию: 1.0). | FLOAT | Да | 0.1 - 16.0 (step: 0.1) |
| `preview` | Живой предпросмотр вычисленного выходного разрешения. Этот виджет только для чтения обновляется автоматически и не принимает пользовательский ввод. | RESOLUTION_PREVIEW | Нет | N/A |
| `multiple` | Ближайшее кратное, до которого округляется итоговое разрешение (по умолчанию: 8). | INT | Нет | 8 - 128 (step: 4) |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `width` | Вычисленная ширина в пикселях, умноженная на выбранное кратное. | INT |
| `height` | Вычисленная высота в пикселях, умноженная на выбранное кратное. | INT |
