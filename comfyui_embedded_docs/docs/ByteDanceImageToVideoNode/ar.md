# وحدة تحويل الصورة إلى فيديو من ByteDance

تقوم وحدة تحويل الصورة إلى فيديو من ByteDance بإنشاء فيديو من صورة مدخلة وتعليمات نصية باستخدام API من ByteDance. تخلق سلسلة فيديو تعكس بشكل مرئي الوصف المقدم، مع خيارات تخصيص دقة الخروج، نسبة الأبعاد، المدة، وغيرها من المعلمات.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | نطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | النموذج من ByteDance الذي سيتم استخدامه لإنشاء الفيديو. الخيارات المتاحة هي: <br>`"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` | STRING | نعم | كما هو مذكور أعلاه |
| `prompt` | التعليمات النصية المستخدمة لإنشاء الفيديو. يجب أن يكون الطول بعد إزالة البيانات الزائدة على الأقل 1 حرف. | STRING | نعم | - |
| `image` | الصورة الأولى التي سيتم استخدامها للفيديو. يجب أن تكون الصورة بين 300x300 و 6000x6000 بكسل، مع نسبة الأبعاد بين 0.4 و 2.5. | IMAGE | نعم | - |
| `resolution` | دقة الفيديو الخروج. الخيارات المتاحة هي: <br>`"480p"`<br>`"720p"`<br>`"1080p"` | STRING | نعم | كما هو مذكور أعلاه |
| `aspect_ratio` | نسبة الأبعاد للفيديو الخروج. الخيارات المتاحة هي: <br>`"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` | STRING | نعم | كما هو مذكور أعلاه |
| `duration` | مدة الفيديو الخروج بالثواني. بالنسبة لنموذج `seedance-1-5-pro-251215`، هي الأقل مدة مدعومة 4 ثانية. | INT | نعم | 3 - 12 |
| `seed` | البذرة التي سيتم استخدامها للإنشاء. اختياري، مع قيمة افتراضية 0. | INT | لا | 0 - 2147483647 |
| `camera_fixed` | تحديد ما إذا كان يجب تثبيت الكاميرا. يضيف المنصة تعليمات لتثبيت الكاميرا إلى التعليمات النصية الخاصة بك، ولكن لا يضمن التأثير الفعلي. اختياري، مع قيمة افتراضية False. | BOOLEAN | لا | - |
| `watermark` | ما إذا كان يجب إضافة علامة مائية "مولد بواسطة AI" إلى الفيديو. اختياري، مع قيمة افتراضية False. | BOOLEAN | لا | - |
| `توليد الصوت` | يتم تجاهل هذا المعامل لجميع النماذج باستثناء `seedance-1-5-pro-251215`. اختياري، مع قيمة افتراضية False. | BOOLEAN | لا | - |

**ملاحظة:** يجب ألا تحتوي التعليمات النصية على الكلمات التالية (بغض النظر عن الحالة): `resolution`، `ratio`، `duration`، `seed`، `camerafixed`، `watermark`. يتم ضبط هذه المعلمات عبر المدخلات المخصصة لها.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output` | ملف الفيديو المولد بناءً على المعلمات المدخلة للصورة والتعليمات النصية. | VIDEO |
