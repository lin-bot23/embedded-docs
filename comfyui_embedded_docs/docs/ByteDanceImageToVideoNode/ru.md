# ByteDance Image to Video

Узел ByteDance Image to Video генерирует видео с использованием моделей ByteDance через API на основе входного изображения и текстового запроса. Он принимает начальный кадр изображения и создает видеопоследовательность, соответствующую указанному описанию. Узел предоставляет различные параметры настройки разрешения видео, соотношения сторон, длительности и других параметров генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель ByteDance, используемая для генерации видео (по умолчанию: `"seedance-1-0-pro-fast-251015"`). | COMBO | Да | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` |
| `prompt` | Текстовый запрос, используемый для генерации видео. Должен содержать не менее 1 символа после удаления пробелов. | STRING | Да | - |
| `image` | Первый кадр для видео. Размер должен быть от 300x300 до 6000x6000 пикселей, соотношение сторон — от 0.4 до 2.5. | IMAGE | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | Длительность выходного видео в секундах (по умолчанию: 5). Для модели `seedance-1-5-pro-251215` минимальная поддерживаемая длительность — 4 секунды. | INT | Да | 3 - 12 |
| `seed` | Зерно (seed) для генерации (по умолчанию: 0). | INT | Нет | 0 - 2147483647 |
| `camera_fixed` | Указывает, следует ли зафиксировать камеру. Платформа добавляет инструкцию зафиксировать камеру к вашему запросу, но не гарантирует фактический результат (по умолчанию: False). | BOOLEAN | Нет | `False`<br>`True` |
| `watermark` | Добавлять ли водяной знак "AI generated" на видео (по умолчанию: False). | BOOLEAN | Нет | `False`<br>`True` |
| `generate_audio` | Этот параметр игнорируется для всех моделей, кроме `seedance-1-5-pro-251215` (по умолчанию: False). | BOOLEAN | Нет | `False`<br>`True` |

**Примечание:** Запрос не должен содержать следующие слова (без учета регистра): `resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`. Эти параметры задаются через соответствующие отдельные входы.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл на основе входного изображения и параметров запроса. | VIDEO |
