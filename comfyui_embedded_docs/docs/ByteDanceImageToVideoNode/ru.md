# Узел ByteDance Image to Video

Узел ByteDance Image to Video генерирует видео из входного изображения и текстового запроса с использованием API компании ByteDance. Он создает видеоряд, который визуально представляет предоставленную описание, с возможностью настроить разрешение, формат экрана, продолжительность и другие параметры вывода.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | ByteDance модель для использования при генерации видео. Доступные опции: <br>`"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` | STRING | Да | Как указано выше |
| `prompt` | Текстовый запрос для генерации видео. Длина запроса после удаления пробелов должна быть не менее 1 символа. | STRING | Да | - |
| `image` | Первый кадр, который будет использоваться для видео. Изображение должно быть между 300x300 и 6000x6000 пикселей, с соотношением сторон между 0.4 и 2.5. | IMAGE | Да | - |
| `resolution` | Разрешение выводного видео. Доступные опции: <br>`"480p"`<br>`"720p"`<br>`"1080p"` | STRING | Да | Как указано выше |
| `aspect_ratio` | Соотношение сторон выводного видео. Доступные опции: <br>`"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` | STRING | Да | Как указано выше |
| `duration` | Продолжительность выводного видео в секундах. Для модели `seedance-1-5-pro-251215` минимальная поддерживаемая продолжительность составляет 4 секунды. | INT | Да | 3 - 12 |
| `seed` | Зародыш для использования при генерации. Опционален, значение по умолчанию 0. | INT | Нет | 0 - 2147483647 |
| `camera_fixed` | Указывает, следует ли фиксировать камеру. Платформа добавляет инструкцию для фиксации камеры к вашему запросу, но не гарантирует реальный эффект. Опционален, значение по умолчанию False. | BOOLEAN | Нет | - |
| `watermark` | Указывает, следует ли добавлять водяной знак "AI generated" к видео. Опционален, значение по умолчанию False. | BOOLEAN | Нет | - |
| `generate_audio` | Этот параметр игнорируется для всех моделей, кроме `seedance-1-5-pro-251215`. Опционален, значение по умолчанию False. | BOOLEAN | Нет | - |

**Примечание:** Запрос не должен содержать следующих слов (без учета регистра): `resolution`, `ratio`, `duration`, `seed`, `camerafixed`, `watermark`. Эти параметры устанавливаются через их отдельные входы.

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Генерируемый видео файл на основе входного изображения и параметров запроса. | VIDEO |
