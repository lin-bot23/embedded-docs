# تبدیل تصویر به ویدیو ByteDance

گره تصویر به ویدیو ByteDance ویدیویی از یک تصویر ورودی و یک پیام متنی با استفاده از API ByteDance تولید می‌کند. این گره یک توالی ویدیویی ایجاد می‌کند که به صورت تصویری توضیحات ارائه شده را نمایش می‌دهد، با امکانات شخصی‌سازی رزولوشن، نسبت ابعاد، مدت زمان و پارامترهای دیگر خروجی.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل ByteDance برای تولید ویدیو. گزینه‌های موجود عبارتند از: <br>`"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` | STRING | بله | همان‌گونه که در بالا لیست شده‌اند |
| `پرامپت` | پیام متنی استفاده شده برای تولید ویدیو. باید حداقل 1 کاراکتر باشد پس از حذف فضاهای خالی. | STRING | بله | - |
| `تصویر` | فریم اول که برای ویدیو استفاده می‌شود. تصویر باید بین 300x300 و 6000x6000 پیکسل باشد و نسبت ابعاد بین 0.4 و 2.5 داشته باشد. | IMAGE | بله | - |
| `رزولوشن` | رزولوشن ویدیوی خروجی. گزینه‌های موجود عبارتند از: <br>`"480p"`<br>`"720p"`<br>`"1080p"` | STRING | بله | همان‌گونه که در بالا لیست شده‌اند |
| `نسبت تصویر` | نسبت ابعاد ویدیوی خروجی. گزینه‌های موجود عبارتند از: <br>`"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` | STRING | بله | همان‌گونه که در بالا لیست شده‌اند |
| `مدت زمان` | مدت زمان ویدیوی خروجی به ثانیه. برای مدل `seedance-1-5-pro-251215`، مدت زمان پشتیبانی شده حداقل 4 ثانیه است. | INT | بله | 3 - 12 |
| `seed` | عدد اول برای تولید. با مقدار پیش‌فرض 0. | INT | خیر | 0 - 2147483647 |
| `ثابت بودن دوربین` | مشخص می‌کند که آیا دوربین را ثابت نگه داریم یا خیر. پلتفرم دستوری برای ثابت نگه داشتن دوربین به پیام شما اضافه می‌کند، اما تضمین نمی‌کند که تأثیر واقعی. با مقدار پیش‌فرض False. | BOOLEAN | خیر | - |
| `واترمارک` | مشخص می‌کند که آیا باید علامت "تولید شده توسط AI" به ویدیو اضافه شود یا خیر. با مقدار پیش‌فرض False. | BOOLEAN | خیر | - |
| `تولید صدا` | این پارامتر برای هر مدل به جز `seedance-1-5-pro-251215` نادیده گرفته می‌شود. با مقدار پیش‌فرض False. | BOOLEAN | خیر | - |

**توجه:** پیام نباید شامل کلمات زیر (حساس به حروف بزرگ): `resolution`، `ratio`، `duration`، `seed`، `camerafixed`، `watermark`. این پارامترها از طریق ورودی‌های اختصاصی خود تنظیم می‌شوند.

## خروجی‌ها
