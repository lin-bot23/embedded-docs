# ایجاد سبک Recraft V4

این گره یک سبک Recraft V4 قابل استفاده مجدد را از ۱ تا ۱۰ تصویر مرجع ایجاد می‌کند. شناسه سبک بازگشتی با هر مدل Recraft V4 و V4.1 از همان نوع خروجی (raster یا vector) کار می‌کند و می‌تواند در مراحل بعدی تولید تصویر مجدداً استفاده شود. حجم کل تمام تصاویر مرجع به ۱۰ مگابایت محدود شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که سبک برای آن ایجاد می‌شود. مدل‌های Standard و Pro یک استخر سبک مشترک دارند: سبک‌های raster با هر مدل Recraft V4 و V4.1 raster کار می‌کنند، سبک‌های vector (*_vector) با هر مدل vector نسخه V4 و V4.1. | COMBO | بله | "recraftv4_styles"<br>"recraftv4_styles_vector"<br>"recraftv4_styles_pro"<br>"recraftv4_styles_pro_vector" |
| `images` | تصاویر مرجع تعریف‌کننده سبک. مراجع مشابه تطابق را دقیق‌تر می‌کنند، مراجع متنوع آن را گسترده‌تر می‌کنند. اسلات قابل افزایش: ۱ تا ۱۰ تصویر متصل کنید (`image_1` تا `image_10`). | IMAGE | بله | ۱ تا ۱۰ تصویر |

### نکات

- حداقل یک تصویر مرجع الزامی است؛ اگر هیچ‌کدام ارائه نشود، گره خطا می‌دهد.
- حداکثر ۱۰ تصویر مرجع مجاز است؛ اگر بیشتر ارائه شود، گره خطا می‌دهد.
- حجم کدگذاری شده کل تصاویر مرجع نباید از ۱۰ مگابایت فراتر رود؛ اگر از حد مجاز عبور کند، گره خطا می‌دهد.
- هر تصویر مرجع قبل از ارسال به API Recraft، حداکثر تا ۲۰۴۸×۲۰۴۸ پیکسل کوچک‌سازی و به صورت WebP کدگذاری می‌شود.
- مدل‌هایی که با `_vector` پایان می‌یابند، سبک‌های vector ایجاد می‌کنند؛ سایر گزینه‌ها سبک‌های raster ایجاد می‌کنند. مدل‌های Standard و Pro در هر نوع خروجی، استخرهای سبک یکسانی را به اشتراک می‌گذارند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `style_id` | شناسه منحصر به فرد سبک ایجاد شده، قابل استفاده با هر مدل Recraft V4 و V4.1 از همان نوع خروجی. | STRING |
