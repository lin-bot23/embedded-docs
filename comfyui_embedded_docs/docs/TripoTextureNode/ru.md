# Tripo: Модель текстур

Этот узел помечен в исходном коде как устаревший (legacy); отображаемое имя — «Tripo: Texture model (Legacy)».

Узел Tripo: Texture model (Legacy) добавляет текстуры к существующей 3D-модели Tripo через API Tripo. Он принимает ID задачи модели, созданной другим узлом Tripo, и возвращает текстурированную модель GLB или FBX после завершения задания текстурирования. Вы можете управлять картами материалов, качеством текстуры, выравниванием и seed, а также направлять текстурирование с помощью текстовой подсказки, изображения стиля или эталонных изображений. Этот узел — legacy-версия инструмента текстурирования.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи Tripo модели для текстурирования. Принимает ID задач модели и ID задач сегментации. | MODEL_TASK_ID, SEGMENT_TASK_ID | Да | - |
| `texture` | Игнорируется: этот узел всегда генерирует текстуры. Оставлен для старых рабочих процессов. (по умолчанию: True) | BOOLEAN | Нет | true<br>false |
| `pbr` | PBR-карты материалов (base color, metallic, roughness, normal); при отключении создаётся простая цветовая текстура. (по умолчанию: True) | BOOLEAN | Нет | true<br>false |
| `texture_seed` | Случайный seed для генерации текстуры. (по умолчанию: 42) | INT | Нет | 0 – 2147483647 |
| `texture_quality` | Качество разрешения текстуры: detailed = HD-текстуры, extreme = 8K Ultra текстуры. (по умолчанию: "standard"). Примерная стоимость: standard $0.10, detailed $0.20, extreme $0.30. | COMBO | Нет | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | Метод выравнивания сгенерированных текстур относительно модели. (по умолчанию: "original_image") | COMBO | Нет | "original_image"<br>"geometry" |
| `texture_prompt` | Необязательная текстовая подсказка для текстурирования. На практике обязательна для импортированных моделей (Tripo: Import Model), у которых нет исходного изображения для определения цветов. Нельзя комбинировать с эталонными изображениями. (по умолчанию: "") | STRING | Нет | - |
| `model_version` | Модель текстурирования: v3.0 для сеток, сгенерированных с v3.x, v2.5 для сеток, сгенерированных с v2.5. (по умолчанию: v3.0_20250812) | COMBO | Нет | Доступно несколько вариантов |
| `style_image` | Эталонное изображение для художественного стиля текстур. Используется только вместе с `texture_prompt`. | IMAGE | Нет | - |
| `reference` | Эталонные изображения, направляющие текстурирование. Нельзя комбинировать с `texture_prompt` или `style_image`. (по умолчанию: "none") | DYNAMIC_COMBO | Нет | "none"<br>"image"<br>"multiview" |
| `part_names` | Имена частей, разделённые запятыми, из Tripo: Segment Model для текстурирования. Пустое значение текстурирует каждую часть. (по умолчанию: "") | STRING | Нет | - |

### Эталонные входы `image`

Эти входы доступны, когда для `reference` задано значение `"image"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | Одно эталонное изображение, которому должны соответствовать текстуры. | IMAGE | Да | - |

### Эталонные входы `multiview`

Эти входы доступны, когда для `reference` задано значение `"multiview"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_front` | Вид спереди (0°). | IMAGE | Да | - |
| `image_left` | Вид слева (90°). | IMAGE | Да | - |
| `image_back` | Вид сзади (180°). | IMAGE | Да | - |
| `image_right` | Вид справа (270°). | IMAGE | Да | - |

**Примечание:** Режимы эталонных изображений `"image"` и `"multiview"` нельзя комбинировать с непустым `texture_prompt` или с `style_image`. Вход `style_image` требует непустого `texture_prompt`. Если `texture_prompt` оставлен пустым, исходная модель уже должна иметь собственное исходное изображение (например, модели, созданные с помощью text-to-model, image-to-model, multiview-to-model или более ранней задачи текстурирования). Модели, не имеющие исходного изображения, — например, импортированные, сегментированные, завершённые или ретопологизированные, — должны текстурироваться с помощью `texture_prompt`; эталонные изображения принимаются только для моделей, которые сгенерировал сам API Tripo. Вход `part_names` можно оставить пустым, чтобы текстурировать каждую часть.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Сгенерированный файл модели (только для обратной совместимости). | STRING |
| `task_id текстуры` | ID завершённой задачи генерации текстуры; может использоваться как вход для других узлов Tripo. | MODEL_TASK_ID |
| `GLB` | Сгенерированная текстурированная модель в формате GLB. Пусто, если источник — quad-сетка или импорт FBX. | FILE3DGLB |
| `FBX` | Сгенерированная текстурированная модель в формате FBX. Tripo возвращает FBX для quad-сеток и импортов FBX; в остальных случаях пусто. | FILE3DFBX |
