# Tripo: Модель текстур

Узел TripoTextureNode добавляет текстуры к существующей 3D-модели Tripo с помощью API Tripo. Он принимает идентификатор задачи модели, созданной другим узлом Tripo, и возвращает модель с текстурами в формате GLB или FBX после завершения задачи текстурирования. Вы можете управлять картами материалов, качеством текстур, выравниванием, сидом, а также задавать направление с помощью текстового промпта, стилевого изображения или эталонных изображений.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | Идентификатор задачи Tripo модели для текстурирования. Принимает идентификаторы задач модели и сегментации. | MODEL_TASK_ID | Да | - |
| `texture` | Игнорируется: этот узел всегда генерирует текстуры. Сохранён для старых рабочих процессов. (по умолчанию: True) | BOOLEAN | Нет | true<br>false |
| `pbr` | Карты материалов PBR (основной цвет, металличность, шероховатость, нормали); при отключении получается простая цветная текстура. (по умолчанию: True) | BOOLEAN | Нет | true<br>false |
| `texture_seed` | Случайный сид для генерации текстур. При использовании одного и того же сида с теми же входными данными результат будет одинаковым. (по умолчанию: 42) | INT | Нет | 0 – 2147483647 |
| `texture_quality` | Качество разрешения текстур: detailed = HD-текстуры, extreme = ультра-текстуры 8K. (по умолчанию: "standard"). Примерная стоимость: standard $0.10, detailed $0.20, extreme $0.30. | COMBO | Нет | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | Метод, используемый для выравнивания сгенерированных текстур по модели. (по умолчанию: "original_image"). | COMBO | Нет | "original_image"<br>"geometry" |
| `texture_prompt` | Необязательный текстовый промпт для управления текстурированием. На практике требуется для импортированных моделей (Tripo: Import Model), у которых нет исходного изображения, из которого можно определить цвета. Не может использоваться вместе с эталонными изображениями. (по умолчанию: "") | STRING | Нет | - |
| `model_version` | Модель текстурирования: v3.0 для мешей, созданных с помощью v3.x, v2.5 для мешей, созданных с помощью v2.5. (по умолчанию: последняя версия v3.0) | COMBO | Нет | Доступно несколько вариантов |
| `style_image` | Эталонное изображение для художественного стиля текстур. Используется только вместе с `texture_prompt`. | IMAGE | Нет | - |
| `reference` | Эталонные изображения, задающие направление текстурам. Не может использоваться вместе с `texture_prompt` или `style_image`. (по умолчанию: "none") | DYNAMIC_COMBO | Нет | "none"<br>"image"<br>"multiview" |
| `part_names` | Имена частей, разделённые запятыми, из узла Tripo: Segment Model для текстурирования. При пустом значении текстурируются все части. (по умолчанию: "") | STRING | Нет | - |

### "image": эталонные входы

Эти входы доступны, когда параметр `reference` установлен в `"image"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | Одно эталонное изображение, которому должны следовать текстуры. | IMAGE | Нет | - |

### "multiview": эталонные входы

Эти входы доступны, когда параметр `reference` установлен в `"multiview"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image_front` | Вид спереди (0°). | IMAGE | Нет | - |
| `image_left` | Вид слева (90°). | IMAGE | Нет | - |
| `image_back` | Вид сзади (180°). | IMAGE | Нет | - |
| `image_right` | Вид справа (270°). | IMAGE | Нет | - |

**Примечание:** Режимы `"image"` и `"multiview"` нельзя сочетать с непустым `texture_prompt` или со `style_image`. Вход `style_image` требует непустой `texture_prompt`. Когда `texture_prompt` оставлен пустым, исходная модель уже должна иметь собственное исходное изображение (например, модели, созданные с помощью text-to-model, image-to-model, multiview-to-model или более ранней задачи текстурирования). Модели, не имеющие исходного изображения, — например импортированные, сегментированные, достроенные или ретопологизированные модели, — должны текстурироваться с помощью `texture_prompt`; эталонные изображения принимаются только для моделей, созданных самим API Tripo.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Сгенерированный файл модели (только для обратной совместимости). | STRING |
| `task_id текстуры` | Идентификатор задачи завершённой операции генерации текстур; может использоваться как вход для других узлов Tripo. | MODEL_TASK_ID |
| `GLB` | Сгенерированная текстурированная модель в формате GLB. Пусто, если исходная модель является квадратной сеткой (quad mesh) или импортирована из FBX. | FILE3DGLB |
| `FBX` | Сгенерированная текстурированная модель в формате FBX. Tripo возвращает FBX для квадратных сеток и импортов FBX; в противном случае поле пусто. | FILE3DFBX |
