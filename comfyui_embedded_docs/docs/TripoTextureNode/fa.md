# Tripo: مدل بافت

گره TripoTextureNode با استفاده از API Tripo، بافت‌ها را به یک مدل سه‌بعدی Tripo موجود اضافه می‌کند. این گره شناسه وظیفه (Task ID) مدلی را که توسط گره Tripo دیگری ایجاد شده است دریافت می‌کند و پس از اتمام کار بافت‌دهی، یک مدل GLB یا FBX بافت‌دار را برمی‌گرداند. شما می‌توانید نقشه‌های متریال، کیفیت بافت، هم‌ترازی و بذر (seed) را کنترل کنید و بافت‌ها را با یک متن راهنما، یک تصویر سبک یا تصاویر مرجع هدایت کنید.

## ورودی‌ها

### ورودی‌های مشترک

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `شناسه وظیفه مدل` | شناسه وظیفه Tripo مربوط به مدل بافت‌دهی شده. شناسه‌های وظیفه مدل و شناسه‌های وظیفه بخش‌بندی را می‌پذیرد. | MODEL_TASK_ID | بله | - |
| `بافت` | نادیده گرفته می‌شود: این گره همیشه بافت تولید می‌کند. برای گردش‌کارهای قدیمی‌تر حفظ شده است. (پیش‌فرض: True) | BOOLEAN | خیر | true<br>false |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، متالیک، زبری، نرمال)؛ خاموش بودن آن یک بافت رنگی ساده ایجاد می‌کند. (پیش‌فرض: True) | BOOLEAN | خیر | true<br>false |
| `بذر بافت` | بذر تصادفی برای تولید بافت. استفاده از همان بذر با همان ورودی‌ها همان نتیجه را تولید می‌کند. (پیش‌فرض: 42) | INT | خیر | 0 – 2147483647 |
| `کیفیت بافت` | کیفیت رزولوشن بافت: detailed = بافت‌های HD، extreme = بافت‌های Ultra 8K. (پیش‌فرض: "standard"). هزینه تقریبی: standard ۰.۱۰ دلار، detailed ۰.۲۰ دلار، extreme ۰.۳۰ دلار. | COMBO | خیر | "standard"<br>"detailed"<br>"extreme" |
| `تراز بافت` | روش مورد استفاده برای هم‌تراز کردن بافت‌های تولید شده با مدل. (پیش‌فرض: "original_image"). | COMBO | خیر | "original_image"<br>"geometry" |
| `texture_prompt` | راهنمای متنی اختیاری برای بافت‌دهی. در عمل برای مدل‌های وارد شده (Tripo: Import Model) الزامی است، زیرا هیچ تصویر منبعی برای استنباط رنگ‌ها ندارند. نمی‌تواند با تصاویر مرجع ترکیب شود. (پیش‌فرض: "") | STRING | خیر | - |
| `model_version` | مدل بافت: v3.0 برای مش‌های تولید شده با v3.x، v2.5 برای مش‌های تولید شده با v2.5. (پیش‌فرض: آخرین نسخه v3.0) | COMBO | خیر | Multiple options available |
| `style_image` | تصویر مرجع برای سبک هنری بافت‌ها. فقط همراه با `texture_prompt` استفاده می‌شود. | IMAGE | خیر | - |
| `reference` | تصاویر مرجع هدایت‌کننده بافت‌ها. نمی‌تواند با `texture_prompt` یا `style_image` ترکیب شود. (پیش‌فرض: "none") | DYNAMIC_COMBO | خیر | "none"<br>"image"<br>"multiview" |
| `part_names` | نام بخش‌ها با جداکننده کاما از Tripo: Segment Model برای بافت‌دهی. خالی بودن همه بخش‌ها را بافت‌دهی می‌کند. (پیش‌فرض: "") | STRING | خیر | - |

### ورودی‌های مرجع "image"

این ورودی‌ها زمانی در دسترس هستند که `reference` روی `"image"` تنظیم شده باشد.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | تک تصویر مرجع که بافت‌ها باید از آن پیروی کنند. | IMAGE | خیر | - |

### ورودی‌های مرجع "multiview"

این ورودی‌ها زمانی در دسترس هستند که `reference` روی `"multiview"` تنظیم شده باشد.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image_front` | نمای جلو (۰ درجه). | IMAGE | خیر | - |
| `image_left` | نمای چپ (۹۰ درجه). | IMAGE | خیر | - |
| `image_back` | نمای عقب (۱۸۰ درجه). | IMAGE | خیر | - |
| `image_right` | نمای راست (۲۷۰ درجه). | IMAGE | خیر | - |

**توجه:** حالت‌های مرجع `"image"` و `"multiview"` نمی‌توانند با یک `texture_prompt` غیرخالی یا با `style_image` ترکیب شوند. ورودی `style_image` نیازمند یک `texture_prompt` غیرخالی است. هنگامی که `texture_prompt` خالی گذاشته می‌شود، مدل مبدأ باید از قبل تصویر منبع خود را داشته باشد (برای مثال، مدل‌های تولید شده توسط text-to-model، image-to-model، multiview-to-model، یا یک وظیفه بافت‌دهی قبلی). مدل‌هایی که تصویر منبع ندارند — مانند مدل‌های وارد شده، بخش‌بندی شده، تکمیل شده، یا بازتوپولوژی شده — باید با یک `texture_prompt` بافت‌دهی شوند؛ تصاویر مرجع فقط برای مدل‌هایی پذیرفته می‌شوند که خود API Tripo آن‌ها را تولید کرده است.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل تولید شده (فقط برای سازگاری معکوس). | STRING |
| `شناسه وظیفه مدل` | شناسه وظیفه مربوط به وظیفه تولید بافت تکمیل شده، قابل استفاده به عنوان ورودی برای سایر گره‌های Tripo. | MODEL_TASK_ID |
| `GLB` | مدل بافت‌دار تولید شده در فرمت GLB. وقتی منبع یک مش چهارضلعی یا یک واردات FBX باشد، خالی است. | FILE3DGLB |
| `FBX` | مدل بافت‌دار تولید شده در فرمت FBX. Tripo برای مش‌های چهارضلعی و واردات FBX، FBX برمی‌گرداند؛ در غیر این صورت خالی است. | FILE3DFBX |
