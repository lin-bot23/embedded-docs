# Tripo: مدل بافت

گره Tripo: Texture model (Legacy) از طریق Tripo API به یک مدل سه‌بعدی Tripo موجود بافت اضافه می‌کند. این گره شناسهٔ وظیفهٔ مدلی را که توسط یک گره Tripo دیگر ساخته شده است می‌گیرد و پس از پایان یافتن کار بافت‌دهی، یک مدل GLB یا FBX بافت‌دار برمی‌گرداند. می‌توانید نقشه‌های متریال، کیفیت بافت، هم‌ترازی و seed را کنترل کنید و بافت‌ها را با یک پرامپت متنی، یک تصویر سبک یا تصاویر مرجع هدایت کنید. این گره نسخهٔ قدیمی (legacy) ابزار بافت است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `شناسه وظیفه مدل` | شناسهٔ وظیفهٔ Tripo برای مدلی که باید بافت‌دهی شود. شناسه‌های وظیفهٔ مدل و شناسه‌های وظیفهٔ بخش‌بندی را می‌پذیرد. | MODEL_TASK_ID, SEGMENT_TASK_ID | بله | - |
| `بافت` | نادیده گرفته می‌شود: این گره همیشه بافت تولید می‌کند. برای گردش‌کارهای قدیمی‌تر نگه داشته شده است. (پیش‌فرض: True) | BOOLEAN | خیر | true<br>false |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، متالیک، زبری، نرمال)؛ خاموش بودن آن یک بافت رنگ یکدست می‌دهد. (پیش‌فرض: True) | BOOLEAN | خیر | true<br>false |
| `بذر بافت` | seed تصادفی برای تولید بافت. (پیش‌فرض: 42) | INT | خیر | 0 – 2147483647 |
| `کیفیت بافت` | کیفیت وضوح بافت: detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra. (پیش‌فرض: "standard"). هزینهٔ تقریبی: standard $0.10، detailed $0.20، extreme $0.30. | COMBO | خیر | "standard"<br>"detailed"<br>"extreme" |
| `تراز بافت` | روشی که برای هم‌ترازی بافت‌های تولیدشده با مدل استفاده می‌شود. (پیش‌فرض: "original_image") | COMBO | خیر | "original_image"<br>"geometry" |
| `texture_prompt` | راهنمای متنی اختیاری برای بافت‌دهی. در عمل برای مدل‌های واردشده (Tripo: Import Model) الزامی است، چون تصویر مبدأیی ندارند تا رنگ‌ها از آن استنباط شود. نمی‌تواند با تصاویر مرجع ترکیب شود. (پیش‌فرض: "") | STRING | خیر | - |
| `model_version` | مدل بافت: v3.0 برای مش‌های تولیدشده با v3.x، v2.5 برای مش‌های تولیدشده با v2.5. (پیش‌فرض: v3.0_20250812) | COMBO | خیر | گزینه‌های متعدد موجود است |
| `style_image` | تصویر مرجع برای سبک هنری بافت‌ها. فقط همراه با `texture_prompt` استفاده می‌شود. | IMAGE | خیر | - |
| `reference` | تصاویر مرجعی که بافت‌ها را هدایت می‌کنند. نمی‌تواند با `texture_prompt` یا `style_image` ترکیب شود. (پیش‌فرض: "none") | DYNAMIC_COMBO | خیر | "none"<br>"image"<br>"multiview" |
| `part_names` | نام‌های بخش جداشده با کاما از Tripo: Segment Model برای بافت‌دهی. خالی بودن آن همهٔ بخش‌ها را بافت‌دهی می‌کند. (پیش‌فرض: "") | STRING | خیر | - |

### ورودی‌های مرجع `image`

این ورودی‌ها زمانی در دسترس هستند که `reference` روی `"image"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | تصویر مرجع تکی که بافت‌ها باید از آن پیروی کنند. | IMAGE | بله | - |

### ورودی‌های مرجع `multiview`

این ورودی‌ها زمانی در دسترس هستند که `reference` روی `"multiview"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `image_front` | نمای روبه‌رو (۰°). | IMAGE | بله | - |
| `image_left` | نمای چپ (۹۰°). | IMAGE | بله | - |
| `image_back` | نمای پشت (۱۸۰°). | IMAGE | بله | - |
| `image_right` | نمای راست (۲۷۰°). | IMAGE | بله | - |

**نکته:** حالت‌های مرجع `"image"` و `"multiview"` را نمی‌توان با `texture_prompt` غیرخالی یا با `style_image` ترکیب کرد. ورودی `style_image` به یک `texture_prompt` غیرخالی نیاز دارد. وقتی `texture_prompt` خالی گذاشته شود، مدل مبدأ باید از قبل تصویر مبدأ خودش را داشته باشد (برای مثال، مدل‌هایی که توسط text-to-model، image-to-model، multiview-to-model یا یک وظیفهٔ بافت‌دهی قبلی تولید شده‌اند). مدل‌هایی که تصویر مبدأ ندارند — مانند مدل‌های واردشده، بخش‌بندی‌شده، تکمیل‌شده یا بازتوپولوژی‌شده — باید با یک `texture_prompt` بافت‌دهی شوند؛ تصاویر مرجع فقط برای مدل‌هایی پذیرفته می‌شوند که خود Tripo API آن‌ها را تولید کرده است. ورودی `part_names` را می‌توان خالی گذاشت تا همهٔ بخش‌ها بافت‌دهی شوند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل تولیدشده (فقط برای سازگاری با نسخه‌های قبلی). | STRING |
| `شناسه وظیفه مدل` | شناسهٔ وظیفهٔ کار بافت‌دهی تکمیل‌شده، قابل استفاده به‌عنوان ورودی برای سایر گره‌های Tripo. | MODEL_TASK_ID |
| `GLB` | مدل بافت‌دار تولیدشده در قالب GLB. هنگامی که مبدأ یک مش چهارضلعی یا یک ورودی FBX باشد، خالی است. | FILE3DGLB |
| `FBX` | مدل بافت‌دار تولیدشده در قالب FBX. Tripo برای مش‌های چهارضلعی و ورودی‌های FBX، FBX برمی‌گرداند؛ در غیر این صورت خالی است. | FILE3DFBX |
