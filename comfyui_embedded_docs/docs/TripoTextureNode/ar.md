# Tripo: نموذج الملمس

عقدة Tripo: Texture model (Legacy) تضيف خامات إلى نموذج Tripo ثلاثي الأبعاد موجود عبر Tripo API. تأخذ معرّف المهمة (task ID) لنموذج أنشأته عقدة Tripo أخرى، وتُعيد نموذجًا مزوّدًا بالخامات بصيغة GLB أو FBX بعد انتهاء مهمة إضافة الخامات. يمكنك التحكم في خرائط المواد، وجودة الخامة، والمحاذاة، والبذرة العشوائية، وتوجيه الخامات عبر أمر نصي، أو صورة نمط، أو صور مرجعية. هذه العقدة نسخة قديمة (legacy) من أداة الخامات.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `معرف_مهمة_النموذج` | معرّف مهمة Tripo للنموذج المطلوب إضافة خامات إليه. يقبل معرّفات مهام النماذج ومعرّفات مهام التقسيم. | MODEL_TASK_ID, SEGMENT_TASK_ID | نعم | - |
| `الملمس` | يتم تجاهله: هذه العقدة تنشئ الخامات دائمًا. يُحتفظ به للتوافق مع سير العمل الأقدم. (الافتراضي: True) | BOOLEAN | لا | true<br>false |
| `PBR` | خرائط مواد PBR (اللون الأساسي، المعدني، الخشونة، normal)؛ إيقافها يعطي خامة بلون سادة. (الافتراضي: True) | BOOLEAN | لا | true<br>false |
| `بذرة_الملمس` | بذرة عشوائية لتوليد الخامات. (الافتراضي: 42) | INT | لا | 0 – 2147483647 |
| `جودة_الملمس` | جودة دقة الخامة: detailed = خامات HD، extreme = خامات 8K Ultra. (الافتراضي: "standard"). التكلفة التقريبية: standard 0.10 دولار، detailed 0.20 دولار، extreme 0.30 دولار. | COMBO | لا | "standard"<br>"detailed"<br>"extreme" |
| `محاذاة_الملمس` | الطريقة المستخدمة لمحاذاة الخامات المولّدة مع النموذج. (الافتراضي: "original_image") | COMBO | لا | "original_image"<br>"geometry" |
| `texture_prompt` | توجيه نصي اختياري لإضافة الخامات. مطلوب عمليًا للنماذج المستوردة (Tripo: Import Model)، التي لا تحمل صورة مصدر لاستنتاج الألوان منها. لا يمكن دمجه مع الصور المرجعية. (الافتراضي: "") | STRING | لا | - |
| `model_version` | نموذج الخامة: v3.0 للشبكات المولّدة باستخدام v3.x، وv2.5 للشبكات المولّدة باستخدام v2.5. (الافتراضي: v3.0_20250812) | COMBO | لا | خيارات متعددة متاحة |
| `style_image` | صورة مرجعية للنمط الفني للخامات. تُستخدم فقط مع `texture_prompt`. | IMAGE | لا | - |
| `reference` | صور مرجعية توجّه الخامات. لا يمكن دمجها مع `texture_prompt` أو `style_image`. (الافتراضي: "none") | DYNAMIC_COMBO | لا | "none"<br>"image"<br>"multiview" |
| `part_names` | أسماء الأجزاء مفصولة بفواصل من Tripo: Segment Model لإضافة الخامات إليها. فارغ يعني إضافة الخامات إلى كل جزء. (الافتراضي: "") | STRING | لا | - |

### المدخلات المرجعية لـ `image`

تتوفر هذه المدخلات عندما تكون قيمة `reference` مضبوطة على `"image"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | صورة مرجعية واحدة يجب أن تتبعها الخامات. | IMAGE | نعم | - |

### المدخلات المرجعية لـ `multiview`

تتوفر هذه المدخلات عندما تكون قيمة `reference` مضبوطة على `"multiview"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image_front` | منظر أمامي (0°). | IMAGE | نعم | - |
| `image_left` | منظر أيسر (90°). | IMAGE | نعم | - |
| `image_back` | منظر خلفي (180°). | IMAGE | نعم | - |
| `image_right` | منظر أيمن (270°). | IMAGE | نعم | - |

**ملاحظة:** لا يمكن دمج وضعي المرجع `"image"` و`"multiview"` مع `texture_prompt` غير فارغ أو مع `style_image`. يتطلب الإدخال `style_image` وجود `texture_prompt` غير فارغ. عندما يُترك `texture_prompt` فارغًا، يجب أن يكون لدى النموذج المصدر صورة مصدر خاصة به بالفعل (على سبيل المثال، النماذج الناتجة عن النص إلى نموذج، أو الصورة إلى نموذج، أو المناظر المتعددة إلى نموذج، أو مهمة خامات سابقة). النماذج التي لا تحمل صورة مصدر — مثل النماذج المستوردة أو المجزّأة أو المكتملة أو المعاد طوبولوجيتها (retopologized) — يجب إضافة الخامات إليها باستخدام `texture_prompt`؛ ولا تُقبل الصور المرجعية إلا للنماذج التي أنشأها Tripo API بنفسه. يمكن ترك إدخال `part_names` فارغًا لإضافة الخامات إلى كل جزء.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | ملف النموذج المولّد (للتوافق العكسي فقط). | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة لمهمة توليد الخامات المكتملة، ويمكن استخدامه كمدخل لعقد Tripo أخرى. | MODEL_TASK_ID |
| `GLB` | النموذج المولّد المزوّد بالخامات بصيغة GLB. فارغ عندما يكون المصدر شبكة quad أو استيراد FBX. | FILE3DGLB |
| `FBX` | النموذج المولّد المزوّد بالخامات بصيغة FBX. يعيد Tripo صيغة FBX للشبكات quad وعمليات استيراد FBX؛ وتكون فارغة بخلاف ذلك. | FILE3DFBX |
