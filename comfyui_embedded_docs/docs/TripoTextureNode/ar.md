# Tripo: نموذج الملمس

تقوم عقدة `TripoTextureNode` بإضافة أنسجة إلى نموذج Tripo ثلاثي الأبعاد موجود باستخدام واجهة Tripo API. تأخذ هذه العقدة معرف المهمة لنموذج تم إنشاؤه بواسطة عقدة Tripo أخرى، وتُرجع نموذج GLB أو FBX مُغطى بالأنسجة بعد اكتمال مهمة التكسية. يمكنك التحكم في خرائط المواد، وجودة النسيج، والمحاذاة، والبذرة، وتوجيه الأنسجة باستخدام نص توجيهي أو صورة نمطية أو صور مرجعية.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرف مهمة Tripo للنموذج المراد تكسيته. يقبل معرفات مهام النماذج ومعرفات مهام التجزئة. | MODEL_TASK_ID | نعم | - |
| `texture` | يُتجاهل: هذه العقدة تُولّد الأنسجة دائمًا. أُبقي للتوافق مع سير العمل الأقدم. (الافتراضي: True) | BOOLEAN | لا | true<br>false |
| `pbr` | خرائط مواد PBR (اللون الأساسي، المعدني، الخشونة، الطبيعي)؛ إيقافها يُنتج نسيجًا بلون بسيط. (الافتراضي: True) | BOOLEAN | لا | true<br>false |
| `texture_seed` | بذرة عشوائية لتوليد النسيج. استخدام البذرة نفسها مع المدخلات نفسها يُنتج النتيجة نفسها. (الافتراضي: 42) | INT | لا | 0 – 2147483647 |
| `texture_quality` | جودة دقة النسيج: `detailed` تعني أنسجة عالية الدقة (HD)، و`extreme` تعني أنسجة فائقة الدقة (8K Ultra). (الافتراضي: `"standard"`). التكلفة التقريبية: standard 0.10 دولار أمريكي، detailed 0.20 دولار أمريكي، extreme 0.30 دولار أمريكي. | COMBO | لا | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | الطريقة المستخدمة لمحاذاة الأنسجة المُولّدة مع النموذج. (الافتراضي: `"original_image"`). | COMBO | لا | "original_image"<br>"geometry" |
| `texture_prompt` | توجيه نصي اختياري للتكسية. مطلوب عمليًا للنماذج المستوردة (Tripo: Import Model) التي لا تحمل صورة مصدر يُستدل منها على الألوان. لا يمكن دمجه مع الصور المرجعية. (الافتراضي: "") | STRING | لا | - |
| `model_version` | نموذج التكسية: إصدار v3.0 للشبكات المُولّدة مع إصدارات v3.x، وإصدار v2.5 للشبكات المُولّدة مع v2.5. (الافتراضي: أحدث إصدار من v3.0) | COMBO | لا | تتوفر خيارات متعددة |
| `style_image` | صورة مرجعية للأسلوب الفني للأنسجة. تُستخدم فقط مع `texture_prompt`. | IMAGE | لا | - |
| `reference` | صور مرجعية تُوجّه الأنسجة. لا يمكن دمجها مع `texture_prompt` أو `style_image`. (الافتراضي: `"none"`) | DYNAMIC_COMBO | لا | "none"<br>"image"<br>"multiview" |
| `part_names` | أسماء الأجزاء من عقدة Tripo: Segment Model مفصولة بفواصل لتكسيتها. عند تركها فارغة، يتم تكسية كل جزء. (الافتراضي: "") | STRING | لا | - |

### `"image"` المدخلات المرجعية

هذه المدخلات متاحة عندما يكون `reference` مضبوطًا على `"image"`.

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `reference_image` | صورة مرجعية واحدة يجب أن تتبعها الأنسجة. | IMAGE | لا | - |

### `"multiview"` المدخلات المرجعية

هذه المدخلات متاحة عندما يكون `reference` مضبوطًا على `"multiview"`.

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image_front` | المنظر الأمامي (0°). | IMAGE | لا | - |
| `image_left` | المنظر الأيسر (90°). | IMAGE | لا | - |
| `image_back` | المنظر الخلفي (180°). | IMAGE | لا | - |
| `image_right` | المنظر الأيمن (270°). | IMAGE | لا | - |

**ملاحظة:** لا يمكن الجمع بين وضعي المرجع `"image"` و`"multiview"` مع قيمة غير فارغة لـ `texture_prompt` ولا مع `style_image`. يتطلب مدخل `style_image` تعبئة `texture_prompt`. إذا تُرك `texture_prompt` فارغًا، فيجب أن يكون للنموذج المصدر صورته المصدر الخاصة به (على سبيل المثال، النماذج الناتجة عن التوليد من نص أو صورة أو عروض متعددة، أو مهمة تكسية سابقة). أما النماذج التي لا تحمل صورة مصدر — مثل النماذج المستوردة أو المجزأة أو المكتملة أو المُعاد بناء شبكتها — فيجب تكسيتها باستخدام `texture_prompt`؛ الصور المرجعية تُقبل فقط للنماذج التي تولّدها Tripo API نفسها.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | ملف النموذج المُولَّد (لأغراض التوافق مع الإصدارات السابقة فقط). | STRING |
| `model task_id` | معرف مهمة توليد النسيج المكتملة، ويمكن استخدامه كمدخل لعُقد Tripo الأخرى. | MODEL_TASK_ID |
| `GLB` | النموذج المُغطى بالأنسجة المُولَّد بصيغة GLB. يكون فارغًا عندما يكون المصدر شبكة رباعية الأضلاع أو استيراد FBX. | FILE3DGLB |
| `FBX` | النموذج المُغطى بالأنسجة المُولَّد بصيغة FBX. تُرجع Tripo صيغة FBX للشبكات الرباعية الأضلاع واستيرادات FBX، وتكون فارغة فيما عدا ذلك. | FILE3DFBX |
