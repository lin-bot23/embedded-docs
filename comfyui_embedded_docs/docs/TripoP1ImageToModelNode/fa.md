# Tripo P1: تبدیل تصویر به مدل

Tripo P1: Image to Model یک تصویر دوبعدی را با استفاده از API Tripo P1 به یک مدل سه‌بعدی تبدیل می‌کند. این گره برای تولید مش‌های کم‌پلی‌گون و آماده بازی بهینه شده است و به شما امکان می‌دهد بین یک مش فقط هندسی یا یک مدل بافت‌دار با نقشه‌های PBR یکی را انتخاب کنید. مدل نهایی به‌صورت یک فایل GLB بازگردانده می‌شود.

## ورودی‌ها

### ورودی‌های مشترک

این پارامترها همیشه در دسترس هستند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | نوع نتیجه را انتخاب می‌کند. «Geometry only» یک مش بدون بافت برمی‌گرداند؛ «Textured» نقشه‌های رنگ/PBR را اضافه می‌کند و تنظیمات بافت اضافی را نمایان می‌سازد. | DYNAMIC_COMBO | بله | `"Geometry only"`<br>`"Textured"` |
| `تصویر` | تصویر دوبعدی منبع که برای تولید مدل سه‌بعدی استفاده می‌شود. یک تصویر لازم است؛ اگر هیچ تصویری ارائه نشود، گره خطا می‌دهد. | IMAGE | بله | - |
| `enable_image_autofix` | پیش‌پردازش تصویر ورودی برای کیفیت تولید بهتر. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `face_limit` | تعداد وجه هدف، 48-20000. مقدار -1 باعث می‌شود Tripo به‌صورت تطبیقی انتخاب کند. (پیش‌فرض: -1) | INT | خیر | -1 تا 20000 |
| `model_seed` | بذری که برای تولید هندسه استفاده می‌شود تا نتایج قابل بازتولید باشند. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `auto_size` | خروجی را طوری مقیاس‌دهی می‌کند که تقریباً با مترهای دنیای واقعی مطابقت داشته باشد. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `export_uv` | در زمان تولید، UV unwrap انجام می‌شود. برای اجراهای سریع‌تر فقط هندسی، خاموش کنید. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `compress_geometry` | فشرده‌سازی هندسه meshopt را اعمال می‌کند (EXT_meshopt_compression). فایل‌های کوچک‌تر، اما پیش‌نمایش سه‌بعدی ComfyUI نمی‌تواند آن‌ها را نمایش دهد؛ قبل از ویرایش، از حالت فشرده خارج کنید. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### ورودی‌های Geometry only

هیچ پارامتر اضافی وجود ندارد. خروجی یک مش بدون بافت است.

### ورودی‌های Textured

این پارامترها زمانی ظاهر می‌شوند که `output_mode` روی `"Textured"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `pbr` | نقشه‌های PBR را شامل می‌شود. وقتی روشن باشد، بافت پایه نیز اجباراً روشن می‌شود. (پیش‌فرض: True) | BOOLEAN | بله | True<br>False |
| `texture_quality` | `"detailed"` = بافت‌های HD، `"extreme"` = بافت‌های 8K Ultra. (پیش‌فرض: `"standard"`) | COMBO | بله | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | اولویت را به وفاداری بصری به تصویر منبع، یا هم‌ترازی با هندسه مش می‌دهد. (پیش‌فرض: `"original_image"`) | COMBO | بله | `"original_image"`<br>`"geometry"` |
| `orientation` | خروجی را برای مطابقت با تصویر منبع می‌چرخاند. فقط زمانی اعمال می‌شود که بافت‌دار باشد. (پیش‌فرض: `"default"`) | COMBO | بله | `"default"`<br>`"align_image"` |
| `texture_seed` | بذری که برای تولید بافت استفاده می‌شود تا نتایج بافت‌دار قابل بازتولید باشند. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

نکته: وقتی `output_mode` روی «Geometry only» است، بافت‌سازی برای درخواست غیرفعال می‌شود. در حالت «Textured»، همیشه یک بافت رنگ درخواست می‌شود؛ غیرفعال‌کردن `pbr` نقشه‌های PBR را حذف می‌کند اما بافت رنگ پایه را نگه می‌دارد، در حالی که فعال‌کردن `pbr` بافت پایه را نیز اجباراً روشن می‌کند. `texture_alignment` و `orientation` فقط در حالت «Textured» در دسترس هستند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-----------|-----------|
| `model_file` | یک رشته شامل نام فایل مدل تولیدشده (`<task_id>.glb`). فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `model task_id` | شناسه وظیفه یکتای بازگشتی از API Tripo برای کار تولید تکمیل‌شده. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB. | FILE3DGLB |
