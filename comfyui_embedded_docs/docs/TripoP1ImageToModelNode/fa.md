# Tripo P1: تبدیل تصویر به مدل

Tripo P1: Image to Model یک تصویر دوبعدی tunggal را با استفاده از API Tripo P1 به یک مدل سه‌بعدی تبدیل می‌کند. این گره برای تولید مش‌های کم‌پلیگون و آماده برای بازی بهینه شده است و به شما اجازه می‌دهد بین یک مش فقط هندسی یا یک مدل بافت‌دار با نقشه‌های PBR انتخاب کنید. مدل نهایی به صورت فایل GLB تحویل داده می‌شود.

## ورودی‌ها

### ورودی‌های مشترک

این پارامترها همیشه در دسترس هستند.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | نوع نتیجه را انتخاب می‌کند. "Geometry only" یک مش بدون بافت返回 می‌کند؛ "Textured" رنگ و نقشه‌های PBR را اضافه می‌کند و تنظیمات بافت اضافی را آشکار می‌کند. | DYNAMIC_COMBO | بله | `"Geometry only"`<br>`"Textured"` |
| `تصویر` | تصویر دوبعدی منبع استفاده شده برای تولید مدل سه‌بعدی. این گره به یک تصویر واحد نیاز دارد و در صورت عدم ارائه، خطا می‌دهد. | IMAGE | بله | - |
| `enable_image_autofix` | پیش‌پردازش تصویر ورودی برای کیفیت تولید بهتر. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `face_limit` | تعداد فیس هدف، 48-20000. -1 به Tripo اجازه می‌دهد به صورت تطبیقی انتخاب کند. (پیش‌فرض: -1) | INT | خیر | -1 تا 20000 |
| `model_seed` | Seed استفاده شده برای تولید هندسه تا نتایج قابل تکرار باشند. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `auto_size` | مقیاس خروجی برای تقریب مترهای دنیای واقعی. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `export_uv` | باز کردن UV در حین تولید. برای اجرای سریع‌تر فقط هندسی خاموش کنید. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `compress_geometry` | اعمال فشرده‌سازی هندسه meshopt (EXT_meshopt_compression). فایل‌های کوچک‌تر، اما پیش‌نمایش 3D ComfyUI نمی‌تواند آن‌ها را نمایش دهد؛ قبل از ویرایش از حالت فشرده خارج کنید. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### ورودی‌های بافت‌دار

این پارامترها زمانی ظاهر می‌شوند که `output_mode` روی "Textured" تنظیم شده باشد. حالت "Geometry only" پارامتر اضافی ندارد.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `pbr` | شامل نقشه‌های PBR. وقتی روشن است، بافت پایه نیز اجباراً روشن می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `texture_quality` | سطح رزولوشن بافت. "detailed" = بافت‌های HD، "extreme" = بافت‌های Ultra 8K. (پیش‌فرض: "standard") | COMBO | خیر | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | اولویت با وفاداری بصری به تصویر منبع، یا هم‌ترازی با هندسه مش. (پیش‌فرض: "original_image") | COMBO | خیر | `"original_image"`<br>`"geometry"` |
| `orientation` | چرخش خروجی برای تطابق با تصویر منبع. فقط زمانی اعمال می‌شود که بافت‌دار باشد. (پیش‌فرض: "default") | COMBO | خیر | `"default"`<br>`"align_image"` |
| `texture_seed` | Seed استفاده شده برای تولید بافت تا نتایج بافت‌دار قابل تکرار باشند. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |

نکته: وقتی `output_mode` روی "Geometry only" است، بافت‌گذاری برای درخواست غیرفعال می‌شود. در حالت "Textured"، یک بافت رنگی همیشه درخواست می‌شود؛ غیرفعال کردن `pbr` نقشه‌های PBR را حذف می‌کند اما بافت رنگ پایه را نگه می‌دارد، در حالی که فعال کردن `pbr` بافت پایه را نیز اجباراً روشن می‌کند.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model_file` | نتیجه مدل سه‌بعدی تولید شده. فقط برای سازگاری معکوس نگهداری شده است. | STRING |
| `model task_id` | شناسه وظیفه منحصر به فرد دریافت شده از API Tripo برای وظیفه تولید تکمیل شده. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولید شده در فرمت GLB. | FILE3DGLB |
