# Tripo P1: من صورة إلى نموذج

تحوّل عقدة Tripo P1: Image to Model صورة ثنائية الأبعاد واحدة إلى نموذج ثلاثي الأبعاد باستخدام واجهة Tripo P1 API. وهي محسّنة لتوليد شبكات منخفضة المضلعات وجاهزة للألعاب، وتتيح لك الاختيار بين شبكة هندسية فقط أو نموذج ملوّن بخرائط PBR. يُرجَع النموذج النهائي كملف GLB.

## المدخلات

### المدخلات العامة

هذه المعاملات متاحة دائمًا.

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | يختار نوع النتيجة. يُعيد الخيار `"Geometry only"` شبكة بدون نسيج؛ بينما يضيف `"Textured"` اللون وخرائط PBR ويكشف عن إعدادات نسيج إضافية. | DYNAMIC_COMBO | نعم | `"Geometry only"`<br>`"Textured"` |
| `image` | الصورة المصدر ثنائية الأبعاد المستخدمة لتوليد النموذج ثلاثي الأبعاد. تتطلب العقدة صورة واحدة وتُصدر خطأً إذا لم يتم توفير أي صورة. | IMAGE | نعم | - |
| `enable_image_autofix` | معالجة مسبقة للصورة المدخلة لتحسين جودة التوليد. (القيمة الافتراضية: False) | BOOLEAN | لا | True<br>False |
| `face_limit` | العدد المستهدف للأوجه، من 48 إلى 20000. القيمة -1 تتيح لـ Tripo الاختيار التكيفي. (القيمة الافتراضية: -1) | INT | لا | -1 إلى 20000 |
| `model_seed` | البذرة المستخدمة في توليد الشكل الهندسي بحيث يمكن إعادة إنتاج النتائج. (القيمة الافتراضية: 42) | INT | لا | 0 إلى 2147483647 |
| `auto_size` | ضبط حجم الناتج ليقترب من الأمتار الحقيقية في العالم. (القيمة الافتراضية: False) | BOOLEAN | لا | True<br>False |
| `export_uv` | تفكيك UV أثناء التوليد. أوقِفه لتسريع عمليات الهندسة فقط. (القيمة الافتراضية: True) | BOOLEAN | لا | True<br>False |
| `compress_geometry` | تطبيق ضغط هندسة meshopt (امتداد EXT_meshopt_compression). ينتج ملفات أصغر حجمًا، لكن العرض ثلاثي الأبعاد في ComfyUI لا يمكنه عرضها؛ فك الضغط قبل التعديل. (القيمة الافتراضية: False) | BOOLEAN | لا | True<br>False |

### المدخلات الملوّنة

تظهر هذه المعاملات عندما يكون `output_mode` مضبوطًا على `"Textured"`. وضع `"Geometry only"` لا يحتوي على معاملات إضافية.

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | تضمين خرائط PBR. عند تشغيله، يُفرض تفعيل النسيج الأساسي أيضًا. (القيمة الافتراضية: True) | BOOLEAN | لا | True<br>False |
| `texture_quality` | مستوى دقة النسيج. `"detailed"` = نسيج عالي الدقة، `"extreme"` = نسيج 8K فائق الدقة. (القيمة الافتراضية: `"standard"`) | COMBO | لا | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | يعطي الأولوية للمحافظة على المظهر البصري مقارنة بالصورة المصدر، أو للمحاذاة مع هندسة الشبكة. (القيمة الافتراضية: `"original_image"`) | COMBO | لا | `"original_image"`<br>`"geometry"` |
| `orientation` | توجيه الناتج ليطابق الصورة المصدر. يُطبَّق فقط عند التلوين. (القيمة الافتراضية: `"default"`) | COMBO | لا | `"default"`<br>`"align_image"` |
| `texture_seed` | البذرة المستخدمة في توليد النسيج بحيث يمكن إعادة إنتاج النتائج الملوّنة. (القيمة الافتراضية: 42) | INT | لا | 0 إلى 2147483647 |

ملاحظة: عندما يكون `output_mode` مضبوطًا على `"Geometry only"`، يكون توليد النسيج معطَّلاً للطلب. وفي وضع `"Textured"`، يُطلب دائمًا نسيج الألوان؛ تعطيل `pbr` يزيل خرائط PBR مع الإبقاء على نسيج اللون الأساسي، بينما يؤدي تفعيل `pbr` إلى فرض تفعيل النسيج الأساسي أيضًا.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | نتيجة النموذج ثلاثي الأبعاد المولَّدة. يُحتفظ بها للتوافق مع الإصدارات السابقة فقط. | STRING |
| `model task_id` | معرف المهمة الفريد الذي تُرجعه واجهة Tripo API لمهمة التوليد المكتملة. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المولَّد بصيغة GLB. | FILE3DGLB |
