# Tripo P1: من صورة إلى نموذج

يقوم Tripo P1: Image to Model بتحويل صورة 2D واحدة إلى نموذج ثلاثي الأبعاد باستخدام Tripo P1 API. وهو مُحسَّن لتوليد شبكات منخفضة المضلعات وجاهزة للألعاب، ويتيح لك الاختيار بين شبكة هندسية فقط أو نموذج مكسو بخرائط PBR. يُعاد النموذج النهائي كملف GLB.

## المدخلات

### المدخلات العامة

هذه المعاملات متاحة دائمًا.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `وضع الإخراج` | يختار نوع النتيجة. تعيد "Geometry only" شبكة بدون نسيج؛ وتضيف "Textured" خرائط اللون/PBR وتكشف إعدادات نسيج إضافية. | DYNAMIC_COMBO | نعم | `"Geometry only"`<br>`"Textured"` |
| `صورة` | صورة 2D المصدر المستخدمة لتوليد النموذج ثلاثي الأبعاد. تلزم صورة واحدة؛ وترفع العقدة خطأً إذا لم يتم توفير أي صورة. | IMAGE | نعم | - |
| `تفعيل تصحيح الصورة التلقائي` | معالجة صورة الإدخال مسبقًا لتحسين جودة التوليد. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `حد الأوجه` | عدد الأوجه المستهدف، 48-20000. تجعل القيمة -1 Tripo تختار تكيفيًا. (الافتراضي: -1) | INT | لا | -1 إلى 20000 |
| `بذرة النموذج` | البذرة المستخدمة في توليد الهندسة بحيث يمكن إعادة إنتاج النتائج. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `تغيير الحجم تلقائيًا` | تحجيم الخرج ليقارب الأمتار في العالم الحقيقي. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `تصدير UV` | إجراء فك UV أثناء التوليد. أوقفه للحصول على عمليات أسرع للهندسة فقط. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `ضغط الهندسة` | تطبيق ضغط الهندسة meshopt (EXT_meshopt_compression). ملفات أصغر، لكن معاينة 3D في ComfyUI لا يمكنها عرضها؛ فك الضغط قبل التحرير. (الافتراضي: False) | BOOLEAN | لا | True<br>False |

### مدخلات Geometry only

لا توجد معاملات إضافية. الخرج عبارة عن شبكة بدون نسيج.

### مدخلات Textured

تظهر هذه المعاملات عندما يتم ضبط `output_mode` على "Textured".

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | تضمين خرائط PBR. عند تشغيله، يتم فرض تشغيل النسيج الأساسي أيضًا. (الافتراضي: True) | BOOLEAN | نعم | True<br>False |
| `texture_quality` | detailed = أنسجة HD، extreme = أنسجة 8K Ultra. (الافتراضي: "standard") | COMBO | نعم | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | إعطاء الأولوية للأمانة البصرية تجاه صورة المصدر، أو المحاذاة إلى هندسة الشبكة. (الافتراضي: "original_image") | COMBO | نعم | `"original_image"`<br>`"geometry"` |
| `orientation` | تدوير الخرج ليطابق صورة المصدر. ينطبق فقط عند استخدام النسيج. (الافتراضي: "default") | COMBO | نعم | `"default"`<br>`"align_image"` |
| `texture_seed` | البذرة المستخدمة في توليد النسيج بحيث يمكن إعادة إنتاج النتائج المنسوجة. (الافتراضي: 42) | INT | نعم | 0 إلى 2147483647 |

ملاحظة: عندما يكون `output_mode` مضبوطًا على "Geometry only"، يتم تعطيل النسيج للطلب. في الوضع "Textured"، يُطلب دائمًا نسيج لوني؛ يؤدي تعطيل `pbr` إلى إزالة خرائط PBR مع الإبقاء على نسيج اللون الأساسي، بينما يؤدي تمكين `pbr` إلى فرض تشغيل النسيج الأساسي أيضًا. لا يتوفر `texture_alignment` و`orientation` إلا في الوضع "Textured".

## المخرجات

| اسم الخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | سلسلة نصية تحتوي على اسم ملف النموذج المولَّد (`<task_id>.glb`). محتفظ بها للتوافق العكسي فقط. | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة الفريد الذي يعيده Tripo API لمهمة التوليد المكتملة. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المولَّد بصيغة GLB. | FILE3DGLB |
