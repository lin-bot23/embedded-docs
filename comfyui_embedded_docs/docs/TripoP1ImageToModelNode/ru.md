# Tripo P1: Изображение в Модель

Tripo P1: Image to Model преобразует одно 2D-изображение в 3D-модель с помощью API Tripo P1. Он оптимизирован для создания low-poly сеток, готовых к использованию в играх, и позволяет выбрать между сеткой только с геометрией или текстурированной моделью с PBR-картами. Готовая модель возвращается в виде GLB-файла.

## Входы

### Общие входы

Эти параметры доступны всегда.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | Выбирает тип результата. «Geometry only» возвращает сетку без текстуры; «Textured» добавляет цвет и PBR-карты и открывает дополнительные настройки текстуры. | DYNAMIC_COMBO | Да | `"Geometry only"`<br>`"Textured"` |
| `image` | Исходное 2D-изображение, используемое для создания 3D-модели. Узел требует одно изображение и возвращает ошибку, если оно не предоставлено. | IMAGE | Да | - |
| `enable_image_autofix` | Предварительная обработка входного изображения для улучшения качества генерации. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `face_limit` | Целевое количество граней: 48–20000. Значение -1 позволяет Tripo выбирать адаптивно. (по умолчанию: -1) | INT | Нет | -1 до 20000 |
| `model_seed` | Сид, используемый для генерации геометрии, чтобы результаты можно было воспроизвести. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `auto_size` | Масштабировать результат до приблизительных реальных размеров в метрах. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `export_uv` | Развертка UV во время генерации. Отключите для ускорения работы в режиме «Geometry only». (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `compress_geometry` | Применить сжатие геометрии meshopt (EXT_meshopt_compression). Файлы меньше, но 3D-просмотр ComfyUI не может их отобразить; распакуйте перед редактированием. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Текстурные входы

Эти параметры появляются, когда `output_mode` имеет значение «Textured». Режим «Geometry only» не имеет дополнительных параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pbr` | Включает PBR-карты. При включении базовая текстура также принудительно включается. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `texture_quality` | Уровень разрешения текстур. «detailed» = HD-текстуры, «extreme» = 8K Ultra-текстуры. (по умолчанию: «standard») | COMBO | Нет | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | Отдавать приоритет визуальному сходству с исходным изображением или соответствию геометрии сетки. (по умолчанию: «original_image») | COMBO | Нет | `"original_image"`<br>`"geometry"` |
| `orientation` | Поворачивает результат в соответствии с исходным изображением. Применяется только при наличии текстуры. (по умолчанию: «default») | COMBO | Нет | `"default"`<br>`"align_image"` |
| `texture_seed` | Сид, используемый для генерации текстуры, чтобы текстурированные результаты можно было воспроизвести. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |

Примечание: Когда `output_mode` имеет значение «Geometry only», текстурирование для запроса отключено. В режиме «Textured» цветная текстура запрашивается всегда; отключение `pbr` удаляет PBR-карты, но сохраняет базовую цветную текстуру, а включение `pbr` также принудительно включает базовую текстуру.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Результат сгенерированной 3D-модели. Сохраняется только для обратной совместимости. | STRING |
| `model task_id` | Уникальный идентификатор задачи, возвращаемый API Tripo для завершённого задания генерации. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
