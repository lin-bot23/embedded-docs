# Tripo P1: Изображение в Модель

Tripo P1: Image to Model преобразует одно 2D-изображение в 3D-модель с помощью API Tripo P1. Узел оптимизирован для генерации низкополигональных мешей, готовых для игр, и позволяет выбирать между мешем только с геометрией или текстурированной моделью с PBR-картами. Готовая модель возвращается в виде файла GLB.

## Входы

### Общие входы

Эти параметры доступны всегда.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `режим_вывода` | Выбирает тип результата. «Geometry only» возвращает меш без текстуры; «Textured» добавляет цветовые/PBR-карты и открывает дополнительные настройки текстуры. | DYNAMIC_COMBO | Да | `"Geometry only"`<br>`"Textured"` |
| `изображение` | Исходное 2D-изображение, используемое для генерации 3D-модели. Требуется одно изображение; если оно не указано, узел выдаёт ошибку. | IMAGE | Да | - |
| `включить_автоисправление_изображения` | Предварительная обработка входного изображения для повышения качества генерации. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `ограничение_граней` | Целевое количество полигонов, 48–20000. -1 позволяет Tripo выбрать адаптивно. (по умолчанию: -1) | INT | Нет | -1 до 20000 |
| `seed_модели` | Сид, используемый для генерации геометрии, чтобы результаты можно было воспроизвести. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `авторазмер` | Масштабирует результат приблизительно в реальные метры. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `экспорт_uv` | Выполнять UV-развёртку во время генерации. Отключите для более быстрых запусков только с геометрией. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `сжать_геометрию` | Применять сжатие геометрии meshopt (EXT_meshopt_compression). Файлы меньше, но 3D-предпросмотр ComfyUI не может их отображать; распакуйте перед редактированием. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы Geometry only

Дополнительных параметров нет. Выходные данные — меш без текстуры.

### Входы Textured

Эти параметры появляются, когда для `output_mode` установлено значение "Textured".

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pbr` | Включить PBR-карты. При включении базовая текстура также принудительно включается. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `texture_quality` | detailed = HD-текстуры, extreme = 8K Ultra-текстуры. (по умолчанию: "standard") | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | Приоритет визуального соответствия исходному изображению или выравнивания по геометрии меша. (по умолчанию: "original_image") | COMBO | Да | `"original_image"`<br>`"geometry"` |
| `orientation` | Повернуть результат в соответствии с исходным изображением. Применяется только при текстурировании. (по умолчанию: "default") | COMBO | Да | `"default"`<br>`"align_image"` |
| `texture_seed` | Сид, используемый для генерации текстуры, чтобы текстурированные результаты можно было воспроизвести. (по умолчанию: 42) | INT | Да | 0 до 2147483647 |

Примечание: Когда `output_mode` имеет значение «Geometry only», текстурирование для запроса отключается. В режиме «Textured» цветовая текстура запрашивается всегда; отключение `pbr` удаляет PBR-карты, но сохраняет базовую цветовую текстуру, а включение `pbr` также принудительно включает базовую текстуру. `texture_alignment` и `orientation` доступны только в режиме «Textured».

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл_модели` | Строка, содержащая имя сгенерированного файла модели (`<task_id>.glb`). Оставлена только для обратной совместимости. | STRING |
| `task_id_модели` | Уникальный ID задачи, возвращаемый API Tripo для завершённой задачи генерации. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
