# MaskPreview

Узел MaskPreview отображает визуальное предварительное просмотр данных маски непосредственно в интерфейсе ComfyUI, не сохраняя их в выходной каталог. Это позволяет проверять маску в любой точке вашего рабочего процесса, при этом маска также проходит через узел без изменений, чтобы её можно было использовать далее.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mask` | Данные маски для предварительного просмотра | MASK | Да | - |
| `filename_prefix` | Префикс имени файла, используемый для предварительного просмотра (по умолчанию: "ComfyUI") | STRING | Нет | - |
| `prompt` | Информация запроса для метаданных (предоставляется автоматически) | PROMPT | Нет | - |
| `extra_pnginfo` | Дополнительная PNG-информация для метаданных (предоставляется автоматически) | EXTRA_PNGINFO | Нет | - |

Только `mask` является видимым входом, который необходимо подключить. Параметры `filename_prefix`, `prompt` и `extra_pnginfo` предоставляются системой: `filename_prefix` использует значение по умолчанию, а `prompt` и `extra_pnginfo` скрыты и автоматически предоставляются средой выполнения ComfyUI.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mask` | Те же данные маски, которые были предварительно просмотрены, возвращаются без изменений для использования в других частях рабочего процесса | MASK |
