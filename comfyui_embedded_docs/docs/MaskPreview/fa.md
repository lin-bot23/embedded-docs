# پیش‌نمایش ماسک

گره MaskPreview یک پیش‌نمایش بصری از داده‌های ماسک را مستقیماً در رابط کاربری ComfyUI نمایش می‌دهد، بدون اینکه آن را در پوشه خروجی ذخیره کند. این امکان به شما می‌دهد تا ماسک را در هر نقطه از جریان کاری خود بررسی کنید، در حالی که ماسک نیز بدون تغییر از گره عبور می‌کند تا بتواند در ادامه مورد استفاده قرار گیرد.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `mask` | داده‌های ماسک برای پیش‌نمایش | MASK | بله | - |
| `filename_prefix` | پیشوند نام فایل استفاده شده برای پیش‌نمایش (پیش‌فرض: "ComfyUI") | STRING | خیر | - |
| `prompt` | اطلاعات پرامپت برای فراداده (به‌صورت خودکار ارائه می‌شود) | PROMPT | خیر | - |
| `extra_pnginfo` | اطلاعات اضافی PNG برای فراداده (به‌صورت خودکار ارائه می‌شود) | EXTRA_PNGINFO | خیر | - |

تنها `mask` یک ورودی قابل مشاهده است که نیاز به اتصال دارد. پارامترهای `filename_prefix`، `prompt` و `extra_pnginfo` توسط سیستم تأمین می‌شوند: `filename_prefix` به مقدار پیش‌فرض خود بازمی‌گردد، در حالی که `prompt` و `extra_pnginfo` پنهان هستند و به‌صورت خودکار توسط زمان اجرای ComfyUI ارائه می‌شوند.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `mask` | همان داده‌های ماسک که پیش‌نمایش شدند، بدون تغییر برگردانده می‌شوند تا بتوان در جای دیگری از جریان کاری از آن‌ها استفاده کرد | MASK |
