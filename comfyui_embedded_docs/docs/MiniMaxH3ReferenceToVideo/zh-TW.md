# MiniMax H3 參考轉影片

MiniMax H3 Reference to Video 節點會建立 MiniMax H3 參考轉影片生成所需的文字條件，以及空的音訊-影片 latent。您提供提示詞與可選的參考圖片、影片和音訊片段，節點會將這些參考編碼為模型在生成時可使用的條件。提示詞會使用 `<Picture i>`、`<Video k>` 與 `<Audio j>` 標籤來引用參考媒體。

注意事項：

- 提示詞使用每種類型各自從 1 開始編號的標籤引用參考媒體：`<Picture i>` 代表圖片、`<Video k>` 代表影片、`<Audio j>` 代表音訊。參考內容會以固定順序提供給模型：圖片、接著影片（每個配樂的 `<Audio j>` 標籤緊接在其 `<Video k>` 之前），最後是獨立音訊。
- 連接到 `ref_video_audio_N` 的配樂會與連接到 `ref_video_N` 的參考影片搭配使用。
- 參考影片必須至少包含 5 個幀（24 fps 下約 0.2 秒），否則節點會拋出錯誤。超過所要求 `length` 的幀會被裁剪，剩餘幀數會調整為模型支援的值。
- 在建立 latent 前，所要求的 `length` 會先對齊至支援的幀數。
