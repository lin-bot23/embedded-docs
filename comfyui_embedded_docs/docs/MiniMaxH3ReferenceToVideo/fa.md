# تبدیل مرجع به ویدیو MiniMax H3

گره MiniMax H3 Reference to Video شرایط متنی و لاتنت خالی صوتی-تصویری مورد نیاز برای تولید ویدیو با ارجاع MiniMax H3 را ایجاد می‌کند. شما یک پرامپت به همراه تصاویر، ویدیوها و کلیپ‌های صوتی ارجاعی اختیاری ارائه می‌دهید و گره این ارجاع‌ها را به شرایطی کدگذاری می‌کند که مدل می‌تواند هنگام تولید از آن‌ها استفاده کند. پرامپت با استفاده از برچسب‌های `<Picture i>`، `<Video k>` و `<Audio j>` به ارجاع‌ها اشاره می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip` | مدل CLIP مورد استفاده برای توکن‌سازی پرامپت و کدگذاری رسانه‌های ارجاعی به توکن‌های conditioning. | CLIP | بله | |
| `vae` | VAE ویدیو مورد استفاده برای کدگذاری تصاویر ارجاعی و فریم‌های ویدیوی ارجاعی. بدون آن، تصاویر/ویدیوهای ارجاعی فقط encoder متن را شرطی‌سازی می‌کنند. | VAE | خیر | |
| `audio_vae` | VAE صوتی مورد استفاده برای کدگذاری صوت ارجاعی. صوت به نرخ نمونه‌برداری VAE صوتی (به‌صورت پیش‌فرض ۳۲ کیلوهرتز) resample می‌شود. بدون آن، صوت ارجاعی فقط encoder متن را شرطی‌سازی می‌کند. | VAE | خیر | |
| `پرامپت` | پرامپت متنی برای ویدیو. رسانه‌های ارجاعی را می‌توان با برچسب‌های `<Picture i>`، `<Video k>` و `<Audio j>` (مبتنی بر ۱ برای هر نوع) آدرس‌دهی کرد. از پرامپت‌های چندخطی و پویا پشتیبانی می‌کند. | STRING | بله | |
| `عرض` | عرض ویدیوی تولید شده بر حسب پیکسل (پیش‌فرض: 1344). | INT | بله | 32 تا 16384 (گام 32) |
| `ارتفاع` | ارتفاع ویدیوی تولید شده بر حسب پیکسل (پیش‌فرض: 768). | INT | بله | 32 تا 16384 (گام 32) |
| `طول` | تعداد فریم در 24 fps؛ 124 = ~5s، محدوده آموزش‌دیده ~124-362 است (پیش‌فرض: 124). | INT | بله | 5 تا 3600 (گام 17) |
| `اندازه تصویر مرجع` | اندازه‌بندی تصویر ارجاعی. `match` هر تصویر ارجاعی را فقط کوچک‌تر می‌کند و نسبت ابعاد را حفظ می‌کند تا به ناحیه پیکسل تولید برسد؛ `max` از لبه کوتاه 2048px پایپ‌لاین ارجاع برای بهترین وفاداری هویت استفاده می‌کند. توکن‌های ارجاع در هر مرحله نمونه‌برداری عبور می‌کنند، بنابراین `max` می‌تواند چندین برابر کندتر باشد (پیش‌فرض: `match`). | COMBO | بله | `"match"`<br>`"max"` |
| `تصاویر مرجع` | اسلات قابل گسترش: اتصال تا 9 تصویر ارجاعی (`ref_image_1` ... `ref_image_9`). تصاویر ارجاعی اگر بزرگ‌تر باشند به لبه کوتاه 2048px کاهش مقیاس می‌یابند و هرگز بزرگ‌نمایی نمی‌شوند. | IMAGE | خیر | 0 تا 9 |
| `ویدیوهای مرجع` | اسلات قابل گسترش: اتصال تا 3 ویدیوی ارجاعی (`ref_video_1` ... `ref_video_3`). فریم‌های ویدیوی ارجاعی در 24 fps (2-15s). | IMAGE | خیر | 0 تا 3 |
| `صداهای ویدیوی مرجع` | اسلات قابل گسترش: اتصال تا 3 صوت همراه (`ref_video_audio_1` ... `ref_video_audio_3`). صوت همراه ویدیوی ارجاعی با شماره یکسان. | AUDIO | خیر | 0 تا 3 |
| `صداهای مرجع` | اسلات قابل گسترش: اتصال تا 3 کلیپ صوتی ارجاعی مستقل (`ref_audio_1` ... `ref_audio_3`). | AUDIO | خیر | 0 تا 3 |

Notes:

- پرامپت با برچسب‌های مبتنی بر ۱ برای هر نوع به رسانه‌های ارجاعی اشاره می‌کند: `<Picture i>` برای تصاویر، `<Video k>` برای ویدیوها و `<Audio j>` برای صوت. ارجاع‌ها به ترتیب ثابتی به مدل ارائه می‌شوند: تصاویر، سپس ویدیوها (با برچسب `<Audio j>` هر صوت همراه درست قبل از `<Video k>` آن)، سپس صوت مستقل.
- صوت همراه متصل به `ref_video_audio_N` با ویدیوی ارجاعی متصل به `ref_video_N` استفاده می‌شود.
- ویدیوهای ارجاعی باید حداقل حاوی 5 فریم (~0.2 ثانیه در 24 fps) باشند، در غیر این صورت گره خطا می‌دهد. فریم‌های فراتر از `length` درخواستی بریده می‌شوند و تعداد فریم باقی‌مانده به مقداری که توسط مدل پشتیبانی می‌شود تنظیم می‌گردد.
- `length` درخواستی قبل از ایجاد لاتنت، با تعداد فریم پشتیبانی‌شده هم‌تراز می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `مثبت` | شرایط شامل پرامپت کدگذاری شده. وقتی رسانه‌های ارجاعی و VAEهای مرتبط ارائه شوند، همچنین شامل محتوای تصویر، ویدیو و صوت ارجاعی کدگذاری شده است که توسط مدل MiniMax H3 استفاده می‌شود. | CONDITIONING |
| `latent` | لاتنت خالی صوتی-تصویری در `width`، `height` و `length` (تعداد فریم) درخواستی. | LATENT |
