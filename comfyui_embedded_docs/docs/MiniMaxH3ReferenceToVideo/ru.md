# MiniMax H3: референс в видео

Узел MiniMax H3 Reference to Video создает текстовый кондишининг и пустой аудио-видео латент, необходимые для генерации видео по эталону MiniMax H3. Вы предоставляете промпт, а также необязательные эталонные изображения, видео и аудиоклипы, а узел кодирует эти эталоны в кондишининг, который модель может использовать при генерации. Промпт ссылается на эталоны с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>`.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip` | Модель CLIP, используемая для токенизации промпта и кодирования эталонных медиа в токены кондишининга. | CLIP | Да | |
| `vae` | Видео VAE, используемый для кодирования эталонных изображений и кадров эталонных видео. Без него эталонные изображения/видео влияют только на текстовый энкодер. | VAE | Нет | |
| `audio_vae` | Аудио VAE, используемый для кодирования эталонного аудио. Аудио передискретизируется до частоты дискретизации аудио VAE (по умолчанию 32 кГц). Без него эталонное аудио влияет только на текстовый энкодер. | VAE | Нет | |
| `prompt` | Текстовый промпт для видео. На эталонные медиа можно ссылаться с помощью тегов `<Picture i>`, `<Video k>` и `<Audio j>` (индексация с 1 для каждого типа). Поддерживает многострочные и динамические промпты. | STRING | Да | |
| `width` | Ширина генерируемого видео в пикселях (по умолчанию: 1344). | INT | Да | 32 до 16384 (шаг 32) |
| `height` | Высота генерируемого видео в пикселях (по умолчанию: 768). | INT | Да | 32 до 16384 (шаг 32) |
| `length` | Количество кадров при 24 fps; 124 = ~5 секунд, обученный диапазон ~124-362 (по умолчанию: 124). | INT | Да | 5 до 3600 (шаг 17) |
| `ref_image_size` | Определение размера эталонного изображения. `match` уменьшает каждое эталонное изображение, сохраняя соотношение сторон, до площади (в пикселях) генерируемого видео; `max` использует короткую сторону 2048px из конвейера эталонов для наилучшего сохранения идентичности. Токены эталонов обрабатываются на каждом шаге сэмплирования, поэтому `max` может быть в несколько раз медленнее (по умолчанию: `match`). | COMBO | Да | `"match"`<br>`"max"` |
| `ref_images` | Расширяемый слот: можно подключить до 9 эталонных изображений (`ref_image_1` ... `ref_image_9`). Эталонные изображения уменьшаются до короткой стороны 2048 пикселей, если они крупнее, и никогда не увеличиваются. | IMAGE | Нет | 0 до 9 |
| `ref_videos` | Расширяемый слот: можно подключить до 3 эталонных видео (`ref_video_1` ... `ref_video_3`). Кадры эталонного видео при 24 fps (2-15 секунд). | IMAGE | Нет | 0 до 3 |
| `ref_video_audios` | Расширяемый слот: можно подключить до 3 звуковых дорожек (`ref_video_audio_1` ... `ref_video_audio_3`). Звуковая дорожка эталонного видео с тем же номером. | AUDIO | Нет | 0 до 3 |
| `ref_audios` | Расширяемый слот: можно подключить до 3 отдельных эталонных аудиоклипов (`ref_audio_1` ... `ref_audio_3`). | AUDIO | Нет | 0 до 3 |

Примечания:

- Промпт ссылается на эталонные медиа с помощью индексов, начинающихся с 1 для каждого типа: `<Picture i>` для изображений, `<Video k>` для видео и `<Audio j>` для аудио. Эталоны передаются модели в фиксированном порядке: сначала изображения, затем видео (при этом метка `<Audio j>` каждой звуковой дорожки расположена непосредственно перед её `<Video k>`), затем отдельные аудио.
- Звуковая дорожка, подключенная к `ref_video_audio_N`, используется с эталонным видео, подключенным к `ref_video_N`.
- Эталонные видео должны содержать не менее 5 кадров (~0,2 секунды при 24 fps), в противном случае узел выдаст ошибку. Кадры сверх запрошенного `length` обрезаются, а оставшееся количество кадров корректируется до значения, поддерживаемого моделью.
- Запрошенное `length` выравнивается до поддерживаемого количества кадров перед созданием латента.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Кондишининг, содержащий закодированный промпт. Если вместе с эталонными медиа предоставлены соответствующие VAE, он также содержит закодированное содержимое эталонных изображений, видео и аудио, используемых моделью MiniMax H3. | CONDITIONING |
| `latent` | Пустой аудио-видео латент с запрошенными `width`, `height` и `length` (количество кадров). | LATENT |
