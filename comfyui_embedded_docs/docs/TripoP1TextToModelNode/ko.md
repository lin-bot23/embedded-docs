# Tripo P1: 텍스트 → 모델

Tripo P1 텍스트-투-3D. 이 노드는 Tripo P1 API를 사용하여 텍스트 설명으로부터 3D 모델을 생성합니다. 안정적인 토폴로지를 갖춘 로우 폴리, 게임용 메시 제작에 최적화되어 있어 실시간 애플리케이션에 적합합니다.

## 입력

### 공통 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `출력 모드` | 생성된 모델이 지오메트리만 포함할지, 아니면 색상/PBR 텍스처도 포함할지 제어합니다. "Geometry only"는 텍스처가 없는 메시를 반환합니다. "Textured"는 색상/PBR 맵을 추가하고 아래의 텍스처 옵션을 표시합니다. | DYNAMIC_COMBO | 예 | `"Geometry only"`<br>`"Textured"` |
| `프롬프트` | 생성하고자 하는 3D 모델의 텍스트 설명입니다. 최대 1024자까지 입력할 수 있습니다. 필수 입력 사항이며 비워둘 수 없습니다. | STRING | 예 | 최대 1024자 |
| `네거티브 프롬프트` | 생성된 모델에 포함되지 않기를 원하는 내용을 설명하는 텍스트입니다. 최대 255자까지 입력할 수 있습니다. 기본값: 설정되지 않음. | STRING | 아니오 | 최대 255자 |
| `이미지 시드` | 무작위성을 제어하는 데 사용되는 시드 값입니다. 기본값: 42. | INT | 아니오 | 0 ~ 2147483647 |
| `페이스 제한` | 목표 면 수입니다. 48-20000 범위입니다. -1은 Tripo가 적응형으로 선택하도록 합니다. 기본값: -1. | INT | 아니오 | -1 ~ 20000 |
| `모델 시드` | 무작위성을 제어하는 데 사용되는 시드 값입니다. 기본값: 42. | INT | 아니오 | 0 ~ 2147483647 |
| `자동 크기 조정` | 출력을 실제 미터 단위에 근사하도록 크기를 조정합니다. 기본값: False. | BOOLEAN | 아니오 | True / False |
| `UV 내보내기` | 생성 중 UV 언랩을 수행합니다. 지오메트리 전용 실행을 더 빠르게 하려면 끄십시오. 기본값: True. | BOOLEAN | 아니오 | True / False |
| `지오메트리 압축` | meshopt 지오메트리 압축(EXT_meshopt_compression)을 적용합니다. 파일 크기가 작아지지만 ComfyUI의 3D 미리보기에서는 표시할 수 없으므로 편집하기 전에 압축을 해제하십시오. 기본값: False. | BOOLEAN | 아니오 | True / False |

### Geometry only 입력

`output_mode`가 `"Geometry only"`로 설정된 경우 추가 입력을 사용할 수 없습니다. 이 모드에서는 텍스처 관련 매개변수가 Tripo로 전송되지 않습니다.

### Textured 입력

이 입력은 `output_mode`가 `"Textured"`로 설정된 경우에만 나타납니다.

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `pbr` | PBR 맵을 포함합니다. 켜면 기본 텍스처도 강제로 켜집니다. 기본값: True. | BOOLEAN | 예 | True / False |
| `texture_quality` | 텍스처 품질 프리셋입니다. detailed = HD 텍스처, extreme = 8K 울트라 텍스처. 기본값: "standard". | COMBO | 예 | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | 텍스처 생성용 시드 값으로, 무작위성을 제어하는 데 사용됩니다. 기본값: 42. | INT | 예 | 0 ~ 2147483647 |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `모델 파일` | 생성된 모델 파일 이름으로, 하위 호환성을 위해서만 유지됩니다. | STRING |
| `모델 task_id` | 모델 생성 요청에 대한 고유 작업 ID입니다. | MODEL_TASK_ID |
| `GLB` | GLB 형식으로 생성된 3D 모델입니다. | FILE3DGLB |
