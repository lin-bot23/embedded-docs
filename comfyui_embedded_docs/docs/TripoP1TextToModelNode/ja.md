# Tripo P1：テキストからモデルへ

Tripo P1 text-to-3D。このノードは、Tripo P1 API を使用してテキスト記述から 3D モデルを生成します。安定したトポロジーを持つ低ポリゴンでゲーム向けのメッシュ作成に最適化されており、リアルタイムアプリケーションに適しています。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `出力モード` | 生成されるモデルにジオメトリのみを含めるか、カラー/PBR テクスチャも含めるかを制御します。"Geometry only" はテクスチャなしのメッシュを返します。"Textured" はカラー/PBR マップを追加し、以下のテクスチャオプションを表示します。 | DYNAMIC_COMBO | はい | `"Geometry only"`<br>`"Textured"` |
| `プロンプト` | 生成したい 3D モデルのテキスト記述。最大 1024 文字。必須で、空にできません。 | STRING | はい | 最大 1024 文字 |
| `ネガティブプロンプト` | 生成されたモデルに含めたくない内容を記述するテキスト。最大 255 文字。デフォルト: 未設定。 | STRING | いいえ | 最大 255 文字 |
| `画像シード` | ランダム性を制御するために使用されるシード値。デフォルト: 42。 | INT | いいえ | 0～2147483647 |
| `面数制限` | 目標の面数、48～20000。-1 を指定すると Tripo が適応的に選択します。デフォルト: -1。 | INT | いいえ | -1～20000 |
| `モデルシード` | ランダム性を制御するために使用されるシード値。デフォルト: 42。 | INT | いいえ | 0～2147483647 |

### ジオメトリのみ入力

`output_mode` が `"Geometry only"` に設定されている場合、追加の入力はありません。このモードでは、テクスチャ関連のパラメータは Tripo に送信されません。

### テクスチャ付き入力

これらの入力は、`output_mode` が `"Textured"` に設定されている場合にのみ表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `pbr` | PBR マップを含めます。オンの場合、ベーステクスチャも強制的にオンになります。デフォルト: True。 | BOOLEAN | はい | True / False |
| `texture_quality` | テクスチャ品質プリセット。detailed = HD テクスチャ、extreme = 8K Ultra テクスチャ。デフォルト: "standard"。 | COMBO | はい | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | テクスチャ生成用のシード値で、ランダム性を制御するために使用します。デフォルト: 42。 | INT | はい | 0～2147483647 |
