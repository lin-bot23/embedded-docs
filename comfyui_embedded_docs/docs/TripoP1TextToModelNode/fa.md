# Tripo P1: تبدیل متن به مدل

این گره با استفاده از API Tripo P1 از روی توضیح متنی، یک مدل سه‌بعدی تولید می‌کند. برای ایجاد مش‌های کم‌پولی (low-poly) و آماده برای بازی با توپولوژی پایدار بهینه شده است و برای برنامه‌های بلادرنگ مناسب می‌باشد.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | کنترل می‌کند که مدل تولید شده فقط شامل هندسه باشد یا بافت‌های رنگی/PBR نیز داشته باشد. انتخاب "Textured" ورودی‌های بافت را در پایین اضافه می‌کند. "Geometry only" یک مش بدون بافت برمی‌گرداند؛ "Textured" نقشه‌های رنگ/PBR را اضافه می‌کند. | DYNAMIC_COMBO | بله | `"Geometry only"`<br>`"Textured"` |
| `prompt` | توضیح متنی مدل سه‌بعدی که می‌خواهید تولید کنید. | STRING | بله | تا 1024 کاراکتر |
| `negative_prompt` | یک توضیح متنی از آنچه نمی‌خواهید در مدل تولید شده باشد. | STRING | خیر | تا 255 کاراکتر |
| `image_seed` | مقدار seed برای تولید تصویر، استفاده برای کنترل تصادفی بودن. پیش‌فرض: 42. | INT | خیر | 0 تا 2147483647 |
| `face_limit` | تعداد وجه هدف، 48-20000. مقدار -1 به Tripo اجازه می‌دهد به صورت تطبیقی انتخاب کند. پیش‌فرض: -1. | INT | خیر | -1 تا 20000 |
| `model_seed` | مقدار seed برای تولید مدل، استفاده برای کنترل تصادفی بودن. پیش‌فرض: 42. | INT | خیر | 0 تا 2147483647 |
| `auto_size` | مقیاس خروجی برای تقریب مترهای دنیای واقعی. پیش‌فرض: False. | BOOLEAN | خیر | True / False |
| `export_uv` | باز کردن UV هنگام تولید. برای اجرای سریع‌تر فقط هندسه، خاموش کنید. پیش‌فرض: True. | BOOLEAN | خیر | True / False |
| `compress_geometry` | اعمال فشرده‌سازی هندسه meshopt (EXT_meshopt_compression). فایل‌های کوچک‌تر، اما پیش‌نمایش سه‌بعدی ComfyUI نمی‌تواند آن‌ها را نمایش دهد؛ قبل از ویرایش از حالت فشرده خارج کنید. پیش‌فرض: False. | BOOLEAN | خیر | True / False |

### ورودی‌های فقط هندسه

وقتی `output_mode` روی `"Geometry only"` تنظیم شده است، ورودی اضافی وجود ندارد. پارامترهای مربوط به بافت در این حالت به Tripo ارسال نمی‌شوند.

### ورودی‌های بافت‌دار

این ورودی‌ها فقط زمانی ظاهر می‌شوند که `output_mode` روی `"Textured"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `pbr` | شامل نقشه‌های PBR. وقتی روشن است، بافت پایه نیز اجباری می‌شود. پیش‌فرض: True. | BOOLEAN | بله | True / False |
| `texture_quality` | از پیش‌تنظیم کیفیت بافت. detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra. پیش‌فرض: "standard". | COMBO | بله | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | مقدار seed برای تولید بافت، استفاده برای کنترل تصادفی بودن. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | مسیر فایل به مدل سه‌بعدی تولید شده، فقط برای سازگاری معکوس نگهداری می‌شود. | STRING |
| `model task_id` | شناسه وظیفه منحصر به فرد برای درخواست تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولید شده در فرمت GLB. | FILE3DGLB |
