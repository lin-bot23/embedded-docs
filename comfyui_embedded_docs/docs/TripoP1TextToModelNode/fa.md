# Tripo P1: تبدیل متن به مدل

Tripo P1 متن‌به‌سه‌بعدی. این گره با استفاده از API Tripo P1 یک مدل سه‌بعدی از توضیحات متنی تولید می‌کند. این گره برای ساخت مش‌های کم‌چندضلعی (low-poly) و آماده بازی با توپولوژی پایدار بهینه شده است و برای کاربردهای بلادرنگ مناسب است.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `حالت خروجی` | کنترل می‌کند که مدل تولیدشده فقط شامل هندسه باشد یا رنگ/بافت‌های PBR نیز داشته باشد. «Geometry only» یک مش بدون بافت برمی‌گرداند. «Textured» نقشه‌های رنگ/PBR را اضافه می‌کند و گزینه‌های بافت زیر را نمایش می‌دهد. | DYNAMIC_COMBO | بله | `"Geometry only"`<br>`"Textured"` |
| `پرامپت` | توضیح متنی مدل سه‌بعدی که می‌خواهید تولید کنید. حداکثر 1024 کاراکتر. الزامی است و نمی‌تواند خالی باشد. | STRING | بله | حداکثر 1024 کاراکتر |
| `پرامپت منفی` | توضیح متنی چیزی که نمی‌خواهید در مدل تولیدشده وجود داشته باشد. حداکثر 255 کاراکتر. پیش‌فرض: تنظیم‌نشده. | STRING | خیر | حداکثر 255 کاراکتر |
| `بذر تصویر` | مقدار seed برای کنترل تصادفی‌بودن. پیش‌فرض: 42. | INT | خیر | 0 تا 2147483647 |
| `محدودیت وجه` | تعداد وجه هدف، 48-20000. مقدار -1 به Tripo اجازه می‌دهد به‌صورت تطبیقی انتخاب کند. پیش‌فرض: -1. | INT | خیر | -1 تا 20000 |
| `بذر مدل` | مقدار seed برای کنترل تصادفی‌بودن. پیش‌فرض: 42. | INT | خیر | 0 تا 2147483647 |
| `اندازه خودکار` | خروجی را طوری مقیاس‌دهی می‌کند که تقریبی از ابعاد واقعی بر حسب متر باشد. پیش‌فرض: False. | BOOLEAN | خیر | True / False |
| `خروجی UV` | در طول تولید، UV unwrap را انجام می‌دهد. برای اجراهای سریع‌تر فقط-هندسه، خاموش کنید. پیش‌فرض: True. | BOOLEAN | خیر | True / False |
| `فشرده‌سازی هندسه` | فشرده‌سازی هندسه meshopt را اعمال می‌کند (EXT_meshopt_compression). فایل‌های کوچک‌تر، اما پیش‌نمایش سه‌بعدی ComfyUI نمی‌تواند آن‌ها را نمایش دهد؛ پیش از ویرایش، از حالت فشرده خارج کنید. پیش‌فرض: False. | BOOLEAN | خیر | True / False |

### ورودی‌های Geometry only

هنگامی که `output_mode` روی `"Geometry only"` تنظیم شود، هیچ ورودی اضافه‌ای در دسترس نیست. پارامترهای مرتبط با بافت در این حالت به Tripo فرستاده نمی‌شوند.

### ورودی‌های Textured

این ورودی‌ها فقط زمانی نمایش داده می‌شوند که `output_mode` روی `"Textured"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `pbr` | نقشه‌های PBR را شامل می‌شود. وقتی روشن باشد، بافت پایه نیز اجباراً روشن می‌شود. پیش‌فرض: True. | BOOLEAN | بله | True / False |
| `texture_quality` | پیش‌تنظیم کیفیت بافت. detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra. پیش‌فرض: "standard". | COMBO | بله | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | مقدار seed برای تولید بافت، که برای کنترل تصادفی‌بودن استفاده می‌شود. پیش‌فرض: 42. | INT | بله | 0 تا 2147483647 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | نام فایل مدل تولیدشده؛ فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `شناسه وظیفه مدل` | شناسه یکتای وظیفه برای درخواست تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB. | FILE3DGLB |
