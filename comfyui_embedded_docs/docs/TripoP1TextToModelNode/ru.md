# Tripo P1: Текст в Модель

Tripo P1 для преобразования текста в 3D. Этот узел генерирует 3D-модель по текстовому описанию с помощью API Tripo P1. Он оптимизирован для создания низкополигональных, готовых для игр мешей со стабильной топологией, что делает его подходящим для приложений реального времени.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | Управляет тем, содержит ли сгенерированная модель только геометрию или также цветовые/PBR-текстуры. "Geometry only" возвращает меш без текстуры. "Textured" добавляет цветовые/PBR-карты и открывает параметры текстуры ниже. | DYNAMIC_COMBO | Да | `"Geometry only"`<br>`"Textured"` |
| `prompt` | Текстовое описание 3D-модели, которую вы хотите сгенерировать. До 1024 символов. Обязательный параметр, не может быть пустым. | STRING | Да | До 1024 символов |
| `negative_prompt` | Текстовое описание того, чего вы не хотите видеть в сгенерированной модели. До 255 символов. По умолчанию: не задано. | STRING | Нет | До 255 символов |
| `image_seed` | Значение seed, используемое для управления случайностью. По умолчанию: 42. | INT | Нет | 0–2147483647 |
| `face_limit` | Целевое количество полигонов, 48–20000. -1 позволяет Tripo выбрать адаптивно. По умолчанию: -1. | INT | Нет | от -1 до 20000 |
| `model_seed` | Значение seed, используемое для управления случайностью. По умолчанию: 42. | INT | Нет | 0–2147483647 |
| `auto_size` | Масштабировать вывод до приблизительного соответствия реальным размерам в метрах. По умолчанию: False. | BOOLEAN | Нет | True / False |
| `export_uv` | Выполнять UV-развёртку во время генерации. Отключите для более быстрых запусков только с геометрией. По умолчанию: True. | BOOLEAN | Нет | True / False |
| `compress_geometry` | Применять сжатие геометрии meshopt (EXT_meshopt_compression). Файлы меньше, но 3D-просмотр в ComfyUI не может их отображать; распакуйте перед редактированием. По умолчанию: False. | BOOLEAN | Нет | True / False |

### Входы только геометрии

Дополнительные входы недоступны, когда для `output_mode` установлено значение `"Geometry only"`. Параметры, связанные с текстурами, в этом режиме не отправляются в Tripo.

### Входы с текстурами

Эти входы появляются только когда для `output_mode` установлено значение `"Textured"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pbr` | Включать PBR-карты. При включении также принудительно включается базовая текстура. По умолчанию: True. | BOOLEAN | Да | True / False |
| `texture_quality` | Предустановка качества текстур. detailed = HD-текстуры, extreme = 8K Ultra-текстуры. По умолчанию: "standard". | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | Значение seed для генерации текстуры, используемое для управления случайностью. По умолчанию: 42. | INT | Да | 0–2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя сгенерированного файла модели, сохранено только для обратной совместимости. | STRING |
| `model task_id` | Уникальный идентификатор задачи для запроса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
