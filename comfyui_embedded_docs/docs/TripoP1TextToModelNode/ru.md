# Tripo P1: Текст в Модель

Этот узел генерирует 3D-модель по текстовому описанию с помощью API Tripo P1. Он оптимизирован для создания низкополигональных моделей, готовых к использованию в играх, со стабильной топологией, что делает его подходящим для приложений реального времени.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `output_mode` | Управляет тем, содержит ли сгенерированная модель только геометрию или также цветовые/PBR-текстуры. Выбор «Textured» добавляет входы текстур ниже. «Geometry only» возвращает сетку без текстур; «Textured» добавляет цветовые/PBR-карты. | DYNAMIC_COMBO | Да | `"Geometry only"`<br>`"Textured"` |
| `prompt` | Текстовое описание 3D-модели, которую вы хотите сгенерировать. До 1024 символов. | STRING | Да | До 1024 символов |
| `negative_prompt` | Текстовое описание того, чего не должно быть в сгенерированной модели. До 255 символов. | STRING | Нет | До 255 символов |
| `image_seed` | Значение seed для генерации изображения, используемое для управления случайностью. По умолчанию: 42. | INT | Нет | 0 до 2147483647 |
| `face_limit` | Целевое количество граней: 48–20000. Значение -1 позволяет Tripo выбирать адаптивно. По умолчанию: -1. | INT | Нет | -1 до 20000 |
| `model_seed` | Значение seed для генерации модели, используемое для управления случайностью. По умолчанию: 42. | INT | Нет | 0 до 2147483647 |
| `auto_size` | Масштабировать выход примерно до реальных метров. По умолчанию: False. | BOOLEAN | Нет | True / False |
| `export_uv` | Развертка UV во время генерации. Отключите для более быстрых запусков только с геометрией. По умолчанию: True. | BOOLEAN | Нет | True / False |
| `compress_geometry` | Применить сжатие геометрии meshopt (EXT_meshopt_compression). Файлы меньше, но предпросмотр 3D в ComfyUI не может их отобразить; распакуйте перед редактированием. По умолчанию: False. | BOOLEAN | Нет | True / False |

### Входы режима «Только геометрия»

Никакие дополнительные входы недоступны, когда `output_mode` установлен в `"Geometry only"`. Параметры, связанные с текстурами, в этом режиме не отправляются в Tripo.

### Входы режима «С текстурами»

Эти входы появляются только когда `output_mode` установлен в `"Textured"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pbr` | Включить PBR-карты. При включении базовая текстура также принудительно включается. По умолчанию: True. | BOOLEAN | Да | True / False |
| `texture_quality` | Пресет качества текстур: detailed = HD-текстуры, extreme = 8K Ultra-текстуры. По умолчанию: «standard». | COMBO | Да | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | Значение seed для генерации текстур, используемое для управления случайностью. По умолчанию: 42. | INT | Да | 0 до 2147483647 |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Путь к файлу сгенерированной 3D-модели; сохранён только для обратной совместимости. | STRING |
| `model task_id` | Уникальный идентификатор задачи запроса на генерацию модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
