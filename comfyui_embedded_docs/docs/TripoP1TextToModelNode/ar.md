# Tripo P1: تحويل النص إلى نموذج

Tripo P1 من النص إلى ثلاثي الأبعاد. تُنشئ هذه العقدة نموذجًا ثلاثي الأبعاد من وصف نصي باستخدام واجهة برمجة تطبيقات Tripo P1. وهي مُحسّنة لإنشاء شبكات منخفضة المضلعات وجاهزة للألعاب ذات طوبولوجيا مستقرة، مما يجعلها مناسبة لتطبيقات الزمن الحقيقي.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `وضع الإخراج` | يتحكم فيما إذا كان النموذج المُولّد يحتوي على الهندسة فقط أم يحتوي أيضًا على ألوان/أنسجة PBR. يعيد "Geometry only" شبكة بدون أنسجة. يضيف "Textured" خرائط ألوان/PBR ويكشف خيارات النسيج أدناه. | DYNAMIC_COMBO | نعم | `"Geometry only"`<br>`"Textured"` |
| `النص` | الوصف النصي للنموذج ثلاثي الأبعاد الذي تريد توليده. حتى 1024 حرفًا. مطلوب ولا يمكن أن يكون فارغًا. | STRING | نعم | حتى 1024 حرفًا |
| `النص السلبي` | وصف نصي لما لا تريده في النموذج المُولّد. حتى 255 حرفًا. الافتراضي: غير محدد. | STRING | لا | حتى 255 حرفًا |
| `بذرة الصورة` | قيمة بذرة تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | لا | 0 إلى 2147483647 |
| `حد الأوجه` | عدد الأوجه المستهدف، 48-20000. القيمة -1 تدع Tripo يختار تكيفيًا. الافتراضي: -1. | INT | لا | -1 إلى 20000 |
| `بذرة النموذج` | قيمة بذرة تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | لا | 0 إلى 2147483647 |
| `تغيير الحجم تلقائيًا` | تحجيم الناتج ليقارب الأمتار في العالم الحقيقي. الافتراضي: False. | BOOLEAN | لا | True / False |
| `تصدير UV` | فك UV أثناء التوليد. أوقفه لعمليات أسرع بالهندسة فقط. الافتراضي: True. | BOOLEAN | لا | True / False |
| `ضغط الهندسة` | تطبيق ضغط الهندسة meshopt (EXT_meshopt_compression). ملفات أصغر، لكن معاينة ComfyUI ثلاثية الأبعاد لا يمكنها عرضها؛ فك الضغط قبل التحرير. الافتراضي: False. | BOOLEAN | لا | True / False |

### مدخلات Geometry only

لا تتوفر مدخلات إضافية عندما يكون `output_mode` مضبوطًا على `"Geometry only"`. لا تُرسَل المعاملات المتعلقة بالنسيج إلى Tripo في هذا الوضع.

### مدخلات Textured

تظهر هذه المدخلات فقط عندما يكون `output_mode` مضبوطًا على `"Textured"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | تضمين خرائط PBR. عند تشغيله، يتم فرض تشغيل النسيج الأساسي أيضًا. الافتراضي: True. | BOOLEAN | نعم | True / False |
| `texture_quality` | إعداد مسبق لجودة النسيج. detailed = أنسجة HD، extreme = أنسجة 8K Ultra. الافتراضي: "standard". | COMBO | نعم | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | قيمة بذرة لتوليد النسيج، تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | نعم | 0 إلى 2147483647 |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | اسم ملف النموذج المُولّد، محفوظ للتوافق مع الإصدارات السابقة فقط. | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة الفريد لطلب توليد النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُولّد بصيغة GLB. | FILE3DGLB |
