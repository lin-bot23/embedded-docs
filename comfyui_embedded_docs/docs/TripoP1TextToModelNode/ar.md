# Tripo P1: تحويل النص إلى نموذج

تنشئ هذه العقدة نموذجًا ثلاثي الأبعاد من وصف نصي باستخدام واجهة برمجة تطبيقات Tripo P1. وهي مُحسَّنة لإنشاء شبكات منخفضة المضلعات وجاهزة للألعاب ذات طوبولوجيا مستقرة، مما يجعلها مناسبة لتطبيقات الوقت الفعلي.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `وضع الإخراج` | يتحكم فيما إذا كان النموذج المُنشأ يحتوي على الهندسة فقط أم يتضمن أيضًا ألوانًا/خرائط PBR. يؤدي اختيار "Textured" إلى إضافة مدخلات النسيج أدناه. يُرجع "Geometry only" شبكة بدون نسيج؛ بينما يضيف "Textured" خرائط الألوان/PBR. | DYNAMIC_COMBO | نعم | `"Geometry only"`<br>`"Textured"` |
| `النص` | الوصف النصي للنموذج ثلاثي الأبعاد الذي تريد توليده. يصل إلى 1024 حرفًا. | STRING | نعم | حتى 1024 حرفًا |
| `النص السلبي` | وصف نصي لما لا تريده في النموذج المُنشأ. يصل إلى 255 حرفًا. | STRING | لا | حتى 255 حرفًا |
| `بذرة الصورة` | قيمة بذرة لتوليد الصور، تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | لا | من 0 إلى 2147483647 |
| `حد الأوجه` | عدد الوجوه المستهدف، من 48 إلى 20000. القيمة -1 تسمح لـ Tripo بالاختيار التكيفي. الافتراضي: -1. | INT | لا | من -1 إلى 20000 |
| `بذرة النموذج` | قيمة بذرة لتوليد النماذج، تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | لا | من 0 إلى 2147483647 |
| `تغيير الحجم تلقائيًا` | قياس المخرجات لتقريب الأبعاد بالمتر الحقيقي. الافتراضي: False. | BOOLEAN | لا | True / False |
| `تصدير UV` | فرد إحداثيات UV أثناء التوليد. أوقف تشغيله لعمليات الهندسة فقط الأسرع. الافتراضي: True. | BOOLEAN | لا | True / False |
| `ضغط الهندسة` | تطبيق ضغط هندسة meshopt (EXT_meshopt_compression). ملفات أصغر، لكن المعاينة ثلاثية الأبعاد في ComfyUI لا يمكنها عرضها؛ فك الضغط قبل التحرير. الافتراضي: False. | BOOLEAN | لا | True / False |

### مدخلات الهندسة فقط

لا تتوفر مدخلات إضافية عندما يتم تعيين `output_mode` إلى `"Geometry only"`. لا يتم إرسال المعاملات المتعلقة بالنسيج إلى Tripo في هذا الوضع.

### مدخلات النسيج

تظهر هذه المدخلات فقط عندما يتم تعيين `output_mode` إلى `"Textured"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | تضمين خرائط PBR. عند التشغيل، يتم فرض تشغيل النسيج الأساسي أيضًا. الافتراضي: True. | BOOLEAN | نعم | True / False |
| `texture_quality` | إعداد مسبق لجودة النسيج. detailed = نسيج عالي الدقة، extreme = نسيج فائق بدقة 8K. الافتراضي: "standard". | COMBO | نعم | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_seed` | قيمة بذرة لتوليد النسيج، تُستخدم للتحكم في العشوائية. الافتراضي: 42. | INT | نعم | من 0 إلى 2147483647 |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | مسار ملف النموذج ثلاثي الأبعاد المُنشأ، محفوظ للتوافق مع الإصدارات السابقة فقط. | STRING |
| `معرّف مهمة النموذج` | المعرّف الفريد للمهمة الخاصة بطلب توليد النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُنشأ بصيغة GLB. | FILE3DGLB |
