# 明るさを調整

Adjust Brightness ノードは、入力画像の明るさを調整します。各ピクセルの値に指定された係数を乗算し、その結果の値を有効な範囲内に収めるようにクランプすることで動作します。係数が 1.0 の場合は画像は変更されず、1.0 未満の値では暗くなり、1.0 を超える値では明るくなります。入力画像にアルファチャンネルがある場合、アルファチャンネルは変更されずにそのまま維持され、透明度が保持されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `image` | 調整する入力画像。 | IMAGE | はい | - |
| `係数` | 明るさ係数。1.0 = 変更なし、<1.0 = 暗く、>1.0 = 明るく。（デフォルト: 1.0） | FLOAT | いいえ | 0.0 - 2.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `画像` | 明るさが調整された出力画像。 | IMAGE |
