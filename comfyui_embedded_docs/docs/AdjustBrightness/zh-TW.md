# 調整亮度

調整亮度節點用於改變影像的明暗程度。它會將影像的色彩值乘以一個 `factor` 係數，並將結果限制在有效的 0.0 到 1.0 範圍內。係數為 1.0 時影像保持不變，小於 1.0 會使影像變暗，大於 1.0 則會使影像變亮。

## 輸入

| 參數 | 描述 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `image` | 要調整的輸入影像。接受單張影像或一批影像。 | IMAGE | 是 | - |
| `亮度係數` | 亮度係數。1.0 = 不變，<1.0 = 變暗，>1.0 = 變亮。（預設值：1.0） | FLOAT | 否 | 0.0 - 2.0 |

注意：如果輸入影像帶有 Alpha 色版（RGBA），只會調整色彩色版。Alpha 色版會原封不動地從輸入複製過來，因為它儲存的是透明度，而非色彩。

## 輸出

| 輸出名稱 | 描述 | 資料類型 |
| --- | --- | --- |
| `影像` | 調整亮度後的輸出影像。如果輸入帶有 Alpha 色版，Alpha 數值會保持不變。 | IMAGE |
