# Регулировка яркости

Узел Adjust Brightness изменяет яркость изображения. Он умножает цветовые значения изображения на `factor` и удерживает результат в допустимом диапазоне от 0.0 до 1.0. Коэффициент 1.0 оставляет изображение без изменений, значения ниже 1.0 делают его темнее, а значения выше 1.0 — ярче.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение для корректировки. Принимает одно изображение или пакет изображений. | IMAGE | Да | - |
| `коэффициент` | Коэффициент яркости. 1.0 = без изменений, <1.0 = темнее, >1.0 = ярче. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 2.0 |

Примечание: Если входное изображение имеет альфа-канал (RGBA), корректируются только цветовые каналы. Альфа-канал копируется из входа без изменений, так как он хранит прозрачность, а не цвет.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Выходное изображение с скорректированной яркостью. Если входное изображение имеет альфа-канал, значения альфа остаются без изменений. | IMAGE |
