# Pixal3DConditioning

## مقدمه

گره Pixal3DConditioning برای آماده‌سازی شرایط تصویر برای خطوط تولید Trellis2 3D طراحی شده است. این گره از مدل بینایی DINOv3 استفاده می‌کند تا ویژگی‌های بصری را از تصویر ورودی در دو رزولوشن استخراج کند. این ویژگی‌ها سپس به صورت نقشه‌های ویژگی مرحله‌ای سازماندهی می‌شوند که می‌توانند به صورت اختیاری با مدل NAF تقویت شوند. این گره همچنین داده‌های دوربین استخراج شده از میدان دید افقی برای محاسبه ماتریس تبدیل پروژه را نیز شامل می‌شود. این گره خروجی یک جفت شرایط مثبت را ارائه می‌دهد که شامل نقشه‌های ویژگی استخراج شده از تصویر و داده‌های پروژه است، همچنین یک جفت شرایط منفی با تانسورهای ویژگی صفر شده برای هدایت بدون کلاسور ارائه می‌دهد.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | مدل ClipVision ViT-L/16 DINOv3 مورد استفاده برای استخراج ویژگی‌ها. | CLIP_VISION | بله | — |
| `تصویر` | تصویر پیش‌پردازش شده از گره ImageCropToMask، برای Pixal3D با pad_factor 1.1. | IMAGE | بله | — |
| `camera_angle_x` | میدان دید افقی در درجه. این پارامتر می‌تواند به گره MoGeGeometryToFOV متصل شود تا میدان دید هر تصویر محاسبه شود. پیش‌فرض: 49.13. | FLOAT | بله | 1.0 – 170.0 |

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `مثبت` | خروجی شرایط مثبت که شامل نقشه‌های ویژگی استخراج شده از تصویر و داده‌های پروژه برای تولید Trellis2 است. | CONDITIONING |
| `منفی` | خروجی شرایط منفی با تانسورهای ویژگی صفر شده، برای هدایت بدون کلاسور استفاده می‌شود. | CONDITIONING |

نکته: مقدار `camera_angle_x` به صورت داخلی به رادیان تبدیل شده و برای محاسبه فاصله دوربین برای ماتریس تبدیل پروژه استفاده می‌شود. وقتی مدل دیداری ارائه شده شامل جزء NAF است، گره همچنین نقشه‌های ویژگی با رزولوشن بالا برای مراحل شکل و بافت تولید می‌کند.
