# Pixal3DConditioning

Этот узел подготавливает кондиционирование изображения для конвейера генерации 3D Trellis2. Он извлекает визуальные признаки из входного изображения с помощью модели компьютерного зрения DINOv3 в двух разрешениях, организует их в карты признаков для каждого этапа (опционально улучшенные моделью NAF) и объединяет их с данными камеры, полученными на основе горизонтального угла обзора. Выходом является пара положительного и отрицательного кондиционирования; в отрицательном для управления без классификатора используются обнулённые признаки.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | DINOv3 ViT-L/16 ClipVision. | CLIP_VISION | Да | — |
| `изображение` | Предварительно обработанное изображение из ImageCropToMask (pad_factor=1.1 для Pixal3D). | IMAGE | Да | — |
| `camera_angle_x` | Горизонтальный угол обзора в градусах (отображаемое имя: fov). Подключите узел MoGeGeometryToFOV (axis='horizontal', unit='degrees'), чтобы задавать FoV для каждого изображения (соответствует значению по умолчанию в базовой реализации). По умолчанию: 49.13. | FLOAT | Да | 1.0 – 170.0 |

Примечание: значение `camera_angle_x` внутри узла преобразуется в радианы и используется для вычисления расстояния до камеры для матрицы проекционного преобразования. Если переданная модель компьютерного зрения содержит компонент NAF, узел дополнительно создаёт карты признаков высокого разрешения для этапов формы и текстуры.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `положительное` | Положительное кондиционирование, содержащее карты признаков, извлечённые из изображения, и данные проекции для генерации Trellis2. | CONDITIONING |
| `отрицательное` | Отрицательное кондиционирование с обнулёнными тензорами признаков; используется для управления без классификатора. | CONDITIONING |
