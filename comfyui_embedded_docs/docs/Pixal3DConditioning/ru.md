```markdown
# Pixal3DConditioning

## Обзор

Узел Pixal3DConditioning предназначен для подготовки условий обработки изображений для потока генерации 3D Trellis2. Он использует визуальную модель DINOv3 для извлечения визуальных характеристик из входного изображения на двух разрешениях. Эти характеристики затем организованы в карты характеристик на каждом этапе, которые можно optionally улучшить с помощью модели NAF. Узел также включает данные камеры, полученные из горизонтального поля зрения, для вычисления матрицы проекции преобразования. Выводится положительная пара условий, которая включает карты характеристик, извлеченные из изображения, и данные проекции, а также отрицательная пара условий с нулевыми тензорами характеристик для классификатора-свободного руководства.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | Модель DINOv3 ViT-L/16 ClipVision, используемая для извлечения характеристик. | CLIP_VISION | Да | — |
| `изображение` | Обработанное изображение из узла ImageCropToMask, предназначенное для Pixal3D с pad_factor 1.1. | IMAGE | Да | — |
| `camera_angle_x` | Угол горизонтального поля зрения в градусах. Этот параметр можно подключить к узлу MoGeGeometryToFOV для поля зрения на изображение. По умолчанию: 49.13. | FLOAT | Да | 1.0 – 170.0 |

## Выводы

| Название вывода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительный вывод условий, содержащий карты характеристик, извлеченные из изображения, и данные проекции для генерации Trellis2. | CONDITIONING |
| `negative` | Отрицательный вывод условий с нулевыми тензорами характеристик, используемый для классификатора-свободного руководства. | CONDITIONING |

Примечание: Значение `camera_angle_x` внутренне преобразуется в раданы и используется для вычисления расстояния камеры для матрицы проекции преобразования. При использовании в узле модели, включающей компонент NAF, узел также производит высокоразрешенные карты характеристик для этапов формы и текстуры.
```
