# Google Gemini

با مدل‌های Gemini گوگل پاسخ‌های متنی تولید کنید. یک پرامپت متنی و به‌صورت اختیاری یک یا چند تصویر، کلیپ صوتی، ویدیو یا فایل را به‌عنوان زمینه چندوجهی ارائه دهید.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل Gemini مورد استفاده برای تولید پاسخ. | DYNAMIC_COMBO | بله | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `راهنما` | ورودی متنی به مدل. دستورالعمل‌ها، پرسش‌ها یا زمینه را به‌صورت دقیق بگنجانید. باید حداقل شامل یک نویسه غیرفاصله باشد. (پیش‌فرض: "") | STRING | بله |  |
| `seed` | بذر برای نمونه‌گیری. برای دریافت بذر تصادفی، مقدار 0 را تنظیم کنید. خروجی قطعی تضمین نمی‌شود. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |
| `system_prompt` | دستورالعمل‌های بنیادین که رفتار مدل را تعیین می‌کنند. (پیش‌فرض: "") | STRING | خیر |  |

### ورودی‌های رسانه و فایل

ورودی‌های زیر بین همه مدل‌ها مشترک‌اند و در کنار ورودی‌های مخصوص هر مدل ظاهر می‌شوند.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `images` | جایگاه قابل گسترش: 1 تا 16 تصویر را متصل کنید (`image_1` ... `image_16`). تصویر(های) اختیاری برای استفاده به‌عنوان زمینه مدل. حداکثر 16 تصویر. | IMAGE | خیر | 0 تا 16 تصویر |
| `audio` | جایگاه قابل گسترش: یک کلیپ صوتی (`audio_1`) را متصل کنید. کلیپ صوتی اختیاری برای استفاده به‌عنوان زمینه مدل. | AUDIO | خیر | 0 تا 1 کلیپ |
| `video` | جایگاه قابل گسترش: یک کلیپ ویدیویی (`video_1`) را متصل کنید. کلیپ ویدیویی اختیاری برای استفاده به‌عنوان زمینه مدل. | VIDEO | خیر | 0 تا 1 کلیپ |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه مدل. ورودی‌هایی از گره Gemini Input Files می‌پذیرد. | GEMINI_INPUT_FILES | خیر |  |

**توجه:** زمانی که رسانه (تصویر، صدا یا ویدیو) پیوست شود، گره نخستین 10 مورد رسانه‌ای را در فضای ذخیره‌سازی ComfyAPI بارگذاری می‌کند و آن‌ها را به‌صورت URL ارسال می‌کند؛ این سهمیه URL بین همه انواع رسانه مشترک است و به ترتیب مصرف می‌شود (ابتدا ویدیو، سپس صدا، سپس تصاویر). هر رسانه باقی‌مانده به‌صورت درون‌خطی با داده base64 کدگذاری می‌شود، با حداکثر حجم مجموع بار درون‌خطی 18 MB. اگر بار درون‌خطی از 18 MB فراتر رود، گره خطا ایجاد می‌کند. پارامتر `prompt` باید حداقل شامل یک نویسه غیرفاصله باشد. تنظیم `seed` روی 0 درخواست بذر تصادفی می‌کند.
