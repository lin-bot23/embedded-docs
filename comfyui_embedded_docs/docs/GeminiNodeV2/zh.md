# Google Gemini

使用 Google 的 Gemini 模型生成文本回复。提供文本提示词，并可选择提供一张或多张图像、音频片段、视频或文件作为多模态上下文。

| 参数 | 描述 | 数据类型 | 必填 | 范围 |

| `model` | 用于生成回复的 Gemini 模型。 | DYNAMIC_COMBO | 是 | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | 输入给模型的文本。请包含详细说明、问题或上下文。必须至少包含一个非空白字符。（默认值：""） | STRING | 是 |  |
