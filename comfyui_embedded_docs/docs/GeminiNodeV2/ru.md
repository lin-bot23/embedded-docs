# Google Gemini

Генерация текстовых ответов с помощью моделей Gemini от Google. Укажите текстовый запрос и при необходимости одно или несколько изображений, аудиоклипов, видео или файлов в качестве мультимодального контекста.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель Gemini, используемая для генерации ответа. | DYNAMIC_COMBO | Да | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `запрос` | Текстовый ввод для модели. Включите подробные инструкции, вопросы или контекст. Должен содержать хотя бы один символ, не являющийся пробельным. (по умолчанию: "") | STRING | Да |  |
| `seed` | Сид для сэмплирования. Установите 0 для случайного сида. Детерминированный вывод не гарантируется. (по умолчанию: 42) | INT | Да | 0 to 2147483647 |
| `системный запрос` | Базовые инструкции, определяющие поведение модели. (по умолчанию: "") | STRING | Нет |  |

### Входы Gemini 3.8 Flash

Эти входы отображаются, когда для `model` установлено значение `"Gemini 3.8 Flash"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | Насколько интенсивно модель рассуждает внутренне перед ответом. HIGH повышает качество на сложных задачах, но расходует больше токенов на размышление и работает медленнее. (по умолчанию: "MEDIUM") | COMBO | Да | `"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `max_output_tokens` | Максимальное количество токенов для генерации, включая внутренние размышления модели. При `thinking_level` HIGH низкое значение может не оставить места для ответа; увеличьте это значение, если ответы возвращаются пустыми или усечёнными. Модель останавливается раньше по завершении, поэтому более высокий лимит не требует дополнительных затрат для коротких ответов. (по умолчанию: 32768) | INT | Да | 16 to 65536 |

**Примечание:** Эта модель не предоставляет параметры сэмплирования `temperature` или `top_p`.

### Входы медиа и файлов

Следующие входы являются общими для всех моделей и отображаются вместе с входами, зависящими от модели.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `images` | Расширяемый слот: подключите от 1 до 16 изображений (`image_1` ... `image_16`). Необязательные изображения для использования в качестве контекста модели. До 16 изображений. | IMAGE | Нет | 0 to 16 images |
| `audio` | Расширяемый слот: подключите один аудиоклип (`audio_1`). Необязательный аудиоклип для использования в качестве контекста модели. | AUDIO | Нет | 0 to 1 clip |
| `video` | Расширяемый слот: подключите один видеоклип (`video_1`). Необязательный видеоклип для использования в качестве контекста модели. | VIDEO | Нет | 0 to 1 clip |
| `files` | Необязательные файлы для использования в качестве контекста модели. Принимает входы от узла Gemini Input Files. | GEMINI_INPUT_FILES | Нет |  |

**Примечание:** Когда прикреплены медиафайлы (изображения, аудио или видео), узел загружает первые 10 медиаэлементов в хранилище ComfyAPI и передаёт их как URL-адреса; этот лимит URL является общим для всех типов медиа и расходуется по порядку (сначала видео, затем аудио, затем изображения). Остальные медиафайлы кодируются встроенно как данные base64, при этом максимальный суммарный размер встроенной полезной нагрузки составляет 18 МБ. Если встроенная полезная нагрузка превысит 18 МБ, узел вызывает ошибку. Параметр `prompt` должен содержать хотя бы один символ, не являющийся пробельным. Установка `seed` в 0 запрашивает случайный сид.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный текстовый ответ от модели Gemini. Если модель не создаёт текст, возвращается строка "Empty response from Gemini model...". | STRING |
