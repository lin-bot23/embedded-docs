# Google Gemini

Google の Gemini モデルでテキスト応答を生成します。テキストプロンプトを入力し、オプションで1つ以上の画像、音声クリップ、動画、またはファイルをマルチモーダルコンテキストとして指定できます。

## 入力

### 共通入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model` | 応答の生成に使用する Gemini モデル。 | DYNAMIC_COMBO | はい | `"Gemini 3.8 Flash"`<br>`"Gemini 3.7 Flash"`<br>`"Gemini 3.5 Flash"`<br>`"Gemini 3.1 Pro"`<br>`"Gemini 3.1 Flash-Lite"` |
| `prompt` | モデルへのテキスト入力。詳細な指示、質問、またはコンテキストを含めてください。少なくとも1つの空白以外の文字を含める必要があります。（デフォルト: ""） | STRING | はい |  |
| `seed` | サンプリング用のシード。0 に設定するとランダムシードになります。決定論的な出力は保証されません。（デフォルト: 42） | INT | はい | 0～2147483647 |
| `system_prompt` | モデルの動作を規定する基盤となる指示。（デフォルト: ""） | STRING | いいえ |  |

### Gemini 3.8 Flash 入力

これらの入力は、`model` が `"Gemini 3.8 Flash"` に設定されている場合に表示されます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `thinking_level` | モデルが回答前に内部でどれだけ深く推論するか。HIGH は難しいタスクの品質を向上させますが、より多くの（思考）トークンを消費し、速度も遅くなります。（デフォルト: "MEDIUM"） | COMBO | はい | `"LOW"`<br>`"MEDIUM"`<br>`"HIGH"` |
| `max_output_tokens` | 生成する最大トークン数（モデルの内部思考を含む）。thinking_level が HIGH の場合、低い値では回答の余地がなくなる可能性があります。応答が空または切り捨てられる場合はこの値を上げてください。モデルは完了時に早期停止するため、短い応答では上限を高くしても追加コストはかかりません。（デフォルト: 32768） | INT | はい | 16～65536 |

以下の入力はすべてのモデルで共有され、モデル固有の入力と並んで表示されます。

| `audio` | 追加可能なスロット: 1 つの音声クリップ（`audio_1`）を接続します。モデルのコンテキストとして使用するオプションの音声クリップ。 | AUDIO | いいえ | 0～1 クリップ |

**注意:** メディア（画像、音声、または動画）が添付されている場合、ノードは最初の 10 件のメディア項目を ComfyAPI ストレージにアップロードし、それらを URL として渡します。この URL の枠はすべてのメディアタイプで共有され、順番に消費されます（動画、次に音声、次に画像）。残りのメディアは base64 データとしてインラインでエンコードされ、インラインのペイロードの合計上限は 18 MB です。インラインペイロードが 18 MB を超える場合、ノードはエラーを発生させます。`prompt` パラメータには、少なくとも 1 つの空白以外の文字を含める必要があります。`seed` を 0 に設定するとランダムシードが要求されます。
