# LTXVFreezeLatent

## 简介

LTXV 冻结潜在值节点旨在将给定潜在值的噪声掩码设置为 0，确保在采样过程中潜在值保持干净。它特别适用于冻结音频或视频潜在值以防止去噪，这可以在音频和视频连接用于交叉注意力之前或对于任何不应进行去噪的潜在值应用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `潜空间` | 要冻结的视频或音频潜在值。音频为 4D；视频为 5D。 | LATENT | 是 | N/A |
| `samples` | 包含潜在样本的张量。 | TENSOR | 是 | 音频：4D（批次，通道，帧，样本）；视频：5D（批次，通道，高度，宽度，帧） |

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `潜空间` | 噪声掩码设置为 0 的潜在值，确保在采样过程中保持干净。 | LATENT |

## 注意事项

- `samples` 张量必须是一个纯张量，而不是连接的音频-视频潜在值。如果是连接的潜在值，应首先使用分离 AV 潜在值节点进行拆分。
- 输出 `latent` 将具有零噪声掩码，这会防止对指定的潜在值进行去噪。
- 节点支持音频和视频潜在值，每种都有不同的张量形状。
- 如果 `samples` 张量的形状与预期的音频或视频形状不匹配，将引发 ValueError。
