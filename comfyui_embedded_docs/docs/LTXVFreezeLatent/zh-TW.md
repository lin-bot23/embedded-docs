# LTXVFreezeLatent

## 概述

LTXV 冻結潛在節點設計用於將給定潛在的 noise_mask 設為 0，確保在採樣過程中潛在保持乾淨。它特別適用於凍結音頻或視頻潛在以防止去噪，這可以在合併音頻和視頻進行交叉注意力之前或對於任何不應該去噪的潛在應用。

## 輸入

| 參數 | 描述 | 資料類型 | 必需 | 范圍 |
|-----------|-------------|-----------|----------|-------|
| `latent` | 要凍結的視頻或音頻潛在。音頻為 4D；視頻為 5D。 | LATENT | 是 | N/A |
| `samples` | 包含潛在樣本的張量。 | TENSOR | 是 | 音頻：4D（批次，通道，幀，樣本）；視頻：5D（批次，通道，高度，寬度，幀） |

## 輸出

| 輸出名 | 描述 | 資料類型 |
|-------------|-------------|-----------|
| `latent` | 將 noise_mask 設為 0 的潛在，確保它在採樣過程中保持乾淨。 | LATENT |

## 注意事項

- `samples` 張量必須是普通張量，而不是合併的音頻-視頻潛在。如果它是合併的潛在，應先使用分離 AV 潛在節點進行分割。
- 輸出的 `latent` 將具有零的 noise_mask，這會防止對指定潛在進行去噪。
- 此節點支持音頻和視頻潛在，每種潛在具有不同的張量形状。
- 如果 `samples` 張量的形状與預期的音頻或視頻形状不匹配，將引發 ValueError。
