```markdown
# LTXV Freeze Latent

## Обзор

Узел LTXV Freeze Latent предназначен для установки значения noise_mask в 0 для заданного латентного значения, что обеспечивает сохранение чистоты латентного значения в процессе采样. Он особенно полезен для замораживания латентных данных аудио или видео, чтобы предотвратить деноising, который может быть применен перед объединением аудио и видео для кросс-внимания или для любого латентного значения, которое не должно быть деноised.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `latent` | Видео или аудио латентное значение для замораживания. Аудио — 4D; видео — 5D. | LATENT | Да | N/A |
| `samples` | Тензор, содержащий латентные образцы. | ТЕНЗОР | Да | Аудио: 4D (batch, channels, frames, samples); Видео: 5D (batch, channels, height, width, frames) |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `latent` | Латентное значение с установленным noise_mask в 0, что обеспечивает его сохранение чистым в процессе采样. | LATENT |

## Замечания

- Тензор `samples` должен быть простым тензором и не должен быть объединенным аудио-видео латентным. Если это объединенный латент, его следует разделить с помощью узла Separate AV Latent сначала.
- Выход `latent` будет иметь noise_mask с нулями, что предотвращает деноising для указанного латентного значения.
- Узел поддерживает как аудио, так и видео латентные значения, с различной структурой тензоров для каждого.
- Если форма тензора `samples` не соответствует ожидаемой структуре аудио или видео, будет выведено ValueError.
```
