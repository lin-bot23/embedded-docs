# بیک‌کردن بافت از وکسل

این گره بافت‌های PBR را با استفاده از چیدمان UV موجود مش، روی یک مش سه‌بعدی پخت (Bake) می‌کند. این گره رنگ و ویژگی‌های متریال را از یک حجم ووکسل تنک (Sparse Voxel Volume) در هر تکسل نمونه‌برداری کرده و یک تصویر رنگ پایه به همراه نقشه‌های متالیک و زبری خروجی می‌دهد. این گره مش را Unwrap نمی‌کند، بنابراین یک گره UV unwrap باید در بالادستی متصل شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش سه‌بعدی برای پخت بافت‌ها روی آن. باید از قبل دارای چیدمان UV باشد؛ یک گره UV unwrap باید در بالادستی متصل شود. | MESH | بله | |
| `voxel_colors` | حجم ووکسل تنک حاوی رنگ‌های هر ووکسل و ویژگی‌های اختیاری PBR (کانال‌های متالیک و زبری). | VOXEL | بله | |
| `texture_size` | رزولوشن اطلس UV مربعی (نام نمایشی: "resolution"، پیش‌فرض: 2048). | INT | بله | 64 تا 8192 |
| `reference_mesh` | مش متراکم اختیاری پیش‌از کاهش؛ هر تکسل را قبل از نمونه‌برداری روی سطح واقعی آن بازتاب می‌دهد و پخت facet شده را روی مش‌های درشت حذف می‌کند. | MESH | خیر | |

یادداشت‌ها:

- مش ورودی باید دارای UV باشد. اگر UV وجود نداشته باشد، گره خطا می‌دهد. UVها باید 1:1 با رأس‌ها باشند (یک UV به ازای هر رأس).
- وقتی مختصات مش و ووکسل شامل بعد دسته (batch) هستند، هر آیتم دسته جداگانه پخت می‌شود. اگر یک آیتم دسته بدون ووکسل یا بدون وجه باشد، نادیده گرفته شده و یک بافت سیاه برای آن صادر می‌شود.
- وقتی `reference_mesh` برای یک دسته ارائه می‌شود، با ایندکس دسته مطابقت داده می‌شود مگر اینکه فقط شامل یک مش باشد، در این صورت آن مش برای همه آیتم‌ها استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `base_color` | نقشه بافت رنگ پایه RGB. مقادیر به صورت float در محدوده 0–1 هستند. | IMAGE |
| `metallic` | نقشه متالیک خاکستری (float, 0–1). سیاه وقتی که رنگ‌های ووکسل حاوی کانال متالیک نباشند. | IMAGE |
| `roughness` | نقشه زبری خاکستری (float, 0–1). سیاه وقتی که رنگ‌های ووکسل حاوی کانال زبری نباشند. | IMAGE |
