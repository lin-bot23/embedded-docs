# Tripo: Дополнение частей сетки

Завершает части сегментированной 3D-модели и восстанавливает отсутствующие или повреждённые области сетки. Принимает ID задачи результата сегментации сетки Tripo, запрашивает у Tripo задание на завершение и ожидает его завершения. При необходимости можно ограничить работу конкретными именами частей. Завершённая модель возвращается в виде файла GLB.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `segment_task_id` | ID задачи сегментации сетки Tripo. Части сегментированной модели, полученные в этой задаче, будут завершены. Подключите выход SEGMENT_TASK_ID предыдущего узла сегментации сетки Tripo. | SEGMENT_TASK_ID | Да | Один ID задачи |
| `part_names` | Имена частей для завершения, разделённые запятыми. Пустое значение завершает все части. По умолчанию: пустая строка. Лишние пробелы вокруг имён удаляются, дубликаты имён игнорируются. | STRING | Нет | Свободный текст или пусто |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Имя файла завершённой модели. Этот выход существует только для обратной совместимости. | STRING |
| `task_id модели` | ID задачи завершения сетки Tripo. Может использоваться как вход другими узлами Tripo, которые ожидают ID задачи модели. | MODEL_TASK_ID |
| `GLB` | Завершённая 3D-модель с восстановленными частями, загруженная в виде файла GLB. | GLB |
