# Tripo: メッシュパーツを補完

セグメント化された3Dモデルの各部分を補完し、メッシュの欠落または破損した領域を修復します。Tripoメッシュセグメンテーション結果のタスクIDを受け取り、Tripoに補完ジョブをリクエストして、完了するまで待機します。必要に応じて、作業対象を特定のパーツ名に限定できます。補完されたモデルはGLBファイルとして返されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `segment_task_id` | TripoメッシュセグメンテーションタスクのタスクID。このタスクでセグメント化されたモデルの各部分が補完されます。以前のTripoメッシュセグメンテーションノードのSEGMENT_TASK_ID出力を接続します。 | SEGMENT_TASK_ID | はい | 単一のタスクID |
| `part_names` | 補完するパーツ名をカンマ区切りで指定します。空の場合はすべてのパーツを補完します。デフォルト: 空文字列。名前の前後の余分なスペースは削除され、重複した名前は無視されます。 | STRING | いいえ | 自由テキストまたは空 |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_file` | 補完されたモデルのファイル名。この出力は後方互換性のためだけに存在します。 | STRING |
| `model task_id` | 補完されたTripoメッシュ補完タスクのタスクID。モデルタスクIDを期待する他のTripoノードへの入力として使用できます。 | MODEL_TASK_ID |
| `GLB` | 修復されたパーツを含む補完済み3Dモデル。GLBファイルとしてダウンロードされます。 | GLB |
