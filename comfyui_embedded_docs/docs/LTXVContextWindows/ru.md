# Окна контекста LTXV

Этот узел задаёт окна контекста для моделей типа LTXV во время сэмплирования. Он разделяет процесс генерации видео на перекрывающиеся окна для управления использованием памяти и улучшения временной согласованности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, к которой применяются окна контекста во время сэмплирования. | MODEL | Да | - |
| `context_length` | Длина окна контекста в реальных кадрах. Должна быть 8*n + 1. (по умолчанию: 145) | INT | Да | Минимум: 1<br>Максимум: nodes.MAX_RESOLUTION<br>Шаг: 8 |
| `context_overlap` | Перекрытие окон контекста в реальных кадрах. (по умолчанию: 40) | INT | Да | Минимум: 0<br>Шаг: 8 |
| `context_schedule` | Алгоритм планирования окон контекста, зависящий от шага. (по умолчанию: UNIFORM_STANDARD) | COMBO | Да | `STATIC_STANDARD`<br>`UNIFORM_STANDARD`<br>`UNIFORM_LOOPED`<br>`BATCHED` |
| `context_stride` | Шаг окна контекста; применим только к равномерным расписаниям. (по умолчанию: 1) | INT | Нет | Минимум: 1 |
| `closed_loop` | Замыкать ли цикл окна контекста; применимо только к зацикленным расписаниям. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `fuse_method` | Метод, используемый для слияния окон контекста. (по умолчанию: PYRAMID) | COMBO | Да | Опции из comfy.context_windows.ContextFuseMethods.LIST_STATIC |
| `freenoise` | Применять ли перемешивание шума FreeNoise; улучшает смешивание окон. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `retain_first_frame` | Сохранять первый латентный кадр в каждом окне контекста (может помочь сохранить начальный референс). (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `split_conds_to_windows` | Разделять ли несколько кондишинингов (созданных узлом ConditionCombine) по каждому окну на основе индекса региона. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

**Примечание:** Параметр `context_length` должен соответствовать формуле 8*n + 1, где n — положительное целое число. Узел автоматически корректирует значение для выполнения этого требования, преобразуя реальные кадры в латентные. `context_overlap` также преобразуется из реальных кадров в латентные (делится на 8).

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `MODEL` | Модель с применёнными окнами контекста для сэмплирования. | MODEL |
