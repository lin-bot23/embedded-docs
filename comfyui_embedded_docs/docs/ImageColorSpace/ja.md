# 画像カラースペースを変換

ImageColorSpace ノードは、画像を sRGB（Rec.709）、リニア Rec.709、HDR（Rec.2020 HLG）、および HDR PQ（Rec.2020 PQ）の色空間間で変換します。SDR 出力への変換、および HDR PQ から HDR への変換では、バッチ全体にわたって過剰な輝度をトーンマッピングし、色域外の色を圧縮します。リニア出力およびリニアから HDR への変換では、拡張値をトーンマッピングせずに保持します。変換は float32 で計算され、アルファチャンネルはそのまま通過します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `image` | 変換する入力画像。 | IMAGE | はい | 任意の有効な画像。 |
| `source` | 入力ピクセルの色空間。デフォルト："sRGB"。 | COMBO | はい | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"`<br>`"linear"` |
| `destination` | 出力ピクセルの色空間。保存ノードをこの同じ色空間に設定してください。デフォルト："sRGB"。 | COMBO | はい | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"`<br>`"linear"` |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `image` | 指定された出力先の色空間に変換された画像。 | IMAGE |

## 注意事項

- リニア 1.0 は sRGB と同じ 203 ニトの基準白色を使用します。HLG は 1000 ニトの基準ディスプレイを使用します。
- リニア出力およびリニアから HDR への変換は、トーンマッピングを行わずに拡張値を保持します。
- SDR 出力および PQ から HLG への変換では、バッチ全体にわたって過剰な輝度をトーンマッピングし（1 つの白色点を共有することでフレームごとに露出が変化しないようにします）、色域外の色を圧縮します。
- 変換は float32 で計算され、中間デバイスと dtype を返します。
- ストレートアルファは色変換されません。RGB チャンネルのみが変換されます。
- `source` と `destination` が同じ場合、色変換は適用されません — 画像は中間デバイスと dtype に移動されるだけです。
