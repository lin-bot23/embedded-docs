# Преобразовать цветовое пространство изображения

Узел ImageColorSpace преобразует изображения между цветовыми пространствами sRGB (Rec.709), линейным Rec.709, HDR (Rec.2020 HLG) и HDR PQ (Rec.2020 PQ). При сужении цветового пространства при преобразовании в выход SDR или из HDR PQ в HDR он выполняет тональную компрессию избыточной яркости по всей партии и сжимает цвета за пределами цветового охвата; преобразования в linear и из linear в HDR сохраняют расширенные значения без тональной компрессии. Преобразования вычисляются в float32, а любой альфа-канал передаётся без изменений.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение для преобразования. | IMAGE | Да | Любое допустимое изображение. |
| `source` | Цветовое пространство входных пикселей. По умолчанию: "sRGB". | COMBO | Да | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"`<br>`"linear"` |
| `destination` | Цветовое пространство выходных пикселей. Задайте в узле сохранения то же цветовое пространство. По умолчанию: "sRGB". | COMBO | Да | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"`<br>`"linear"` |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `image` | Преобразованное изображение в указанном целевом цветовом пространстве. | IMAGE |

## Примечания

- Линейное значение 1.0 использует тот же опорный белый уровень 203 нит, что и sRGB; HLG использует опорный дисплей 1000 нит.
- Линейный выход и преобразования из линейного в HDR сохраняют расширенные значения без тональной компрессии.
- Выход SDR и преобразование из PQ в HLG выполняют тональную компрессию избыточной яркости по всей партии (используя одну общую точку белого, чтобы экспозиция не менялась от кадра к кадру) и сжимают цвета, выходящие за пределы цветового охвата.
- Преобразования вычисляются в float32 и возвращают промежуточные устройство и dtype.
- Прямая альфа (straight alpha) не подвергается цветовому преобразованию; преобразуются только каналы RGB.
- Если `source` и `destination` совпадают, цветовое преобразование не применяется — изображение только переносится на промежуточное устройство с промежуточным dtype.
