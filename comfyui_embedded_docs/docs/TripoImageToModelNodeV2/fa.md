# TripoImageToModelNodeV2

گره Tripo: Image to Model یک تصویر مرجع واحد را با استفاده از سرویس تصویر به مدل Tripo به یک مدل سه‌بعدی تبدیل می‌کند. این گره تصویر را بارگذاری می‌کند، یک وظیفه تولید ارسال می‌کند، منتظر می‌ماند تا وظیفه کامل شود، و فایل سه‌بعدی حاصل را همراه با شناسه وظیفه بازمی‌گرداند. این یک گره API است، بنابراین به یک کلید API معتبر Comfy نیاز دارد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر مرجع مورد استفاده برای تولید مدل سه‌بعدی. | IMAGE | بله | — |
| `model_version` | نسخه مدلی که برای تولید استفاده می‌شود. اگر تنظیم نشود، گره به نسخه v3.1 (20260211) Tripo بازمی‌گردد. | COMBO | خیر | فهرست نسخه‌های مدل Tripo |
| `texture` | نقشه‌های بافت را تولید می‌کند. خاموش بودن آن هندسه خالی را برمی‌گرداند و `pbr` را نادیده می‌گیرد (پیش‌فرض: true). | BOOLEAN | خیر | true<br>false |
| `pbr` | نقشه‌های متریال PBR (رنگ پایه، متالیک، زبری، نرمال). نیازمند `texture` است (پیش‌فرض: true). | BOOLEAN | خیر | true<br>false |
| `model_seed` | دانه مورد استفاده برای مرحله تولید هندسه (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `orientation` | تنظیم جهت اعمال شده به مدل تولید شده (پیش‌فرض: DEFAULT). | COMBO | خیر | گزینه‌های جهت‌گیری Tripo، پیش‌فرض `DEFAULT` |
| `texture_seed` | دانه مورد استفاده برای مرحله تولید بافت (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `texture_quality` | detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra (پیش‌فرض: "standard"). | COMBO | خیر | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | نحوه تراز شدن بافت‌ها روی هندسه تولید شده (پیش‌فرض: "original_image"). | COMBO | خیر | "original_image"<br>"geometry" |
| `face_limit` | حداکثر تعداد وجه. 1- به Tripo اجازه می‌دهد تا به‌صورت تطبیقی انتخاب کند (حدود 1.4 میلیون وجه در v3.x استاندارد، 2 میلیون در detailed). Tripo به‌صورت بی‌صدا محدود می‌کند: v2.5 در 500,000، مش‌های quad در 150,000 (پیش‌فرض: -1). | INT | خیر | -1 تا 2000000 |
| `quad` | خروجی مش quad. Tripo مش‌های quad را به‌صورت FBX ارائه می‌دهد، بنابراین نتیجه در خروجی FBX می‌آید و خروجی GLB خالی می‌ماند (پیش‌فرض: false). | BOOLEAN | خیر | true<br>false |
| `geometry_quality` | سطح کیفیت هندسه تولید شده (پیش‌فرض: "standard"). | COMBO | خیر | "standard"<br>"detailed" |
| `smart_low_poly` | مش کم‌پالیگان با توپولوژی تمیز و دست‌ساز (500-20,000 وجه، quad 500-10,000). بهترین گزینه برای سوژه‌های ساده؛ سوژه‌های پیچیده ممکن است شکست بخورند (پیش‌فرض: false). | BOOLEAN | خیر | true<br>false |
| `auto_size` | مدل‌های بافت‌دار را به اندازه واقعی آن‌ها در متر مقیاس‌بندی می‌کند. Tripo اندازه را به‌عنوان تبدیل صحنه مدل ذخیره می‌کند و هنگام تبدیل، ریگ یا ری‌تارگت کردن مدل آن را اعمال می‌کند؛ بدون بافت نادیده گرفته می‌شود (پیش‌فرض: true). | BOOLEAN | خیر | true<br>false |

**یادداشت‌ها:**

- `image` الزامی است؛ اگر تصویری ارائه نشود، گره خطا می‌دهد.
- وقتی `smart_low_poly` فعال است و `face_limit` روی مقداری غیر از -1 تنظیم شده باشد، حد باید بین 500 و 20,000 برای مش‌های مثلثی، یا بین 500 و 10,000 وقتی `quad` فعال است باشد. مقادیر دیگر خطا می‌دهند.
- وقتی `texture` غیرفعال است، `pbr` بدون توجه به تنظیماتش خاموش می‌شود، و `auto_size` تأثیری ندارد.
- مقدار `face_limit` برابر -1 به Tripo به‌عنوان "بدون محدودیت" ارسال می‌شود و به سرویس اجازه می‌دهد تا به‌صورت تطبیقی انتخاب کند.
- یک فرمت فایل سه‌بعدی جدید که گره نمی‌تواند بازگرداند (هر چیزی غیر از GLB یا FBX) باعث خطا می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model task_id` | شناسه وظیفه Tripo برای کار تولید. | MODEL_TASK_ID |
| `GLB` | مدل تولید شده به‌صورت فایل GLB. وقتی `quad` فعال است خالی است. | FILE3DGLB |
| `FBX` | مدل تولید شده به‌صورت فایل FBX. فقط زمانی پر می‌شود که `quad` فعال باشد. | FILE3DFBX |
