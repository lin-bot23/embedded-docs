# TripoImageToModelNodeV2

Узел Tripo: Image to Model превращает одно эталонное изображение в 3D-модель с помощью сервиса Tripo image-to-model. Он загружает изображение, отправляет задачу генерации, ожидает завершения задачи и возвращает полученный 3D-файл вместе с ID задачи. Это API-узел, поэтому для его работы требуется действующий ключ Comfy API.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Эталонное изображение, используемое для генерации 3D-модели. | IMAGE | Да | — |
| `model_version` | Версия модели, используемая для генерации. Если не задана, узел использует версию Tripo v3.1 (20260211) по умолчанию. | COMBO | Нет | Список версий моделей Tripo |
| `texture` | Генерировать карты текстуры. При выключении возвращается только геометрия, а `pbr` игнорируется (по умолчанию: true). | BOOLEAN | Нет | true<br>false |
| `pbr` | PBR-карты материалов (основной цвет, металличность, шероховатость, нормали). Требует `texture` (по умолчанию: true). | BOOLEAN | Нет | true<br>false |
| `model_seed` | Seed, используемый на этапе генерации геометрии (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `orientation` | Настройка ориентации, применяемая к сгенерированной модели (по умолчанию: DEFAULT). | COMBO | Нет | Опции ориентации Tripo, по умолчанию `DEFAULT` |
| `texture_seed` | Seed, используемый на этапе генерации текстуры (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `texture_quality` | detailed = HD-текстуры, extreme = 8K Ultra-текстуры (по умолчанию: "standard"). | COMBO | Нет | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | Способ выравнивания текстур на сгенерированной геометрии (по умолчанию: "original_image"). | COMBO | Нет | "original_image"<br>"geometry" |
| `face_limit` | Максимальное количество полигонов. -1 позволяет Tripo выбрать адаптивно (около 1,4 млн полигонов на v3.x standard, 2 млн на detailed). Tripo ограничивает без предупреждения: v2.5 — 500 000, quad-сетки — 150 000 (по умолчанию: -1). | INT | Нет | от -1 до 2000000 |
| `quad` | Вывод quad-сетки. Tripo поставляет quad-сетки в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остаётся пустым (по умолчанию: false). | BOOLEAN | Нет | true<br>false |
| `geometry_quality` | Уровень качества сгенерированной геометрии (по умолчанию: "standard"). | COMBO | Нет | "standard"<br>"detailed" |
| `smart_low_poly` | Низкополигональная сетка с чистой топологией в ручном стиле (500–20 000 полигонов, quad 500–10 000). Лучше всего подходит для простых объектов; сложные могут не сработать (по умолчанию: false). | BOOLEAN | Нет | true<br>false |
| `auto_size` | Масштабировать модели с текстурами до их реального размера в метрах. Tripo сохраняет размер как трансформацию сцены модели и запекает его при конвертации, риггинге или ретаргетинге модели; игнорируется без текстуры (по умолчанию: true). | BOOLEAN | Нет | true<br>false |

**Примечания:**

- `image` обязателен; узел выдаёт ошибку, если изображение не передано.
- Когда `smart_low_poly` включён и `face_limit` установлен в значение, отличное от -1, ограничение должно быть в диапазоне от 500 до 20 000 для треугольных сеток или от 500 до 10 000, если включён `quad`. Другие значения вызывают ошибку.
- Когда `texture` отключён, `pbr` принудительно отключается независимо от его настройки, а `auto_size` не имеет эффекта.
- `face_limit` со значением -1 отправляется в Tripo как "no limit", позволяя сервису выбрать адаптивно.
- Новый формат 3D-файла, который узел не может вернуть (любой, кроме GLB или FBX), вызывает ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model task_id` | ID задачи Tripo для задания генерации. | MODEL_TASK_ID |
| `GLB` | Сгенерированная модель в виде файла GLB. Пусто, если включён `quad`. | FILE3DGLB |
| `FBX` | Сгенерированная модель в виде файла FBX. Заполняется только когда включён `quad`. | FILE3DFBX |
