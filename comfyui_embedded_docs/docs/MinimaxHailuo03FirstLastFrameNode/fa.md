# تبدیل اولین و آخرین فریم MiniMax H3 به ویدیو

این گره با استفاده از مدل‌های MiniMax H3، از یک تصویر فریم اول و به‌صورت اختیاری یک تصویر فریم آخر، ویدیو تولید می‌کند. انتخابگر `model` تعیین می‌کند که کدام تنظیمات و محدودیت‌های تولید اعمال شوند و نسبت ابعاد ویدیوی تولید شده از تصاویر ارائه‌شده پیروی می‌کند.

## ورودی‌ها

### ورودی‌های مشترک

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `model` | مدلی که برای تولید ویدیو استفاده می‌شود. انتخاب یک مدل، تنظیمات خاص آن مدل را در پایین نمایش می‌دهد. | DYNAMIC_COMBO | بله | "MiniMax H3"<br>"MiniMax H3 Max"<br>"MiniMax H3 Max Turbo" |
| `first_frame` | تصویر فریم اول برای ویدیو. ویدیوی تولید شده از نسبت ابعاد این تصویر پیروی می‌کند. | IMAGE | بله | - |
| `last_frame` | تصویر فریم آخر اختیاری برای ویدیو. هنگام ارائه، ویدیو از فریم اول به سمت این فریم آخر تولید می‌شود. | IMAGE | خیر | - |
| `seed` | seed تصادفی. درخواست یکسان با seed یکسان نتایج مشابهی می‌دهد، اما یکسان بودن آن‌ها تضمین نمی‌شود. شامل گزینه‌ی «control after generate» است. پیش‌فرض: 42. | INT | بله | 0 تا 4294967295 |
| `watermark` | آیا واترمارک AIGC به ویدیو اضافه شود یا خیر. این یک پارامتر پیشرفته است. فقط توسط مدل `MiniMax H3` پشتیبانی می‌شود. پیش‌فرض: False. | BOOLEAN | بله | True<br>False |

### ورودی‌های MiniMax H3

این تنظیمات زمانی نمایش داده می‌شوند که `MiniMax H3` در انتخابگر `model` انتخاب شود.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن prompt برای تولید ویدیو. باید حداقل شامل یک کاراکتر غیر از فاصله باشد. | STRING | بله | Multiline text |
| `resolution` | رزولوشن ویدیوی خروجی. | COMBO | بله | "768P"<br>"2K" |
| `duration` | مدت زمان ویدیوی خروجی به ثانیه. پیش‌فرض: 5. | INT | بله | 4 تا 15 |

### ورودی‌های MiniMax H3 Max و MiniMax H3 Max Turbo

این تنظیمات زمانی نمایش داده می‌شوند که either `MiniMax H3 Max` یا `MiniMax H3 Max Turbo` در انتخابگر `model` انتخاب شود. هر دو مدل تنظیمات یکسانی را ارائه می‌دهند.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | متن prompt برای تولید ویدیو. نباید خالی یا فقط شامل فاصله باشد و به ۵۰,۰۰۰ کاراکتر محدود است. | STRING | بله | Multiline text |
| `resolution` | رزولوشن ویدیوی خروجی. پیش‌فرض: 768P. | COMBO | بله | "480P"<br>"768P" |
| `duration` | مدت زمان ویدیوی خروجی به ثانیه. پیش‌فرض: 5. | INT | بله | 5 تا 15 |
| `prompt_expansion_mode` | میزان تلاش صرف‌شده برای بازنویسی prompt قبل از تولید. پیش‌فرض: balanced. | COMBO | بله | "balanced"<br>"quality" |

**نکاتی درباره محدودیت‌ها:**

- prompt باید حاوی متن باشد: promptهای خالی یا فقط شامل فاصله رد می‌شوند.
- هر تصویر فریم ارائه‌شده باید حداقل ۲۵۶ پیکسل عرض و ۲۵۶ پیکسل ارتفاع داشته باشد، با نسبت ابعاد عرض به ارتفاع بین ۰.۴ تا ۲.۵ (تقریباً ۲:۵ تا ۵:۲). این الزام برای `first_frame` و در صورت ارائه، `last_frame` اعمال می‌شود.
- هنگامی که `last_frame` حذف می‌شود، ویدیو فقط از فریم اول تولید می‌شود.
- ویدیوی خروجی از نسبت ابعاد تصاویر ارائه‌شده پیروی می‌کند.
- `watermark` فقط توسط `MiniMax H3` پشتیبانی می‌شود. فعال کردن آن با `MiniMax H3 Max` یا `MiniMax H3 Max Turbo` باعث ایجاد خطا می‌شود.
- مدت زمان برای `MiniMax H3` از ۴ تا ۱۵ ثانیه و برای `MiniMax H3 Max` و `MiniMax H3 Max Turbo` از ۵ تا ۱۵ ثانیه است.
