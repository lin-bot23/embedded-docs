# MiniMax H3: видео по первому и последнему кадру

Этот узел генерирует видео на основе изображения первого кадра и, опционально, изображения последнего кадра с помощью моделей MiniMax H3. Селектор `model` определяет, какие настройки и ограничения генерации применяются, а соотношение сторон итогового видео соответствует переданным изображениям.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `model` | Модель, используемая для генерации видео. Выбор модели отображает её настройки ниже. | DYNAMIC_COMBO | Да | "MiniMax H3"<br>"MiniMax H3 Max"<br>"MiniMax H3 Max Turbo" |
| `first_frame` | Изображение первого кадра для видео. Соотношение сторон генерируемого видео соответствует этому изображению. | IMAGE | Да | - |
| `last_frame` | Необязательное изображение последнего кадра для видео. Если оно задано, видео генерируется от первого кадра к этому последнему кадру. | IMAGE | Нет | - |
| `seed` | Случайный сид. Одинаковый запрос с одним и тем же сидом даёт похожие, но не гарантированно идентичные результаты. Включает опцию «управление после генерации». По умолчанию: 42. | INT | Да | 0 до 4294967295 |
| `watermark` | Добавлять ли AIGC-водяной знак к видео. Это расширенный параметр. Поддерживается только моделью `MiniMax H3`. По умолчанию: False. | BOOLEAN | Да | True<br>False |

### Входы MiniMax H3

Эти настройки отображаются, когда в селекторе `model` выбрана модель `MiniMax H3`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `prompt` | Текстовый промпт для генерации видео. Должен содержать хотя бы один непробельный символ. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "768P"<br>"2K" |
| `duration` | Длительность выходного видео в секундах. По умолчанию: 5. | INT | Да | 4 до 15 |

### Входы MiniMax H3 Max и MiniMax H3 Max Turbo

Эти настройки отображаются, когда в селекторе `model` выбрана модель `MiniMax H3 Max` или `MiniMax H3 Max Turbo`. Обе модели имеют одинаковые настройки.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|----------|----------|------------|--------------|----------|
| `prompt` | Текстовый промпт для генерации видео. Он не должен быть пустым или состоять только из пробельных символов, а его длина ограничена 50 000 символов. | STRING | Да | Многострочный текст |
| `resolution` | Разрешение выходного видео. По умолчанию: 768P. | COMBO | Да | "480P"<br>"768P" |
| `duration` | Длительность выходного видео в секундах. По умолчанию: 5. | INT | Да | 5 до 15 |
| `prompt_expansion_mode` | Объём усилий, затрачиваемых на переписывание промпта перед генерацией. По умолчанию: balanced. | COMBO | Да | "balanced"<br>"quality" |

**Примечания по ограничениям:**

- Промпт должен содержать текст: пустые промпты и промпты, состоящие только из пробельных символов, отклоняются.
- Любое переданное изображение кадра должно быть не менее 256 пикселей в ширину и 256 пикселей в высоту, с соотношением ширины к высоте от 0,4 до 2,5 (примерно от 2:5 до 5:2). Это требование применяется к `first_frame` и, при наличии, к `last_frame`.
- Если `last_frame` не указан, видео генерируется только из первого кадра.
- Выходное видео соответствует соотношению сторон переданных изображений.
- `watermark` поддерживается только моделью `MiniMax H3`. Включение этого параметра для `MiniMax H3 Max` или `MiniMax H3 Max Turbo` вызывает ошибку.
- Длительность составляет от 4 до 15 секунд для `MiniMax H3` и от 5 до 15 секунд для `MiniMax H3 Max` и `MiniMax H3 Max Turbo`.
