# LTXVSeparateGeneratedKeyframes

```markdown
# Отделенные сгенерированные ключевые кадры LTXV

## Обзор

Нод LTXV Separate Generated Keyframes удаляет сгенерированные ключевые кадры из образца латентного и условий, что позволяет обрабатывать их отдельно перед пространственным масштабированием латентного видео. Этот нод предназначен для использования перед пространственным масштабированием и не должен запускаться после LTXV Crop Guides, так как он рассматривает сгенерированные ключевые кадры как disposable guides и удаляет их.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительные условия с удаленными метаданными сгенерированных ключевых кадров. | CONDITIONING | Да | N/A |
| `negative` | Отрицательные условия с удаленными метаданными сгенерированных ключевых кадров. | CONDITIONING | Да | N/A |
| `latent` | Видео латент с удаленными сгенерированными ключевыми кадрами. | LATENT | Да | N/A |
| `keyframes_to_batch` | Возвратить ключевые кадры в виде пачки единичных латентных кадров. Оставьте без изменений для получения одного многофреймового латентного, что ожидается латентным масштабировщиком и Add Generated Keyframes. | ЛОЖЬ | Нет | по умолчанию: False |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительные условия с удаленными метаданными сгенерированных ключевых кадров. | CONDITIONING |
| `negative` | Отрицательные условия с удаленными метаданными сгенерированных ключевых кадров. | CONDITIONING |
| `latent` | Видео латент с удаленными сгенерированными ключевыми кадрами. | LATENT |
| `keyframes` | Удаленные ключевые кадры, помеченные сгенерированными_keyframe_indices и сгенерированными_keyframe_num_frames. Введите эти данные в более поздний Add Generated Keyframes для инициализации новых слотов или для Generated Keyframes To Guides для их привязки в качестве замороженных изображений guides (индексы ремаппингуются, если длина канваса изменилась). | LATENT |

## Замечания

- Параметр `keyframes_to_batch` определяет, возвращаются ли ключевые кадры в виде пачки единичных латентных кадров или в виде одного многофреймового латентного.
- Нод обеспечивает удаление сгенерированных ключевых кадров из условий и латентного перед дальнейшей обработкой.
- Выход `keyframes` можно использовать для инициализации новых слотов для сгенерированных ключевых кадров или для их привязки в качестве замороженных изображений guides.
- Нод вызывает `ValueError`, если латент не содержит сгенерированных ключевых кадров или если ключевые кадры не соответствуют ожидаемому формату.
- Нод предполагает, что сгенерированные ключевые кадры были добавлены с помощью нода LTXV Add Generated Keyframes и что они совместимы с текущим латентом.
```
