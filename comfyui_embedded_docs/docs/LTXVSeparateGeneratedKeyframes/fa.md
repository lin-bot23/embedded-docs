# LTXVSeparateGeneratedKeyframes

```markdown
# لایه جداگانه کلیدفریم‌های تولید شده LTXV

## مقدمه

لایه جداگانه کلیدفریم‌های تولید شده LTXV کلیدفریم‌های تولید شده را از یک نمونه latent و conditioning حذف می‌کند، که به مدیریت جداگانه قبل از بزرگ‌سازی فضایی latent ویدیو منجر می‌شود. این لایه طراحی شده است که قبل از بزرگ‌سازی فضایی استفاده شود و نباید پس از اجرای LTXV Crop Guides اجرا شود، زیرا کلیدفریم‌های تولید شده را به عنوان راهنماهای قابل استفاده مجدد در نظر می‌گیرد و آن‌ها را حذف می‌کند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `positive` | conditioning مثبت با حذف داده‌های کلیدفریم تولید شده. | CONDITIONING | بله | N/A |
| `negative` | conditioning منفی با حذف داده‌های کلیدفریم تولید شده. | CONDITIONING | بله | N/A |
| `latent` | latent ویدیو با حذف کلیدفریم‌های تولید شده. | LATENT | بله | N/A |
| `keyframes_to_batch` | کلیدفریم‌ها را به عنوان یک مجموعه از latent‌های تک‌تصویری بازگرداند. برای دریافت یک latent چند‌تصویری، که چیزی است که latent upsampler و Add Generated Keyframes انتظار دارند، این گزینه را غیرفعال کنید. | BOOLEAN | خیر | پیش‌فرض: False |

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `positive` | conditioning مثبت با حذف داده‌های کلیدفریم تولید شده. | CONDITIONING |
| `negative` | conditioning منفی با حذف داده‌های کلیدفریم تولید شده. | CONDITIONING |
| `latent` | latent ویدیو با حذف کلیدفریم‌های تولید شده. | LATENT |
| `keyframes` | کلیدفریم‌های جدا شده، با برچسب‌های generated_keyframe_indices و generated_keyframe_num_frames. این کلیدفریم‌ها را به یک Add Generated Keyframes بعدی برای شروع جدید‌ترین سلات‌ها یا به Generated Keyframes To Guides برای فیکس کردن آن‌ها به عنوان راهنماهای تصویری فیکس شده (اگر طول کانواس تغییر کرده باشد، شماره‌ها دوباره‌سازی می‌شوند) ارسال کنید. | LATENT |

## یادداشت‌ها

- پارامتر `keyframes_to_batch` تعیین می‌کند که آیا کلیدفریم‌ها به عنوان یک مجموعه از latent‌های تک‌تصویری بازگردانده می‌شوند یا خیر.
- این لایه اطمینان حاصل می‌کند که کلیدفریم‌های تولید شده از conditioning و latent حذف می‌شوند قبل از هر پردازش دیگری.
- خروجی `keyframes` می‌تواند برای شروع جدید‌ترین سلات‌ها برای کلیدفریم‌های تولید شده یا برای فیکس کردن آن‌ها به عنوان راهنماهای تصویری فیکس شده استفاده شود.
- این لایه یک `ValueError` برمی‌انگیزد اگر latent شامل کلیدفریم‌های تولید شده نباشد یا اگر کلیدفریم‌ها با فرمت انتظاری مطابقت نداشته باشند.
- این لایه فرض می‌کند که کلیدفریم‌های تولید شده با استفاده از لایه LTXV Add Generated Keyframes اضافه شده‌اند و با latent فعلی سازگار هستند.
```
