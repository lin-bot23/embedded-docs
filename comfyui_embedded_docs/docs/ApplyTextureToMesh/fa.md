# اعمال بافت بر مش

این گره تصاویر بافت baked شده را به چیدمان UV یک مش متصل می‌کند تا بتوانند همراه با مش توسط گره SaveGLB صادر شوند. مش UV-unwrapped شده‌ای را که برای baking استفاده کرده‌اید، به همراه نقشه‌های تصویر baked شده متصل کنید. نقشه‌های اختیاری metallic، roughness و occlusion در یک بافت ORM واحد بسته‌بندی می‌شوند و ارائه یک نقشه normal نیز نرمال‌های smooth و tangent‌های مورد نیاز برای سایه‌زنی صحیح را ذخیره می‌کند.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `mesh` | مش UV-unwrapped شده‌ای که بافت‌های baked شده به آن متصل خواهند شد. باید همان مشی باشد که در حین baking استفاده شده است؛ اگر مش دارای UV نباشد، خطا ایجاد می‌شود. | MESH | بله | — |
| `base_color` | تصویر base color baked شده. به عنوان بافت مش ذخیره شده و به محدوده ۰ تا ۱ محدود (clamp) می‌شود. | IMAGE | بله | — |
| `metallic` | نقشه metallic baked شده. به عنوان کانال آبی بافت ORM ترکیبی استفاده می‌شود؛ در صورت عدم ارائه، مقدار پیش‌فرض ۰ است. | IMAGE | خیر | — |
| `roughness` | نقشه roughness baked شده. به عنوان کانال سبز بافت ORM ترکیبی استفاده می‌شود؛ در صورت عدم ارائه، مقدار پیش‌فرض ۱ است. | IMAGE | خیر | — |
| `occlusion` | نقشه ambient occlusion baked شده. به عنوان کانال قرمز بافت ORM ترکیبی استفاده می‌شود؛ در صورت عدم ارائه، مقدار پیش‌فرض ۱ است. هنگام ارائه، بافت ORM همچنین به عنوان بافت occlusion برای SaveGLB علامت‌گذاری می‌شود. | IMAGE | خیر | — |
| `normal_map` | نقشه normal tangent-space baked شده. هنگام ارائه، گره پایه tangent را برای هر رأس مجدداً محاسبه کرده و نرمال‌های رأس smooth را صادر می‌کند تا نقشه normal به درستی سایه‌زنی شود. | IMAGE | خیر | — |

نکته: هنگامی که هر یک از `metallic`، `roughness` یا `occlusion` متصل شوند، هر سه در یک بافت glTF ORM واحد با کانال‌های R = occlusion، G = roughness، B = metallic بسته‌بندی می‌شوند. نقشه‌های ارائه‌نشده با مقادیر پیش‌فرض پر می‌شوند (occlusion ۱، roughness ۱، metallic ۰) و نقشه‌هایی با رزولوشن‌های مختلف به بزرگ‌ترین عرض و ارتفاع تغییر اندازه می‌یابند. هنگامی که `normal_map` متصل می‌شود، نرمال‌های مش با نرمال‌های رأس smooth محاسبه‌شده جایگزین شده و یک پایه tangent اضافه می‌شود. مختصات UV که خارج از محدوده [0,1] قرار می‌گیرند، ضمن حفظ نسبت ابعاد، به صورت یکنواخت به داخل [0,1] مقیاس‌دهی می‌شوند.
