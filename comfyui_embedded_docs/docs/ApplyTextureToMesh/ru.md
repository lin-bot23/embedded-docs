# Применить текстуру к mesh

Данный узел прикрепляет изображения запечённых текстур к UV-развёртке меша, чтобы их можно было экспортировать вместе с мешем с помощью узла SaveGLB. Подключите тот же меш с UV-развёрткой, который использовался при запекании, а также запечённые карты. Дополнительные карты металличности, шероховатости и окклюзии упаковываются в единую ORM-текстуру, а при подаче карты нормалей дополнительно сохраняются сглаженные нормали и касательные, необходимые для корректного затенения.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------------|----------|
| `mesh` | Меш с UV-развёрткой, к которому будут прикреплены запечённые текстуры. Должен быть тем же мешем, что использовался при запекании; если у меша отсутствует UV-развёртка, возникает ошибка. | MESH | Да | — |
| `base_color` | Запечённая карта базового цвета. Сохраняется как текстура меша и ограничивается диапазоном 0–1. | IMAGE | Да | — |
| `metallic` | Запечённая карта металличности. Используется как синий канал объединённой ORM-текстуры; при отсутствии по умолчанию принимает значение 0. | IMAGE | Нет | — |
| `roughness` | Запечённая карта шероховатости. Используется как зелёный канал объединённой ORM-текстуры; при отсутствии по умолчанию принимает значение 1. | IMAGE | Нет | — |
| `occlusion` | Запечённая карта окклюзии. Используется как красный канал объединённой ORM-текстуры; при отсутствии по умолчанию принимает значение 1. При наличии карты ORM-текстура также помечается как текстура окклюзии для SaveGLB. | IMAGE | Нет | — |
| `normal_map` | Запечённая карта нормалей в касательном пространстве. При подаче карты узел пересчитывает касательный базис для каждой вершины и экспортирует сглаженные вершинные нормали, чтобы карта нормалей обеспечивала корректное затенение. | IMAGE | Нет | — |

Примечание: если подключена хотя бы одна из карт `metallic`, `roughness` или `occlusion`, все три упаковываются в единую ORM-текстуру glTF с каналами R = окклюзия, G = шероховатость, B = металличность. Отсутствующие карты заполняются значениями по умолчанию (окклюзия 1, шероховатость 1, металличность 0), а карты с разным разрешением приводятся к наибольшим ширине и высоте. Когда подключена `normal_map`, нормали меша заменяются вычисленными сглаженными вершинными нормалями и добавляется касательный базис. UV-координаты, выходящие за пределы диапазона [0,1], равномерно масштабируются в диапазон [0,1] с сохранением соотношения сторон.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-------------|
| `mesh` | Исходный меш с прикреплёнными к его UV-развёртке изображениями текстур, готовый к сохранению узлом SaveGLB. | MESH |
