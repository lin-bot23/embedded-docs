# 將紋理套用至網格

此節點將烘焙紋理影像附加到網格的 UV 佈局，以便可透過 SaveGLB 節點與網格一同匯出。請連接烘焙時使用的同一個 UV 展開網格，以及烘焙的影像貼圖。可選的金屬度、粗糙度與環境光遮蔽貼圖會打包為單一 ORM 紋理；提供法線貼圖時，也會儲存正確著色所需的光滑法線與切線。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `mesh` | 烘焙紋理將附加到的 UV 展開網格。必須是烘焙時使用的同一個網格；若網格沒有 UV，會引發錯誤。 | MESH | 是 | — |
| `base_color` | 烘焙的基礎顏色影像。作為網格的紋理儲存，並限制在 0 到 1 的範圍內。 | IMAGE | 是 | — |
| `metallic` | 烘焙的金屬度貼圖。用作組合 ORM 紋理的藍色通道；未提供時預設為 0。 | IMAGE | 否 | — |
| `roughness` | 烘焙的粗糙度貼圖。用作組合 ORM 紋理的綠色通道；未提供時預設為 1。 | IMAGE | 否 | — |
| `occlusion` | 烘焙的環境光遮蔽貼圖。用作組合 ORM 紋理的紅色通道；未提供時預設為 1。提供時，ORM 紋理也會被標記為 SaveGLB 的遮蔽紋理。 | IMAGE | 否 | — |
| `normal_map` | 烘焙的切線空間法線貼圖。提供時，節點會重新計算每個頂點的切線基底，並匯出平滑的頂點法線，使法線貼圖能正確著色。 | IMAGE | 否 | — |

注意：當 `metallic`、`roughness` 或 `occlusion` 任一連接時，三者會被打包至單一 glTF ORM 紋理中，通道為 R = occlusion、G = roughness、B = metallic。缺少的貼圖會以預設值填補（occlusion 1、roughness 1、metallic 0），而解析度不同的貼圖會調整為最大的寬度與高度。當 `normal_map` 連接時，網格的法線會替換為計算出的平滑頂點法線，並加入切線基底。落在 [0,1] 範圍之外的 UV 座標會均勻縮放到 [0,1] 內，同時保持寬高比。
