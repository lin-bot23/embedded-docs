# پیش‌نمایش Point Cloud

گره Preview Point Cloud به شما امکان می‌دهد فایل ابر نقطه‌ای سه‌بعدی را در رابط کاربری ComfyUI مشاهده کنید، بدون اینکه آن را در پوشه خروجی ComfyUI ذخیره کنید. این گره ابر نقطه‌ای را در یک مکان موقت ذخیره کرده و در یک پنجره پیش‌نمایش سه‌بعدی نمایش می‌دهد و همزمان داده‌های مدل، اطلاعات مدل، اطلاعات دوربین و ابعاد پیش‌نمایش را برای پردازش‌های بعدی عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | فایل ابر نقطه‌ای (.ply) | FILE3D | بله | - |
| `model_3d_info` | اطلاعات مربوط به مدل سه‌بعدی | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی نمای دید سه‌بعدی | LOAD3D | بله | - |
| `camera_info` | اطلاعات دوربین برای نمای سه‌بعدی | LOAD3DCAMERA | خیر | - |
| `width` | عرض پنجره پیش‌نمایش (پیش‌فرض: 1024) | INT | بله | 1 تا 4096 |
| `height` | ارتفاع پنجره پیش‌نمایش (پیش‌فرض: 1024) | INT | بله | 1 تا 4096 |

**توجه:** `model_3d_info` و `camera_info` ورودی‌های پیشرفته اختیاری هستند. وقتی این‌ها متصل نمی‌شوند، گره به مقادیر مربوطی که در `viewport_state` ذخیره شده‌اند باز می‌گردد. فایل ابر نقطه‌ای به جای پوشه خروجی، در پوشه موقت ComfyUI نوشته می‌شود. این یک گره خروجی (پایانه) است، بنابراین عمدتاً برای نمایش پیش‌نمایش در رابط کاربری استفاده می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | داده‌های مدل ابر نقطه‌ای | FILE3D |
| `model_3d_info` | اطلاعات مربوط به مدل سه‌بعدی | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین برای نمای سه‌بعدی | LOAD3DCAMERA |
| `width` | عرض پنجره پیش‌نمایش | INT |
| `height` | ارتفاع پنجره پیش‌نمایش | INT |
