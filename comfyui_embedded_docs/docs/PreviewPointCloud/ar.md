# معاينة سحابة النقاط

تتيح لك عقدة Preview Point Cloud عرض ملف سحابة نقاط ثلاثية الأبعاد في واجهة ComfyUI دون حفظه في دليل الإخراج الخاص بـ ComfyUI. فهي تحفظ سحابة النقاط في موقع مؤقت وتعرضها في نافذة معاينة ثلاثية الأبعاد، مع تمرير بيانات النموذج ومعلومات النموذج ومعلومات الكاميرا وأبعاد المعاينة للمعالجة اللاحقة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | ملف سحابة النقاط (.ply) | FILE3D | نعم | - |
| `model_3d_info` | معلومات حول النموذج ثلاثي الأبعاد | LOAD3DMODELINFO | لا | - |
| `viewport_state` | الحالة الحالية لمنفذ العرض ثلاثي الأبعاد | LOAD3D | نعم | - |
| `camera_info` | معلومات الكاميرا للعرض ثلاثي الأبعاد | LOAD3DCAMERA | لا | - |
| `width` | عرض نافذة المعاينة (الافتراضي: 1024) | INT | نعم | 1 إلى 4096 |
| `height` | ارتفاع نافذة المعاينة (الافتراضي: 1024) | INT | نعم | 1 إلى 4096 |

ملاحظة: `model_3d_info` و`camera_info` مدخلات اختيارية متقدمة. عندما تكون غير متصلة، تعود العقدة إلى القيم المقابلة المخزنة في `viewport_state`. يُكتب ملف سحابة النقاط إلى الدليل المؤقت لـ ComfyUI بدلاً من دليل الإخراج. هذه عقدة إخراج (طرفية)، لذلك تُستخدم أساسًا لعرض المعاينة في الواجهة.

| اسم المخرج | الوصف | نوع البيانات |
