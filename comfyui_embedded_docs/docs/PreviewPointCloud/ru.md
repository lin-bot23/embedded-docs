# Предпросмотр облака точек

Узел Preview Point Cloud позволяет просматривать файл 3D-облака точек в интерфейсе ComfyUI без сохранения его в выходной каталог ComfyUI. Он сохраняет облако точек во временное расположение и отображает его в окне 3D-предпросмотра, а также передает данные модели, информацию о модели, информацию о камере и размеры предпросмотра для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Файл облака точек (.ply) | FILE3D | Да | - |
| `model_3d_info` | Информация о 3D-модели | LOAD3DMODELINFO | Нет | - |
| `viewport_state` | Текущее состояние 3D-вьюпорта | LOAD3D | Да | - |
| `camera_info` | Информация о камере для 3D-вида | LOAD3DCAMERA | Нет | - |
| `width` | Ширина окна предпросмотра (по умолчанию: 1024) | INT | Да | 1 до 4096 |
| `height` | Высота окна предпросмотра (по умолчанию: 1024) | INT | Да | 1 до 4096 |

Примечание: `model_3d_info` и `camera_info` — необязательные дополнительные входы. Если они не подключены, узел использует соответствующие значения, хранящиеся в `viewport_state`. Файл облака точек записывается во временный каталог ComfyUI, а не в выходной каталог. Это выходной (терминальный) узел, поэтому он в основном используется для отображения предпросмотра в интерфейсе.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Данные облака точек модели | FILE3D |
| `model_3d_info` | Информация о 3D-модели | LOAD3DMODELINFO |
| `camera_info` | Информация о камере для 3D-вида | LOAD3DCAMERA |
| `width` | Ширина окна предпросмотра | INT |
| `height` | Высота окна предпросмотра | INT |
