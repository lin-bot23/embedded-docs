# Tripo P1: Мульти-вид в Модель

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Вид спереди (0°). Обязательный. | IMAGE | Да | - |
| `изображение_слева` | Вид слева (90°), т. е. левая сторона объекта. | IMAGE | Нет | - |
| `изображение_сзади` | Вид сзади (180°). | IMAGE | Нет | - |
| `изображение_справа` | Вид справа (270°), т. е. правая сторона объекта. | IMAGE | Нет | - |
| `режим_вывода` | Выберите тип генерируемой модели. «Geometry only» возвращает меш без текстуры. «Textured» добавляет цветовые/PBR-карты. | DYNAMIC_COMBO | Да | "Geometry only"<br>"Textured" |
| `ограничение_граней` | Целевое количество граней, 48–20000. -1 позволяет Tripo выбрать адаптивно. (по умолчанию: -1) | INT | Нет | -1 до 20000 |
| `seed_модели` | Сид для воспроизводимой генерации модели. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `авторазмер` | Масштабировать выходной объект до приблизительных реальных размеров в метрах. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `экспорт_uv` | Выполнять UV-развёртку во время генерации. Отключите для более быстрых запусков в режиме только геометрии. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `сжать_геометрию` | Применять сжатие геометрии meshopt (EXT_meshopt_compression). Файлы меньше, но 3D-предпросмотр ComfyUI не может их отображать; распакуйте перед редактированием. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы Geometry only

Для этого режима дополнительные входы не отображаются. Сгенерированная модель возвращается без текстуры.

### Входы Textured

Эти входы появляются, когда для `output_mode` установлено значение `"Textured"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `pbr` | Включать PBR-карты. При включении базовая текстура также принудительно включается. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `texture_quality` | Уровень качества текстуры. `detailed` = HD-текстуры, `extreme` = 8K Ultra-текстуры. (по умолчанию: "standard") | COMBO | Да | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | Приоритет визуального соответствия исходному изображению или выравнивания по геометрии меша. (по умолчанию: "original_image") | COMBO | Да | "original_image"<br>"geometry" |
| `orientation` | Повернуть выходной объект в соответствии с исходным изображением. Применяется только при текстурировании. (по умолчанию: "default") | COMBO | Да | "default"<br>"align_image" |
| `texture_seed` | Сид, используемый для генерации текстуры. (по умолчанию: 42) | INT | Да | 0 до 2147483647 |

**Примечание:** Необходимо предоставить как минимум 2 изображения: вид спереди (`image`) плюс хотя бы один из других видов (`image_left`, `image_back` или `image_right`). Если предоставлено меньше 2 изображений, узел вызовет ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл_модели` | Имя файла сгенерированной GLB-модели (только для обратной совместимости). | STRING |
| `task_id_модели` | Уникальный ID задачи для этого запроса на генерацию модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
