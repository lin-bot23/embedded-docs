# Tripo P1: Мульти-вид в Модель

Этот узел генерирует 3D-модель по двум–четырём эталонным изображениям объекта или персонажа. Предоставьте вид спереди в сочетании с любыми видами слева, сзади и справа — узел вернёт реконструированный объект в виде GLB-сетки.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `image` | Вид спереди (0°). Обязательно. | IMAGE | Да | - |
| `image_left` | Вид слева (90°), то есть левая сторона объекта. | IMAGE | Нет | - |
| `image_back` | Вид сзади (180°). | IMAGE | Нет | - |
| `image_right` | Вид справа (270°), то есть правая сторона объекта. | IMAGE | Нет | - |
| `output_mode` | Выберите тип генерируемой модели. Значение "Geometry only" возвращает сетку без текстуры. "Textured" добавляет цветовые/PBR-карты. | DYNAMIC_COMBO | Да | "Geometry only"<br>"Textured" |
| `face_limit` | Целевое количество граней, 48–20000. Значение -1 позволяет Tripo выбрать автоматически. (по умолчанию: -1) | INT | Нет | -1 до 20000 |
| `model_seed` | Сид для воспроизводимой генерации модели. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `auto_size` | Масштабировать результат до приблизительных реальных размеров в метрах. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `export_uv` | Развёртка UV во время генерации. Отключите для более быстрой работы в режиме Geometry only. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `compress_geometry` | Применить сжатие геометрии meshopt (EXT_meshopt_compression). Файлы становятся меньше, но 3D-предпросмотр ComfyUI не может отобразить их; распакуйте перед редактированием. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |

### Входы Geometry only

Для этого режима дополнительные входы не отображаются. Сгенерированная модель возвращается без текстуры.

### Входы Textured

Эти входы появляются, когда `output_mode` установлен в `"Textured"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `pbr` | Включить PBR-карты. При включении базовая текстура также принудительно включается. (по умолчанию: True) | BOOLEAN | Да | True<br>False |
| `texture_quality` | Уровень качества текстуры. `detailed` — HD-текстуры, `extreme` — сверхдетализированные текстуры 8K Ultra. (по умолчанию: "standard") | COMBO | Да | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | Отдавать приоритет визуальной точности по отношению к исходному изображению или выравниванию по геометрии сетки. (по умолчанию: "original_image") | COMBO | Да | "original_image"<br>"geometry" |
| `orientation` | Повернуть результат в соответствии с исходным изображением. Применяется только для текстурированных моделей. (по умолчанию: "default") | COMBO | Да | "default"<br>"align_image" |
| `texture_seed` | Сид, используемый для генерации текстуры. (по умолчанию: 42) | INT | Да | 0 до 2147483647 |

**Примечание:** Необходимо предоставить как минимум 2 изображения: вид спереди (`image`) плюс хотя бы один из других видов (`image_left`, `image_back` или `image_right`). Если предоставлено менее двух изображений, узел выдаст ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|---|---|---|
| `model_file` | Имя файла сгенерированной GLB-модели (только для обратной совместимости). | STRING |
| `model_task_id` | Уникальный идентификатор задачи для этого запроса на генерацию модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. | FILE3DGLB |
