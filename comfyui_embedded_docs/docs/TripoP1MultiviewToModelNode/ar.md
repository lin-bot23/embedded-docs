# Tripo P1: من عدة زوايا إلى نموذج

تولّد هذه العقدة نموذجًا ثلاثي الأبعاد من صورتين إلى أربع صور مرجعية لكائن أو شخصية. قدّم المنظر الأمامي بالإضافة إلى أي مزيج من المناظر اليسرى والخلفية واليمنى، وتُعيد العقدة العنصر المعاد بناؤه كشبكة GLB.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `صورة` | منظر أمامي (0°). مطلوب. | IMAGE | نعم | - |
| `صورة اليسار` | منظر يسار (90°)، أي الجانب الأيسر للعنصر. | IMAGE | لا | - |
| `صورة الخلف` | منظر خلفي (180°). | IMAGE | لا | - |
| `صورة اليمين` | منظر يمين (270°)، أي الجانب الأيمن للعنصر. | IMAGE | لا | - |
| `وضع الإخراج` | اختر نوع النموذج المراد توليده. تُعيد "Geometry only" شبكة بدون خامة. يضيف "Textured" خرائط ألوان/PBR. | DYNAMIC_COMBO | نعم | "Geometry only"<br>"Textured" |
| `حد الأوجه` | عدد الأوجه المستهدف، 48-20000. تجعل -1 أداة Tripo تختار بشكل تكيفي. (الافتراضي: -1) | INT | لا | -1 إلى 20000 |
| `بذرة النموذج` | بذرة لتوليد نموذج قابل لإعادة الإنتاج. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `تغيير الحجم تلقائيًا` | تحجيم المخرجات لتقريبها من الأمتار في العالم الواقعي. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `تصدير UV` | فك UV أثناء التوليد. أوقفه للحصول على عمليات أسرع للهندسة فقط. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `ضغط الهندسة` | تطبيق ضغط هندسة meshopt (EXT_meshopt_compression). ملفات أصغر، لكن معاينة 3D في ComfyUI لا تستطيع عرضها؛ فكّ الضغط قبل التحرير. (الافتراضي: False) | BOOLEAN | لا | True<br>False |

### مدخلات Geometry only

لا تظهر مدخلات إضافية لهذا الوضع. يُعاد النموذج المولّد دون خامة.

### مدخلات Textured

تظهر هذه المدخلات عندما يتم ضبط `output_mode` على `"Textured"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | تضمين خرائط PBR. عند تشغيله، يتم إجبار تشغيل الخامة الأساسية أيضًا. (الافتراضي: True) | BOOLEAN | نعم | True<br>False |
| `texture_quality` | مستوى جودة الخامات. `detailed` = خامات HD، `extreme` = خامات 8K فائقة. (الافتراضي: "standard") | COMBO | نعم | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | إعطاء الأولوية للأمانة البصرية تجاه الصورة المصدر، أو المحاذاة إلى هندسة الشبكة. (الافتراضي: "original_image") | COMBO | نعم | "original_image"<br>"geometry" |
| `orientation` | تدوير المخرجات لتطابق الصورة المصدر. لا ينطبق إلا عند استخدام الخامات. (الافتراضي: "default") | COMBO | نعم | "default"<br>"align_image" |
| `texture_seed` | البذرة المستخدمة لتوليد الخامات. (الافتراضي: 42) | INT | نعم | 0 إلى 2147483647 |

**ملاحظة:** يجب تقديم صورتين على الأقل: المنظر الأمامي (`image`) بالإضافة إلى واحد على الأقل من المناظر الأخرى (`image_left`، `image_back`، أو `image_right`). إذا تم تقديم أقل من صورتين، فسترفع العقدة خطأً.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | اسم ملف نموذج GLB المولّد (للتوافق مع الإصدارات السابقة فقط). | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة الفريد لطلب توليد هذا النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المولّد بصيغة GLB. | FILE3DGLB |
