# Tripo P1: من عدة زوايا إلى نموذج

يُنشئ هذا العقد نموذجًا ثلاثي الأبعاد من صورتين إلى أربع صور مرجعية لجسمٍ أو شخصية. وفّر المنظر الأمامي مع أي توليفة من المناظر اليسرى والخلفية واليمنى، وتُعيد العقدة الموضوع المُعاد بناؤه كشبكة GLB.

## المدخلات

### المدخلات العامة

| Parameter | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | المنظر الأمامي (0°). مطلوب. | IMAGE | نعم | - |
| `image_left` | المنظر الأيسر (90°)، أي الجانب الأيسر للموضوع. | IMAGE | لا | - |
| `image_back` | المنظر الخلفي (180°). | IMAGE | لا | - |
| `image_right` | المنظر الأيمن (270°)، أي الجانب الأيمن للموضوع. | IMAGE | لا | - |
| `output_mode` | اختر نوع النموذج المراد إنشاؤه. يُرجع «Geometry only» شبكة بدون نسيج، بينما يُضيف «Textured» خرائط الألوان/الـ PBR. | DYNAMIC_COMBO | نعم | "Geometry only"<br>"Textured" |
| `face_limit` | عدد الوجوه المستهدف، من 48 إلى 20000. القيمة -1 تسمح لـ Tripo بالاختيار التلقائي. (الافتراضي: -1) | INT | لا | -1 إلى 20000 |
| `model_seed` | بذرة لتوليد النموذج بشكل قابل للتكرار. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `auto_size` | قياس المخرَج ليقارب الأمتار الواقعية. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `export_uv` | فكّ تمديدات الـ UV أثناء الإنشاء. أوقفه لتسريع العمليات التي تكون الهندسة فقط. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `compress_geometry` | تطبيق ضغط هندسة meshopt (EXT_meshopt_compression). ينتج ملفات أصغر، لكن لا يمكن لمعاينة ComfyUI ثلاثية الأبعاد عرضها؛ فكّ الضغط قبل التعديل. (الافتراضي: False) | BOOLEAN | لا | True<br>False |

### مدخلات الهندسة فقط

لا تظهر أي مدخلات إضافية لهذا الوضع. يُعاد النموذج المُنشأ بدون نسيج.

### مدخلات النسيج

تظهر هذه المدخلات عندما يكون `output_mode` مضبوطًا على `"Textured"`.

| Parameter | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `pbr` | يتضمن خرائط PBR. عند تشغيله، يتم أيضًا فرض النسيج الأساسي. (الافتراضي: True) | BOOLEAN | نعم | True<br>False |
| `texture_quality` | مستوى جودة النسيج. `detailed` = نسيج عالي الدقة (HD)، `extreme` = نسيج فائق الدقة 8K. (الافتراضي: "standard") | COMBO | نعم | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | إعطاء الأولوية للدقة البصرية للصورة المصدر، أو للمطابقة مع هندسة الشبكة. (الافتراضي: "original_image") | COMBO | نعم | "original_image"<br>"geometry" |
| `orientation` | تدوير المخرَج لمطابقة الصورة المصدر. يُطبَّق فقط عند التكسية. (الافتراضي: "default") | COMBO | نعم | "default"<br>"align_image" |
| `texture_seed` | البذرة المستخدمة لتوليد النسيج. (الافتراضي: 42) | INT | نعم | 0 إلى 2147483647 |

**ملاحظة:** يجب عليك توفير صورتين على الأقل: المنظر الأمامي (`image`) مع واحد على الأقل من المناظر الأخرى (`image_left`، `image_back`، أو `image_right`). إذا تم توفير أقل من صورتين، فسترفع العقدة خطأً.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | اسم ملف نموذج GLB المُنشأ (لأغراض التوافق مع الإصدارات السابقة فقط). | STRING |
| `model_task_id` | المعرّف الفريد للمهمة الخاص بطلب إنشاء هذا النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُنشأ بصيغة GLB. | FILE3DGLB |
