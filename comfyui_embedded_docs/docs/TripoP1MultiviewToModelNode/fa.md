# Tripo P1: تبدیل چندنما به مدل

این گره یک مدل سه‌بعدی را از دو تا چهار تصویر مرجع از یک شیء یا کاراکتر تولید می‌کند. نمای جلو را به همراه هر ترکیبی از نمای چپ، پشت و راست ارائه دهید؛ گره سوژه بازسازی‌شده را به صورت مش GLB برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `image` | نمای جلو (۰ درجه). الزامی. | IMAGE | بله | - |
| `image_left` | نمای چپ (۹۰ درجه)، یعنی سمت چپ سوژه. | IMAGE | خیر | - |
| `image_back` | نمای پشت (۱۸۰ درجه). | IMAGE | خیر | - |
| `image_right` | نمای راست (۲۷۰ درجه)، یعنی سمت راست سوژه. | IMAGE | خیر | - |
| `output_mode` | نوع مدل تولیدی را انتخاب کنید. «Geometry only» یک مش بدون بافت برمی‌گرداند. «Textured» نقشه‌های رنگ/PBR را اضافه می‌کند. | DYNAMIC_COMBO | بله | "Geometry only"<br>"Textured" |
| `face_limit` | تعداد وجه هدف، ۴۸ تا ۲۰۰۰۰. مقدار -1 به Tripo اجازه می‌دهد به صورت تطبیقی انتخاب کند. (پیش‌فرض: -1) | INT | خیر | -1 تا 20000 |
| `model_seed` | Seed برای تولید مدل قابل تکرار. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `auto_size` | مقیاس خروجی را به مترهای دنیای واقعی تقریب بزند. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `export_uv` | باز کردن UV در حین تولید. برای اجرای سریع‌تر فقط هندسه خاموش کنید. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `compress_geometry` | اعمال فشرده‌سازی هندسه meshopt (EXT_meshopt_compression). فایل‌های کوچک‌تر، اما پیش‌نمایش سه‌بعدی ComfyUI نمی‌تواند آن‌ها را نمایش دهد؛ قبل از ویرایش از حالت فشرده خارج کنید. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### ورودی‌های فقط هندسه

برای این حالت ورودی اضافی نمایش داده نمی‌شود. مدل تولیدشده بدون بافت برمی‌گردد.

### ورودی‌های بافت‌دار

این ورودی‌ها زمانی ظاهر می‌شوند که `output_mode` روی `"Textured"` تنظیم شده باشد.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `pbr` | شامل نقشه‌های PBR شود. وقتی روشن است، بافت پایه نیز اجباراً روشن می‌شود. (پیش‌فرض: True) | BOOLEAN | بله | True<br>False |
| `texture_quality` | سطح کیفیت بافت. `detailed` = بافت‌های HD، `extreme` = بافت‌های Ultra 8K. (پیش‌فرض: "standard") | COMBO | بله | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | اولویت با وفاداری بصری به تصویر منبع، یا هم‌ترازی با هندسه مش. (پیش‌فرض: "original_image") | COMBO | بله | "original_image"<br>"geometry" |
| `orientation` | چرخش خروجی برای تطابق با تصویر منبع. فقط زمانی اعمال می‌شود که بافت‌دار باشد. (پیش‌فرض: "default") | COMBO | بله | "default"<br>"align_image" |
| `texture_seed` | Seed استفاده‌شده برای تولید بافت. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

**توجه:** باید حداقل ۲ تصویر ارائه دهید: نمای جلو (`image`) به علاوه حداقل یکی از نمای‌های دیگر (`image_left`، `image_back` یا `image_right`). اگر کمتر از ۲ تصویر ارائه شود، گره خطا خواهد داد.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل GLB تولیدشده (فقط برای سازگاری معکوس). | STRING |
| `model_task_id` | شناسه وظیفه منحصر‌به‌فرد برای این درخواست تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در فرمت GLB. | FILE3DGLB |
