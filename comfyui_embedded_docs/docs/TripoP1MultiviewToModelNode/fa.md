# Tripo P1: تبدیل چندنما به مدل

این گره یک مدل سه‌بعدی از دو تا چهار تصویر مرجع از یک شیء یا شخصیت تولید می‌کند. نمای روبه‌رو را به‌همراه هر ترکیبی از نماهای چپ، پشت و راست ارائه دهید؛ گره سوژه بازسازی‌شده را به‌صورت یک مش GLB برمی‌گرداند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | نمای روبه‌رو (۰ درجه). الزامی است. | IMAGE | بله | - |
| `image_left` | نمای چپ (۹۰ درجه)، یعنی سمت چپ سوژه. | IMAGE | خیر | - |
| `image_back` | نمای پشت (۱۸۰ درجه). | IMAGE | خیر | - |
| `image_right` | نمای راست (۲۷۰ درجه)، یعنی سمت راست سوژه. | IMAGE | خیر | - |
| `output_mode` | نوع مدل برای تولید را انتخاب می‌کند. «Geometry only» یک مش بدون بافت برمی‌گرداند. «Textured» نقشه‌های رنگ/PBR را اضافه می‌کند. | DYNAMIC_COMBO | بله | "Geometry only"<br>"Textured" |
| `face_limit` | تعداد هدف وجه‌ها، ۴۸ تا ۲۰۰۰۰. مقدار -1 باعث می‌شود Tripo به‌صورت تطبیقی انتخاب کند. (پیش‌فرض: -1) | INT | خیر | -1 تا 20000 |
| `model_seed` | Seed برای تولید مدل قابل بازتولید. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `auto_size` | خروجی را طوری مقیاس‌دهی می‌کند که تقریباً با مترهای دنیای واقعی مطابقت داشته باشد. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `export_uv` | در هنگام تولید، UV unwrap انجام می‌شود. برای اجراهای سریع‌تر فقط هندسه، آن را خاموش کنید. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `compress_geometry` | فشرده‌سازی هندسه meshopt را اعمال می‌کند (EXT_meshopt_compression). فایل‌های کوچک‌تر، اما پیش‌نمایش سه‌بعدی ComfyUI نمی‌تواند آن‌ها را نمایش دهد؛ پیش از ویرایش، از حالت فشرده خارج کنید. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |

### ورودی‌های Geometry only

برای این حالت، هیچ ورودی اضافی نمایش داده نمی‌شود. مدل تولیدشده بدون بافت برگردانده می‌شود.

### ورودی‌های Textured

این ورودی‌ها زمانی نمایش داده می‌شوند که `output_mode` روی `"Textured"` تنظیم شده باشد.

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `pbr` | نقشه‌های PBR را شامل می‌شود. وقتی روشن باشد، بافت پایه نیز به‌اجبار روشن می‌شود. (پیش‌فرض: True) | BOOLEAN | بله | True<br>False |
| `texture_quality` | سطح کیفیت بافت. `detailed` = بافت‌های HD، `extreme` = بافت‌های 8K Ultra. (پیش‌فرض: "standard") | COMBO | بله | "standard"<br>"detailed"<br>"extreme" |
| `texture_alignment` | وفاداری بصری به تصویر منبع یا هم‌ترازی با هندسه مش را در اولویت قرار می‌دهد. (پیش‌فرض: "original_image") | COMBO | بله | "original_image"<br>"geometry" |
| `orientation` | خروجی را برای مطابقت با تصویر منبع می‌چرخاند. فقط در حالت بافت‌دار اعمال می‌شود. (پیش‌فرض: "default") | COMBO | بله | "default"<br>"align_image" |
| `texture_seed` | Seed مورد استفاده برای تولید بافت. (پیش‌فرض: 42) | INT | بله | 0 تا 2147483647 |

**توجه:** باید حداقل ۲ تصویر ارائه دهید: نمای روبه‌رو (`image`) به‌همراه حداقل یکی از نماهای دیگر (`image_left`، `image_back` یا `image_right`). اگر کمتر از ۲ تصویر ارائه شود، گره خطا می‌دهد.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل مدل GLB تولیدشده (فقط برای سازگاری با نسخه‌های قبلی). | STRING |
| `model task_id` | شناسه وظیفه یکتای این درخواست تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB. | FILE3DGLB |
