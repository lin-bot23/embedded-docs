# متنبئ مدة LTXV

تتنبأ هذه العقدة بالمدة الطبيعية للقطة لنص موجّه باستخدام رأس مدة LTX 2.4 المُحمّل عبر ModelPatchLoader،ثم تُقرِّب النتيجة إلى شبكة إطارات VAE ذات الأساس 8k+1. يُحوَّل التنبؤ إلى عدد إطارات باستخدام معدل الإطارات المحدد وحدود المدة الدنيا والقصوى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج المستخدم لمعالجة تضمينات النص وتشغيل رأس المدة. | MODEL | نعم | لا ينطبق |
| `إيجابي` | الشرط الذي يوفّر تضمينات نص الموجّه والبيانات الوصفية اللازمة للتنبؤ بالمدة. | CONDITIONING | نعم | لا ينطبق |
| `duration_head` | رأس مدة LTX 2.4 المُحمّل عبر ModelPatchLoader. يجب أن يكون رأس مدة LTX. | MODEL_PATCH | نعم | لا ينطبق |
| `معدل الإطارات` | معدل الإطارات بإطارات في الثانية المستخدم لتحويل الثواني إلى إطارات (الافتراضي: 24.0). | FLOAT | نعم | 1.0 إلى 120.0 |
| `الحد الأدنى للثواني` | الحد الأدنى للمدة بالثواني المستخدم عند تحويل التنبؤ إلى عدد إطارات (الافتراضي: 1.0). | FLOAT | نعم | 0.5 إلى 120.0 |
| `الحد الأقصى للثواني` | الحد الأقصى للمدة بالثواني المستخدم عند تحويل التنبؤ إلى عدد إطارات (الافتراضي: 20.0). | FLOAT | نعم | 0.5 إلى 120.0 |

ملاحظة: يجب أن يكون مدخل `duration_head` رقعة نموذج (model patch) تحتوي على رأس مدة LTX. إذا لم تكن رقعة النموذج المتصلة رأس مدة LTX، تطرح العقدة استثناء ValueError. يُستخدم إدخال الشرط الأول فقط — إذا كان `positive` يحتوي على دفعة تضم أكثر من موجّه، تقيّم العقدة أول موجّه فقط.

## المخرجات

| اسم المخرجات | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `عدد الإطارات` | المدة المتوقعة المحوّلة إلى عدد إطارات والمقرّبة إلى شبكة إطارات VAE ذات الأساس 8k+1. | INT |
| `الثواني` | المدة المتوقعة الخام (غير المقيدة). هذه هي القيمة قبل التقريب إلى شبكة الإطارات. | FLOAT |
