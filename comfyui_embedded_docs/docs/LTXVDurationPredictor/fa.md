# پیش‌بینی‌کننده مدت زمان LTXV

این گره مدت‌زمان طبیعی شات را برای یک پرامپت متنی پیش‌بینی می‌کند؛ این کار با استفاده از یک هد مدت‌زمان LTX 2.4 که با ModelPatchLoader بارگذاری شده انجام می‌شود و سپس نتیجه را به شبکه فریم 8k+1 مربوط به VAE منطبق می‌کند. پیش‌بینی با استفاده از نرخ فریم انتخاب‌شده و محدودیت‌های حداقل و حداکثر مدت‌زمان، به تعداد فریم تبدیل می‌شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدلی که برای پیش‌پردازش جاسازی‌های متن و اجرای هد مدت‌زمان استفاده می‌شود. | MODEL | بله | نامرتبط |
| `مثبت` | کاندیشنینگی که جاسازی‌های متن و فراداده‌های پرامپت را برای پیش‌بینی مدت‌زمان فراهم می‌کند. | CONDITIONING | بله | نامرتبط |
| `duration head` | هد مدت‌زمان LTX 2.4 بارگذاری شده با ModelPatchLoader. باید یک هد مدت‌زمان LTX باشد. | MODEL_PATCH | بله | نامرتبط |
| `نرخ فریم` | نرخ فریم بر حسب فریم بر ثانیه که برای تبدیل ثانیه به فریم استفاده می‌شود (پیش‌فرض: 24.0). | FLOAT | بله | 1.0 تا 120.0 |
| `حداقل ثانیه` | حداقل مدت‌زمان بر حسب ثانیه که هنگام تبدیل پیش‌بینی به تعداد فریم استفاده می‌شود (پیش‌فرض: 1.0). | FLOAT | بله | 0.5 تا 120.0 |
| `حداکثر ثانیه` | حداکثر مدت‌زمان بر حسب ثانیه که هنگام تبدیل پیش‌بینی به تعداد فریم استفاده می‌شود (پیش‌فرض: 20.0). | FLOAT | بله | 0.5 تا 120.0 |

نکته: ورودی `duration_head` باید یک مدل پچ حاوی یک هد مدت‌زمان LTX باشد. اگر مدل پچ متصل شده یک هد مدت‌زمان LTX نباشد، گره یک خطای ValueError ایجاد می‌کند. تنها اولین ورودی کاندیشنینگ استفاده می‌شود — اگر `positive` شامل یک دسته شامل بیش از یک پرامپت باشد، گره فقط اولین مورد را ارزیابی می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تعداد فریم‌ها` | مدت‌زمان پیش‌بینی‌شده که به تعداد فریم تبدیل شده و به شبکه فریم 8k+1 مربوط به VAE منطبق شده است. | INT |
| `ثانیه` | مدت‌زمان پیش‌بینی‌شده خام (بدون اعمال محدودیت). این مقدار قبل از منطبق شدن با شبکه فریم است. | FLOAT |
