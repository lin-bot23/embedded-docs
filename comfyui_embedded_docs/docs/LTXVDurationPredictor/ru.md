# LTXV Duration Predictor

Этот узел предсказывает естественную длительность плана для текстового запроса с помощью головы длительности LTX 2.4, загруженной через ModelPatchLoader, а затем привязывает результат к сетке кадров VAE 8k+1. Прогноз преобразуется в количество кадров с использованием выбранной частоты кадров и минимального и максимального пределов длительности.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model` | Модель, используемая для предварительной обработки текстовых эмбеддингов и запуска головы длительности. | MODEL | Да | N/A |
| `positive` | Кондиционирование, которое предоставляет текстовые эмбеддинги запроса и метаданные для прогнозирования длительности. | CONDITIONING | Да | N/A |
| `duration_head` | Голова длительности LTX 2.4, загруженная с помощью ModelPatchLoader. Должна быть головой длительности LTX. | MODEL_PATCH | Да | N/A |
| `frame_rate` | Частота кадров в кадрах в секунду, используемая для преобразования секунд в кадры (по умолчанию: 24.0). | FLOAT | Да | 1.0 до 120.0 |
| `min_seconds` | Минимальная длительность в секундах, используемая при преобразовании прогноза в количество кадров (по умолчанию: 1.0). | FLOAT | Да | 0.5 до 120.0 |
| `max_seconds` | Максимальная длительность в секундах, используемая при преобразовании прогноза в количество кадров (по умолчанию: 20.0). | FLOAT | Да | 0.5 до 120.0 |

Примечание. Вход `duration_head` должен быть патчем модели, содержащим голову длительности LTX. Если подключенный патч модели не является головой длительности LTX, узел вызывает исключение ValueError. Используется только первая запись кондиционирования: если `positive` содержит пакет с более чем одним запросом, узел вычисляет только первый из них.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `num_frames` | Прогнозируемая длительность, преобразованная в количество кадров и привязанная к сетке кадров VAE 8k+1. | INT |
| `seconds` | Сырое (неограниченное) прогнозируемое значение длительности. Это значение до привязки к сетке кадров. | FLOAT |
