# Tripo: تحويل النموذج

يحوّل هذا العقد نموذج Tripo ثلاثي الأبعاد الحالي إلى صيغة ملف ثلاثي الأبعاد أخرى. يأخذ معرّف المهمة لنموذج تم إنشاؤه أو معالجته مسبقًا بواسطة إحدى عمليات Tripo (مثل إنشاء النموذج، أو الهيكلة، أو إعادة الاستهداف، أو التجزئة)، ويُرسل مهمة تحويل إلى واجهة Tripo API، وينتظر اكتمال تلك المهمة، ثم يعيد ملف النموذج المحوَّل.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | معرّف مهمة نموذج Tripo المراد تحويله. يجب أن يكون ناتجًا عن مهمة سابقة لتوليد نماذج Tripo أو الهيكلة أو إعادة الاستهداف أو التجزئة. إذا كان المعرّف مفقودًا أو فارغًا، يرفع العقد خطأً. | STRING (معرّف مهمة Tripo) | نعم | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `التنسيق` | صيغة الملف الهدف للنموذج ثلاثي الأبعاد المحوَّل. | COMBO | نعم | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `رباعي` | يحوّل المثلثات إلى رباعيات عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `حد الوجه` | الحد الأقصى لعدد الوجوه في النموذج المحوَّل. اضبط القيمة على -1 لعدم وجود حد (الافتراضي: -1). | INT | لا | -1 إلى 2000000 |
| `حجم النسيج` | دقة القوامات الناتجة بالبكسل (الافتراضي: 4096). | INT | لا | 128 إلى 8192 |
| `تنسيق النسيج` | صيغة الملف المستخدمة لتصدير القوامات (الافتراضي: JPEG). | COMBO | لا | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `فرض التماثل` | يفرض تماثل النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `تسوية القاع` | يفلّت قاع النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `عتبة تسوية القاع` | عمق التسطيح المستخدم مع `flatten_bottom` (الافتراضي: 0.01). تُطبَّق هذه القيمة فقط عند تمكين `flatten_bottom`. | FLOAT | لا | 0.01 إلى 1.0 |
| `محور إلى مركز القاع` | ينقل نقطة الارتكاز إلى منتصف قاع النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `عامل المقياس` | عامل القياس المطبَّق على النموذج المحوَّل (الافتراضي: 1.0). | FLOAT | لا | 0.01 and above |
| `مع الحركة` | يحتفظ بالهيكل العظمي والرسوم المتحركة للنماذج المُهيكَلة أو المُعاد استهدافها (الافتراضي: True). | BOOLEAN | لا | True or False |
| `تجميع UV` | يعيد تجميع إحداثيات UV عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `خبز` | يخبز الخامات المتقدمة في القوامات الأساسية لتوافق أوسع (الافتراضي: True). | BOOLEAN | لا | True or False |
| `أسماء الأجزاء` | قائمة بأسماء أجزاء النموذج مفصولة بفواصل لإرسالها إلى التحويل. تُتجاهل الإدخالات الفارغة وتُزال الأسماء المكررة. اتركه فارغًا لحذف هذا الخيار (الافتراضي: فارغ). | STRING | لا | قائمة بأسماء الأجزاء مفصولة بفواصل |
| `إعداد FBX` | إعداد مسبق للتوافق مع FBX. يقوم bake_scale بدمج تحويل المقياس في الهندسة (الافتراضي: blender). | COMBO | لا | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `تصدير ألوان الرؤوس` | يصدر ألوان الرؤوس عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `تصدير الاتجاه` | المحور الأمامي للنموذج المُصدَّر. القيمة default تُبقي محور +x الخاص بـ Tripo (الافتراضي: default). | COMBO | لا | default<br>+x<br>-x<br>+y<br>-y |
| `تحريك في المكان` | يُحرّك النموذج في مكانه عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |

**ملاحظة:** باستثناء `original_model_task_id` و`format`، جميع المدخلات هي إعدادات متقدمة اختيارية. تُحذف الإعدادات التي تبقى على قيمها الافتراضية من طلب التحويل، بحيث تستخدم Tripo API سلوكها القياسي. يكون للمدخل `flatten_bottom_threshold` معنى فقط عند تمكين `flatten_bottom`.
