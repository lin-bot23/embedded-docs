# Tripo: تحويل النموذج

تحوّل هذه العقدة نموذج Tripo ثلاثي الأبعاد موجود إلى تنسيق ملف ثلاثي الأبعاد آخر. تأخذ مُعرّف المهمة لنموذج أُنشئ أو جرى معالجته مسبقًا عبر عملية Tripo (مثل توليد النموذج، أو التجهيز الهيكلي، أو إعادة الاستهداف، أو التقسيم)، وترسل مهمة تحويل إلى Tripo API، وتنتظر اكتمال تلك المهمة، ثم تُرجع ملف النموذج المحوَّل.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | معرّف المهمة لنموذج Tripo المراد تحويله. يجب أن يأتي من مهمة سابقة لتوليد نموذج Tripo، أو التجهيز الهيكلي، أو إعادة الاستهداف، أو التقسيم. إذا كان المعرّف مفقودًا أو فارغًا، ترفع العقدة خطأ. | STRING | نعم | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `التنسيق` | تنسيق الملف الهدف للنموذج ثلاثي الأبعاد المحوَّل. | COMBO | نعم | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `رباعي` | تحويل المثلثات إلى أشكال رباعية عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `حد الوجه` | الحد الأقصى لعدد الأوجه في النموذج المحوَّل. اضبطه على -1 لعدم وجود حد (الافتراضي: -1). | INT | لا | -1 إلى 2000000 |
| `حجم النسيج` | دقة الخامات الناتجة بالبكسل (الافتراضي: 4096). | INT | لا | 128 إلى 8192 |
| `تنسيق النسيج` | تنسيق الملف المستخدم للخامات المصدَّرة (الافتراضي: JPEG). | COMBO | لا | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `فرض التماثل` | فرض تماثل النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `تسوية القاع` | تسطيح الجزء السفلي من النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `عتبة تسوية القاع` | عمق التسطيح المستخدم مع `flatten_bottom` (الافتراضي: 0.01). تُطبَّق هذه القيمة فقط عند تمكين `flatten_bottom`. | FLOAT | لا | 0.01 إلى 1.0 |
| `محور إلى مركز القاع` | نقل نقطة الارتكاز إلى مركز الجزء السفلي من النموذج عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `عامل المقياس` | عامل القياس المطبَّق على النموذج المحوَّل (الافتراضي: 1.0). | FLOAT | لا | 0.01 and above |
| `مع الحركة` | الاحتفاظ بالهيكل العظمي والحركة للنماذج المجهزة هيكليًا أو المعاد استهدافها (الافتراضي: True). | BOOLEAN | لا | True or False |
| `تجميع UV` | إعادة تجميع إحداثيات UV عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `خبز` | خبز المواد المتقدمة في الخامات الأساسية لتوافق أوسع (الافتراضي: True). | BOOLEAN | لا | True or False |
| `أسماء الأجزاء` | قائمة أسماء أجزاء النموذج المفصولة بفواصل والتي ستُرسَل إلى التحويل. يتم تجاهل الإدخالات الفارغة وإزالة الأسماء المكررة. اتركه فارغًا لحذف هذا الخيار (الافتراضي: فارغ). | STRING | لا | Comma-separated list of part names |
| `إعداد FBX` | إعداد مسبق لتوافق FBX. يقوم bake_scale بخبز تحويل القياس في الهندسة (الافتراضي: blender). | COMBO | لا | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `تصدير ألوان الرؤوس` | تصدير ألوان الرؤوس عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |
| `تصدير الاتجاه` | المحور الأمامي للنموذج المصدَّر. تحافظ القيمة default على +x الخاص بـ Tripo (الافتراضي: default). | COMBO | لا | default<br>+x<br>-x<br>+y<br>-y |
| `تحريك في المكان` | تحريك النموذج في موضعه عند التمكين (الافتراضي: False). | BOOLEAN | لا | True or False |

**ملاحظة:** باستثناء `original_model_task_id` و `format`، فإن جميع المدخلات هي إعدادات متقدمة اختيارية. تُحذف معظم الإعدادات التي تُترك عند قيمها الافتراضية من طلب التحويل حتى يتمكن Tripo API من استخدام سلوكه القياسي. يتم إرسال خيارَي `with_animation` و `bake` دائمًا. لا تُطبَّق `flatten_bottom_threshold` إلا عند تمكين `flatten_bottom`.
