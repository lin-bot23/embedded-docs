# Tripo: Конвертировать модель

Этот узел преобразует существующую 3D-модель Tripo в другой формат 3D-файла. Он принимает идентификатор задачи модели, ранее созданной или обработанной одной из операций Tripo (например, генерация модели, риггинг, ретаргетинг или сегментация), отправляет задачу конвертации в Tripo API, ожидает её завершения и затем возвращает преобразованный файл модели.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | Идентификатор задачи Tripo-модели для конвертации. Он должен быть получен из более ранней задачи генерации Tripo-модели, риггинга, ретаргетинга или сегментации. Если идентификатор отсутствует или пуст, узел вызывает ошибку. | STRING (ID задачи Tripo) | Да | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `format` | Целевой формат файла для преобразованной 3D-модели. | COMBO | Да | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `quad` | Преобразовывать треугольники в четырёхугольники при включении (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `face_limit` | Максимальное количество граней в преобразованной модели. Установите -1, чтобы снять ограничение (по умолчанию: -1). | INT | Нет | -1 до 2000000 |
| `texture_size` | Разрешение выходных текстур в пикселях (по умолчанию: 4096). | INT | Нет | 128 до 8192 |
| `texture_format` | Формат файла, используемый для экспортируемых текстур (по умолчанию: JPEG). | COMBO | Нет | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `force_symmetry` | Принудительно делать модель симметричной при включении (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `flatten_bottom` | Уплощать нижнюю часть модели при включении (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `flatten_bottom_threshold` | Глубина уплощения, используемая с `flatten_bottom` (по умолчанию: 0.01). Это значение применяется только при включённом `flatten_bottom`. | FLOAT | Нет | 0.01 до 1.0 |
| `pivot_to_center_bottom` | Перемещать точку поворота в центр нижней части модели при включении (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `scale_factor` | Коэффициент масштаба, применяемый к преобразованной модели (по умолчанию: 1.0). | FLOAT | Нет | 0.01 and above |
| `with_animation` | Сохранять скелет и анимацию для моделей с риггингом или ретаргетингом (по умолчанию: True). | BOOLEAN | Нет | True or False |
| `pack_uv` | Перепаковывать UV-координаты при включении (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `bake` | Запекать сложные материалы в базовые текстуры для более широкой совместимости (по умолчанию: True). | BOOLEAN | Нет | True or False |
| `part_names` | Разделённый запятыми список имён частей модели для отправки на конвертацию. Пустые элементы игнорируются, повторяющиеся имена удаляются. Оставьте значение пустым, чтобы не использовать эту опцию (по умолчанию: пусто). | STRING | Нет | Разделённый запятыми список имён частей |
| `fbx_preset` | Пресет совместимости FBX. Значение `bake_scale` запекает масштабное преобразование в геометрию (по умолчанию: blender). | COMBO | Нет | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `export_vertex_colors` | Экспортировать цвета вершин при включении (по умолчанию: False). | BOOLEAN | Нет | True or False |
| `export_orientation` | Ось направления «вперёд» экспортируемой модели. Значение default сохраняет направление +x Tripo (по умолчанию: default). | COMBO | Нет | default<br>+x<br>-x<br>+y<br>-y |
| `animate_in_place` | Анимировать модель на месте при включении (по умолчанию: False). | BOOLEAN | Нет | True or False |

**Примечание:** Кроме `original_model_task_id` и `format`, все входные параметры являются необязательными дополнительными настройками. Параметры, оставленные со значениями по умолчанию, исключаются из запроса на конвертацию, поэтому Tripo API использует стандартное поведение. Входной параметр `flatten_bottom_threshold` имеет смысл только при включённом `flatten_bottom`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Преобразованная модель в запрошенном формате. OBJ поставляется Tripo в виде ZIP-архива (сетка, материалы и текстуры). | FILE_3D |
