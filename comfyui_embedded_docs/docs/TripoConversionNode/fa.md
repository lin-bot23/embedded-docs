# Tripo: تبدیل مدل

این گره یک مدل سه‌بعدی Tripo موجود را به فرمت فایل سه‌بعدی دیگری تبدیل می‌کند. این گره شناسه وظیفه (Task ID) مدلی را دریافت می‌کند که قبلاً توسط یک عملیات Tripo (مانند تولید مدل، ریگینگ، ری‌تارگتینگ یا قطعه‌بندی) ایجاد یا پردازش شده است، یک وظیفه تبدیل را به API Tripo ارسال می‌کند، منتظر اتمام آن وظیفه می‌ماند و سپس فایل مدل تبدیل‌شده را ارائه می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | شناسه وظیفه مدل Tripo برای تبدیل. باید از یک وظیفه قبلی تولید مدل، ریگینگ، ری‌تارگتینگ یا قطعه‌بندی Tripo گرفته شده باشد. اگر شناسه موجود نباشد یا خالی باشد، گره خطا ایجاد می‌کند. | STRING (شناسه وظیفه Tripo) | بله | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `format` | فرمت فایل هدف برای مدل سه‌بعدی تبدیل‌شده. | COMBO | بله | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `quad` | در صورت فعال‌ بودن، مثلث‌ها را به چهارضلعی‌ها تبدیل می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `face_limit` | حداکثر تعداد وجه‌ها در مدل تبدیل‌شده. برای بدون محدودیت روی -1 تنظیم شود (پیش‌فرض: -1). | INT | خیر | -1 تا 2000000 |
| `texture_size` | رزولوشن بافت‌های خروجی بر حسب پیکسل (پیش‌فرض: 4096). | INT | خیر | 128 تا 8192 |
| `texture_format` | فرمت فایل مورد استفاده برای بافت‌های صادرشده (پیش‌فرض: JPEG). | COMBO | خیر | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `force_symmetry` | در صورت فعال‌ بودن، مدل را متقارن می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `flatten_bottom` | در صورت فعال‌ بودن، کف مدل را تخت می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `flatten_bottom_threshold` | عمق تخت‌سازی مورد استفاده با `flatten_bottom` (پیش‌فرض: 0.01). این مقدار فقط زمانی اعمال می‌شود که `flatten_bottom` فعال باشد. | FLOAT | خیر | 0.01 تا 1.0 |
| `pivot_to_center_bottom` | در صورت فعال‌ بودن، نقطه محور (pivot) را به مرکز کف مدل منتقل می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `scale_factor` | ضریب مقیاس اعمال‌شده بر مدل تبدیل‌شده (پیش‌فرض: 1.0). | FLOAT | خیر | 0.01 و بالاتر |
| `with_animation` | اسکلت و انیمیشن مدل‌های ریگ‌شده یا ری‌تارگت‌شده را حفظ می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | True or False |
| `pack_uv` | در صورت فعال‌ بودن، مختصات UV را دوباره بسته‌بندی می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `bake` | متریال‌های پیشرفته را برای سازگاری بیشتر در بافت‌های پایه ثبت می‌کند (Bake) (پیش‌فرض: True). | BOOLEAN | خیر | True or False |
| `part_names` | لیست نام‌های بخش‌های مدل برای ارسال به تبدیل، جدا شده با کاما. ورودی‌های خالی نادیده گرفته می‌شوند و نام‌های تکراری حذف می‌شوند. برای حذف این گزینه خالی بگذارید (پیش‌فرض: خالی). | STRING | خیر | لیست نام‌های بخش‌ها جدا شده با کاما |
| `fbx_preset` | پیش‌فرض سازگاری FBX. گزینه bake_scale تبدیل مقیاس را در هندسه ثبت می‌کند (Bake) (پیش‌فرض: blender). | COMBO | خیر | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `export_vertex_colors` | در صورت فعال‌ بودن، رنگ‌های رأس (vertex colors) را صادر می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `export_orientation` | محور جلوی مدل صادرشده. گزینه default محور +x Tripo را حفظ می‌کند (پیش‌فرض: default). | COMBO | خیر | default<br>+x<br>-x<br>+y<br>-y |
| `animate_in_place` | در صورت فعال‌ بودن، مدل را در محل انیمیت می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |

**توجه:** به جز `original_model_task_id` و `format`, تمام ورودی‌ها تنظیمات پیشرفته اختیاری هستند. تنظیماتی که روی مقادیر پیش‌فرض خود باقی می‌مانند از درخواست تبدیل حذف می‌شوند تا API Tripo از رفتار استاندارد خود استفاده کند. ورودی `flatten_bottom_threshold` فقط زمانی معنا دارد که `flatten_bottom` فعال باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
