# Tripo: تبدیل مدل

این گره یک مدل سه‌بعدی Tripo موجود را به قالب فایل سه‌بعدی دیگری تبدیل می‌کند. شناسه وظیفه (Task ID) مدلی را می‌گیرد که پیش‌تر توسط یک عملیات Tripo (مانند تولید مدل، ریگ‌بندی، بازهدف‌گذاری یا بخش‌بندی) ایجاد یا پردازش شده است، یک وظیفه تبدیل به Tripo API ارسال می‌کند، منتظر پایان آن می‌ماند و سپس فایل مدل تبدیل‌شده را برمی‌گرداند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | شناسه وظیفه (Task ID) مدل Tripo برای تبدیل. باید از یک وظیفه پیشین تولید مدل، ریگ‌بندی، بازهدف‌گذاری یا بخش‌بندی Tripo آمده باشد. اگر شناسه موجود نباشد یا خالی باشد، گره خطا ایجاد می‌کند. | STRING | بله | MODEL_TASK_ID<br>RIG_TASK_ID<br>RETARGET_TASK_ID<br>SEGMENT_TASK_ID |
| `فرمت` | قالب فایل مقصد برای مدل سه‌بعدی تبدیل‌شده. | COMBO | بله | GLTF<br>USDZ<br>FBX<br>OBJ<br>STL<br>3MF |
| `quad` | در صورت فعال بودن، مثلث‌ها را به چهارضلعی تبدیل می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `محدودیت چهره` | حداکثر تعداد وجه در مدل تبدیل‌شده. برای بدون محدودیت روی -1 تنظیم کنید (پیش‌فرض: -1). | INT | خیر | -1 تا 2000000 |
| `اندازه تکسچر` | رزولوشن بافت‌های خروجی بر حسب پیکسل (پیش‌فرض: 4096). | INT | خیر | 128 تا 8192 |
| `فرمت تکسچر` | قالب فایل مورد استفاده برای بافت‌های صادرشده (پیش‌فرض: JPEG). | COMBO | خیر | BMP<br>DPX<br>HDR<br>JPEG<br>OPEN_EXR<br>PNG<br>TARGA<br>TIFF<br>WEBP |
| `اجبار تقارن` | در صورت فعال بودن، مدل را وادار به متقارن بودن می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `تخت کردن پایین` | در صورت فعال بودن، پایین مدل را مسطح می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `آستانه تخت کردن پایین` | عمق مسطح‌سازی مورد استفاده همراه با `flatten_bottom` (پیش‌فرض: 0.01). این مقدار تنها زمانی اعمال می‌شود که `flatten_bottom` فعال باشد. | FLOAT | خیر | 0.01 تا 1.0 |
| `محور به مرکز پایین` | در صورت فعال بودن، نقطه محوری را به پایین مرکز مدل منتقل می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `ضریب مقیاس` | ضریب مقیاس اعمال‌شده به مدل تبدیل‌شده (پیش‌فرض: 1.0). | FLOAT | خیر | 0.01 and above |
| `با انیمیشن` | اسکلت و انیمیشن مدل‌های ریگ‌شده یا بازهدف‌گذاری‌شده را نگه می‌دارد (پیش‌فرض: True). | BOOLEAN | خیر | True or False |
| `بسته‌بندی UV` | در صورت فعال بودن، مختصات UV را دوباره بسته‌بندی می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `بِیک` | مواد پیشرفته را برای سازگاری بیشتر در بافت‌های پایه بیک می‌کند (پیش‌فرض: True). | BOOLEAN | خیر | True or False |
| `نام بخش‌ها` | فهرست جداشده با کاما از نام‌های بخش‌های مدل برای ارسال به تبدیل. ورودی‌های خالی نادیده گرفته می‌شوند و نام‌های تکراری حذف می‌شوند. برای حذف این گزینه، آن را خالی بگذارید (پیش‌فرض: خالی). | STRING | خیر | فهرست نام‌های بخش جداشده با کاما |
| `پیش‌تنظیم FBX` | پیش‌تنظیم سازگاری FBX. bake_scale تبدیل مقیاس را در هندسه بیک می‌کند (پیش‌فرض: blender). | COMBO | خیر | blender<br>mixamo<br>3dsmax<br>bake_scale |
| `خروجی رنگ رأس‌ها` | در صورت فعال بودن، رنگ‌های رأس را صادر می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |
| `خروجی جهت` | محور جلو برای مدل صادرشده. default محور +x مربوط به Tripo را نگه می‌دارد (پیش‌فرض: default). | COMBO | خیر | default<br>+x<br>-x<br>+y<br>-y |
| `انیمیشن در محل` | در صورت فعال بودن، مدل را در جای خود انیمیت می‌کند (پیش‌فرض: False). | BOOLEAN | خیر | True or False |

**توجه:** به‌جز `original_model_task_id` و `format`، همه ورودی‌ها تنظیمات پیشرفته اختیاری هستند. بیشتر تنظیماتی که در مقادیر پیش‌فرض خود رها شوند، از درخواست تبدیل حذف می‌شوند تا Tripo API بتواند رفتار استاندارد خود را اعمال کند. گزینه‌های `with_animation` و `bake` همیشه ارسال می‌شوند. `flatten_bottom_threshold` تنها زمانی اعمال می‌شود که `flatten_bottom` فعال باشد.
