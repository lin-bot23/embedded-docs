# Tripo: بخش‌بندی مدل

این گره یک مدل سه‌بعدی را به بخش‌های جداگانه تقسیم می‌کند. آن را به سرویس بخش‌بندی Tripo می‌فرستد، منتظر پایان کار می‌ماند و مدل بخش‌بندی‌شده را در قالب GLB همراه با فهرستی از نام بخش‌ها که با کاما از هم جدا شده‌اند برمی‌گرداند. این نام بخش‌ها به‌عنوان ورودی مراحل بعدی مانند Tripo: Complete Mesh Parts، Tripo: Retopology و Tripo: Convert model استفاده می‌شوند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه وظیفه مدل سه‌بعدی که باید به بخش‌ها تقسیم شود. | MODEL_TASK_ID | بله | ناموجود |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | نام فایل خروجی مدل GLB بخش‌بندی‌شده، به شکل `<task_id>.glb`. فقط برای حفظ سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `segment task_id` | شناسه وظیفه کار بخش‌بندی که نتیجه را تولید کرده است. | SEGMENT_TASK_ID |
| `GLB` | مدل سه‌بعدی بخش‌بندی‌شده، به‌صورت فایل GLB. | GLB |
| `part_names` | نام‌های بخش‌ها که با کاما از هم جدا شده‌اند. | STRING |
