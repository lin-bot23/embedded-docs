# Tripo: تقسيم النموذج

تقوم هذه العقدة بتقسيم نموذج ثلاثي الأبعاد إلى أجزاء منفصلة. ترسل النموذج إلى خدمة التقسيم Tripo، وتنتظر انتهاء المهمة، ثم تُعيد النموذج المُقسَّم بصيغة GLB مع قائمة أسماء الأجزاء مفصولة بفواصل. تُستخدم أسماء الأجزاء هذه كمدخلات للخطوات اللاحقة مثل Tripo: Complete Mesh Parts وTripo: Retopology وTripo: Convert model.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف المهمة (task ID) للنموذج ثلاثي الأبعاد المراد تقسيمه إلى أجزاء. | MODEL_TASK_ID | نعم | N/A |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | اسم ملف الإخراج لنموذج GLB المُقسَّم، بالصيغة `<task_id>.glb`. محتفظ به للتوافق مع الإصدارات السابقة فقط. | STRING |
| `مهمة task_id` | معرّف المهمة (task ID) لمهمة التقسيم التي أنتجت النتيجة. | SEGMENT_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُقسَّم، كملف GLB. | GLB |
| `part_names` | أسماء الأجزاء مفصولة بفواصل. | STRING |
