# تبدیل مرجع MiniMax H3 به ویدیو

این گره با استفاده از مدل‌های MiniMax H3 یک ویدیو تولید می‌کند، که بر اساس تصاویر، ویدیوها و صوت‌های مرجع شرطی‌گذاری شده است. ارجاعات در پرامپت بر اساس ترتیب اتصال آن‌ها نامیده می‌شوند: "Image 1"، "Image 2"، "Video 1"، "Audio 1" و غیره. دو مدل در دسترس است: "MiniMax H3" و "MiniMax H3 Max".

## ورودی‌ها

### ورودی‌های مشترک

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل مورد استفاده برای تولید ویدیو (پیش‌فرض: "MiniMax H3"). انتخاب "MiniMax H3" ورودی‌های تولید و مرجع MiniMax H3 را در زیر فراهم می‌کند. انتخاب "MiniMax H3 Max" ورودی‌های تولید و مرجع MiniMax H3 Max را در زیر فراهم می‌کند. | DYNAMIC_COMBO | بله | "MiniMax H3"<br>"MiniMax H3 Max" |
| `seed` | seed تصادفی. درخواست یکسان با seed یکسان نتایج مشابه، اما نه لزوماً یکسان، می‌دهد (پیش‌فرض: 42). | INT | بله | 0 تا 4294967295 |
| `واترمارک` | آیا واترمارک AIGC به ویدیو اضافه شود (پیش‌فرض: false). فقط توسط مدل MiniMax H3 پشتیبانی می‌شود. | BOOLEAN | خیر | true<br>false |

### ورودی‌های MiniMax H3

این ورودی‌ها زمانی در دسترس هستند که "MiniMax H3" به عنوان مدل انتخاب شود.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | پرامپت متنی برای تولید ویدیو. رسانه‌های مرجع می‌توانند بر اساس ترتیب خود ارجاع داده شوند، برای مثال "Image 1"، "Image 2"، "Video 1" یا "Audio 1". | STRING | بله | Minimum 1 character |
| `resolution` | رزولوشن ویدیوی خروجی (پیش‌فرض: "768P"). | COMBO | بله | "768P"<br>"2K" |
| `ratio` | نسبت ابعاد ویدیوی خروجی (پیش‌فرض: "adaptive"). | COMBO | بله | "adaptive"<br>"16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | مدت زمان ویدیوی خروجی بر حسب ثانیه (پیش‌فرض: 5). | INT | بله | 4 تا 15 |

### ورودی‌های مرجع

این ورودی‌های مرجع بین هر دو مدل مشترک هستند. هر کدام یک اسلات قابل افزایش هستند.

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `reference_images` | اسلات قابل افزایش: اتصال تا ۹ آیتم (`image_1`...`image_9`). تصاویر مرجع سوژه یا سبک، که در پرامپت به صورت "Image 1".."Image 9" بر اساس ترتیب اتصال ارجاع داده می‌شوند. حداکثر ۹ تصویر. | IMAGE | خیر | 0 تا 9 images |
| `reference_videos` | اسلات قابل افزایش: اتصال تا ۳ آیتم (`video_1`...`video_3`). ویدیوهای مرجع حرکت یا صحنه، که در پرامپت به صورت "Video 1".."Video 3" بر اساس ترتیب اتصال ارجاع داده می‌شوند. حداکثر ۳ ویدیو، هر کدام ۲ تا ۱۵ ثانیه، در مجموع ۱۵ ثانیه. | VIDEO | خیر | 0 تا 3 videos |
| `reference_audios` | اسلات قابل افزایش: اتصال تا ۳ آیتم (`audio_1`...`audio_3`). ارجاعات صوتی، که در پرامپت به صورت "Audio 1".."Audio 3" بر اساس ترتیب اتصال ارجاع داده می‌شوند. حداکثر ۳ کلیپ، هر کدام ۲ تا ۱۵ ثانیه، در مجموع ۱۵ ثانیه. بدون تصویر یا ویدیوی مرجع قابل استفاده نیست. | AUDIO | خیر | 0 تا 3 clips |

### محدودیت‌های پارامتر

- حداقل یک تصویر مرجع یا یک ویدیوی مرجع الزامی است. صوت مرجع به تنهایی پذیرفته نمی‌شود.
- هر تصویر مرجع باید نسبت ابعادی بین تقریباً ۰.۴ تا ۲.۵ (۲:۵ تا ۵:۲) و حداقل عرض و ارتفاع ۲۵۶ پیکسل داشته باشد.
- هر ویدیوی مرجع باید بین ۲ تا ۱۵ ثانیه طول داشته باشد با نرخ فریم بین ۲۳.۹۷۶ تا ۶۰ FPS. مدت زمان کل تمام ویدیوهای مرجع نمی‌تواند از ۱۵ ثانیه تجاوز کند.
- هر کلیپ صوتی مرجع باید بین ۲ تا ۱۵ ثانیه طول داشته باشد. مدت زمان کل تمام کلیپ‌های صوتی مرجع نمی‌تواند از ۱۵ ثانیه تجاوز کند.
- وقتی "MiniMax H3 Max" انتخاب می‌شود، تنظیم `watermark` باید غیرفعال باشد.
- وقتی "MiniMax H3 Max" انتخاب می‌شود، تعداد کل فایل‌های مرجع (تصاویر، ویدیوها و صوت با هم) نمی‌تواند از ۱۲ تجاوز کند.
