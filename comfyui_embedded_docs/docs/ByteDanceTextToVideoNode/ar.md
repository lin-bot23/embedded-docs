# ByteDance نص إلى فيديو

تقوم وحدة تحويل النص إلى فيديو من ByteDance بإنتاج الفيديوهات باستخدام نماذج ByteDance عبر واجهة برمجة التطبيقات (API) بناءً على إشارات نصية. تأخذ الوحدة نصوصًا نصية وضبطات فيديو متعددة كمدخلات، ثم تنتج فيديو يتطابق مع التفاصيل المقدمة. تقوم الوحدة بمعالجة اتصالات API وتعيد الفيديو المُنتج كخرج.

## نظرة عامة

تُصمم وحدة تحويل النص إلى فيديو من ByteDance لتحويل إشارات النص إلى فيديوهات باستخدام قدرات الذكاء الاصطناعي لـ ByteDance. يمكن للمستخدمين تحديد النموذج، دقة الفيديو، نسبة الأبعاد، المدة، وغيرها من المعلمات لتحكم في عملية إنشاء الفيديو.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | نطاق |
|-----------|-------------|-----------|----------|-------|
| `النموذج` | النموذج الذي سيُستخدم للإنشاء. | STRING | نعم | 
  - "seedance-1-5-pro-251215"
  - "seedance-1-0-pro-250528"
  - "seedance-1-0-pro-fast-251015" |
| `النص الموجه` | الإشارة النصية المستخدمة لإنتاج الفيديو. | STRING | نعم | إدخال نص متعدد الأسطر |
| `الدقة` | دقة الفيديو المُنتج. | STRING | نعم | 
  - "480p"
  - "720p"
  - "1080p" |
| `نسبة العرض إلى الارتفاع` | نسبة الأبعاد للفيديو المُنتج. | STRING | نعم | 
  - "16:9"
  - "4:3"
  - "1:1"
  - "3:4"
  - "9:16"
  - "21:9" |
| `المدة` | مدة الفيديو المُنتج بالثواني. | INT | نعم | من 3 إلى 12 ثانية |
| `البذرة` | البذرة التي سيُستخدمها للإنشاء. | INT | لا | من 0 إلى 2,147,483,647 |
| `الكاميرا ثابتة` | تحديد ما إذا كان يجب تثبيت الكاميرا. | BOOLEAN | لا | - |
| `علامة مائية` | تحديد ما إذا كان يجب إضافة علامة مائية "مُنتج بواسطة الذكاء الاصطناعي" على الفيديو. | BOOLEAN | لا | - |
| `توليد الصوت` | هذا المعامل يتم تجاهله لجميع النماذج باستثناء `seedance-1-5-pro-251215`. | BOOLEAN | لا | - |

**محدوديات المعاملات:**

- يجب أن يحتوي المعامل `prompt` على على الأقل رمز واحد بعد إزالة البيانات الزائدة.
- لا يمكن أن يحتوي المعامل `prompt` على المعاملات النصية التالية: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- يتم تقييد `duration` إلى قيم بين 3 و 12 ثانية.
- بالنسبة لنموذج `seedance-1-5-pro-251215`، هي مدة الدعم الأدنى هي 4 ثانية.
- يقبل المعامل `seed` قيمًا من 0 إلى 2,147,483,647.
- يتم تجاهل المعامل `generate_audio` لجميع النماذج باستثناء `seedance-1-5-pro-251215`.
