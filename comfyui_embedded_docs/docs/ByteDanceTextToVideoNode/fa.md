# تبدیل متن به ویدیو ByteDance

گره تبدیل متن به ویدیو ByteDance ویدیو‌هایی را با استفاده از مدل‌های ByteDance از طریق یک API بر اساس نکات نوشتاری تولید می‌کند. این گره نکات نوشتاری و تنظیمات مختلف ویدیو را به عنوان ورودی می‌گیرد، سپس ویدیویی که با مشخصات ارائه شده مطابقت دارد، ایجاد می‌کند. این گره ارتباط با API را مدیریت کرده و ویدیوی تولید شده را به عنوان خروجی بازمی‌گرداند.

## مقدمه

گره تبدیل متن به ویدیو ByteDance طراحی شده است تا نکات نوشتاری را به ویدیو‌ها تبدیل کند که از توانایی‌های هوش مصنوعی ByteDance استفاده می‌کند. کاربران می‌توانند مدل، رزولوشن، نسبت ابعاد، طول و سایر پارامترها را مشخص کنند تا فرآیند تولید ویدیو را کنترل کنند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل ByteDance برای استفاده در تولید. | STRING | بله | 
  - "seedance-1-5-pro-251215"
  - "seedance-1-0-pro-250528"
  - "seedance-1-0-pro-fast-251015" |
| `پرامپت` | نکات نوشتاری استفاده شده برای تولید ویدیو. | STRING | بله | ورودی متن چند خطی |
| `وضوح` | رزولوشن ویدیوی خروجی. | STRING | بله | 
  - "480p"
  - "720p"
  - "1080p" |
| `نسبت تصویر` | نسبت ابعاد ویدیوی خروجی. | STRING | بله | 
  - "16:9"
  - "4:3"
  - "1:1"
  - "3:4"
  - "9:16"
  - "21:9" |
| `مدت زمان` | طول ویدیوی خروجی به ثانیه. | INT | بله | 3 تا 12 ثانیه |
| `بذر` | عدد اول برای استفاده در تولید. | INT | خیر | 0 تا 2,147,483,647 |
| `ثابت بودن دوربین` | مشخص می‌کند که آیا دوربین را ثابت نگه داریم یا خیر. | BOOLEAN | خیر | - |
| `واترمارک` | مشخص می‌کند که آیا برچسب "تولید شده توسط AI" به ویدیو اضافه شود یا خیر. | BOOLEAN | خیر | - |
| `تولید صدا` | این پارامتر برای مدل‌های غیر `seedance-1-5-pro-251215` نادیده گرفته می‌شود. | BOOLEAN | خیر | - |

**محدودیت‌های پارامتر:**

- `prompt` باید حداقل 1 کاراکتر پس از حذف فاصله‌ها داشته باشد.
- `prompt` نمی‌تواند شامل پارامترهای نوشتاری زیر باشد: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- `duration` محدود به مقادیر بین 3 تا 12 ثانیه است.
- برای مدل `seedance-1-5-pro-251215`، طول حداقلی پشتیبانی شده 4 ثانیه است.
- `seed` مقادیر از 0 تا 2,147,483,647 را پذیرش می‌کند.
- پارامتر `generate_audio` فقط زمانی اثر دارد که `model` به `seedance-1-5-pro-251215` تنظیم شود؛ برای مدل‌های دیگر نادیده گرفته می‌شود.
