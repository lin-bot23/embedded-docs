# Узел Text to Video от ByteDance

Узел Text to Video от ByteDance генерирует видео с использованием моделей ByteDance через API на основе текстовых подсказок. Он принимает текстовое описание и различные параметры видео в качестве входных данных, затем создает видео, соответствующее предоставленным спецификациям. Узел обрабатывает коммуникацию с API и возвращает сгенерированное видео в качестве выходных данных.

## Обзор

Узел Text to Video от ByteDance предназначен для преобразования текстовых подсказок в видео с использованием возможностей AI от ByteDance. Пользователи могут specify the model, resolution, aspect ratio, duration, и другие параметры для управления процессом генерации видео.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель ByteDance, которую использовать для генерации. | STRING | Да | 
  - "seedance-1-5-pro-251215"
  - "seedance-1-0-pro-250528"
  - "seedance-1-0-pro-fast-251015" |
| `промпт` | Текстовая подсказка, используемая для генерации видео. | STRING | Да | Multiline text input |
| `разрешение` | Разрешение выходного видео. | STRING | Да | 
  - "480p"
  - "720p"
  - "1080p" |
| `соотношение_сторон` | Соотношение сторон выходного видео. | STRING | Да | 
  - "16:9"
  - "4:3"
  - "1:1"
  - "3:4"
  - "9:16"
  - "21:9" |
| `длительность` | Продолжительность выходного видео в секундах. | INT | Да | 3 до 12 секунд |
| `сид` | Seed для использования при генерации. | INT | Нет | 0 до 2,147,483,647 |
| `камера_зафиксирована` | Указывает, следует ли фиксировать камеру. | BOOLEAN | Нет | - |
| `водяной_знак` | Указывает, следует ли добавить водяной знак "AI generated" на видео. | BOOLEAN | Нет | - |
| `generate_audio` | Этот параметр игнорируется для всех моделей, кроме `seedance-1-5-pro-251215`. | BOOLEAN | Нет | - |

**Ограничения параметров:**

- Подсказка `prompt` должна содержать по крайней мере 1 символ после удаления пробелов.
- Подсказка `prompt` не может содержать следующих текстовых параметров: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- Продолжительность `duration` ограничена значениями между 3 и 12 секунд.
- Для модели `seedance-1-5-pro-251215` минимальная поддерживаемая продолжительность составляет 4 секунды.
- Параметр `seed` принимает значения от 0 до 2,147,483,647.
- Параметр `generate_audio` имеет эффект только при установке `model` в `seedance-1-5-pro-251215`; он игнорируется для всех других моделей.

## Выходы

| Название выходного параметра | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный файл видео. | VIDEO |

**Примечание:** Узел Text to Video от ByteDance является узлом API и требует токенов аутентификации и ключей API для правильной работы. Эти данные предоставляются через скрытые входы `auth_token_comfy_org` и `api_key_comfy_org`.
