# ByteDance Текст в Видео

Узел ByteDance Text to Video генерирует видео с использованием моделей ByteDance через API на основе текстового запроса. Вы предоставляете текстовый запрос и выбираете такие настройки, как модель, разрешение, соотношение сторон и длительность; узел отправляет запрос на генерацию и возвращает сгенерированное видео.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель ByteDance, используемая для генерации видео (по умолчанию: `"seedance-1-0-pro-fast-251015"`). | COMBO | Да | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"`<br>`"seedance-1-0-pro-fast-251015"` |
| `промпт` | Текстовый запрос, используемый для генерации видео. | STRING | Да | - |
| `разрешение` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `соотношение_сторон` | Соотношение сторон выходного видео. | COMBO | Да | `"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `длительность` | Длительность выходного видео в секундах (по умолчанию: 5). | INT | Да | от 3 до 12 |
| `сид` | Сид, используемый для генерации (по умолчанию: 0). | INT | Нет | от 0 до 2 147 483 647 |
| `камера_зафиксирована` | Указывает, нужно ли фиксировать камеру. Платформа добавляет к запросу инструкцию о фиксации камеры, но не гарантирует фактический результат (по умолчанию: False). | BOOLEAN | Нет | - |
| `водяной_знак` | Нужно ли добавлять на видео водяной знак «AI generated» (по умолчанию: False). | BOOLEAN | Нет | - |
| `generate_audio` | Этот параметр игнорируется для всех моделей, кроме `seedance-1-5-pro-251215` (по умолчанию: False). | BOOLEAN | Нет | - |

**Ограничения параметров:**

- Параметр `prompt` должен содержать не менее 1 символа после удаления пробельных символов.
- Параметр `prompt` не может содержать следующие текстовые параметры: "resolution", "ratio", "duration", "seed", "camerafixed", "watermark".
- Узел формирует итоговый текстовый запрос, добавляя к исходному тексту запроса выбранные значения параметров `resolution`, `aspect_ratio`, `duration`, `seed`, `camera_fixed` и `watermark`.
- Параметр `duration` ограничен значениями от 3 до 12 секунд. Для модели `seedance-1-5-pro-251215` минимальная поддерживаемая длительность составляет 4 секунды.
- Параметр `seed` принимает значения от 0 до 2 147 483 647.
- Параметр `generate_audio` действует только тогда, когда для параметра `model` установлено значение `seedance-1-5-pro-251215`; для всех остальных моделей он игнорируется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированный видеофайл | VIDEO |
