# OpenAI ChatGPT

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ورودی‌های متنی برای مدل که برای تولید پاسخ استفاده می‌شوند (پیش‌فرض: رشته خالی). | STRING | بله | - |
| `persist_context` | این پارامتر منسوخ شده است و تأثیری ندارد (پیش‌فرض: False). | BOOLEAN | بله | - |
| `model` | مدل مورد استفاده برای تولید پاسخ (پیش‌فرض: `gpt-5`) | COMBO | بله | `gpt-6-astra`<br>`gpt-5.6-sol`<br>`gpt-5.6-terra`<br>`gpt-5.6-luna`<br>`gpt-5.5-pro`<br>`gpt-5.5`<br>`gpt-5`<br>`gpt-5-mini`<br>`gpt-5-nano`<br>`gpt-4.1`<br>`gpt-4.1-mini`<br>`gpt-4.1-nano`<br>`o4-mini`<br>`o3`<br>`o1-pro`<br>`o1` |
| `images` | تصویر(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. برای گنجاندن چندین تصویر، می‌توانید از گره Batch Images استفاده کنید. | IMAGE | خیر | - |
| `files` | فایل(های) اختیاری برای استفاده به‌عنوان زمینه برای مدل. ورودی‌هایی را از گره OpenAI Chat Input Files می‌پذیرد. | OPENAI_INPUT_FILES | خیر | - |
| `advanced_options` | پیکربندی اختیاری برای مدل. ورودی‌هایی را از گره OpenAI Chat Advanced Options می‌پذیرد. | OPENAI_CHAT_CONFIG | خیر | - |

توجه: هنگامی که پیکربندی `advanced_options` که یک تلاش استدلال را تنظیم می‌کند متصل باشد، `model` انتخاب‌شده باید از آن مقدار تلاش پشتیبانی کند. برای مثال، خانواده مدل‌های gpt-4.1 از هیچ تلاش استدلالی پشتیبانی نمی‌کند، `gpt-5.5` از none، low، medium، high و xhigh پشتیبانی می‌کند و `gpt-5.5-pro` از medium، high و xhigh پشتیبانی می‌کند. اگر تلاش استدلال توسط مدل انتخاب‌شده پشتیبانی نشود، گره خطا می‌دهد.
