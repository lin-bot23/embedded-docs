# OpenAI ChatGPT

این گره پاسخ‌های متنی از مدل OpenAI تولید می‌کند. یک ورودی متنی و گزینه‌ای تصاویر یا فایل‌ها به عنوان زمینه، دریافت می‌کند و سپس این اطلاعات را به مدل OpenAI ارسال می‌کند تا پاسخ متنی تولید شود.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `prompt` | ورودی‌های متنی به مدل، که برای تولید پاسخ استفاده می‌شود. این متنی است که می‌خواهید مدل به آن پاسخ دهد. | STRING | بله | - |
| `persist_context` | این پارامتر منسوخ شده و هیچ تأثیری ندارد. برای سازگاری با گذشته شامل شده است اما تأثیری بر رفتار گره ندارد. | BOOLEAN | خیر | - |
| `model` | مدلی که برای تولید پاسخ استفاده می‌شود. از بین مدل‌های موجود OpenAI انتخاب کنید. | COMBO | بله | gpt-6-astra<br>gpt-5.6-sol<br>gpt-5.6-terra<br>gpt-5.6-luna<br>gpt-5.5-pro<br>gpt-5.5<br>gpt-5<br>gpt-5-mini<br>gpt-5-nano<br>gpt-4.1<br>gpt-4.1-mini<br>gpt-4.1-nano<br>o4-mini<br>o3<br>o1-pro<br>o1 |
| `images` | تصویر(ها) گزینه‌ای برای استفاده به عنوان زمینه برای مدل. برای اضافه کردن چندین تصویر، می‌توانید از گره Batch Images استفاده کنید. | IMAGE | خیر | - |
| `files` | فایل(ها) گزینه‌ای برای استفاده به عنوان زمینه برای مدل. ورودی‌ها از گره OpenAI Chat Input Files دریافت می‌شوند. | OPENAI_INPUT_FILES | خیر | - |
| `advanced_options` | تنظیمات گزینه‌ای برای مدل. ورودی‌ها از گره OpenAI Chat Advanced Options دریافت می‌شوند. | OPENAI_CHAT_CONFIG | خیر | - |

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `output_text` | پاسخ متنی تولید شده توسط مدل OpenAI. این متنی است که بر اساس ورودی‌های پیشنهادی و زمینه تولید شده است. | STRING |

## یادداشت‌ها

- پارامتر `persist_context` منسوخ شده و هیچ تأثیری ندارد. برای سازگاری با گذشته شامل شده است اما تأثیری بر رفتار گره ندارد.
- ورودی `images` می‌تواند برای ارائه زمینه اضافی به مدل استفاده شود. اگر چندین تصویر ارائه شد، باید با استفاده از گره Batch Images به هم متصل شوند.
- ورودی `files` به شما امکان می‌دهد تا زمینه اضافی به صورت فایل ارائه دهید. این فایل‌ها باید از گره OpenAI Chat Input Files متصل شوند.
- ورودی `advanced_options` برای تنظیمات دقیق‌تر رفتار مدل استفاده می‌شود. این ورودی باید از گره OpenAI Chat Advanced Options متصل شود.
- هزینه استفاده از این گره بستگی به مدلی دارد که انتخاب می‌کنید. هزینه بر اساس تعداد توکن‌های استفاده شده توسط مدل محاسبه می‌شود. هزینه دقیق در رابط کاربری گره نمایش داده می‌شود.
- این مستند تغییرات منبع کد را منعکس می‌کند، از جمله حذف پارامتر منسوخ شده `persist_context` و اضافه کردن ورودی‌های `images` و `files`. همچنین توضیحات دستی و یادداشت‌های موجود در مستند قبلی که همچنان معتبر هستند، حفظ شده‌اند.
