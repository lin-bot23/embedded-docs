# OpenAI ChatGPT

Этот узел генерирует текстовые ответы от модели OpenAI. Он принимает текстовый запрос и optionally изображения или файлы в качестве контекста, а затем отправляет эту информацию в модель OpenAI для генерации текстового ответа.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовые входы для модели, используемые для генерации ответа. Это текст, на который модель должна ответить. | STRING | Да | - |
| `сохранять_контекст` | Этот параметр устарел и не оказывает никакого влияния. Он включен для обратной совместимости, но не влияет на поведение узла. | BOOLEAN | Нет | - |
| `модель` | Модель, используемая для генерации ответа. Выберите из доступных моделей OpenAI. | COMBO | Да | gpt-6-astra<br>gpt-5.6-sol<br>gpt-5.6-terra<br>gpt-5.6-luna<br>gpt-5.5-pro<br>gpt-5.5<br>gpt-5<br>gpt-5-mini<br>gpt-5-nano<br>gpt-4.1<br>gpt-4.1-mini<br>gpt-4.1-nano<br>o4-mini<br>o3<br>o1-pro<br>o1 |
| `изображения` | Опциональные изображения для использования в качестве контекста модели. Для включения нескольких изображений можно использовать узел Batch Images. | IMAGE | Нет | - |
| `файлы` | Опциональные файлы для использования в качестве контекста модели. Принимает входы от узла OpenAI Chat Input Files. | OPENAI_INPUT_FILES | Нет | - |
| `расширенные_настройки` | Опциональная конфигурация модели. Принимает входы от узла OpenAI Chat Advanced Options. | OPENAI_CHAT_CONFIG | Нет | - |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output_text` | Текстовый ответ, генерируемый моделью OpenAI. Это генерируемый текст на основе входного запроса и контекста. | STRING |

## Замечания

- Параметр `persist_context` устарел и не оказывает никакого влияния. Он включен для обратной совместимости, но не должен использоваться.
- Вход `images` можно использовать для предоставления дополнительного контекста модели. Если предоставляются несколько изображений, они должны быть подключены с помощью узла Batch Images.
- Вход `files` позволяет предоставлять дополнительный контекст в виде файлов. Эти файлы должны быть подключены от узла OpenAI Chat Input Files.
- Вход `advanced_options` позволяет более детально настроить поведение модели. Этот вход должен быть подключен от узла OpenAI Chat Advanced Options.
- Ценообразование для использования этого узла зависит от выбранной модели. Стоимость рассчитывается на основе количества токенов, используемых моделью. Точная стоимость будет отображаться в интерфейсе узла.
