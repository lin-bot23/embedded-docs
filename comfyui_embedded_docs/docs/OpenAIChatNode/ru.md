# OpenAI ChatGPT

Этот узел генерирует текстовые ответы с помощью модели OpenAI. Он отправляет ваш текстовый запрос и, при необходимости, изображения или файлы в модель OpenAI и возвращает сгенерированный текстовый ответ.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `запрос` | Текстовые входы для модели, используемые для генерации ответа (по умолчанию: пустая строка). | STRING | Да | - |
| `сохранять_контекст` | Этот параметр устарел и не оказывает эффекта (по умолчанию: False). | BOOLEAN | Да | - |
| `модель` | Модель, используемая для генерации ответа (по умолчанию: `gpt-5`) | COMBO | Да | `gpt-6-astra`<br>`gpt-5.6-sol`<br>`gpt-5.6-terra`<br>`gpt-5.6-luna`<br>`gpt-5.5-pro`<br>`gpt-5.5`<br>`gpt-5`<br>`gpt-5-mini`<br>`gpt-5-nano`<br>`gpt-4.1`<br>`gpt-4.1-mini`<br>`gpt-4.1-nano`<br>`o4-mini`<br>`o3`<br>`o1-pro`<br>`o1` |
| `изображения` | Необязательные изображения для использования в качестве контекста для модели. Чтобы включить несколько изображений, можно использовать узел Batch Images. | IMAGE | Нет | - |
| `файлы` | Необязательные файлы для использования в качестве контекста для модели. Принимает входы от узла OpenAI Chat Input Files. | OPENAI_INPUT_FILES | Нет | - |
| `расширенные_настройки` | Необязательная конфигурация для модели. Принимает входы от узла OpenAI Chat Advanced Options. | OPENAI_CHAT_CONFIG | Нет | - |

Примечание. Когда подключена конфигурация `advanced_options`, которая задаёт уровень рассуждений (reasoning effort), выбранная `model` должна поддерживать этот уровень. Например, семейство моделей gpt-4.1 не поддерживает никакого уровня рассуждений, `gpt-5.5` поддерживает none, low, medium, high и xhigh, а `gpt-5.5-pro` поддерживает medium, high и xhigh. Если уровень рассуждений не поддерживается выбранной моделью, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output_text` | Текстовый ответ, сгенерированный моделью OpenAI. | STRING |
