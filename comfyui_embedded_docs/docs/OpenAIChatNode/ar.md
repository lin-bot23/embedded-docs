# OpenAI ChatGPT

هذه العقدة تولّد استجابات نصية من نموذج OpenAI. تُرسل نص المطالبة الخاص بك، واختياريًا الصور أو الملفات، إلى نموذج OpenAI وتُرجِع الاستجابة النصية المُولَّدة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | النصوص المُدخلة إلى النموذج، وتُستخدم لتوليد استجابة (الافتراضي: سلسلة فارغة). | STRING | نعم | - |
| `persist_context` | هذه المعلمة مُهملة وليس لها أي تأثير (الافتراضي: False). | BOOLEAN | نعم | - |
| `model` | النموذج المستخدم لتوليد الاستجابة (الافتراضي: `gpt-5`) | COMBO | نعم | `gpt-6-astra`<br>`gpt-5.6-sol`<br>`gpt-5.6-terra`<br>`gpt-5.6-luna`<br>`gpt-5.5-pro`<br>`gpt-5.5`<br>`gpt-5`<br>`gpt-5-mini`<br>`gpt-5-nano`<br>`gpt-4.1`<br>`gpt-4.1-mini`<br>`gpt-4.1-nano`<br>`o4-mini`<br>`o3`<br>`o1-pro`<br>`o1` |
| `images` | صورة أو صور اختيارية لاستخدامها كسياق للنموذج. لتضمين صور متعددة، يمكنك استخدام عقدة Batch Images. | IMAGE | لا | - |
| `files` | ملفات اختيارية لاستخدامها كسياق للنموذج. تقبل مدخلات من عقدة OpenAI Chat Input Files. | OPENAI_INPUT_FILES | لا | - |
| `advanced_options` | إعداد اختياري للنموذج. يقبل مدخلات من عقدة OpenAI Chat Advanced Options. | OPENAI_CHAT_CONFIG | لا | - |

ملاحظة: عند توصيل إعداد `advanced_options` يحدد مستوى جهد الاستدلال، يجب أن يدعم النموذج المحدد قيمة مستوى الجهد هذا. على سبيل المثال، لا تدعم عائلة نماذج gpt-4.1 أي مستوى من مستويات جهد الاستدلال، بينما يدعم `gpt-5.5` القيم none وlow وmedium وhigh وxhigh، ويدعم `gpt-5.5-pro` القيم medium وhigh وxhigh. إذا كان مستوى جهد الاستدلال غير مدعوم من النموذج المحدد، تُصدر العقدة خطأً.
