# OpenAI ChatGPT

يُنتج هذا العقد ردود نصية من نموذج OpenAI. يتلقى إدخالات نصية واختياري صور أو ملفات كسياق، ثم يرسل هذه المعلومات إلى نموذج OpenAI لإنشاء رد نصي.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | نطاق |
|-----------|-------------|-----------|----------|-------|
| `prompt` | إدخالات النص إلى النموذج، تستخدم لإنشاء الرد. هذا هو النص الذي تريد أن يرد النموذج عليه. | STRING | نعم | - |
| `persist_context` | هذا المعامل تم إزالته ولم يعد له أي تأثير. تم إضافته للتوافق مع الإصدارات السابقة ولكنه لا يؤثر على سلوك العقد. | BOOLEAN | لا | - |
| `model` | النموذج المستخدم لإنشاء الرد. اختر من بين النماذج المتاحة لـ OpenAI. | COMBO | نعم | gpt-6-astra<br>gpt-5.6-sol<br>gpt-5.6-terra<br>gpt-5.6-luna<br>gpt-5.5-pro<br>gpt-5.5<br>gpt-5<br>gpt-5-mini<br>gpt-5-nano<br>gpt-4.1<br>gpt-4.1-mini<br>gpt-4.1-nano<br>o4-mini<br>o3<br>o1-pro<br>o1 |
| `images` | صور اختيارية تستخدم كسياق للنموذج. لاستخدام صور متعددة، يمكنك استخدام عقد Batch Images. | IMAGE | لا | - |
| `files` | ملفات اختيارية تستخدم كسياق للنموذج. يقبل الإدخالات من عقد OpenAI Chat Input Files. | OPENAI_INPUT_FILES | لا | - |
| `advanced_options` | تكوين اختياري للنموذج. يقبل الإدخالات من عقد OpenAI Chat Advanced Options. | OPENAI_CHAT_CONFIG | لا | - |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `output_text` | النص الرد الذي أنشأه نموذج OpenAI. هذا هو النص المُنتج بناءً على الإدخال النصي والسياق. | STRING |

## ملاحظات

- المعامل `persist_context` تم إزالته ولم يعد له أي تأثير. تم إضافته للتوافق مع الإصدارات السابقة ولكنه لا يجب استخدامه.
- يمكن استخدام الإدخال `images` لتقديم سياق إضافي للنموذج. إذا تم تقديم صور متعددة، يجب ربطها باستخدام عقد Batch Images.
- يسمح الإدخال `files` بتقديم سياق إضافي على شكل ملفات. يجب ربط هذه الملفات من عقد OpenAI Chat Input Files.
- يسمح الإدخال `advanced_options` بتكوين سلوك النموذج بشكل مفصل. يجب ربط هذا الإدخال من عقد OpenAI Chat Advanced Options.
- تكلفة استخدام هذا العقد تعتمد على النموذج المختار. يتم حساب التكلفة بناءً على عدد التokens المستخدمة من قبل النموذج. سيتم عرض تكلفة الدقة في واجهة العقد.

هذه الوثيقة تعكس التغييرات في الكود المصدر، بما في ذلك إزالة المعامل المزيل `persist_context` وإضافة المدخلات `images` و`files`. كما تُبقِ الوثيقة الوصفات والملحوظات التي كتبت يدويًا من الوثيقة الموجودة وما تزال صحيحة.
