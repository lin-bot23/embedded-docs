# تطبيق Anima LLLite

أنيماللايت تطبيق (AnimaLLLiteApply) يطبّق ترقيعًا خفيفًا للرسوم المتحركة على نموذج الانتشار، مما يتيح توليدًا محكومًا من صورة إلى صورة مع قوة وتوقيت قابلين للضبط. يدمج هذا الترقيع ترقيع نموذج مُهيأ مسبقًا مع صورة إدخال وقناع اختياري، ويعدّل طبقات الانتباه وطبقات MLP في النموذج للتأثير على عملية التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model` | نموذج الانتشار الأساسي الذي سيتم تطبيق الترقيع عليه | MODEL | نعم | |
| `model_patch` | ترقيع الرسوم المتحركة المُهيأ مسبقًا والذي سيتم تطبيقه | MODEL_PATCH | نعم | |
| `image` | الصورة المرجعية لتوجيه عملية التوليد. يتم استخدام أول 3 قنوات لونية فقط (RGB) | IMAGE | نعم | |
| `strength` | قوة تأثير الترقيع (الافتراضي: 1.0) | FLOAT | نعم | -10.0 إلى 10.0 |
| `start_percent` | النسبة المئوية من عملية إزالة الضوضاء التي يبدأ عندها تأثير الترقيع (الافتراضي: 0.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `end_percent` | النسبة المئوية من عملية إزالة الضوضاء التي يتوقف عندها تأثير الترقيع (الافتراضي: 1.0) | FLOAT | نعم | 0.0 إلى 1.0 |
| `mask` | قناع اختياري لتحديد تأثير الترقيع على مناطق معينة من الصورة | MASK | لا | |

**ملاحظة حول قيود المعاملات:** إذا كان `model_patch` يحتوي على 4 قنوات إدخال ولم يتم توفير `mask`، فسيتم إنشاء قناع صفري تلقائيًا ليطابق أبعاد الصورة. إذا لم يكن `model_patch` يحتوي على 4 قنوات إدخال، فسيتم تجاهل معامل `mask` وتعيينه إلى `None`. يُشار إلى هذه العقدة على أنها تجريبية في ComfyUI.
