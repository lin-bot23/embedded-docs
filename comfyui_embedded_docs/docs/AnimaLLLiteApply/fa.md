# اعمال Anima LLLite

AnimaLLLiteApply یک پچ انیمیشن سبک را به یک مدل دیفیوژن اعمال می‌کند و تولید تصویر به تصویر کنترل‌شده را با قابلیت تنظیم قدرت و زمان‌بندی ممکن می‌سازد. این گره یک پچ مدل از پیش پیکربندی‌شده را با یک تصویر ورودی و ماسک اختیاری ادغام می‌کند و لایه‌های توجه و MLP مدل را برای تأثیرگذاری بر فرآیند تولید تغییر می‌دهد.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل دیفیوژن پایه برای اعمال پچ | MODEL | بله | |
| `patch مدل` | پچ انیمیشن از پیش پیکربندی‌شده برای اعمال | MODEL_PATCH | بله | |
| `تصویر` | تصویر مرجع برای هدایت تولید. تنها ۳ کانال رنگ اول (RGB) استفاده می‌شوند | IMAGE | بله | |
| `شدت` | قدرت اثر پچ (پیش‌فرض: ۱.۰) | FLOAT | بله | -10.0 تا 10.0 |
| `درصد شروع` | درصدی از فرآیند حذف نویز که در آن پچ شروع به اثرگذاری می‌کند (پیش‌فرض: ۰.۰) | FLOAT | بله | 0.0 تا 1.0 |
| `درصد پایان` | درصدی از فرآیند حذف نویز که در آن پچ توقف اثرگذاری می‌کند (پیش‌فرض: ۱.۰) | FLOAT | بله | 0.0 تا 1.0 |
| `ماسک` | یک ماسک اختیاری برای محدود کردن اثر پچ به نواحی خاصی از تصویر | MASK | خیر | |

**توجه درباره محدودیت‌های پارامتر:** اگر `model_patch` دارای ۴ کانال ورودی باشد و `mask` ارائه نشده باشد، یک ماسک صفر به‌طور خودکار برای تطابق با ابعاد تصویر ایجاد می‌شود. اگر `model_patch` دارای ۴ کانال ورودی نباشد، پارامتر `mask` نادیده گرفته شده و روی `None` تنظیم می‌شود. این گره در ComfyUI به عنوان آزمایشی علامت‌گذاری شده است.
