# Развёртка UV-сетки

Генерирует UV-атлас для 3D-сетки. Поверхность сетки разбивается на участки, каждый участок разворачивается в двух измерениях, после чего развёрнутые участки упаковываются в UV-атлас в диапазоне [0,1]. Вершины на швах участков дублируются, поэтому результирующая сетка может содержать больше вершин, чем входная.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Входная сетка для развёртки. Принимает одну сетку или пакет сеток. | MESH | Да | — |
| `segmenter` | Алгоритм построения участков для развёртки. `pec`: быстрое построение участков на GPU на основе параллельного схлопывания рёбер. `adaptive`: CPU, медленнее. (по умолчанию: "pec") | COMBO | Да | "pec"<br>"adaptive" |
| `resolution` | Целевое разрешение атласа для автоматического масштабирования по плотности текселей (0 = подгонка под содержимое). (по умолчанию: 1024) | INT | Да | 0 до 8192 (шаг 256) |
| `padding` | Отступ между участками в текселях. (по умолчанию: 1) | INT | Да | 0 до 16 |
| `weld_distance` | Радиус объединения совпадающих вершин, выраженный как доля протяжённости сетки (0 = автоматически). Увеличьте примерно до 0.001, если получаются отдельные карты для треугольников (входные вершины не сварены). (по умолчанию: 0.0) | FLOAT | Да | 0.0 до 1.0 (шаг 0.0001) |

Примечание: если входная сетка содержит несваренные вершины, узел может предупредить о низкой смежности граней и создавать UV-карты для каждой грани; увеличение значения `weld_distance` объединяет совпадающие вершины перед развёрткой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Входная сетка со сгенерированным UV-атласом в диапазоне [0,1]. Вершины на швах дублируются, поэтому количество вершин на выходе может превышать исходное. Цвета вершин и текстура входной сетки сохраняются. | MESH |
