# بازکردن UVهای مش

یک اطلس UV برای یک مش سه‌بعدی تولید می‌کند. سطح مش به بخش‌ها (charts) تقسیم می‌شود، هر بخش به دو بعد مسطح می‌شود و بخش‌های مسطح شده در یک اطلس UV با محدوده [0,1] بسته‌بندی می‌شوند. رأس‌های واقع در درزهای بخش‌ها تکثیر می‌شوند، بنابراین مش خروجی ممکن است دارای رأس‌های بیشتری نسبت به مش ورودی باشد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مش` | مش ورودی برای عملیات unwrap. یک مش تکی یا یک دسته از مش‌ها را می‌پذیرد. | MESH | بله | — |
| `بخش‌بند` | الگوریتم بخش‌بندی برای استفاده. `pec`: بخش‌بندی سریع فروپاشی لبه موازی روی GPU. `adaptive`: CPU، کندتر. (پیش‌فرض: "pec") | COMBO | بله | "pec"<br>"adaptive" |
| `وضوح` | رزولوشن هدف اطلس برای مقیاس خودکار چگالی تکسل (0 = auto). (پیش‌فرض: 1024) | INT | بله | 0 تا 8192 (گام 256) |
| `فاصله‌گذاری` | فاصله تکسل بین بخش‌ها. (پیش‌فرض: 1) | INT | بله | 0 تا 16 |
| `weld_distance` | شعاع ادغام رأس‌های منطبق به عنوان کسری از وسعت مش (0 = auto). اگر بخش‌های هر مثلث را دریافت می‌کنید (ورودی unwelded)، آن را تا ~0.001 افزایش دهید. (پیش‌فرض: 0.0) | FLOAT | بله | 0.0 تا 1.0 (گام 0.0001) |

توجه: اگر مش ورودی حاوی رأس‌های جوش‌نخورده (unwelded) باشد، گره ممکن است هشدار دهد که مجاورت وجه‌ها پایین است و بخش‌های UV برای هر وجه تولید کند؛ افزایش `weld_distance` رأس‌های منطبق را قبل از باز کردن نقشه (unwrapping) ادغام می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `مش` | مش ورودی با یک اطلس UV تولید شده در محدوده [0,1]. رأس‌های درز تکثیر می‌شوند، بنابراین تعداد رأس خروجی می‌تواند از ورودی بیشتر باشد. رنگ‌های رأس و بافت از مش ورودی حفظ می‌شوند. | MESH |
