# 展開網格 UV

為 3D 網格產生 UV 圖集。網格表面會被分割成多個圖塊，每個圖塊會被展平為二維，再將展平後的圖塊打包至 [0,1] UV 圖集。位於圖塊接縫上的頂點會被重複，因此輸出網格的頂點數可能多於輸入網格。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `網格` | 要進行 UV 展開的輸入網格。可接受單一網格或一批網格。 | MESH | 是 | — |
| `分割器` | 要使用的圖塊分割演算法。`pec`：在 GPU 上以快速平行邊緣塌陷（parallel-edge-collapse）演算法產生圖塊。`adaptive`：使用 CPU，速度較慢。（預設為 "pec"） | COMBO | 是 | "pec"<br>"adaptive" |
| `解析度` | 用於紋素密度自動縮放的目標圖集解析度（0 = 自動適應內容）。（預設值：1024） | INT | 是 | 0 至 8192 (步進值 256) |
| `邊距` | 圖塊之間的紋素邊距（texel padding）。（預設值：1） | INT | 是 | 0 至 16 |
| `weld_distance` | 重合頂點合併的半徑，以網格範圍的比例表示（0 = 自動）。若出現每個三角形各自成為圖塊（代表輸入未焊接），請將此值提高到約 0.001。（預設值：0.0） | FLOAT | 是 | 0.0 至 1.0 (步進值 0.0001) |

注意：如果輸入網格包含未焊接的頂點，節點可能會警告面鄰接性過低，並產生每個面一個 UV 圖塊；增加 `weld_distance` 可在展開前合併重合頂點。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
