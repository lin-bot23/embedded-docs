# Tripo: هدف‌گذاری مجدد مدل ریگ‌شده

TripoRetargetNode یک انیمیشن پیش‌تنظیم‌شده را روی یک مدل سه‌بعدی ریگ‌شدهٔ موجود اعمال می‌کند. شناسهٔ وظیفه (task ID) مدلی را می‌گیرد که قبلاً ریگ شده است، یک درخواست بازهدف‌گذاری (retarget) به Tripo API می‌فرستد و فایل انیمیشن‌شدهٔ حاصل را دانلود می‌کند. مدل انیمیشن‌شده می‌تواند به‌صورت GLB یا FBX بازگردانده شود، همراه با هندسهٔ مش اختیاری و پخش درجای اختیاری.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `شناسه وظیفه مدل اصلی` | شناسهٔ وظیفهٔ مدل سه‌بعدی ریگ‌شدهٔ قبلی برای بازهدف‌گذاری. وظیفهٔ ارجاع‌شده باید یک وظیفهٔ ریگ باشد. | RIG_TASK_ID | بله | - |
| `انیمیشن` | پیش‌تنظیم انیمیشنی که باید روی مدل ریگ‌شده اعمال شود. انیمیشن‌های `preset:*` با هر دو مدل ریگ کار می‌کنند. انیمیشن‌های `preset:biped:*` برای ریگ‌های مدل v1.0-20240301 ساخته شده‌اند؛ یک ریگ v2.5 فقط chop، climb، dive، fall، hurt، idle، jump، run، shoot، slash، turn و walk را می‌پذیرد. | COMBO | بله | `"preset:idle"`<br>`"preset:walk"`<br>`"preset:run"`<br>`"preset:dive"`<br>`"preset:climb"`<br>`"preset:jump"`<br>`"preset:slash"`<br>`"preset:shoot"`<br>`"preset:hurt"`<br>`"preset:fall"`<br>`"preset:turn"`<br>`"preset:quadruped:walk"`<br>`"preset:hexapod:walk"`<br>`"preset:octopod:walk"`<br>`"preset:serpentine:march"`<br>`"preset:aquatic:march"`<br>به‌همراه گزینه‌های اضافی `"preset:biped:*"` که در رابط کاربری نمایش داده می‌شوند |
| `out_format` | فرمت فایل خروجی؛ نتیجه در خروجی متناظر ارائه می‌شود. (پیش‌فرض: glb) | COMBO | خیر | `"glb"`<br>`"fbx"` |
| `export_with_geometry` | مش را در خروجی بگنجانید؛ در حالت خاموش فقط اسکلت انیمیشن‌شده صادر می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `animate_in_place` | انیمیشن را درجا، بدون جابه‌جایی ریشه، پخش کنید. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `auth_token_comfy_org` | توکن احراز هویت برای دسترسی به Comfy.org API (پارامتر مخفی). | AUTH_TOKEN_COMFY_ORG | خیر | - |
| `api_key_comfy_org` | کلید API برای دسترسی به سرویس Comfy.org (پارامتر مخفی). | API_KEY_COMFY_ORG | خیر | - |
| `unique_id` | شناسهٔ یکتا برای ردیابی عملیات (پارامتر مخفی). | UNIQUE_ID | خیر | - |

توجه: انیمیشن‌های گروه `preset:*` با هر دو مدل ریگ کار می‌کنند. انیمیشن‌های گروه `preset:biped:*` برای ریگ‌های مدل v1.0-20240301 ساخته شده‌اند؛ یک ریگ v2.5 فقط chop، climb، dive، fall، hurt، idle، jump، run، shoot، slash، turn و walk را می‌پذیرد. اگر ریگ ارجاع‌شده با مشخصات Mixamo و نسخهٔ مدلی که با `v1.0` شروع می‌شود ساخته شده باشد، فراخوانی بازهدف‌گذاری با خطا شکست می‌خورد. فرمت خروجی درخواستی باید GLB یا FBX باشد؛ اگر سرویس هر نوع فایل دیگری بازگرداند، گره خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل سه‌بعدی انیمیشن‌شدهٔ تولیدشده (فقط برای سازگاری با نسخه‌های قبلی). | STRING |
| `شناسه وظیفه ری‌تارگت` | شناسهٔ وظیفه برای ردیابی عملیات بازهدف‌گذاری. | RETARGET_TASK_ID |
| `GLB` | مدل سه‌بعدی انیمیشن‌شده در قالب GLB. زمانی پر می‌شود که `out_format` برابر glb باشد. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی انیمیشن‌شده در قالب FBX. زمانی پر می‌شود که `out_format` برابر fbx باشد. | FILE3DFBX |
