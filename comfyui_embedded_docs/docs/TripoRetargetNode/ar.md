# Tripo: إعادة توجيه النموذج المجهز

تطبّق عقدة TripoRetargetNode حركة معدّة مسبقًا على نموذج ثلاثي الأبعاد مجهّز بهيكل عظمي موجود. تأخذ معرّف المهمة لنموذج سبق تجهيزه بهيكل عظمي، وترسل طلب إعادة استهداف إلى Tripo API، وتنزّل الملف المتحرك الناتج. يمكن إرجاع النموذج المتحرك بصيغة GLB أو FBX، مع هندسة شبكية اختيارية وتشغيل اختياري في المكان.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `معرف_مهمة_النموذج_الأصلي` | معرّف المهمة للنموذج ثلاثي الأبعاد المجهّز بهيكل عظمي مسبقًا المراد إعادة استهدافه. يجب أن تكون المهمة المشار إليها مهمة تجهيز هيكل عظمي. | RIG_TASK_ID | نعم | - |
| `الرسوم_المتحركة` | إعداد الحركة المسبق المراد تطبيقه على النموذج المجهّز بهيكل عظمي. تعمل حركات `preset:*` مع كلا نموذجي الهيكل العظمي. حركات `preset:biped:*` مصممة لهياكل من إصدار النموذج v1.0-20240301؛ ويقبل هيكل v2.5 فقط chop، climb، dive، fall، hurt، idle، jump، run، shoot، slash، turn، وwalk. | COMBO | نعم | `"preset:idle"`<br>`"preset:walk"`<br>`"preset:run"`<br>`"preset:dive"`<br>`"preset:climb"`<br>`"preset:jump"`<br>`"preset:slash"`<br>`"preset:shoot"`<br>`"preset:hurt"`<br>`"preset:fall"`<br>`"preset:turn"`<br>`"preset:quadruped:walk"`<br>`"preset:hexapod:walk"`<br>`"preset:octopod:walk"`<br>`"preset:serpentine:march"`<br>`"preset:aquatic:march"`<br>بالإضافة إلى خيارات إضافية `"preset:biped:*"` تظهر في واجهة المستخدم |
| `out_format` | تنسيق ملف الإخراج؛ تصل النتيجة على المخرج المطابق. (القيمة الافتراضية: glb) | COMBO | لا | `"glb"`<br>`"fbx"` |
| `export_with_geometry` | تضمين الشبكة في التصدير؛ عند إيقافه يتم تصدير الهيكل العظمي المتحرك فقط. (القيمة الافتراضية: True) | BOOLEAN | لا | True<br>False |
| `animate_in_place` | تشغيل الحركة في المكان، دون إزاحة الجذر. (القيمة الافتراضية: False) | BOOLEAN | لا | True<br>False |
| `auth_token_comfy_org` | رمز مصادقة للوصول إلى Comfy.org API (معامل مخفي). | AUTH_TOKEN_COMFY_ORG | لا | - |
| `api_key_comfy_org` | مفتاح API لخدمة Comfy.org (معامل مخفي). | API_KEY_COMFY_ORG | لا | - |
| `unique_id` | معرّف فريد لتتبع العملية (معامل مخفي). | UNIQUE_ID | لا | - |

ملاحظة: تعمل الحركات في مجموعة `preset:*` مع كلا نموذجي الهيكل العظمي. الحركات في مجموعة `preset:biped:*` مصممة لهياكل من إصدار النموذج v1.0-20240301؛ ويقبل هيكل v2.5 فقط chop، climb، dive، fall، hurt، idle، jump، run، shoot، slash، turn، وwalk. إذا أُنشئ الهيكل المشار إليه وفق مواصفة Mixamo وإصدار نموذج يبدأ بـ `v1.0`، يفشل استدعاء إعادة الاستهداف مع خطأ. يجب أن يكون تنسيق الإخراج المطلوب GLB أو FBX؛ وإذا أعادت الخدمة أي نوع ملف آخر، ترفع العقدة خطأً.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | ملف نموذج ثلاثي الأبعاد متحرك الناتج (للتوافق مع الإصدارات السابقة فقط). | STRING |
| `معرّف مهمة إعادة الاستهداف` | معرّف المهمة لتتبع عملية إعادة الاستهداف. | RETARGET_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المتحرك بصيغة GLB. يُملأ عندما تكون قيمة `out_format` هي glb. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المتحرك بصيغة FBX. يُملأ عندما تكون قيمة `out_format` هي fbx. | FILE3DFBX |
