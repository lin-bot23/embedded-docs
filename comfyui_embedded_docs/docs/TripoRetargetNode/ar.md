# Tripo: إعادة توجيه النموذج المجهز

تطبّق عقدة TripoRetargetNode رسمًا متحركًا مُعدًا مسبقًا على نموذج ثلاثي الأبعاد مُجهَّز بهيكل عظمي. تأخذ العقدة معرف المهمة لنموذج تم تجهيزه مسبقًا، وترسل طلب إعادة استهداف إلى Tripo API، وتنزّل ملف الرسوم المتحركة الناتج. يمكن إرجاع النموذج المتحرك بصيغة GLB أو FBX، مع إمكانية تضمين هندسة الشبكة اختياريًا وتشغيل موضعي اختياري.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | معرف المهمة للنموذج ثلاثي الأبعاد المُجهَّز مسبقًا الذي سيتم إعادة استهدافه. يجب أن تكون المهمة المُشار إليها مهمة تجهيز هيكلي؛ إذ لا يمكن استخدام هيكل عظمي مُصنَّع وفق مواصفات Mixamo على إصدار النموذج v1.0 في إعادة الاستهداف. | RIG_TASK_ID | نعم | - |
| `animation` | الرسم المتحرك المُعد مسبقًا المطلوب تطبيقه على النموذج المُجهَّز. تعمل رسوم `preset:*` مع كلا نموذجي الهيكل؛ بينما تتطلب رسوم `preset:biped:*` هيكلًا مُصنَّعًا بإصدار النموذج v1.0-20240301. | COMBO | نعم | `"preset:idle"`<br>`"preset:walk"`<br>`"preset:run"`<br>`"preset:dive"`<br>`"preset:climb"`<br>`"preset:jump"`<br>`"preset:slash"`<br>`"preset:shoot"`<br>`"preset:hurt"`<br>`"preset:fall"`<br>`"preset:turn"`<br>`"preset:quadruped:walk"`<br>`"preset:hexapod:walk"`<br>`"preset:octopod:walk"`<br>`"preset:serpentine:march"`<br>`"preset:aquatic:march"`<br>بالإضافة إلى خيارات `"preset:biped:*"` الإضافية المعروضة في واجهة المستخدم |
| `out_format` | صيغة ملف الإخراج؛ تصل النتيجة إلى المخرج المطابق. (الافتراضي: glb) | COMBO | لا | `"glb"`<br>`"fbx"` |
| `export_with_geometry` | تضمين الشبكة في التصدير؛ عند إيقاف هذا الخيار يُصدَّر الهيكل العظمي المتحرك فقط. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `animate_in_place` | تشغيل الحركة في مكانها، دون إزاحة الجذر. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `auth_token_comfy_org` | رمز المصادقة للوصول إلى Comfy.org API (معلمة مخفية). | AUTH_TOKEN_COMFY_ORG | لا | - |
| `api_key_comfy_org` | مفتاح API للوصول إلى خدمة Comfy.org (معلمة مخفية). | API_KEY_COMFY_ORG | لا | - |
| `unique_id` | معرّف فريد لتتبع العملية (معلمة مخفية). | UNIQUE_ID | لا | - |

ملاحظة: تعمل الرسوم المتحركة في مجموعة `preset:*` مع كلا نموذجي الهيكل، بينما تتطلب الرسوم المتحركة في مجموعة `preset:biped:*` هيكلًا عظميًا مُصنَّعًا بإصدار النموذج v1.0-20240301. إذا أُنشئ الهيكل المُشار إليه بمواصفات Mixamo وكان إصدار النموذج يبدأ بـ `v1.0`، فإن استدعاء إعادة الاستهداف يفشل مع ظهور خطأ.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | ملف النموذج ثلاثي الأبعاد المتحرك المُنشأ (للتوافق مع الإصدارات السابقة فقط). | STRING |
| `retarget task_id` | معرف المهمة لتتبع عملية إعادة الاستهداف. | RETARGET_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المتحرك بصيغة GLB. يُملأ هذا المخرج عندما تكون `out_format` هي glb. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المتحرك بصيغة FBX. يُملأ هذا المخرج عندما تكون `out_format` هي fbx. | FILE3DFBX |
