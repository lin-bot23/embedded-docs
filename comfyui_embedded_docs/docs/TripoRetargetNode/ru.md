# Tripo: Перепривязка ригнутой модели

Узел TripoRetargetNode применяет готовую анимацию к существующей 3D‑модели с ригом. Он принимает идентификатор задачи модели, которая ранее была оснащена ригом, отправляет запрос на ретаргетинг в Tripo API и загружает полученный анимированный файл. Анимированная модель может быть возвращена в формате GLB или FBX, с возможностью включения геометрии сетки и воспроизведения на месте.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `идентификатор_задачи_исходной_модели` | Идентификатор задачи ранее оснащенной ригом 3D‑модели для ретаргетинга. Указанная задача должна быть задачей рига; риг, созданный по спецификации Mixamo на версии модели v1.0, не может использоваться для ретаргетинга. | RIG_TASK_ID | Да | - |
| `анимация` | Пресет анимации для применения к модели с ригом. Анимации `preset:*` работают с ригами обоих типов; анимации `preset:biped:*` требуют риг, созданный с помощью модели v1.0-20240301. | COMBO | Да | `"preset:idle"`<br>`"preset:walk"`<br>`"preset:run"`<br>`"preset:dive"`<br>`"preset:climb"`<br>`"preset:jump"`<br>`"preset:slash"`<br>`"preset:shoot"`<br>`"preset:hurt"`<br>`"preset:fall"`<br>`"preset:turn"`<br>`"preset:quadruped:walk"`<br>`"preset:hexapod:walk"`<br>`"preset:octopod:walk"`<br>`"preset:serpentine:march"`<br>`"preset:aquatic:march"`<br>плюс дополнительные опции `"preset:biped:*"`, отображаемые в интерфейсе |
| `out_format` | Формат выходного файла; результат появится в соответствующем выходе. (по умолчанию: glb) | COMBO | Нет | `"glb"`<br>`"fbx"` |
| `export_with_geometry` | Включать сетку в экспорт; при выключенном состоянии экспортируется только анимированный скелет. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `animate_in_place` | Воспроизводить анимацию на месте, без смещения корня. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `auth_token_comfy_org` | Токен аутентификации для доступа к API Comfy.org (скрытый параметр). | AUTH_TOKEN_COMFY_ORG | Нет | - |
| `api_key_comfy_org` | API‑ключ для доступа к сервисам Comfy.org (скрытый параметр). | API_KEY_COMFY_ORG | Нет | - |
| `unique_id` | Уникальный идентификатор для отслеживания операции (скрытый параметр). | UNIQUE_ID | Нет | - |

Примечание: анимации из группы `preset:*` работают с ригами обоих типов, а анимации из группы `preset:biped:*` требуют риг, созданный с помощью модели v1.0-20240301. Если риг, на который ссылается задача, был создан по спецификации Mixamo и с версией модели, начинающейся с `v1.0`, вызов ретаргетинга завершится ошибкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Сгенерированный анимированный файл 3D‑модели (только для обратной совместимости). | STRING |
| `task_id ретаргетинга` | Идентификатор задачи для отслеживания операции ретаргетинга. | RETARGET_TASK_ID |
| `GLB` | Анимированная 3D‑модель в формате GLB. Заполняется, когда `out_format` имеет значение glb. | FILE3DGLB |
| `FBX` | Анимированная 3D‑модель в формате FBX. Заполняется, когда `out_format` имеет значение fbx. | FILE3DFBX |
