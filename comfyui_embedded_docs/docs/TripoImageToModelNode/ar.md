# Tripo: الصورة إلى نموذج

تولّد هذه العقدة نماذج ثلاثية الأبعاد بشكلٍ متزامنٍ اعتمادًا على صورة واحدة، وذلك باستخدام واجهة برمجة تطبيقات Tripo. قدّم صورة إدخال، وستُنشئ العقدة نموذجًا ثلاثي الأبعاد مكتملًا منها، مع تحكمات اختيارية في إصدار النموذج، وتوليد القوام، ومستوى التفاصيل، وصيغة الإخراج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصورة` | صورة الإدخال المستخدمة لتوليد النموذج ثلاثي الأبعاد. يجب توفير صورة، وإلا سترفع العقدة خطأً. | IMAGE | نعم | - |
| `إصدار النموذج` | إصدار النموذج المستخدم في التوليد. | COMBO | لا | `"v1.4"`<br>`"v3.0"`<br>`"v3.5"`<br>`"v3.6"` |
| `النمط` | لم يعد مدعومًا من Tripo ويتم تجاهله. أُدرج فقط لدعم سير العمل الأقدم. (الافتراضي: `"None"`) | COMBO | لا | `"None"`<br>`"realistic"`<br>`"cartoon"`<br>`"sculpture"`<br>`"low_poly"` |
| `النسيج` | توليد خرائط القوام. عند التعطيل، يُرجَع شكل هندسي خام فقط ويُتجاهَل `pbr`. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `pbr` | خرائط مواد PBR (اللون الأساسي، المعدنية، الخشونة، والاتجاهات الطبيعية). يتطلب تفعيل `texture`. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `بذرة النموذج` | البذرة العشوائية لتوليد النموذج. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `الاتجاه` | إعداد اتجاه النموذج المُولَّد. (الافتراضي: `"default"`) | COMBO | لا | `"default"`<br>`"front"`<br>`"back"`<br>`"left"`<br>`"right"`<br>`"top"`<br>`"bottom"` |
| `بذرة النسيج` | البذرة العشوائية لتوليد القوام. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `جودة النسيج` | مستوى جودة توليد القوام: `detailed` = قوام عالي الدقة (HD)، `extreme` = قوام فائق الدقة 8K. (الافتراضي: `"standard"`) | COMBO | لا | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `محاذاة النسيج` | طريقة محاذاة خريطة القوام على النموذج. (الافتراضي: `"original_image"`) | COMBO | لا | `"original_image"`<br>`"geometry"` |
| `حد الوجه` | الحد الأقصى لعدد الوجوه. القيمة -1 تترك الاختيار التكيفي لـ Tripo (نحو 1.4 مليون وجه في إصدار v3.x القياسي، و2 مليون في المستوى التفصيلي). ويقيّد Tripo الحدود بصمت: إصدار v2.5 عند 500,000، والشبكات الرباعية عند 150,000. (الافتراضي: -1) | INT | لا | -1 إلى 2000000 |
| `رباعي` | إخراج شبكة رباعية الوجوه. يسلّم Tripo الشبكات الرباعية بصيغة FBX؛ لذا تصل النتيجة إلى مخرج FBX بينما يبقى مخرج GLB فارغًا. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `جودة الهندسة` | مستوى جودة توليد الهندسة. (الافتراضي: `"standard"`) | COMBO | لا | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | شبكة منخفضة المضلعات (Low Poly) بطوبولوجيا نظيفة بأسلوب النمذجة اليدوية (500-20,000 وجه، أو 500-10,000 وجه عند تفعيل إخراج `quad`). الأنسب للمواضيع البسيطة؛ أما المعقّدة فقد تفشل. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `auto_size` | يضبط مقياس النماذج ذات القوام على حجمها الحقيقي بالأمتار. يخزّن Tripo الحجم بوصفه تحويلًا لمشهد النموذج، ويُدمجه عند تحويل النموذج أو تجهيزه للحركة أو إعادة توجيه حركته؛ ويُتجاهَل عند عدم وجود قوام. (الافتراضي: True) | BOOLEAN | لا | True<br>False |

ملاحظة: صورة `image` مطلوبة؛ إذا كانت مفقودة، سترفع العقدة خطأً من نوع RuntimeError. عندما تكون قيمة `texture` False، يحتوي النموذج على هندسة خام فقط وتُجبَر `pbr` على False. عند تفعيل `smart_low_poly`، يجب أن تكون `face_limit` بين 500 و20,000 للشبكات المثلثية، أو بين 500 و10,000 عندما يكون `quad` مفعّلًا أيضًا؛ وإذا كان الحد غير صالح، سترفع العقدة خطأً من نوع ValueError. ضبط `face_limit` على -1 (الافتراضي) لا يرسل حدًا صريحًا للوجوه إلى واجهة برمجة التطبيقات، ويترك الاختيار التكيفي لـ Tripo.

## المخرجات

| اسم المُخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | ملف النموذج ثلاثي الأبعاد المُولَّد (لأغراض التوافق مع الإصدارات السابقة فقط). | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة لتتبّع عملية توليد النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُولَّد بصيغة GLB. يكون فارغًا عند تفعيل `quad`. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المُولَّد بصيغة FBX. لا يُملأ إلا عند تفعيل `quad`. | FILE3DFBX |
