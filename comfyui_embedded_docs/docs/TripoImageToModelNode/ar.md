# Tripo: الصورة إلى نموذج

يولّد نماذج ثلاثية الأبعاد بشكل متزامن اعتمادًا على صورة واحدة باستخدام Tripo API. قدّم صورة إدخال، وستنشئ العقدة نموذجًا ثلاثي الأبعاد مكتملًا منها، مع عناصر تحكم اختيارية لإصدار النموذج، وتوليد القوام، ومستوى التفاصيل، وتنسيق الإخراج. هذه هي النسخة القديمة من عقدة تحويل الصورة إلى نموذج، وأُبقيت لدعم سير العمل الأقدم.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصورة` | صورة الإدخال المستخدمة لتوليد النموذج ثلاثي الأبعاد. يجب توفير صورة، وإلا فسترفع العقدة خطأً. | IMAGE | نعم | - |
| `إصدار النموذج` | إصدار النموذج المستخدم في التوليد. | COMBO | لا | `"v1.4"`<br>`"v3.0"`<br>`"v3.5"`<br>`"v3.6"` |
| `النمط` | لم يعد مدعومًا من Tripo ويُتجاهل. أُبقي لدعم سير العمل الأقدم. (الافتراضي: `"None"`) | COMBO | لا | `"None"`<br>`"realistic"`<br>`"cartoon"`<br>`"sculpture"`<br>`"low_poly"` |
| `النسيج` | توليد خرائط القوام. عند الإيقاف، يُعاد شكل هندسي مجرّد ويتم تجاهل `pbr`. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `pbr` | خرائط مواد PBR (اللون الأساسي، المعدني، الخشونة، normal). يتطلب `texture`. (الافتراضي: True) | BOOLEAN | لا | True<br>False |
| `بذرة النموذج` | بذرة عشوائية لتوليد النموذج. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `الاتجاه` | إعداد الاتجاه للنموذج المُولّد. (الافتراضي: `"default"`) | COMBO | لا | `"default"`<br>`"front"`<br>`"back"`<br>`"left"`<br>`"right"`<br>`"top"`<br>`"bottom"` |
| `بذرة النسيج` | بذرة عشوائية لتوليد القوام. (الافتراضي: 42) | INT | لا | 0 إلى 2147483647 |
| `جودة النسيج` | مستوى الجودة لتوليد القوام: `detailed` = قوام بدقة HD، `extreme` = قوام فائق بدقة 8K. (الافتراضي: `"standard"`) | COMBO | لا | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `محاذاة النسيج` | طريقة المحاذاة لتعيين القوام. (الافتراضي: `"original_image"`) | COMBO | لا | `"original_image"`<br>`"geometry"` |
| `حد الوجه` | الحد الأقصى لعدد الأوجه. -1 يتيح لـ Tripo الاختيار تكيفيًا (حوالي 1.4M وجه على v3.x standard، و2M على detailed). يقوم Tripo بالقص بصمت: v2.5 عند 500,000، والشبكات الرباعية عند 150,000. (الافتراضي: -1) | INT | لا | -1 إلى 2000000 |
| `رباعي` | إخراج شبكة رباعية. تُسلّم Tripo الشبكات الرباعية بصيغة FBX، لذا تصل النتيجة عبر مخرج FBX ويبقى مخرج GLB فارغًا. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `جودة الهندسة` | مستوى الجودة لتوليد الهندسة. (الافتراضي: `"standard"`) | COMBO | لا | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | شبكة منخفضة المضلعات (Low-poly) ببنية طوبولوجية نظيفة بأسلوب مصنوع يدويًا (500-20,000 وجه، وquad 500-10,000). الأفضل للكائنات البسيطة؛ وقد تفشل الكائنات المعقدة. (الافتراضي: False) | BOOLEAN | لا | True<br>False |
| `auto_size` | تحجيم النماذج ذات القوام إلى حجمها الواقعي بالأمتار. تخزّن Tripo الحجم كتحويل مشهد للنموذج وتُضمّنه عند تحويل النموذج أو تجهيزه للتحريك أو إعادة استهدافه؛ ويُتجاهل بدون قوام. (الافتراضي: True) | BOOLEAN | لا | True<br>False |

ملاحظة: يُعد `image` مطلوبًا؛ إذا كان مفقودًا، فسترفع العقدة RuntimeError. عندما تكون `texture` مساوية لـ False، يحتوي النموذج على هندسة مجردة فقط وتُجبَر `pbr` على False. عند تمكين `smart_low_poly`، يجب أن يكون `face_limit` بين 500 و20,000 للشبكات المثلثية، أو بين 500 و10,000 عند تمكين `quad` أيضًا؛ وإذا كان الحد غير صالح، فسترفع العقدة ValueError. تعيين `face_limit` إلى -1 (القيمة الافتراضية) لا يرسل حدًا صريحًا للأوجه إلى API، مما يتيح لـ Tripo الاختيار تكيفيًا.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | ملف النموذج ثلاثي الأبعاد المُولّد (للتوافق مع الإصدارات السابقة فقط). | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة لتتبع عملية توليد النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المُولّد بصيغة GLB. فارغ عند تمكين `quad`. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المُولّد بصيغة FBX. يُملأ فقط عند تمكين `quad`. | FILE3DFBX |
