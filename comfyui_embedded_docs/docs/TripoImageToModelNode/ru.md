# Tripo: Изображение в модель

Синхронно генерирует 3D-модели на основе одного изображения с помощью API Tripo. Подайте входное изображение, и узел создаст из него готовую 3D-модель с дополнительными настройками версии модели, генерации текстур, уровня детализации и формата вывода.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение, используемое для создания 3D-модели. Изображение должно быть предоставлено, иначе узел вызовет ошибку. | IMAGE | Да | - |
| `model_version` | Версия модели, используемая для генерации. | COMBO | Нет | `"v1.4"`<br>`"v3.0"`<br>`"v3.5"`<br>`"v3.6"` |
| `style` | Больше не поддерживается Tripo и игнорируется. Сохранён для старых рабочих процессов. (по умолчанию: `"None"`) | COMBO | Нет | `"None"`<br>`"realistic"`<br>`"cartoon"`<br>`"sculpture"`<br>`"low_poly"` |
| `texture` | Создавать карты текстур. Если выключено, возвращается геометрия без текстур, а параметр `pbr` игнорируется. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `pbr` | PBR-карты материалов (основной цвет, металличность, шероховатость, нормали). Требует `texture`. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `model_seed` | Случайное зерно для генерации модели. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `orientation` | Настройка ориентации для сгенерированной модели. (по умолчанию: `"default"`) | COMBO | Нет | `"default"`<br>`"front"`<br>`"back"`<br>`"left"`<br>`"right"`<br>`"top"`<br>`"bottom"` |
| `texture_seed` | Случайное зерно для генерации текстур. (по умолчанию: 42) | INT | Нет | 0 до 2147483647 |
| `texture_quality` | Уровень качества генерации текстур: `detailed` = HD-текстуры, `extreme` = 8K Ultra-текстуры. (по умолчанию: `"standard"`) | COMBO | Нет | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | Метод выравнивания при наложении текстур. (по умолчанию: `"original_image"`) | COMBO | Нет | `"original_image"`<br>`"geometry"` |
| `face_limit` | Максимальное количество граней. Значение -1 позволяет Tripo выбирать адаптивно (примерно 1,4 млн граней для v3.x standard, 2 млн для detailed). Tripo незаметно ограничивает: v2.5 — 500 000, quad-сетки — 150 000. (по умолчанию: -1) | INT | Нет | -1 до 2000000 |
| `quad` | Вывод четырёхугольной сетки. Tripo передаёт четырёхугольные сетки в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остаётся пустым. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `качество геометрии` | Уровень качества генерации геометрии. (по умолчанию: `"standard"`) | COMBO | Нет | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | Низкополигональная сетка с чистой, сделанной вручную топологией (500–20 000 граней; для quad — 500–10 000). Лучше всего подходит для простых объектов; для сложных может завершиться ошибкой. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `auto_size` | Масштабировать текстурированные модели до их реального размера в метрах. Tripo сохраняет размер как трансформацию сцены модели и встраивает его при конвертации, риггинге или ретаргетинге модели; без текстуры игнорируется. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |

Примечание: параметр `image` обязателен; если он отсутствует, узел вызывает RuntimeError. Когда `texture` равен False, модель содержит только геометрию без текстур, а `pbr` принудительно устанавливается в False. Если `smart_low_poly` включён, `face_limit` должен находиться в диапазоне от 500 до 20 000 для треугольных сеток или от 500 до 10 000, если также включён `quad`; если предел недопустим, узел вызывает ValueError. Установка значения -1 (по умолчанию) для `face_limit` не передаёт в API явного ограничения по граням, позволяя Tripo выбирать адаптивно.

## Выходы

| Имя выхода | Описание | Тип данных |
|------------|----------|------------|
| `файл модели` | Сгенерированный файл 3D-модели (только для обратной совместимости). | STRING |
| `task_id модели` | Идентификатор задачи для отслеживания процесса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. Пусто, когда включён `quad`. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. Заполняется только при включённом `quad`. | FILE3DFBX |
