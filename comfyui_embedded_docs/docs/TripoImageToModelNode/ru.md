# Tripo: Изображение в модель

Синхронно генерирует 3D-модели на основе одного изображения с помощью API Tripo. Укажите входное изображение, и узел создаст готовую 3D-модель из него, с дополнительными настройками версии модели, генерации текстуры, уровня детализации и выходного формата. Это устаревшая версия узла преобразования изображения в модель, сохранённая для старых рабочих процессов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение, используемое для генерации 3D-модели. Изображение обязательно, иначе узел выдаёт ошибку. | IMAGE | Да | - |
| `model_version` | Версия модели, используемая для генерации. | COMBO | Нет | `"v1.4"`<br>`"v3.0"`<br>`"v3.5"`<br>`"v3.6"` |
| `style` | Больше не поддерживается Tripo и игнорируется. Сохранён для старых рабочих процессов. (по умолчанию: `"None"`) | COMBO | Нет | `"None"`<br>`"realistic"`<br>`"cartoon"`<br>`"sculpture"`<br>`"low_poly"` |
| `texture` | Генерировать текстурные карты. При выключении возвращается только геометрия без текстуры, а `pbr` игнорируется. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `pbr` | Карты PBR-материала (базовый цвет, металличность, шероховатость, нормали). Требует `texture`. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |
| `model_seed` | Случайное зерно для генерации модели. (по умолчанию: 42) | INT | Нет | от 0 до 2147483647 |
| `orientation` | Настройка ориентации сгенерированной модели. (по умолчанию: `"default"`) | COMBO | Нет | `"default"`<br>`"front"`<br>`"back"`<br>`"left"`<br>`"right"`<br>`"top"`<br>`"bottom"` |
| `texture_seed` | Случайное зерно для генерации текстуры. (по умолчанию: 42) | INT | Нет | от 0 до 2147483647 |
| `texture_quality` | Уровень качества генерации текстуры: `detailed` = HD-текстуры, `extreme` = Ultra-текстуры 8K. (по умолчанию: `"standard"`) | COMBO | Нет | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | Метод выравнивания для наложения текстуры. (по умолчанию: `"original_image"`) | COMBO | Нет | `"original_image"`<br>`"geometry"` |
| `face_limit` | Максимальное количество граней. -1 позволяет Tripo выбрать адаптивно (около 1,4 млн граней в стандартном режиме v3.x, 2 млн в режиме detailed). Tripo ограничивает без предупреждения: v2.5 — 500 000, quad-меши — 150 000. (по умолчанию: -1) | INT | Нет | от -1 до 2000000 |
| `quad` | Вывод quad-меша. Tripo выдаёт quad-меши в формате FBX, поэтому результат приходит на выход FBX, а выход GLB остаётся пустым. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `качество геометрии` | Уровень качества генерации геометрии. (по умолчанию: `"standard"`) | COMBO | Нет | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | Low-poly-меш с чистой топологией в ручном стиле (500–20 000 граней, quad 500–10 000). Лучше всего подходит для простых объектов; сложные могут не получиться. (по умолчанию: False) | BOOLEAN | Нет | True<br>False |
| `auto_size` | Масштабировать текстурированные модели до их реального размера в метрах. Tripo сохраняет размер как преобразование сцены модели и запекает его при конвертации, риггинге или ретаргетинге модели; игнорируется без текстуры. (по умолчанию: True) | BOOLEAN | Нет | True<br>False |

Примечание: `image` обязателен; если он отсутствует, узел выдаёт RuntimeError. Когда `texture` имеет значение False, модель содержит только геометрию без текстуры, а `pbr` принудительно устанавливается в False. Когда `smart_low_poly` включён, `face_limit` должен быть между 500 и 20 000 для треугольных мешей или между 500 и 10 000, если также включён `quad`; если лимит недействителен, узел выдаёт ValueError. Установка `face_limit` в -1 (значение по умолчанию) не отправляет в API явный лимит граней, позволяя Tripo выбрать его адаптивно.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Файл сгенерированной 3D-модели (только для обратной совместимости). | STRING |
| `task_id модели` | ID задачи для отслеживания процесса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. Пустой, когда включён `quad`. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. Заполняется только когда включён `quad`. | FILE3DFBX |
