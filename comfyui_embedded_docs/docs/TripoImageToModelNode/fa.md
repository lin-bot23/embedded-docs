# Tripo: تصویر به مدل

این گره مدل‌های سه‌بعدی را به صورت همزمان و بر پایه یک تصویر واحد، با استفاده از API سرویس Tripo تولید می‌کند. با ارائه یک تصویر ورودی، این گره یک مدل سه‌بعدی نهایی از آن ایجاد می‌نماید. کنترل‌های اختیاری برای نسخه مدل، تولید بافت (texture)، سطح جزئیات و فرمت خروجی نیز فراهم شده است.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی مورد استفاده برای تولید مدل سه‌بعدی. باید یک تصویر ارائه شود، در غیر این صورت گره خطا می‌دهد. | IMAGE | بله | - |
| `نسخه مدل` | نسخه مدل مورد استفاده برای تولید. | COMBO | خیر | `"v1.4"`<br>`"v3.0"`<br>`"v3.5"`<br>`"v3.6"` |
| `سبک` | دیگر توسط Tripo پشتیبانی نمی‌شود و نادیده گرفته می‌شود. برای گردش‌کارهای قدیمی حفظ شده است. (پیش‌فرض: `"None"`) | COMBO | خیر | `"None"`<br>`"realistic"`<br>`"cartoon"`<br>`"sculpture"`<br>`"low_poly"` |
| `تکسچر` | تولید نقشه‌های بافت. اگر خاموش باشد، فقط هندسه خام برگردانده می‌شود و `pbr` نادیده گرفته می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، متالیک، زبری، نرمال). نیازمند `texture` است. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `بذر مدل` | Seed تصادفی برای تولید مدل. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `جهت` | تنظیم جهت‌گیری برای مدل تولید شده. (پیش‌فرض: `"default"`) | COMBO | خیر | `"default"`<br>`"front"`<br>`"back"`<br>`"left"`<br>`"right"`<br>`"top"`<br>`"bottom"` |
| `بذر تکسچر` | Seed تصادفی برای تولید بافت. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `کیفیت تکسچر` | سطح کیفیت برای تولید بافت: `detailed` = بافت‌های HD، `extreme` = بافت‌های Ultra 8K. (پیش‌فرض: `"standard"`) | COMBO | خیر | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `تراز تکسچر` | روش هم‌ترازی برای نگاشت بافت. (پیش‌فرض: `"original_image"`) | COMBO | خیر | `"original_image"`<br>`"geometry"` |
| `محدودیت چهره` | حداکثر تعداد وجه‌ها (faces). مقدار -1 به Tripo اجازه می‌دهد به صورت تطبیقی انتخاب کند (حدود ۱.۴ میلیون وجه در v3.x استاندارد، ۲ میلیون در detailed). Tripo به صورت پنهان محدود می‌کند: v2.5 در ۵۰۰,۰۰۰، مش‌های quad در ۱۵۰,۰۰۰. (پیش‌فرض: -1) | INT | خیر | -1 تا 2000000 |
| `quad` | خروجی مش Quad. Tripo مش‌های quad را به صورت FBX ارائه می‌دهد، بنابراین نتیجه در خروجی FBX قرار می‌گیرد و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `کیفیت هندسه` | سطح کیفیت برای تولید هندسه. (پیش‌فرض: `"standard"`) | COMBO | خیر | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | مش Low-poly با توپولوژی تمیز و سبک دست‌ساز (۵۰۰ تا ۲۰,۰۰۰ وجه، quad ۵۰۰ تا ۱۰,۰۰۰). بهترین گزینه برای سوژه‌های ساده؛ سوژه‌های پیچیده ممکن است شکست بخورند. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `auto_size` | مقیاس‌دهی مدل‌های دارای بافت به اندازه واقعی آن‌ها در متر. Tripo اندازه را به عنوان transform صحنه مدل ذخیره می‌کند و هنگام تبدیل، ریگ‌بندی یا retarget کردن مدل آن را تثبیت می‌کند؛ بدون بافت نادیده گرفته می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |

توجه: یک `image` الزامی است؛ اگر وجود نداشته باشد، گره یک RuntimeError ایجاد می‌کند. وقتی `texture` False است، مدل فقط شامل هندسه خام است و `pbr` مجبور به False می‌شود. وقتی `smart_low_poly` فعال است، `face_limit` باید برای مش‌های مثلثی بین ۵۰۰ تا ۲۰,۰۰۰ باشد، یا بین ۵۰۰ تا ۱۰,۰۰۰ وقتی `quad` نیز فعال است؛ اگر محدودیت نامعتبر باشد، گره یک ValueError ایجاد می‌کند. تنظیم `face_limit` روی -1 (پیش‌فرض) هیچ محدودیت وجه صریحی به API ارسال نمی‌کند و به Tripo اجازه می‌دهد به صورت تطبیقی انتخاب کند.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل سه‌بعدی تولید شده (فقط برای سازگاری معکوس). | STRING |
| `شناسه وظیفه مدل` | شناسه وظیفه (Task ID) برای ردیابی فرآیند تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولید شده در فرمت GLB. وقتی `quad` فعال باشد خالی است. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی تولید شده در فرمت FBX. فقط وقتی `quad` فعال باشد پر می‌شود. | FILE3DFBX |
