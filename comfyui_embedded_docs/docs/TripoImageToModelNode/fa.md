# Tripo: تصویر به مدل

مدل‌های سه‌بعدی را به‌صورت همگام و بر پایه یک تصویر واحد، با استفاده از API شرکت Tripo تولید می‌کند. یک تصویر ورودی ارائه دهید و این گره از آن یک مدل سه‌بعدی نهایی می‌سازد، همراه با کنترل‌های اختیاری برای نسخه مدل، تولید بافت، سطح جزئیات و قالب خروجی. این نسخه قدیمی گره image-to-model است که برای گردش‌کارهای قدیمی‌تر نگه داشته شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر ورودی که برای تولید مدل سه‌بعدی استفاده می‌شود. باید یک تصویر ارائه شود، در غیر این صورت گره خطا ایجاد می‌کند. | IMAGE | بله | - |
| `نسخه مدل` | نسخه مدلی که برای تولید استفاده می‌شود. | COMBO | خیر | `"v1.4"`<br>`"v3.0"`<br>`"v3.5"`<br>`"v3.6"` |
| `سبک` | دیگر توسط Tripo پشتیبانی نمی‌شود و نادیده گرفته می‌شود. برای گردش‌کارهای قدیمی‌تر نگه داشته شده است. (پیش‌فرض: `"None"`) | COMBO | خیر | `"None"`<br>`"realistic"`<br>`"cartoon"`<br>`"sculpture"`<br>`"low_poly"` |
| `تکسچر` | نقشه‌های بافت را تولید می‌کند. حالت خاموش، هندسه بدون بافت برمی‌گرداند و `pbr` را نادیده می‌گیرد. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، متالیک، زبری، نرمال). نیازمند `texture` است. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |
| `بذر مدل` | seed تصادفی برای تولید مدل. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `جهت` | تنظیم جهت‌گیری برای مدل تولیدشده. (پیش‌فرض: `"default"`) | COMBO | خیر | `"default"`<br>`"front"`<br>`"back"`<br>`"left"`<br>`"right"`<br>`"top"`<br>`"bottom"` |
| `بذر تکسچر` | seed تصادفی برای تولید بافت. (پیش‌فرض: 42) | INT | خیر | 0 تا 2147483647 |
| `کیفیت تکسچر` | سطح کیفیت برای تولید بافت: `detailed` = بافت‌های HD، `extreme` = بافت‌های Ultra 8K. (پیش‌فرض: `"standard"`) | COMBO | خیر | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `تراز تکسچر` | روش هم‌ترازی برای نگاشت بافت. (پیش‌فرض: `"original_image"`) | COMBO | خیر | `"original_image"`<br>`"geometry"` |
| `محدودیت چهره` | حداکثر تعداد وجه. مقدار -1 به Tripo اجازه می‌دهد به‌صورت تطبیقی انتخاب کند (حدود 1.4M وجه در v3.x استاندارد، 2M در detailed). Tripo به‌صورت بی‌صدا محدود می‌کند: v2.5 در 500,000، مش‌های quad در 150,000. (پیش‌فرض: -1) | INT | خیر | -1 تا 2000000 |
| `quad` | خروجی مش quad. Tripo مش‌های quad را به‌صورت FBX ارائه می‌دهد، بنابراین نتیجه در خروجی FBX قرار می‌گیرد و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `کیفیت هندسه` | سطح کیفیت برای تولید هندسه. (پیش‌فرض: `"standard"`) | COMBO | خیر | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | مش کم‌پالیگان با توپولوژی تمیز و به سبک دست‌ساز (500-20,000 وجه، quad 500-10,000). برای سوژه‌های ساده بهترین است؛ ممکن است سوژه‌های پیچیده شکست بخورند. (پیش‌فرض: False) | BOOLEAN | خیر | True<br>False |
| `auto_size` | مدل‌های بافت‌دار را به اندازه واقعی آن‌ها بر حسب متر مقیاس‌دهی می‌کند. Tripo اندازه را به‌عنوان ترنسفورم صحنه مدل ذخیره می‌کند و هنگام تبدیل، ریگ یا ریتارگت شدن مدل آن را bake می‌کند؛ بدون بافت نادیده گرفته می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | True<br>False |

توجه: یک `image` الزامی است؛ اگر وجود نداشته باشد، گره یک RuntimeError ایجاد می‌کند. وقتی `texture` برابر False باشد، مدل فقط شامل هندسه بدون بافت است و `pbr` به False اجبار می‌شود. وقتی `smart_low_poly` فعال باشد، `face_limit` باید برای مش‌های مثلثی بین 500 و 20,000 باشد، یا وقتی `quad` هم فعال است بین 500 و 10,000؛ اگر محدودیت نامعتبر باشد، گره یک ValueError ایجاد می‌کند. تنظیم `face_limit` روی -1 (پیش‌فرض) هیچ محدودیت وجه صریحی به API نمی‌فرستد و به Tripo اجازه می‌دهد به‌صورت تطبیقی انتخاب کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | فایل مدل سه‌بعدی تولیدشده (فقط برای سازگاری با نسخه‌های قدیمی). | STRING |
| `شناسه وظیفه مدل` | شناسه وظیفه برای پیگیری فرایند تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB. وقتی `quad` فعال است خالی می‌ماند. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی تولیدشده در قالب FBX. فقط زمانی پر می‌شود که `quad` فعال باشد. | FILE3DFBX |
