# Загрузить видео

Узел Load Video загружает видеофайлы из входного каталога и делает их доступными для обработки в рабочем процессе. Он считывает видеофайлы из указанной входной папки и выводит их в виде видеоданных, которые можно подключить к другим узлам обработки видео.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `файл` | Видеофайл для загрузки из входного каталога. Раскрывающийся список динамически заполняется всеми видеофайлами, найденными во входной папке ComfyUI, а новые видеофайлы можно загрузить напрямую через интерфейс выбора файла. | COMBO | Да | Доступно несколько вариантов (все видеофайлы во входном каталоге) |

**Примечание:** Доступные варианты для параметра `file` динамически формируются из видеофайлов, присутствующих во входном каталоге. Отображаются только видеофайлы с поддерживаемыми типами содержимого. Вы также можете загрузить новый видеофайл непосредственно через интерфейс выбора файла узла. Если ранее выбранный видеофайл больше не найден, узел сообщает об ошибке недопустимого файла.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `video` | Загруженные видеоданные, которые могут быть переданы другим узлам обработки видео для дальнейшей обработки или анализа. | VIDEO |
