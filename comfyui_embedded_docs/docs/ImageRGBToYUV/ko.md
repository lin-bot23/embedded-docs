# ImageRGBToYUV

ImageRGBToYUV 노드는 RGB 이미지를 YUV 색 공간으로 변환합니다. 이미지를 Y(휘도, 즉 밝기), U(청색 차분 색차), V(적색 차분 색차)의 세 가지 구성 요소로 분할하고, 각 구성 요소를 입력 이미지와 동일한 크기의 개별 이미지로 반환합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `이미지` | YUV로 변환할 입력 RGB 이미지입니다. 이미지에 알파 채널이 포함된 경우 처음 세 개(RGB) 채널만 사용됩니다. | IMAGE | 예 | - |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `Y` | YUV 색 공간의 휘도(밝기) 구성 요소 | IMAGE |
| `U` | YUV 색 공간의 청색 차분 색차 구성 요소 | IMAGE |
| `V` | YUV 색 공간의 적색 차분 색차 구성 요소 | IMAGE |

각 출력은 입력 이미지와 동일한 너비, 높이 및 채널 수를 갖습니다. 해당 Y, U 또는 V 구성 요소가 모든 채널에 걸쳐 반복되므로 모든 출력이 표준 이미지로 반환됩니다.
