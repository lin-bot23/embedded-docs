# ImageRGBToYUV

ImageRGBToYUV ノードは、RGB 画像を YUV 色空間に変換します。画像を 3 つのコンポーネント（Y（輝度・明るさ）、U（青の色差クロマ）、V（赤の色差クロマ））に分割し、各コンポーネントを入力と同じサイズの独立した画像として返します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | YUV に変換する入力 RGB 画像です。画像にアルファチャンネルが含まれる場合、最初の3つのチャンネル（RGB）のみが使用されます。 | IMAGE | はい | - |

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `Y` | YUV 色空間の輝度（明るさ）コンポーネント | IMAGE |
| `U` | YUV 色空間の青の色差クロマコンポーネント | IMAGE |
| `V` | YUV 色空間の赤の色差クロマコンポーネント | IMAGE |

各出力は、入力画像と同じ幅、高さ、チャンネル数を持ちます。対応する Y、U、V コンポーネントがすべてのチャンネルに繰り返し配置されるため、すべての出力が標準的な画像として返されます。
