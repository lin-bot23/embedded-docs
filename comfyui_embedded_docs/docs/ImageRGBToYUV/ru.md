# ImageRGBToYUV

# Изображение RGB в YUV

Узел ImageRGBToYUV выполняет конверсию цветового пространства из RGB в YUV. Он принимает изображение RGB в качестве входа и outputs три отдельных изображения, представляющие каналы YUV: Y (луминанс), U (разность по синему) и V (разность по красному).

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображение` | Входное изображение RGB, которое нужно преобразовать в цветовое пространство YUV. Это должно быть изображение с тремя каналами. | ИЗОБРАЖЕНИЕ | Да | - |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `Y`         | Канал Y представляет луминанс (яркость) изображения. | ИЗОБРАЖЕНИЕ |
| `U`         | Канал U представляет компонент разности по синему. | ИЗОБРАЖЕНИЕ |
| `V`         | Канал V представляет компонент разности по красному. | ИЗОБРАЖЕНИЕ |

Выходные изображения будут иметь те же размеры, что и входное изображение.
