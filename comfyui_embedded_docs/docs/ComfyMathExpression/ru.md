# Математическое выражение

Узел ComfyMathExpression вычисляет математическую формулу, заданную в виде текста. Формула может ссылаться на входные значения узла по буквенным именам, например `a`, `b`, `c`. Через расширяемую группу `values` можно добавить необходимое количество входных значений. Результат вычисления возвращается одновременно как число с плавающей запятой, целое число и логическое значение.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `выражение` | Математическая формула для вычисления, записанная в виде текста (например, `a + b`), где в качестве переменных используются буквенные имена входных значений. Поддерживается многострочный ввод. (по умолчанию: "a + b") | STRING | Да | N/A |
| `значения` | Расширяемая группа входных значений, предоставляющая переменные для выражения. Каждому добавленному в группу значению автоматически присваивается следующее имя в виде строчной латинской буквы, начиная с `a` (`a`, `b`, `c`, ...), и это имя затем можно использовать внутри `expression`. Каждый элемент принимает число (INT или FLOAT) или логическое значение (TRUE/FALSE). | FLOAT, INT, BOOLEAN | Да | от 1 до 26 значений, с именами от `a` до `z` |

### Примечания и ограничения

- `expression` не может быть пустым или содержать только пробельные символы.
- Выражение должно вычисляться в числовой результат (INT или FLOAT). Если результат имеет другой тип, например текст, узел выдаёт ошибку.
- Числовой результат должен быть конечным и преобразуемым в число с плавающей запятой (float). Слишком большие или не являющиеся конечными числами результаты вызывают ошибку.
- Весь набор входных значений также доступен внутри выражения под именем переменной `values` (в виде списка), поэтому возможны выражения вида `sum(values)`.
- Внутри выражения доступны следующие математические функции: `sum`, `min`, `max`, `abs`, `round`, `pow`, `sqrt`, `ceil`, `floor`, `log`, `log2`, `log10`, `sin`, `cos`, `tan`, `int`, `float`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `FLOAT` | Результат выражения в виде числа с плавающей запятой. | FLOAT |
| `INT` | Результат выражения, преобразованный в целое число с отбрасыванием дробной части. | INT |
| `BOOL` | Результат, преобразованный в логическое значение: TRUE, если числовой результат не равен нулю; FALSE, если он равен нулю. | BOOLEAN |
