# عبارت ریاضی

گره ComfyMathExpression یک فرمول ریاضی را که به صورت متن نوشته‌اید ارزیابی می‌کند. فرمول می‌تواند به مقادیر ورودی گره با استفاده از نام‌های حرفی مانند `a`، `b`، `c` ارجاع دهد و می‌توانید از طریق گروه قابل گسترش `values` به هر تعداد مقدار ورودی که نیاز دارید اضافه کنید. نتیجه محاسبه هم‌زمان به صورت یک عدد اعشاری، یک عدد صحیح و یک مقدار بولی بازگردانده می‌شود.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `عبارت` | فرمول ریاضی برای ارزیابی، نوشته شده به صورت متن (مثلاً `a + b`)، با استفاده از نام‌های حرفی مقادیر ورودی به عنوان متغیرها. ورودی چندخطی. (پیش‌فرض: "a + b") | STRING | بله | N/A |
| `مقادیر` | گروه قابل گسترش مقادیر ورودی که متغیرها را برای عبارت فراهم می‌کند. هر مقداری که به گروه اضافه می‌شود به‌طور خودکار نام حرفی کوچک بعدی را از `a` شروع می‌کند (`a`، `b`، `c`، ...) و آن نام سپس می‌تواند داخل `expression` استفاده شود. هر آیتم یک عدد (INT یا FLOAT) یا یک بولی (TRUE/FALSE) را می‌پذیرد. | FLOAT, INT, BOOLEAN | بله | 1 تا 26 مقدار، نام‌گذاری شده از `a` تا `z` |

### نکات و محدودیت‌ها

- `expression` نمی‌تواند خالی باشد یا فقط شامل whitespace باشد.
- عبارت باید به یک نتیجه عددی (INT یا FLOAT) ارزیابی شود. اگر نتیجه نوع متفاوتی باشد، مانند متن، گره خطا می‌دهد.
- نتیجه عددی باید متناهی و قابل تبدیل به عدد اعشاری باشد. نتایجی که خیلی بزرگ هستند یا متناهی نیستند باعث خطا می‌شوند.
- کل مجموعه مقادیر ورودی نیز داخل عبارت تحت نام متغیر `values` (به صورت یک لیست) در دسترس است، بنابراین عباراتی مانند `sum(values)` امکان‌پذیر هستند.
- توابع ریاضی زیر داخل عبارت در دسترس هستند: `sum`، `min`، `max`، `abs`، `round`، `pow`، `sqrt`، `ceil`، `floor`، `log`، `log2`، `log10`، `sin`، `cos`، `tan`، `int`، `float`.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `FLOAT` | نتیجه عبارت به صورت یک عدد اعشاری. | FLOAT |
| `INT` | نتیجه عبارت تبدیل شده به یک عدد صحیح، با حذف بخش اعشاری. | INT |
| `بولین` | نتیجه تبدیل شده به یک مقدار بولی: TRUE وقتی نتیجه عددی صفر نیست، FALSE وقتی صفر است. | BOOLEAN |
