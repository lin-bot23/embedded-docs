# Регулировка контрастности

Узел Adjust Contrast регулирует контраст входного изображения, масштабируя разницу между светлыми и тёмными областями вокруг середины цветового диапазона. Коэффициент 1.0 оставляет изображение без изменений, значения ниже 1.0 уменьшают контраст, а значения выше 1.0 увеличивают контраст.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение, для которого требуется отрегулировать контраст. | IMAGE | Да | - |
| `коэффициент` | Коэффициент контраста. 1.0 — без изменений, <1.0 — меньше контраста, >1.0 — больше контраста. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 2.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Результирующее изображение с отрегулированным контрастом. Значения пикселей ограничены диапазоном 0.0–1.0. Если входное изображение имеет альфа-канал, этот канал сохраняется без изменений. | IMAGE |
