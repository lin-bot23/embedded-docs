# Регулировка контрастности

Узел Adjust Contrast изменяет уровень контрастности входного изображения. Он работает, регулируя разницу между светлыми и темными областями изображения. Фактор 1.0 оставляет изображение без изменений, значения ниже 1.0 уменьшают контраст, а значения выше 1.0 увеличивают его. Если входное изображение содержит альфа-канал, он передаётся без изменений, сохраняя прозрачность.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `image` | Входное изображение, для которого выполняется настройка контраста. | IMAGE | Да | - |
| `коэффициент` | Коэффициент контраста. 1.0 = без изменений, <1.0 = меньше контраста, >1.0 = больше контраста. (по умолчанию: 1.0) | FLOAT | Нет | 0.0 - 2.0 |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `изображения` | Результирующее изображение с отрегулированным контрастом. Значения пикселей ограничены диапазоном 0.0–1.0. | IMAGE |
