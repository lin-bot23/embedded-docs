# 調整對比度

「Adjust Contrast」節點透過在色彩範圍的中點附近縮放亮部與暗部之間的差異，來調整輸入影像的對比度。係數為 1.0 時影像維持不變；低於 1.0 會降低對比度；高於 1.0 則會增強對比度。

## 輸入

| 參數 | 描述 | 資料型別 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `image` | 輸入影像，將調整其對比度。 | IMAGE | 是 | - |
| `對比度係數` | 對比度係數。1.0 = 無變化，<1.0 = 降低對比度，>1.0 = 增強對比度。（預設值：1.0） | FLOAT | 否 | 0.0 - 2.0 |

## 輸出

| 輸出名 | 描述 | 資料型別 |
| --- | --- | --- |
| `影像` | 調整對比度後產生的影像。像素值會被限制在 0.0–1.0 範圍內。若輸入影像含有 Alpha 色版，該色版會原樣保留。 | IMAGE |
