# コントラストを調整

Adjust Contrast ノードは、入力画像のコントラストレベルを変更します。画像の明るい部分と暗い部分の差を調整することで機能します。ファクターが 1.0 の場合は画像は変化せず、1.0 未満の値ではコントラストが減少し、1.0 を超える値ではコントラストが増加します。入力画像にアルファチャンネルがある場合、アルファチャンネルは変更されずにそのまま維持され、透明度が保持されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `image` | コントラストを調整する入力画像。 | IMAGE | 必須 | - |
| `係数` | コントラストファクター。1.0 = 変更なし、<1.0 = コントラスト減少、>1.0 = コントラスト増加。（デフォルト: 1.0） | FLOAT | 任意 | 0.0 - 2.0 |

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `画像` | コントラストが調整された結果の画像。ピクセル値は 0.0～1.0 の範囲にクランプされます。 | IMAGE |
