# ضبط التباين

تقوم عقدة Adjust Contrast بضبط تباين الصورة المدخلة عن طريق تحجيم الفرق بين المناطق الفاتحة والداكنة حول نقطة منتصف نطاق الألوان. تُبقي القيمة 1.0 الصورة دون تغيير، بينما تقلّل القيم الأقل من 1.0 التباين، وتزيده القيم الأعلى من 1.0.

## المدخلات

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `image` | الصورة المدخلة التي سيتم ضبط تباينها. | IMAGE | نعم | - |
| `عامل التباين` | عامل التباين. 1.0 = بدون تغيير، <1.0 = تباين أقل، >1.0 = تباين أكبر. (الافتراضي: 1.0) | FLOAT | لا | 0.0 - 2.0 |

## المخرجات

| Output Name | Description | Data Type |
| --- | --- | --- |
| `الصور` | الصورة الناتجة مع ضبط التباين. يتم تقييد قيم البكسلات إلى النطاق 0.0–1.0. إذا كانت الصورة المدخلة تحتوي على قناة ألفا، يتم الحفاظ على تلك القناة دون تغيير. | IMAGE |
