# Tripo: متن به مدل

این گره قدیمی با استفاده از API Tripo، مدل‌های سه‌بعدی نهایی را از روی یک توصیف متنی تولید می‌کند. منتظر می‌ماند تا تولید کامل شود و سپس فایل مدل را برمی‌گرداند، به‌صورت اختیاری همراه با بافت‌ها و متریال‌های PBR. این گره منسوخ علامت‌گذاری شده و برای گردش‌کارهای قدیمی‌تر نگه داشته شده است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | ضروری | محدوده |
|-----------|-------------|-----------|----------|-------|
| `پرامپت` | توصیف متنی مدل سه‌بعدی برای تولید (چندخطی). این پارامتر الزامی است و نمی‌تواند خالی باشد. | STRING | بله | - |
| `پرامپت منفی` | توصیف متنی آنچه باید در مدل تولیدشده از آن پرهیز شود (چندخطی). حداکثر 255 کاراکتر. فقط زمانی به API فرستاده می‌شود که خالی نباشد. | STRING | خیر | حداکثر 255 کاراکتر |
| `نسخه مدل` | نسخه مدل Tripo برای استفاده در تولید (پیش‌فرض: v3_1_20260211). | COMBO | خیر | چند گزینه موجود است |
| `استایل` | دیگر توسط Tripo پشتیبانی نمی‌شود و نادیده گرفته می‌شود. برای گردش‌کارهای قدیمی‌تر نگه داشته شده است (پیش‌فرض: "None"). | COMBO | خیر | چند گزینه موجود است |
| `تکسچر` | نقشه‌های بافت را تولید می‌کند. خاموش بودن آن هندسه بدون بافت برمی‌گرداند و `pbr` را نادیده می‌گیرد (پیش‌فرض: True). | BOOLEAN | خیر | true / false |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، فلزی، زبری، نرمال). نیازمند `texture` است؛ وقتی `texture` خاموش باشد، به‌اجبار خاموش می‌شود (پیش‌فرض: True). | BOOLEAN | خیر | true / false |
| `بذر تصویر` | بذری که برای مرحله تولید تصویر استفاده می‌شود (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `بذر مدل` | بذری که برای مرحله تولید مدل استفاده می‌شود (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `بذر تکسچر` | بذری که برای مرحله تولید بافت استفاده می‌شود (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `کیفیت تکسچر` | کیفیت بافت‌های تولیدشده. detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra (پیش‌فرض: standard). | COMBO | خیر | "standard"<br>"detailed"<br>"extreme" |
| `محدودیت وجه` | حداکثر تعداد وجه. مقدار -1 باعث می‌شود Tripo به‌صورت تطبیقی انتخاب کند (حدود 1.4M وجه در v3.x استاندارد، 2M در detailed). Tripo بی‌سروصدا محدود می‌کند: v2.5 در 500,000، مش‌های quad در 150,000. (پیش‌فرض: -1) | INT | خیر | -1 تا 2000000 |
| `چهارضلعی` | خروجی مش quad. Tripo مش‌های quad را به‌صورت FBX ارائه می‌دهد، بنابراین نتیجه روی خروجی FBX می‌آید و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | خیر | true / false |
| `کیفیت هندسه` | کیفیت هندسه تولیدشده (پیش‌فرض: standard). | COMBO | خیر | "standard"<br>"detailed" |
| `smart_low_poly` | مش کم‌تعداد با توپولوژی تمیز و دست‌ساز (500-20,000 وجه، quad 500-10,000). برای سوژه‌های ساده بهترین است؛ سوژه‌های پیچیده ممکن است شکست بخورند. (پیش‌فرض: False) | BOOLEAN | خیر | true / false |
| `auto_size` | مدل‌های بافت‌دار را به اندازه واقعی‌شان بر حسب متر مقیاس می‌دهد. Tripo اندازه را به‌عنوان ترانسفورم صحنه مدل ذخیره می‌کند و هنگام تبدیل، ریگ‌کردن یا ری‌تارگت‌کردن مدل آن را در مدل لحاظ می‌کند؛ بدون بافت نادیده گرفته می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | true / false |

**نکته‌ها:**
- این گره منسوخ است و به‌عنوان گره قدیمی علامت‌گذاری شده است. برای سازگاری با گردش‌کارهای قدیمی‌تر نگه داشته شده است.
- پارامتر `prompt` الزامی است: پرامپت خالی باعث می‌شود گره خطا بدهد.
- `pbr` نیازمند `texture` است. وقتی `texture` خاموش باشد، گره `pbr` را به‌اجبار خاموش می‌کند و مقدار آن را نادیده می‌گیرد. `auto_size` نیز بدون `texture` اثری ندارد.
- وقتی `smart_low_poly` فعال باشد و `face_limit` روی مقداری غیر از -1 تنظیم شده باشد، محدودیت وجه باید برای خروجی مثلثی بین 500 و 20,000، یا وقتی `quad` فعال است بین 500 و 10,000 باشد؛ در غیر این صورت گره خطا می‌دهد.
- وقتی `quad` فعال باشد، مش quad تولیدشده به‌صورت FBX ارائه می‌شود، بنابراین خروجی FBX پر می‌شود و خروجی GLB خالی می‌ماند.
- پارامتر `style` پذیرفته می‌شود اما نادیده گرفته می‌شود.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | نام فایل مدل سه‌بعدی تولیدشده با قالب `<task_id>.<format>`، فقط برای سازگاری با نسخه‌های قبلی نگه داشته شده است. | STRING |
| `شناسه وظیفه مدل` | شناسه یکتای وظیفه برای فرایند تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدشده در قالب GLB. وقتی `quad` فعال باشد خالی است. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی تولیدشده در قالب FBX. فقط وقتی `quad` فعال باشد پر می‌شود. | FILE3DFBX |
