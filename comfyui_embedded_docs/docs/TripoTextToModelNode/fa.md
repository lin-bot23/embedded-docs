# Tripo: متن به مدل

با استفاده از API سرویس Tripo، مدل‌های سه‌بعدی کامل را از روی توضیحات متنی تولید می‌کند. این گره منتظر می‌ماند تا تولید تکمیل شود و سپس فایل مدل را برگردانده، و به‌صورت اختیاری شامل بافت‌ها و متریال‌های PBR خواهد بود.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `prompt` | توضیحات متنی مدل سه‌بعدی برای تولید (چندخطی). این پارامتر الزامی است و نمی‌تواند خالی باشد. | STRING | بله | - |
| `negative_prompt` | توضیحات متنی مواردی که باید در مدل تولیدی اجتناب شوند (چندخطی). حداکثر ۲۵۵ کاراکتر. تنها در صورت غیرخالی بودن به API ارسال می‌شود. | STRING | خیر | تا ۲۵۵ کاراکتر |
| `model_version` | نسخه مدل Tripo مورد استفاده برای تولید (پیش‌فرض: v3.1-20260211). | COMBO | خیر | چندین گزینه موجود است |
| `style` | سبک اعمال‌شده به مدل تولیدی (پیش‌فرض: None). دیگر توسط Tripo پشتیبانی نمی‌شود و نادیده گرفته می‌شود؛ برای سازگاری با گردش‌کارهای قدیمی حفظ شده است. | COMBO | خیر | چندین گزینه موجود است |
| `texture` | اینکه آیا نقشه‌های بافت تولید شوند یا خیر. حالت خاموش هندسه بدون بافت را برگردانده و `pbr` را نادیده می‌گیرد (پیش‌فرض: True). | BOOLEAN | خیر | true / false |
| `pbr` | اینکه آیا نقشه‌های متریال PBR (رنگ پایه، متالیک، زبری، نرمال) تولید شوند یا خیر. نیازمند `texture` است؛ وقتی `texture` خاموش باشد، اجباراً خاموش می‌شود (پیش‌فرض: True). | BOOLEAN | خیر | true / false |
| `image_seed` | Seed مورد استفاده برای مرحله تولید تصویر (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `model_seed` | Seed مورد استفاده برای مرحله تولید مدل (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `texture_seed` | Seed مورد استفاده برای مرحله تولید بافت (پیش‌فرض: 42). | INT | خیر | 0 تا 2147483647 |
| `texture_quality` | کیفیت بافت‌های تولیدی. detailed = بافت‌های HD، extreme = بافت‌های 8K Ultra (پیش‌فرض: standard). | COMBO | خیر | "standard"<br>"detailed"<br>"extreme" |
| `face_limit` | حداکثر تعداد وجه‌ها. -1 به Tripo اجازه می‌دهد به‌صورت تطبیقی انتخاب کند (حدود 1.4 میلیون وجه در v3.x استاندارد، 2 میلیون در detailed). Tripo به‌صورت پنهان محدود می‌کند: v2.5 در 500,000، مش‌های quad در 150,000. (پیش‌فرض: -1) | INT | خیر | -1 تا 2000000 |
| `quad` | خروجی مش Quad. Tripo مش‌های quad را به‌صورت FBX تحویل می‌دهد، بنابراین نتیجه در خروجی FBX قرار گرفته و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | خیر | true / false |
| `geometry_quality` | کیفیت هندسه تولیدی (پیش‌فرض: standard). | COMBO | خیر | "standard"<br>"detailed" |
| `smart_low_poly` | مش کم‌پولی با توپولوژی تمیز به سبک دست‌ساز (500 تا 20,000 وجه، quad 500 تا 10,000). بهترین گزینه برای سوژه‌های ساده؛ موارد پیچیده ممکن است شکست بخورند. (پیش‌فرض: False) | BOOLEAN | خیر | true / false |
| `auto_size` | مقیاس‌دهی مدل‌های دارای بافت به اندازه واقعی آن‌ها در جهان واقعی بر حسب متر. Tripo اندازه را به‌عنوان تبدیل صحنه مدل ذخیره کرده و هنگام تبدیل، ریگ‌بندی یا تغییر هدف مدل آن را تثبیت می‌کند؛ بدون بافت نادیده گرفته می‌شود. (پیش‌فرض: True) | BOOLEAN | خیر | true / false |

**نکات:**
- پارامتر `prompt` الزامی است: یک `prompt` خالی باعث می‌شود گره خطا دهد.
- `pbr` نیازمند `texture` است. وقتی `texture` خاموش باشد، گره `pbr` را مجبور به خاموشی کرده و مقدار آن را نادیده می‌گیرد. `auto_size` نیز بدون `texture` اثری ندارد.
- وقتی `smart_low_poly` فعال باشد و `face_limit` روی مقداری غیر از -1 تنظیم شده باشد، محدودیت وجه باید برای خروجی مثلثی بین 500 تا 20,000، یا وقتی `quad` فعال است بین 500 تا 10,000 باشد؛ در غیر این صورت گره خطا می‌دهد.
- وقتی `quad` فعال باشد، مش quad تولیدی به‌صورت FBX تحویل داده می‌شود، بنابراین خروجی FBX پر شده و خروجی GLB خالی می‌ماند.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model_file` | فایل مدل سه‌بعدی تولیدی، فقط برای سازگاری معکوس حفظ شده است. | STRING |
| `model task_id` | شناسه وظیفه یکتا برای فرآیند تولید مدل. | MODEL_TASK_ID |
| `GLB` | مدل سه‌بعدی تولیدی در فرمت GLB. وقتی `quad` فعال باشد خالی است. | FILE3DGLB |
| `FBX` | مدل سه‌بعدی تولیدی در فرمت FBX. تنها وقتی `quad` فعال باشد پر می‌شود. | FILE3DFBX |
