# Tripo: Текст в модель

Этот устаревший узел генерирует готовые 3D-модели из текстового описания с использованием API Tripo. Он ожидает завершения генерации, а затем возвращает файл модели, при необходимости с текстурами и PBR-материалами. Он помечен как устаревший и сохранён для старых рабочих процессов.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Текстовое описание 3D-модели для генерации (многострочное). Этот параметр обязателен и не может быть пустым. | STRING | Да | - |
| `негативный_промпт` | Текстовое описание того, чего следует избегать в генерируемой модели (многострочное). До 255 символов. Отправляется в API только если не пустое. | STRING | Нет | До 255 символов |
| `версия_модели` | Версия модели Tripo для использования при генерации (по умолчанию: v3_1_20260211). | COMBO | Нет | Доступно несколько вариантов |
| `стиль` | Больше не поддерживается Tripo и игнорируется. Сохранён для старых рабочих процессов (по умолчанию: "None"). | COMBO | Нет | Доступно несколько вариантов |
| `текстура` | Генерировать карты текстуры. При выключении возвращается чистая геометрия, а `pbr` игнорируется (по умолчанию: True). | BOOLEAN | Нет | true / false |
| `PBR` | Карты PBR-материалов (основной цвет, металлический, шероховатость, нормали). Требует `texture`; принудительно отключается, когда `texture` выключен (по умолчанию: True). | BOOLEAN | Нет | true / false |
| `image_seed` | Зерно, используемое на этапе генерации изображения (по умолчанию: 42). | INT | Нет | 0 to 2147483647 |
| `model_seed` | Зерно, используемое на этапе генерации модели (по умолчанию: 42). | INT | Нет | 0 to 2147483647 |
| `texture_seed` | Зерно, используемое на этапе генерации текстуры (по умолчанию: 42). | INT | Нет | 0 to 2147483647 |
| `texture_quality` | Качество генерируемых текстур. detailed = HD-текстуры, extreme = 8K Ultra текстуры (по умолчанию: standard). | COMBO | Нет | "standard"<br>"detailed"<br>"extreme" |
| `face_limit` | Максимальное количество полигонов. -1 позволяет Tripo выбирать адаптивно (около 1.4M полигонов на v3.x standard, 2M на detailed). Tripo ограничивает без предупреждения: v2.5 на 500,000, quad-меши на 150,000. (по умолчанию: -1) | INT | Нет | -1 to 2000000 |
| `quad` | Вывод quad-меша. Tripo предоставляет quad-меши в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остаётся пустым. (по умолчанию: False) | BOOLEAN | Нет | true / false |
| `качество геометрии` | Качество генерируемой геометрии (по умолчанию: standard). | COMBO | Нет | "standard"<br>"detailed" |
| `smart_low_poly` | Низкополигональный меш с чистой, стилизованной под ручную работу топологией (500-20,000 полигонов, quad 500-10,000). Лучше всего подходит для простых объектов; сложные могут не сгенерироваться. (по умолчанию: False) | BOOLEAN | Нет | true / false |
| `auto_size` | Масштабировать текстурированные модели до их реального размера в метрах. Tripo сохраняет размер как трансформацию сцены модели и встраивает его при конвертации, риггинге или ретаргетинге модели; игнорируется без текстуры. (по умолчанию: True) | BOOLEAN | Нет | true / false |

**Примечания:**
- Этот узел устарел и помечен как устаревший. Он сохранён для обратной совместимости со старыми рабочими процессами.
- Параметр `prompt` обязателен: пустой запрос вызывает ошибку в узле.
- `pbr` требует `texture`. Когда `texture` выключен, узел принудительно отключает `pbr` и игнорирует его значение. `auto_size` также не действует без `texture`.
- Когда `smart_low_poly` включён и `face_limit` установлен в значение, отличное от -1, ограничение числа полигонов должно быть между 500 и 20,000 для вывода треугольников, или между 500 и 10,000, когда `quad` включён; в противном случае узел выдаёт ошибку.
- Когда `quad` включён, сгенерированный quad-меш поставляется в формате FBX, поэтому выход FBX заполняется, а выход GLB остаётся пустым.
- Параметр `style` принимается, но игнорируется.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Имя файла сгенерированной 3D-модели в формате `<task_id>.<format>`, сохранено только для обратной совместимости. | STRING |
| `task_id модели` | Уникальный идентификатор задачи для процесса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. Пусто, когда `quad` включён. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. Заполняется только когда `quad` включён. | FILE3DFBX |
