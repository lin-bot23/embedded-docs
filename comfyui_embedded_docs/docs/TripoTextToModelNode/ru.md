# Tripo: Текст в модель

Генерирует готовые 3D-модели по текстовому описанию с помощью API Tripo. Узел ожидает завершения генерации, а затем возвращает файл модели, опционально с текстурами и материалами PBR.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `промпт` | Текстовое описание 3D-модели для генерации (многострочное). Этот параметр обязателен и не может быть пустым. | STRING | Да | - |
| `негативный_промпт` | Текстовое описание того, чего следует избегать в генерируемой модели (многострочное). До 255 символов. Отправляется в API только при непустом значении. | STRING | Нет | до 255 символов |
| `версия_модели` | Версия модели Tripo, используемая для генерации (по умолчанию: v3.1-20260211). | COMBO | Нет | Доступно несколько вариантов |
| `стиль` | Стиль, применяемый к генерируемой модели (по умолчанию: None). Больше не поддерживается Tripo и игнорируется; сохранен для старых рабочих процессов. | COMBO | Нет | Доступно несколько вариантов |
| `текстура` | Следует ли генерировать карты текстур. Значение Off возвращает только геометрию и игнорирует `pbr` (по умолчанию: True). | BOOLEAN | Нет | true / false |
| `PBR` | Следует ли генерировать карты материалов PBR (базовый цвет, металличность, шероховатость, нормали). Требует `texture`; принудительно отключается, когда `texture` отключен (по умолчанию: True). | BOOLEAN | Нет | true / false |
| `image_seed` | Сид, используемый на этапе генерации изображения (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `model_seed` | Сид, используемый на этапе генерации модели (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `texture_seed` | Сид, используемый на этапе генерации текстур (по умолчанию: 42). | INT | Нет | от 0 до 2147483647 |
| `texture_quality` | Качество генерируемых текстур. detailed = HD-текстуры, extreme = ультра-текстуры 8K (по умолчанию: standard). | COMBO | Нет | "standard"<br>"detailed"<br>"extreme" |
| `face_limit` | Максимальное количество граней. Значение -1 позволяет Tripo выбирать адаптивно (около 1,4 млн граней при стандартном качестве v3.x, 2 млн при детальном). Tripo молча ограничивает: для v2.5 до 500 000, для четырехугольных сеток до 150 000. (по умолчанию: -1) | INT | Нет | от -1 до 2000000 |
| `quad` | Выход четырехугольной сетки. Tripo поставляет четырехугольные сетки в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остается пустым. (по умолчанию: False) | BOOLEAN | Нет | true / false |
| `качество геометрии` | Качество генерируемой геометрии (по умолчанию: standard). | COMBO | Нет | "standard"<br>"detailed" |
| `smart_low_poly` | Низкополигональная сетка с чистой топологией, созданной вручную (500–20 000 граней, для четырехугольных сеток 500–10 000). Лучше всего подходит для простых объектов; сложные могут не получиться. (по умолчанию: False) | BOOLEAN | Нет | true / false |
| `auto_size` | Масштабировать текстурированные модели до их реального размера в метрах. Tripo сохраняет размер как трансформацию сцены модели и запекает его при конвертации, оснащении скелетом или ретаргетинге модели; игнорируется без текстуры. (по умолчанию: True) | BOOLEAN | Нет | true / false |

**Примечания:**
- Параметр `prompt` является обязательным: пустой prompt вызывает ошибку узла.
- `pbr` требует `texture`. Когда `texture` отключен, узел принудительно отключает `pbr` и игнорирует его значение. `auto_size` также не действует без `texture`.
- Когда `smart_low_poly` включен, а `face_limit` задан значением, отличным от -1, предел количества граней должен составлять от 500 до 20 000 для треугольных сеток, или от 500 до 10 000 при включенном `quad`; в противном случае узел выдает ошибку.
- Когда `quad` включен, сгенерированная четырехугольная сетка поставляется в формате FBX, поэтому выход FBX заполнен, а выход GLB остается пустым.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Сгенерированный файл 3D-модели, сохранен только для обратной совместимости. | STRING |
| `task_id модели` | Уникальный идентификатор задачи для процесса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированная 3D-модель в формате GLB. Пусто, когда `quad` включен. | FILE3DGLB |
| `FBX` | Сгенерированная 3D-модель в формате FBX. Заполнен только при включенном `quad`. | FILE3DFBX |
