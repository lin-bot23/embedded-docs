# Tripo: النص إلى نموذج

تُولِّد هذه العقدة نماذج ثلاثية الأبعاد مكتملة من وصف نصي باستخدام واجهة برمجة تطبيقات Tripo. تنتظر العقدة اكتمال التوليد ثم تُرجع ملف النموذج، مع إمكانية تضمين القوام ومواد PBR اختياريًا.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
|-----------|-------------|-----------|----------|-------|
| `المطالبة` | وصف نصي للنموذج ثلاثي الأبعاد المطلوب توليده (متعدد الأسطر). هذا المعامل إلزامي ولا يمكن أن يكون فارغًا. | STRING | نعم | - |
| `النص_السلبي` | وصف نصي لما يجب تجنبه في النموذج المولّد (متعدد الأسطر). يصل إلى 255 حرفًا. يُرسل إلى الواجهة البرمجية فقط عندما يكون غير فارغ. | STRING | لا | حتى 255 حرفًا |
| `إصدار_النموذج` | إصدار نموذج Tripo المستخدم في التوليد (الافتراضي: v3.1-20260211). | COMBO | لا | تتوفر خيارات متعددة |
| `النمط` | النمط المُطبَّق على النموذج المولّد (الافتراضي: None). لم يعد مدعومًا من Tripo ويُتجاهل؛ أُبقي لتوافق سير العمل القديم. | COMBO | لا | تتوفر خيارات متعددة |
| `الملمس` | تحديد ما إذا كان سيتم توليد خرائط القوام. عند إيقافه، يُرجع هندسة مجردة ويتجاهل `pbr` (الافتراضي: True). | BOOLEAN | لا | true / false |
| `PBR` | تحديد ما إذا كان سيتم توليد خرائط مواد PBR (اللون الأساسي، المعدني، الخشونة، الطبيعي). يتطلب تفعيل `texture`؛ ويُجبر على الإيقاف عندما يكون `texture` متوقفًا (الافتراضي: True). | BOOLEAN | لا | true / false |
| `بذرة_الصورة` | البذرة المستخدمة في مرحلة توليد الصورة (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `بذرة_النموذج` | البذرة المستخدمة في مرحلة توليد النموذج (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `بذرة_الملمس` | البذرة المستخدمة في مرحلة توليد القوام (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `جودة_الملمس` | جودة القوام المولّد. detailed = قوام عالي الدقة (HD)، extreme = قوام فائق الدقة 8K (الافتراضي: standard). | COMBO | لا | "standard"<br>"detailed"<br>"extreme" |
| `حد_الوجه` | الحد الأقصى لعدد الأوجه. القيمة -1 تترك لـ Tripo الاختيار بشكل تكيفي (حوالي 1.4 مليون وجه على الإصدار القياسي v3.x، و2 مليون على detailed). يقوم Tripo بتقييدها تلقائيًا: v2.5 عند 500,000، والشبكات الرباعية عند 150,000. (الافتراضي: -1) | INT | لا | -1 إلى 2000000 |
| `رباعي` | إخراج شبكة رباعية. يسلّم Tripo الشبكات الرباعية بصيغة FBX، لذلك تصل النتيجة إلى مخرج FBX ويبقى مخرج GLB فارغًا. (الافتراضي: False) | BOOLEAN | لا | true / false |
| `جودة الهندسة` | جودة الهندسة المولّدة (الافتراضي: standard). | COMBO | لا | "standard"<br>"detailed" |
| `smart_low_poly` | شبكة منخفضة المضلعات بطوبولوجيا نظيفة على طراز الصناعة اليدوية (500-20,000 وجه، الرباعي 500-10,000). مثالية للمواضيع البسيطة؛ وقد تفشل في المعقدة. (الافتراضي: False) | BOOLEAN | لا | true / false |
| `auto_size` | ضبط حجم النماذج المزوّدة بقوام على حجمها الحقيقي بالأمتار. يخزّن Tripo الحجم كتحويل مشهد للنموذج ويُدمجه عند تحويل النموذج أو تجهيزه بهيكل أو إعادة استهدافه؛ ويُتجاهل دون قوام. (الافتراضي: True) | BOOLEAN | لا | true / false |

**ملاحظات:**
- معامل `prompt` إلزامي: الوصف الفارغ يتسبب في رفع العقدة لخطأ.
- `pbr` يتطلب تفعيل `texture`. عندما يكون `texture` متوقفًا، تفرض العقدة إيقاف `pbr` وتتجاهل قيمته. كما لا يكون لـ `auto_size` أي تأثير بدون `texture`.
- عند تفعيل `smart_low_poly` وتعيين `face_limit` إلى قيمة غير -1، يجب أن يتراوح حد الأوجه بين 500 و20,000 بالنسبة للإخراج المثلثي، أو بين 500 و10,000 عند تفعيل `quad`؛ وإلا ترفع العقدة خطأً.
- عند تفعيل `quad`، تُسلَّم الشبكة الرباعية المولّدة بصيغة FBX، لذلك يمتلئ مخرج FBX ويبقى مخرج GLB فارغًا.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | ملف النموذج ثلاثي الأبعاد المولّد، أُبقي للتوافق مع الإصدارات السابقة فقط. | STRING |
| `معرّف مهمة النموذج` | المعرّف الفريد للمهمة الخاصة بعملية توليد النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المولّد بصيغة GLB. يكون فارغًا عند تفعيل `quad`. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المولّد بصيغة FBX. يُملأ فقط عند تفعيل `quad`. | FILE3DFBX |
