# Tripo: النص إلى نموذج

تُنشئ هذه العقدة القديمة نماذج ثلاثية الأبعاد مكتملة من وصف نصي باستخدام واجهة Tripo البرمجية. تنتظر اكتمال التوليد ثم تُرجع ملف النموذج، مع أنسجة ومواد PBR اختياريًا. وهي مُعلَّمة كمهملة وتُحتفظ بها لسير العمل الأقدم.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `المطالبة` | وصف نصي للنموذج ثلاثي الأبعاد المراد توليده (متعدد الأسطر). هذا المعامل مطلوب ولا يمكن أن يكون فارغًا. | STRING | نعم | - |
| `النص_السلبي` | وصف نصي لما يجب تجنبه في النموذج المولّد (متعدد الأسطر). حتى 255 حرفًا. يُرسل إلى واجهة API فقط عندما يكون غير فارغ. | STRING | لا | حتى 255 حرفًا |
| `إصدار_النموذج` | إصدار نموذج Tripo المراد استخدامه للتوليد (الافتراضي: v3_1_20260211). | COMBO | لا | خيارات متعددة متاحة |
| `النمط` | لم يعد مدعومًا من Tripo ويُتجاهل. يُحتفظ به لسير العمل الأقدم (الافتراضي: "None"). | COMBO | لا | خيارات متعددة متاحة |
| `الملمس` | توليد خرائط النسيج. عند الإيقاف يُرجع هندسة مجردة ويتجاهل `pbr` (الافتراضي: True). | BOOLEAN | لا | true / false |
| `PBR` | خرائط مواد PBR (اللون الأساسي، المعدني، الخشونة، normal). يتطلب `texture`؛ يُفرض إيقافه عندما يكون `texture` متوقفًا (الافتراضي: True). | BOOLEAN | لا | true / false |
| `بذرة_الصورة` | البذرة المستخدمة لمرحلة توليد الصورة (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `بذرة_النموذج` | البذرة المستخدمة لمرحلة توليد النموذج (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `بذرة_الملمس` | البذرة المستخدمة لمرحلة توليد النسيج (الافتراضي: 42). | INT | لا | 0 إلى 2147483647 |
| `جودة_الملمس` | جودة الأنسجة المولّدة. detailed = أنسجة HD، extreme = أنسجة 8K فائقة الدقة (الافتراضي: standard). | COMBO | لا | "standard"<br>"detailed"<br>"extreme" |
| `حد_الوجه` | الحد الأقصى لعدد الأوجه. -1 يتيح لـ Tripo الاختيار التكيفي (حوالي 1.4M وجه في v3.x standard، و2M في detailed). يقوم Tripo بالتقييد بصمت: v2.5 عند 500,000، والشبكات الرباعية عند 150,000. (الافتراضي: -1) | INT | لا | -1 إلى 2000000 |
| `رباعي` | مخرج شبكة رباعية. يُسلّم Tripo الشبكات الرباعية بصيغة FBX، لذا تصل النتيجة في مخرج FBX ويبقى مخرج GLB فارغًا. (الافتراضي: False) | BOOLEAN | لا | true / false |
| `جودة الهندسة` | جودة الهندسة المولّدة (الافتراضي: standard). | COMBO | لا | "standard"<br>"detailed" |
| `smart_low_poly` | شبكة منخفضة المضلعات بطوبولوجيا نظيفة ومصممة يدويًا (500-20,000 وجه، رباعية 500-10,000). الأفضل للأجسام البسيطة؛ قد تفشل الأجسام المعقدة. (الافتراضي: False) | BOOLEAN | لا | true / false |
| `auto_size` | تحجيم النماذج ذات الأنسجة إلى حجمها الواقعي بالأمتار. يخزّن Tripo الحجم كتحويل مشهد للنموذج ويدمجه عند تحويل النموذج أو تجهيزه الهيكلي أو إعادة استهدافه؛ يُتجاهل بدون `texture`. (الافتراضي: True) | BOOLEAN | لا | true / false |

**ملاحظات:**
- هذه العقدة مهملة ومُعلَّمة كعقدة قديمة. تُحتفظ بها للتوافق العكسي مع سير العمل الأقدم.
- المعامل `prompt` إلزامي: وجود `prompt` فارغ يؤدي إلى أن تُطلق العقدة خطأً.
- يتطلب `pbr` وجود `texture`. عندما يكون `texture` متوقفًا، تفرض العقدة إيقاف `pbr` وتتجاهل قيمته. كما لا يكون لـ `auto_size` أي تأثير بدون `texture`.
- عند تمكين `smart_low_poly` وضبط `face_limit` على قيمة غير -1، يجب أن يكون حد الأوجه بين 500 و20,000 لمخرج المثلثات، أو بين 500 و10,000 عند تمكين `quad`؛ وإلا تُطلق العقدة خطأً.
- عند تمكين `quad`، تُسلَّم الشبكة الرباعية المولّدة بصيغة FBX، لذا يُملأ مخرج FBX ويبقى مخرج GLB فارغًا.
- يُقبل المعامل `style` ولكن يُتجاهل.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | اسم ملف النموذج ثلاثي الأبعاد المولّد بالصيغة `<task_id>.<format>`، يُحتفظ به للتوافق العكسي فقط. | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة الفريد لعملية توليد النموذج. | MODEL_TASK_ID |
| `GLB` | النموذج ثلاثي الأبعاد المولّد بصيغة GLB. فارغ عند تمكين `quad`. | FILE3DGLB |
| `FBX` | النموذج ثلاثي الأبعاد المولّد بصيغة FBX. يُملأ فقط عند تمكين `quad`. | FILE3DFBX |
