# Pixal3DMultiViewConditioning

## 概述

Pixal3D 多视图条件节点是一个固定轨道装置，以90度间隔生成物体的前视图、左视图、后视图和右视图。它用于创建适用于Pixal3D应用的框架视图，其中物体在其最宽处占据大约1/1.1的框架宽度，并在每个视图中保持相同的比例。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | 带有捆绑NAF权重的DINOv3 ViT-L/16 ClipVision模型。 | MODEL | 是 | N/A |
| `fov` | 视图的水平视野，单位为度。 | 浮点数 | 是 | 1.0 - 170.0 |
| `front` | 物体前侧的方形视图，带有透明度或黑色背景。 | IMAGE | 是 | N/A |
| `left` | 物体左侧的方形视图，带有透明度或黑色背景。 | IMAGE | 可选 | N/A |
| `back` | 物体后侧的方形视图，带有透明度或黑色背景。 | IMAGE | 可选 | N/A |
| `right` | 物体右侧的方形视图，带有透明度或黑色背景。 | IMAGE | 可选 | N/A |

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `positive` | Pixal3D 多视图条件节点的正条件输出。 | 条件 |

## 注意事项

- `fov` 参数控制视图的框架水平视野。对于装置渲染和大多数多视图生成器，20度的值是典型的。
- 首个连接的视图（前、左、后、右顺序）被认为是前视图，网格姿态设置为该视图。
- 如果没有提供前视图，将记录警告，网格姿态将使用第一个连接的视图作为其前视图。
- 节点假定视图是方形且与装置一样框架化。物体在其最宽处应占据大约1/1.1的框架宽度，并且每个视图中应保持相同的比例。
- 节点输出两个条件对象，一个用于正条件，一个用于负条件。这些可以用于条件Pixal3D模型或其他接受条件输入的节点。
