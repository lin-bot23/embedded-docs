# Pixal3DMultiViewConditioning

## Обзор

Узел Pixal3D Multi-View Conditioning представляет собой стационарный риг, который генерирует передние, левые, задние и правые виды объекта с интервалом в 90 градусов. Он используется для создания рамочных видов для приложений Pixal3D, где объект занимает около 1/1.1 части кадра в самом широком месте, поддерживая одинаковый масштаб во всех видах.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | DINOv3 ViT-L/16 ClipVision с включенными весами NAF. | MODEL | Да | Н/Д |
| `fov` | Горизонтальный FOV в градусах для видов в рамке. | FLOAT | Да | 1.0 - 170.0 |
| `front` | Квадратный вид передней стороны объекта, с альфа-каналом или на черном фоне. | IMAGE | Да | Н/Д |
| `left` | Квадратный вид левой стороны объекта, с альфа-каналом или на черном фоне. | IMAGE | Опционально | Н/Д |
| `back` | Квадратный вид задней стороны объекта, с альфа-каналом или на черном фоне. | IMAGE | Опционально | Н/Д |
| `right` | Квадратный вид правой стороны объекта, с альфа-каналом или на черном фоне. | IMAGE | Опционально | Н/Д |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное условие для узла Pixal3D Multi-View Conditioning. | CONDITIONING |
| `negative` | Отрицательное условие для узла Pixal3D Multi-View Conditioning. | CONDITIONING |

## Примечания

- Параметр `fov` контролирует горизонтальный угол поля зрения для видов в рамке. Значение 20 градусов типично для рендеров рига и большинства многоугольных генераторов.
- Первый подключенный вид (в порядке front, left, back, right) считается передним, и модель настроена для этого вида.
- Если передний вид не предоставлен, выводится предупреждение, и модель будет настроена с первым подключенным видом как его передним.
- Узел предполагает, что виды квадратные и рамочные, как риг. Объект должен занимать около 1/1.1 части кадра в самом широком месте, и одинаковый масштаб должен поддерживаться во всех видах.
- Узел выводит два объекта Условие, один для положительного и один для отрицательного условия. Эти объекты можно использовать для условия моделей Pixal3D или других узлов, принимающих входы Условие.
