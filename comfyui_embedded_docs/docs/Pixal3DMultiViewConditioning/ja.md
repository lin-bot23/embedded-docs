# Pixal3DMultiViewConditioning

## 概要

Pixal3D マルチビュー条件設定ノードは、物体の前、左、後、右のビューを90度間隔で生成する固定オーロラリグです。Pixal3Dアプリケーション用のフレームビューを作成するために使用され、物体がフレームの約1/1.1の幅で表示され、すべてのビューで同じスケールが維持されます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|------------|------|----------|------|-------|
| `clip_vision_model` | DINOv3 ViT-L/16 ClipVision にバンドルされた NAF 重みを持つモデル。 | MODEL | はい | N/A |
| `fov` | フレーム内のビューの水平視野角（度）。 | FLOAT | はい | 1.0 - 170.0 |
| `front` | 物体の前側の正方形のビュー、アルファチャンネル付きまたは黒い背景上。 | IMAGE | はい | N/A |
| `left` | 物体の左側の正方形のビュー、アルファチャンネル付きまたは黒い背景上。 | IMAGE | オプション | N/A |
| `back` | 物体の後側の正方形のビュー、アルファチャンネル付きまたは黒い背景上。 | IMAGE | オプション | N/A |
| `right` | 物体の右側の正方形のビュー、アルファチャンネル付きまたは黒い背景上。 | IMAGE | オプション | N/A |

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `positive` | Pixal3D マルチビュー条件設定ノードのポジティブ条件設定出力。 | CONDITIONING |
| `negative` | Pixal3D マルチビュー条件設定ノードのネガティブ条件設定出力。 | CONDITIONING |

## 注意事項

- `fov` パラメータは、フレーム内のビューの水平視野角を制御します。リグレンダリングやほとんどのマルチビューガジェネレータには20度が一般的です。
- 初めて接続されたビュー（前、左、後、右の順序）が前と見なされ、メッシュはこのビューに合わせてポーズされます。
- フロントビューが提供されていない場合、警告がログに記録され、メッシュは最初に接続されたビューを前としてポーズされます。
- ノードはビューが正方形でリグのようにフレーム内に収まっていると仮定します。物体は最も幅広い場所でフレームの約1/1.1を占めるべきであり、すべてのビューで同じスケールが維持されるべきです。
- ノードはポジティブおよびネガティブの条件設定オブジェクトの両方を出力します。これらはPixal3DモデルやConditioning入力を受け入れる他のノードに条件設定として使用できます。
