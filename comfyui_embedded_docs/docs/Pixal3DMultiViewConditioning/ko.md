# Pixal3DMultiViewConditioning

```markdown
# Pixal3D 다중 시점 조건 설정 노드

## 개요

Pixal3D 다중 시점 조건 설정 노드는 90도 간격으로 대면, 좌면, 후면, 우면의 시점을 생성하는 고정된 공전 라이그입니다. 이 노드는 대상이 프레임의 약 1/1.1 정도로 걸쳐 있으며, 모든 시점에서 같은 크기를 유지하는 프레임 뷰를 생성하는 데 사용됩니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `clip_vision_model` | DINOv3 ViT-L/16 ClipVision과 함께 제공된 NAF 가중치를 포함한 모델. | MODEL | 예 | N/A |
| `fov` | 시점의 프레임에 맞춘 수평 FOV(각도). | FLOAT | 예 | 1.0 - 170.0 |
| `front` | 대상의 전면을 보여주는 사각형 뷰, 알파나 검은 배경으로. | IMAGE | 예 | N/A |
| `left` | 대상의 좌면을 보여주는 사각형 뷰, 알파나 검은 배경으로. | IMAGE | 선택 | N/A |
| `back` | 대상의 후면을 보여주는 사각형 뷰, 알파나 검은 배경으로. | IMAGE | 선택 | N/A |
| `right` | 대상의 우면을 보여주는 사각형 뷰, 알파나 검은 배경으로. | IMAGE | 선택 | N/A |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | Pixal3D 다중 시점 조건 설정 노드의 긍정 조건 설정 출력. | CONDITIONING |
| `negative` | Pixal3D 다중 시점 조건 설정 노드의 부정 조건 설정 출력. | CONDITIONING |

## 주의사항

- `fov` 매개변수는 시점의 프레임에 맞춘 수평 시야각을 제어합니다. 20도의 값은 라이그 렌더링과 대부분의 다중 시점 생성기에 일반적입니다.
- 첫 번째 연결된 시점(대면, 좌면, 후면, 우면 순서)이 전면으로 간주되며, 메시는 이 시점에 맞춰됩니다.
- 대면 시점이 제공되지 않으면 경고가 로그에 기록되고, 메시는 첫 번째 연결된 시점을 전면으로 사용하여 맞춰집니다.
- 노드는 시점이 사각형이고 라이그와 같이 프레임에 맞춰져 있다고 가정합니다. 대상은 가장 넓은 부분에서 프레임의 약 1/1.1 정도로 걸쳐 있어야 하며, 모든 시점에서 같은 크기를 유지해야 합니다.
- 노드는 긍정 조건 설정과 부정 조건 설정을 각각 두 개의 조건 설정 객체로 출력합니다. 이들은 Pixal3D 모델이나 조건 설정 입력을 받는 다른 노드에 조건 설정으로 사용될 수 있습니다.
```
