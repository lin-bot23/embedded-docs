# 隨機排序影片-文字配對

此節點會隨機打亂清單中影片與文字配對的順序，並確保每個影片仍與其對應的文字保持配對。此節點接受兩個長度相同的清單，並對兩者套用相同的隨機排列，因此在打亂後原始配對關係依然保留。種子值（`seed`）可控制打亂順序，以便重現結果。

## 輸入

| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `影片` | 要打亂的影片清單。 | VIDEO | 是 | 影片項目清單 |
| `文字` | 要打亂的文字清單（與影片配對的說明文字）。 | STRING | 是 | 文字字串清單 |
| `隨機種子` | 決定打亂順序的隨機種子（預設值：0）。 | INT | 是 | 0 至 18446744073709551615 |

注意：`videos` 與 `texts` 的長度必須相同，因為此節點會將每個影片與相同位置的文字配對，並在打亂時保留這些配對。在內部，`seed` 值在產生隨機順序前會先以 4294967295（2^32 - 1）取模，因此極大的種子值可能產生與較小種子值相同的打亂結果。
