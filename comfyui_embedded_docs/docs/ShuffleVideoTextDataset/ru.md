# Перемешать Пары Видео-Текст

Этот узел случайным образом перемешивает порядок пар видео-текст в списке, сохраняя каждое видео в паре с соответствующим текстом. Он принимает два списка одинаковой длины и применяет одну и ту же случайную перестановку к обоим, гарантируя, что исходные пары сохраняются после перемешивания. Значение seed управляет порядком перемешивания, чтобы результаты можно было воспроизвести.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `видео` | Список видео для перемешивания. | VIDEO | Да | Список видеоэлементов |
| `тексты` | Список текстов для перемешивания (подписи, связанные с видео). | STRING | Да | Список текстовых строк |
| `seed` | Случайное зерно, определяющее порядок перемешивания (по умолчанию: 0). | INT | Да | от 0 до 18446744073709551615 |

Примечание: списки `videos` и `texts` должны иметь одинаковую длину, поскольку узел сопоставляет каждое видео с текстом на той же позиции и сохраняет эти пары при перемешивании. Внутренне значение `seed` уменьшается с помощью модуля 4294967295 (2^32 - 1) перед генерацией случайного порядка, поэтому очень большие значения seed могут давать то же перемешивание, что и меньшие.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `видео` | Перемешанные видео в новом случайном порядке. | VIDEO |
| `тексты` | Перемешанные тексты в том же новом порядке, что и видео. | STRING |
