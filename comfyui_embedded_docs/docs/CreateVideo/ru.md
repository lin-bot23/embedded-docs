# Создать видео

Узел Create Video объединяет последовательность изображений в видео. Вы можете задать скорость воспроизведения в кадрах в секунду, при необходимости добавить аудио и выбрать формат сжатия, битовую глубину и цветовое пространство итогового видео.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `изображения` | Изображения, из которых создаётся видео. | IMAGE | Да | - |
| `кадров в секунду` | Количество кадров в секунду для скорости воспроизведения видео (по умолчанию: 30.0). | FLOAT | Да | 1.0 - 120.0 |
| `аудио` | Аудио, добавляемое к видео. | AUDIO | Нет | - |
| `bit_depth` | Auto использует 8 бит для sRGB и 10 бит для HDR. Явные варианты 8 бит и 10 бит не зависят от цветового пространства. (по умолчанию: "auto") | COMBO | Нет | `"auto"`<br>8<br>10 |
| `color_space` | Цветовое пространство входных изображений. HDR выбирает BT.2020/HLG, а HDR PQ выбирает BT.2020/PQ. (по умолчанию: "sRGB") | COMBO | Нет | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |
| `codec` | При необходимости сразу закодировать видео. None сохраняет изображения в тензорной форме; Auto использует H.264. (по умолчанию: "none") | COMBO | Нет | `"none"`<br>Доступные варианты видеокодеков из списка видеокодеков (например, `"auto"` и другие поддерживаемые кодеки) |

Примечание. Когда для `bit_depth` задано значение `"auto"`, узел автоматически использует 10 бит для цветовых пространств HDR и HDR PQ и 8 бит для sRGB.

Примечание. Параметр `codec` — это расширенная опция. Если оставить его равным `"none"`, выходные данные остаются в тензорной форме; выбор любого другого кодека немедленно кодирует видео.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Сгенерированное видео, содержащее входные изображения и необязательное аудио. | VIDEO |
