# 動画を作成

Create Video ノードは、一連の画像をビデオに結合します。再生速度をフレーム毎秒で設定し、必要に応じてオーディオを追加し、生成されるビデオの圧縮形式、ビット深度、色空間を選択できます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `画像` | ビデオを作成する元となる画像です。 | IMAGE | はい | - |
| `fps` | ビデオの再生速度を指定するフレーム毎秒（デフォルト：30.0）。 | FLOAT | はい | 1.0 - 120.0 |
| `オーディオ` | ビデオに追加するオーディオです。 | AUDIO | いいえ | - |
| `bit_depth` | `"auto"` は sRGB では 8-bit、HDR では 10-bit を使用します。明示的な 8-bit と 10-bit の選択は色空間とは独立しています。（デフォルト："auto"） | COMBO | いいえ | `"auto"`<br>8<br>10 |
| `color_space` | 入力画像の色空間です。HDR は BT.2020/HLG を選択し、HDR PQ は BT.2020/PQ を選択します。（デフォルト："sRGB"） | COMBO | いいえ | `"sRGB"`<br>`"HDR"`<br>`"HDR PQ"` |
| `codec` | 任意でビデオを即座にエンコードします。`"none"` は画像をテンソル形式のまま保持し、`"auto"` は H.264 を使用します。（デフォルト："none"） | COMBO | いいえ | `"none"`<br>ビデオコーデック一覧から利用可能なビデオコーデックオプション（例：`"auto"` およびその他のサポートされるコーデック） |

注：`bit_depth` が `"auto"` に設定されている場合、ノードは HDR および HDR PQ 色空間には自動的に 10-bit を使用し、sRGB には 8-bit を使用します。

注：`codec` パラメータは詳細設定オプションです。`"none"` のままにすると、出力はテンソル形式のままになります。それ以外のコーデックを選択すると、ビデオが即座にエンコードされます。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `output` | 入力画像とオプションのオーディオを含む生成済みビデオです。 | VIDEO |
