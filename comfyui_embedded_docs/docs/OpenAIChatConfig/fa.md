# تنظیمات پیشرفته ChatGPT OpenAI

نود تنظیمات پیشرفته ChatGPT OpenAI به شما امکان می‌دهد تا تنظیمات اضافی برای نودهای Chat OpenAI تعیین کنید. این نود تنظیمات پیشرفته‌ای را فراهم می‌کند که کنترل می‌کند چگونه مدل پاسخ‌ها را تولید می‌کند، از جمله رفتار قطع کردن، محدودیت‌های طول پاسخ و دستورالعمل‌های سفارشی.

## مقدمه

نود تنظیمات پیشرفته ChatGPT OpenAI برای بهبود عملکرد نودهای Chat OpenAI طراحی شده است و به کاربران اجازه می‌دهد تا تنظیمات پیشرفته‌ای را برای تنظیم پاسخ‌های مدل به نیازهای خاص خود مشخص کنند.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `truncation` | استراتژی قطع کردن برای پاسخ مدل. auto: اگر محتوای این پاسخ و پاسخ‌های قبلی از اندازه پنجره محتوای مدل فراتر رود، مدل پاسخ را برای تطابق با پنجره محتوای بهینه قطع خواهد کرد و ورودی‌های وسط مکالمه را حذف می‌کند. disabled: اگر پاسخ مدل از اندازه پنجره محتوای مدل فراتر رود، درخواست با خطای 400 شکست خواهد خورد (پیش‌فرض: "auto") | STRING | بله | "auto"<br>"disabled" |
| `max_output_tokens` | محدودیت بالایی برای تعداد توکن‌هایی که می‌توان برای یک پاسخ تولید کرد، شامل توکن‌های قابل مشاهده و توکن‌های استدلالی (پیش‌فرض: 4096) | INT | خیر | 16 تا 16384 |
| `instructions` | دستورالعمل‌هایی برای مدل در مورد نحوه تولید پاسخ (ورودی چندخطی پشتیبانی می‌شود) | STRING | خیر | - |
| `reasoning_effort` | میزان استدلالی که مدل قبل از پاسخ دادن انجام می‌دهد. 'default' انتخاب بین مدل را واگذار می‌کند. سطح‌های پشتیبانی شده برای هر مدل متفاوت است: GPT-6 Astra low-max، GPT-5.6 none-max (بدون حداقل)، GPT-5.5 none-xhigh، GPT-5.5 Pro medium-xhigh، GPT-5 minimal-high، o-series low-high; GPT-4.1 استدلال ندارد. سطح‌های پشتیبانی نشده قبل از ارسال درخواست رد می‌شوند (پیش‌فرض: "default") | STRING | خیر | "default"<br>"none"<br>"minimal"<br>"low"<br>"medium"<br>"high"<br>"xhigh"<br>"max" |

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | شیء تنظیمات که شامل تنظیمات مشخص شده برای استفاده با نودهای Chat OpenAI است | OPENAI_CHAT_CONFIG |

## یادداشت‌ها

- پارامتر `max_output_tokens` محدودیت بالایی برای تعداد توکن‌های کل، شامل توکن‌های قابل مشاهده و توکن‌های استدلالی تنظیم می‌کند.
- پارامتر `reasoning_effort` به شما امکان می‌دهد تا سطح استدلالی که مدل قبل از تولید پاسخ انجام می‌دهد را مشخص کنید. سطح‌های پشتیبانی شده بسته به مدل مورد استفاده متفاوت است.
- پارامتر `instructions` می‌تواند برای ارائه دستورالعمل‌های دقیق به مدل برای هدایت فرآیند تولید پاسخ استفاده شود.
- پارامتر `truncation` تعیین می‌کند که آیا مدل باید پاسخ را خودکار قطع کند یا در صورت تجاوز از اندازه پنجره محتوای به خطای 400 شکست بخورد.
