# تنظیمات پیشرفته OpenAI ChatGPT

گره OpenAIChatConfig به شما امکان می‌دهد گزینه‌های پیشرفته‌ای تعریف کنید که نحوه تولید پاسخ توسط گره OpenAI Chat را کنترل می‌کنند. می‌توانید راهبرد برش را تنظیم کنید، تعداد توکن‌های خروجی را محدود کنید، دستورالعمل‌های سفارشی ارائه دهید و انتخاب کنید مدل پیش از پاسخ‌دادن چقدر استدلال کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `truncation` | راهبرد برش برای پاسخ مدل. auto: اگر زمینه این پاسخ و پاسخ‌های قبلی از اندازه پنجره زمینه مدل فراتر رود، مدل پاسخ را برای جا شدن در پنجره زمینه با حذف آیتم‌های ورودی از میانه گفت‌وگو برش می‌دهد. disabled: اگر پاسخ مدل از اندازه پنجره زمینه یک مدل فراتر رود، درخواست با خطای 400 شکست می‌خورد (پیش‌فرض: "auto") | COMBO | بله | "auto"<br>"disabled" |
| `max_output_tokens` | حد بالایی برای تعداد توکن‌هایی که می‌توان برای یک پاسخ تولید کرد، شامل توکن‌های خروجی قابل مشاهده و توکن‌های استدلال (پیش‌فرض: 4096) | INT | خیر | 16 تا 16384 |
| `instructions` | دستورالعمل‌هایی برای مدل درباره نحوه تولید پاسخ (ورودی چندخطی پشتیبانی می‌شود) | STRING | خیر | - |
| `reasoning_effort` | میزان استدلال مدل پیش از پاسخ‌دادن. «default» انتخاب را به مدل واگذار می‌کند. سطوح پشتیبانی‌شده بسته به مدل متفاوت است: GPT-6 Astra از low تا max، GPT-5.6 از none تا max (بدون minimal)، GPT-5.5 از none تا xhigh، GPT-5.5 Pro از medium تا xhigh، GPT-5 از minimal تا high، سری o از low تا high؛ GPT-4.1 استدلال ندارد. سطوح پشتیبانی‌نشده پیش از ارسال درخواست رد می‌شوند. (پیش‌فرض: "default") | COMBO | خیر | "default"<br>"none"<br>"minimal"<br>"low"<br>"medium"<br>"high"<br>"xhigh"<br>"max" |

توجه: اگرچه `top_p` و `temperature` در مشخصات API به‌عنوان ویژگی فهرست شده‌اند، اما برای همه مدل‌ها پشتیبانی نمی‌شوند و بنابراین به‌عنوان ورودی در دسترس قرار نمی‌گیرند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | شیء پیکربندی حاوی تنظیمات مشخص‌شده برای استفاده با گره‌های OpenAI Chat | OPENAI_CHAT_CONFIG |
