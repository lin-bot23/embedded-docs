# خيارات متقدمة OpenAI ChatGPT

يُمكّن العقد OpenAI ChatGPT Advanced Options من ضبط إعدادات إضافية للعقدات OpenAI Chat Nodes. يوفر هذا العقد إعدادات متقدمة تتحكم في كيفية توليد النموذج للردود، بما في ذلك سلوك التقطيع، حدود طول النصوص الصادرة، والإرشادات المخصصة.

## نظرة عامة

يُصمم عقد OpenAI ChatGPT Advanced Options لتعزيز وظيفة العقدات OpenAI Chat Nodes عن طريق السماح للمستخدمين بتحديد خيارات إعدادات متقدمة. يمكن لهذه الإعدادات تعديل توليد ردود النموذج لتلبية متطلبات محددة.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | نطاق |
|-----------|-------------|-----------|----------|-------|
| `الاقتصاص` | استراتيجية التقطيع التي سيستخدمها النموذج للردود. auto: إذا تجاوز سياق هذا الرد وسياق الردود السابقة حجم نافذة سياق النموذج، سيقوم النموذج بتقطيع الرد ليتناسب مع نافذة السياق عن طريق إسقاط عناصر الإدخال في منتصف الحوار. disabled: إذا كان رد النموذج سيتجاوز حجم نافذة السياق لنموذج، سيتم رفض الطلب بخطأ 400 (الافتراضي: "auto") | STRING | نعم | "auto"<br>"disabled" |
| `الرموز المخرجة القصوى` | حد أعلى لعدد التokens الذي يمكن توليده للرد، بما في ذلك التokens المرئية والت tokens التفكيرية (الافتراضي: 4096) | INT | لا | 16 إلى 16384 |
| `التعليمات` | إرشادات للنموذج حول كيفية توليد الرد (يدعم الإدخال المتعدد الأسطر) | STRING | لا | - |
| `reasoning_effort` | مقدار التفكير الذي يقوم به النموذج قبل الرد. 'default' يترك الخيار للنموذج. تختلف المستويات المدعومة لكل نموذج: GPT-6 Astra low-max، GPT-5.6 none-max (بدون أقل قيمة)، GPT-5.5 none-xhigh، GPT-5.5 Pro medium-xhigh، GPT-5 minimal-high، o-series low-high; GPT-4.1 لا يدعم التفكير. يتم رفض المستويات غير المدعومة قبل إرسال الطلب (الافتراضي: "default") | STRING | لا | "default"<br>"none"<br>"minimal"<br>"low"<br>"medium"<br>"high"<br>"xhigh"<br>"max" |

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | مكتبة إعدادات تحتوي على الإعدادات المحددة للاستخدام مع العقدات OpenAI Chat Nodes | OPENAI_CHAT_CONFIG |

## ملاحظات

- يضبط المعامل `max_output_tokens` الحد الأعلى لعدد الرموز (tokens) الكلي، بما في ذلك رموز المخرجات المرئية ورموز التفكير.
- يسمح المعامل `reasoning_effort` بتخصيص مستوى التفكير الذي يجب أن يقوم به النموذج قبل توليد الرد. تختلف المستويات المدعومة بناءً على النموذج المستخدم.
- يمكن استخدام المعامل `instructions` لتقديم إرشادات مفصلة للنموذج لتهدية عملية توليد الرد.
- يحدد المعامل `truncation` ما إذا كان النموذج يجب أن يقطع الرد تلقائيًا إذا تجاوز حجم نافذة السياق أو يفشل بخطأ 400.
