# Уровень настроек OpenAI ChatGPT Дополнительные параметры

Уровень настроек OpenAI ChatGPT Дополнительные параметры позволяет настроить дополнительные параметры для узлов OpenAI Chat Nodes. Этот уровень настроек предоставляет продвинутые параметры, которые контролируют способ генерации ответов моделью, включая поведение обрезки, ограничения длины вывода и пользовательские инструкции.

## Обзор

Уровень настроек OpenAI ChatGPT Дополнительные параметры разработан для улучшения функциональности узлов OpenAI Chat Nodes, позволяя пользователям specify продвинутые параметры конфигурации. Эти настройки могут помочь настроить генерацию ответов модели в соответствии с конкретными требованиями.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `усечение` | Стратегия обрезки для ответа модели. auto: Если контекст этого ответа и предыдущих exceeds exceeds размер окна контекста модели, модель обрежет ответ, чтобы вписаться в окно контекста, удалив элементы ввода в середине разговора. disabled: Если ответ модели exceed exceed размер окна контекста для модели, запрос будет fail с ошибкой 400 (по умолчанию: "auto") | STRING | Да | "auto"<br>"disabled" |
| `макс_выходные_токены` | Верхний предел числа токенов, которые могут быть сгенерированы для ответа, включая видимые токены вывода и токены рассуждения (по умолчанию: 4096) | INT | Нет | 16 до 16384 |
| `инструкции` | Инструкции для модели о том, как генерировать ответ (поддерживается ввод multiline) | STRING | Нет | - |
| `reasoning_effort` | Степень рассуждения модели перед ответом. 'default' оставляет выбор модели. Поддерживаемые уровни различаются в зависимости от модели: GPT-6 Astra low-max, GPT-5.6 none-max (без minimal), GPT-5.5 none-xhigh, GPT-5.5 Pro medium-xhigh, GPT-5 minimal-high, o-series low-high; GPT-4.1 не имеет рассуждения. Неподдерживаемые уровни отклоняются до того, как запрос будет отправлен (по умолчанию: "default") | STRING | Нет | "default"<br>"none"<br>"minimal"<br>"low"<br>"medium"<br>"high"<br>"xhigh"<br>"max" |

## Выходы

| Название вывода | Описание | Тип данных |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | Объект конфигурации, содержащий指定的 настройки для использования с узлами OpenAI Chat Nodes | OPENAI_CHAT_CONFIG |

## Примечания

- Параметр `max_output_tokens` устанавливает верхний предел общего числа токенов, включая как видимые токены вывода, так и токены рассуждения.
- Параметр `reasoning_effort` позволяет specify specify уровень рассуждения, который модель должна apply apply перед генерацией ответа. Поддерживаемые уровни различаются в зависимости от используемой модели.
- Параметр `instructions` можно использовать для предоставления подробных инструкций модели для guidance guidance процесса генерации ответа.
- Параметр `truncation` определяет, должен ли модель автоматически truncate truncate ответ, если он exceeds exceeds размер окна контекста, или fail fail с ошибкой 400.
