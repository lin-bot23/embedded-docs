# Расширенные настройки OpenAI ChatGPT

Узел OpenAIChatConfig позволяет задавать дополнительные параметры, управляющие тем, как узел OpenAI Chat формирует ответы. Вы можете настроить стратегию усечения, ограничить количество выходных токенов, задать пользовательские инструкции и выбрать, насколько глубоко модель должна «рассуждать» перед ответом.

## Входы

| Параметр | Описание | Тип данных | Требуется | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `усечение` | Стратегия усечения, используемая для ответа модели. auto: если контекст этого ответа и предыдущих ответов превышает размер окна контекста модели, модель усечёт ответ, чтобы он поместился в окно контекста, отбрасывая элементы в середине разговора. disabled: если ответ модели превысит размер окна контекста модели, запрос завершится ошибкой 400 (по умолчанию: "auto") | COMBO | Да | "auto"<br>"disabled" |
| `макс_выходные_токены` | Верхняя граница количества токенов, которые могут быть сгенерированы для ответа, включая видимые выходные токены и токены рассуждений (по умолчанию: 4096) | INT | Нет | 16 до 16384 |
| `инструкции` | Инструкции модели о том, как формировать ответ (поддерживается многострочный ввод) | STRING | Нет | - |
| `reasoning_effort` | Определяет, насколько глубоко модель рассуждает перед ответом. Значение "default" оставляет выбор за моделью. Поддерживаемые уровни различаются в зависимости от модели: GPT-6 Astra — от low до max, GPT-5.6 — от none до max (без минимального), GPT-5.5 — от none до xhigh, GPT-5.5 Pro — от medium до xhigh, GPT-5 — от minimal до high, o-series — от low до high; GPT-4.1 не поддерживает рассуждения. Неподдерживаемые уровни отклоняются до отправки запроса. (по умолчанию: "default") | COMBO | Нет | "default"<br>"none"<br>"minimal"<br>"low"<br>"medium"<br>"high"<br>"xhigh"<br>"max" |

Примечание: хотя свойства `top_p` и `temperature` перечислены в спецификации API, они поддерживаются не всеми моделями и поэтому не выведены во входные параметры.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `OPENAI_CHAT_CONFIG` | Объект конфигурации, содержащий указанные настройки для использования с узлами OpenAI Chat | OPENAI_CHAT_CONFIG |
