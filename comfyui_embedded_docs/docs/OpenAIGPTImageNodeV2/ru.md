# OpenAI GPT Image 2

Этот узел генерирует изображения с помощью OpenAI GPT Image API. Он поддерживает пять моделей — `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst`, `gpt-image-2`, `gpt-image-1.5` и `gpt-image-1` — позволяет прикреплять эталонные изображения для редактирования изображений и может использовать маску, чтобы указать, какие части изображения следует заменить.

## Входы

### Общие входы

Эти входы отображаются всегда.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель OpenAI GPT Image для использования. Выбор модели открывает дополнительные параметры, специфичные для этой модели. | DYNAMIC_COMBO | Да | `"gpt-image-2.5-flare"`<br>`"gpt-image-2.5-sunburst"`<br>`"gpt-image-2"`<br>`"gpt-image-1.5"`<br>`"gpt-image-1"` |
| `prompt` | Текстовый запрос для GPT Image (по умолчанию: `""`). | STRING | Да | N/A |
| `n` | Сколько изображений генерировать (по умолчанию: `1`). | INT | Да | 1 до 8 |
| `seed` | Сид для воспроизводимости результатов (по умолчанию: `0`). Пока не реализован в бэкенде. | INT | Да | 0 до 2147483647 |

### Входы gpt-image-2.5-flare и gpt-image-2.5-sunburst

Эти входы появляются, когда `model` установлен в `gpt-image-2.5-flare` или `gpt-image-2.5-sunburst`. Обе модели используют одинаковый набор параметров.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `size` | Размер изображения. Выберите "Custom", чтобы использовать произвольные ширину и высоту (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"1024x1024"`<br>`"1024x1536"`<br>`"1536x1024"`<br>`"2048x2048"`<br>`"2048x1152"`<br>`"1152x2048"`<br>`"3840x2160"`<br>`"2160x3840"`<br>`"Custom"` |
| `custom_width` | Используется только когда `model.size` установлен в "Custom". Должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | 480 до 3840 (шаг 16) |
| `custom_height` | Используется только когда `model.size` установлен в "Custom". Должно быть кратно 16 (по умолчанию: `1024`). | INT | Нет | 480 до 3840 (шаг 16) |
| `background` | Возвращать изображение с фоном или без него (по умолчанию: `"auto"`). | COMBO | Да | `"auto"`<br>`"opaque"`<br>`"transparent"` |
| `quality` | Качество изображения, влияет на стоимость и время генерации (по умолчанию: `"low"`). | COMBO | Да | `"low"`<br>`"medium"`<br>`"high"`<br>`"xhigh"`<br>`"max"` |
| `model.images` | Необязательные эталонные изображения для редактирования изображений. До 16 изображений. Подробнее см. «Эталонные входы». | IMAGE | Нет | 0 до 16 |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно эталонное изображение. | MASK | Нет | N/A |

### Эталонные входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model.images` | Расширяемый слот: подключайте элементы от 1 до N (например, `image_1`...`image_16`); до 16 эталонных изображений для всех моделей. | IMAGE | Нет | 1 до 16 |
| `model.mask` | Необязательная маска для инпейнтинга (белые области будут заменены). Требуется ровно одно эталонное изображение. | MASK | Нет | N/A |

**Ограничения и лимиты параметров:**

- Когда `model.size` установлен в "Custom" (только для `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` и `gpt-image-2`), `model.custom_width` и `model.custom_height` должны быть кратны 16, длина наибольшей стороны не должна превышать 3840, соотношение сторон не должно превышать 3:1, а общее количество пикселей должно быть от 655 360 до 8 294 400.
- Параметр `model.mask` требует ровно одного эталонного изображения в `model.images`: он не может использоваться без изображения и не может использоваться более чем с одним изображением.
- При использовании `model.mask` его высота и ширина должны совпадать с высотой и шириной эталонного изображения.
- Когда `model.images` предоставлено, узел работает в режиме редактирования изображения; без `model.images` он генерирует изображения только на основе запроса.
- Эталонные изображения и маска уменьшаются перед отправкой в API.
- Уровни качества `"xhigh"` и `"max"` доступны только для `gpt-image-2.5-flare` и `gpt-image-2.5-sunburst`.
- Вариант фона `"transparent"` доступен для `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst`, `gpt-image-1.5` и `gpt-image-1`, но не для `gpt-image-2`.
- `seed` в настоящее время не реализован в бэкенде.
