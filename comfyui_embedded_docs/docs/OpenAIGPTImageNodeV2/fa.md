# OpenAI GPT Image ۲

این گره با استفاده از API تصویر GPT شرکت OpenAI تصاویر تولید می‌کند. از پنج مدل پشتیبانی می‌کند — `gpt-image-2.5-flare`، `gpt-image-2.5-sunburst`، `gpt-image-2`، `gpt-image-1.5` و `gpt-image-1` — به شما امکان می‌دهد تصاویر مرجع را برای ویرایش تصویر پیوست کنید، و می‌تواند از ماسک برای تعیین بخش‌هایی از تصویر که باید جایگزین شوند استفاده کند.

### ورودی‌های مرجع

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `model.images` | اسلات قابل‌افزایش: 1..N آیتم را متصل کنید (مثلاً `image_1`...`image_16`)؛ حداکثر 16 تصویر مرجع برای همه مدل‌ها. | IMAGE | خیر | 1 تا 16 |
| `model.mask` | ماسک اختیاری برای inpainting (نواحی سفید جایگزین می‌شوند). دقیقاً به یک تصویر مرجع نیاز دارد. | MASK | خیر | N/A |

**محدودیت‌ها و قیدهای پارامترها:**

- زمانی که `model.size` روی «Custom» است (فقط `gpt-image-2.5-flare`، `gpt-image-2.5-sunburst` و `gpt-image-2`)، `model.custom_width` و `model.custom_height` باید هر دو مضربی از 16 باشند، بلندترین ضلع نباید از 3840 بیشتر شود، نسبت ابعاد نباید از 3:1 بیشتر شود، و تعداد کل پیکسل‌ها باید بین 655,360 و 8,294,400 باشد.
- `model.mask` دقیقاً به یک تصویر مرجع در `model.images` نیاز دارد: بدون تصویر قابل استفاده نیست و با بیش از یک تصویر نیز قابل استفاده نیست.
- زمانی که `model.mask` استفاده می‌شود، ارتفاع و عرض آن باید با ارتفاع و عرض تصویر مرجع مطابقت داشته باشد.
- زمانی که `model.images` ارائه شود، گره در حالت ویرایش تصویر اجرا می‌شود؛ بدون `model.images`، تصاویر را تنها بر اساس درخواست متنی تولید می‌کند.
- تصاویر مرجع و ماسک پیش از ارسال به API مقیاس‌کوچک می‌شوند.
- سطوح کیفیت `"xhigh"` و `"max"` فقط برای `gpt-image-2.5-flare` و `gpt-image-2.5-sunburst` در دسترس هستند.
- گزینه پس‌زمینه `"transparent"` برای `gpt-image-2.5-flare`، `gpt-image-2.5-sunburst`، `gpt-image-1.5` و `gpt-image-1` در دسترس است، اما برای `gpt-image-2` نه.
- `seed` در حال حاضر در بک‌اند پیاده‌سازی نشده است.
