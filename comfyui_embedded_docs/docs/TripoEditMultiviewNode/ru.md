# Tripo: Редактирование ракурсов

Редактирует виды результата Tripo: Image to Multiview, используя отдельную текстовую инструкцию для каждого вида. Виды без инструкции остаются без изменений. Отредактированные изображения предназначены для подключения к Tripo: Multiview to Model для создания 3D-модели; отредактированный набор multiview нельзя редактировать повторно.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | ID задачи результата Tripo: Image to Multiview, виды которого будут редактироваться. Должен поступать из узла Tripo: Image to Multiview. | MULTIVIEW_TASK_ID | Да | Task ID |
| `front_prompt` | Текстовая инструкция, описывающая правку, которую нужно применить к виду спереди. Если пусто, вид спереди остаётся без изменений. По умолчанию: пустая строка. | STRING | Нет | Multiline text |
| `left_prompt` | Текстовая инструкция, описывающая правку, которую нужно применить к виду слева. Если пусто, вид слева остаётся без изменений. По умолчанию: пустая строка. | STRING | Нет | Multiline text |
| `back_prompt` | Текстовая инструкция, описывающая правку, которую нужно применить к виду сзади. Если пусто, вид сзади остаётся без изменений. По умолчанию: пустая строка. | STRING | Нет | Multiline text |
| `right_prompt` | Текстовая инструкция, описывающая правку, которую нужно применить к виду справа. Если пусто, вид справа остаётся без изменений. По умолчанию: пустая строка. | STRING | Нет | Multiline text |

Примечание: Как минимум один из четырёх промптов (`front_prompt`, `left_prompt`, `back_prompt`, `right_prompt`) должен содержать непустой текст; текст, состоящий только из пробельных символов, считается пустым, и если все промпты пусты, узел вызывает ошибку.

Примечание: Стоимость составляет примерно 0,05 USD за каждый вид, для которого задана инструкция правки.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `front` | Отредактированное изображение вида спереди. | IMAGE |
| `слева` | Отредактированное изображение вида слева. | IMAGE |
| `сзади` | Отредактированное изображение вида сзади. | IMAGE |
| `справа` | Отредактированное изображение вида справа. | IMAGE |
