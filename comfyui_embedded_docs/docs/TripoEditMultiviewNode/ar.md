# Tripo: تحرير متعدد المناظر

يعدّل واجهات نتيجة Tripo: Image to Multiview باستخدام تعليمة نصية منفصلة لكل واجهة. تبقى الواجهات التي لا تحتوي على تعليمة دون تغيير. الصور المعدلة مخصصة لأن تُوصل بعقدة Tripo: Multiview to Model لإنشاء نموذج ثلاثي الأبعاد؛ ولا يمكن تعديل مجموعة العروض المتعددة المعدلة مرة أخرى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | معرّف المهمة لنتيجة Tripo: Image to Multiview التي ستُعدّل واجهاتها. يجب أن يأتي من عقدة Tripo: Image to Multiview. | MULTIVIEW_TASK_ID | نعم | معرّف المهمة |
| `front_prompt` | تعليمة نصية تصف التعديل المراد تطبيقه على الواجهة الأمامية. عندما تكون فارغة، تبقى الواجهة الأمامية دون تغيير. القيمة الافتراضية: سلسلة فارغة. | STRING | لا | نص متعدد الأسطر |
| `left_prompt` | تعليمة نصية تصف التعديل المراد تطبيقه على الواجهة اليسرى. عندما تكون فارغة، تبقى الواجهة اليسرى دون تغيير. القيمة الافتراضية: سلسلة فارغة. | STRING | لا | نص متعدد الأسطر |
| `back_prompt` | تعليمة نصية تصف التعديل المراد تطبيقه على الواجهة الخلفية. عندما تكون فارغة، تبقى الواجهة الخلفية دون تغيير. القيمة الافتراضية: سلسلة فارغة. | STRING | لا | نص متعدد الأسطر |
| `right_prompt` | تعليمة نصية تصف التعديل المراد تطبيقه على الواجهة اليمنى. عندما تكون فارغة، تبقى الواجهة اليمنى دون تغيير. القيمة الافتراضية: سلسلة فارغة. | STRING | لا | نص متعدد الأسطر |

ملاحظة: يجب أن يحتوي واحد على الأقل من التعليقات النصية الأربعة (`front_prompt`، `left_prompt`، `back_prompt`، `right_prompt`) على نص غير فارغ؛ تُعتبر النصوص المكوّنة من مسافات بيضاء فقط فارغة، وإذا كانت جميع التعليقات النصية فارغة فإن العقدة تُطلق خطأً.

ملاحظة: تبلغ التكلفة حوالي 0.05 دولار أمريكي لكل واجهة لديها تعليمة تعديل.
