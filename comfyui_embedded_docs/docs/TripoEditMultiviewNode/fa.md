# Tripo: Edit Multiview

ویرایش نماهای یک نتیجه Tripo: Image to Multiview را با استفاده از یک دستور متنی جداگانه برای هر نما انجام می‌دهد. نماهایی که دستوری برای آن‌ها وجود ندارد، بدون تغییر می‌مانند. تصاویر ویرایش‌شده برای اتصال به Tripo: Multiview to Model و ساخت مدل سه‌بعدی در نظر گرفته شده‌اند؛ یک مجموعه چندنمایی ویرایش‌شده را نمی‌توان دوباره ویرایش کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `multiview_task_id` | شناسه کار نتیجه Tripo: Image to Multiview که نماهای آن ویرایش خواهند شد. باید از گره Tripo: Image to Multiview بیاید. | MULTIVIEW_TASK_ID | بله | شناسه کار |
| `front_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای جلو را توصیف می‌کند. وقتی خالی باشد، نمای جلو بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |
| `left_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای چپ را توصیف می‌کند. وقتی خالی باشد، نمای چپ بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |
| `back_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای پشت را توصیف می‌کند. وقتی خالی باشد، نمای پشت بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |
| `right_prompt` | دستور متنی که ویرایش مورد اعمال روی نمای راست را توصیف می‌کند. وقتی خالی باشد، نمای راست بدون تغییر می‌ماند. پیش‌فرض: رشته خالی. | STRING | خیر | متن چندخطی |

توجه: حداقل یکی از چهار پرامپت (`front_prompt`، `left_prompt`، `back_prompt`، `right_prompt`) باید متن غیرخالی داشته باشد؛ متنی که فقط شامل فاصله باشد خالی در نظر گرفته می‌شود، و اگر همه پرامپت‌ها خالی باشند، گره خطا می‌دهد.

توجه: هزینه به‌ازای هر نما که دستور ویرایش دارد، تقریباً 0.05 دلار آمریکا است.
