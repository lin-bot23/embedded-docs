# LTXVAddGeneratedKeyframes

## Обзор

Нод LTXV Add Generated Keyframes добавляет детализированные кейфреймы к видео latent. Каждый кейфрейм представляет один latent кадр токенов, охватывающий один пكسель кадра, который денoisится с видео и не является частью декодированного вывода. Размещение определяется параметром interval_frames, который specifies the pixel-frame stride для автоматического размещения.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительное условие, к которому добавляются кейфреймы. | CONDITIONING | Да | N/A |
| `negative` | Отрицательное условие, к которому добавляются кейфреймы. | CONDITIONING | Да | N/A |
| `vae` | Используется только для чтения масштабных факторов latent. | VAE | Да | N/A |
| `latent` | Простой 5D видео latent, к которому генерируются кейфреймы. Добавляйте их перед Concat AV Latent. | LATENT | Да | N/A |
| `interval_frames` | Шаг пكسель кадра для автоматического размещения. По умолчанию 24 соответствует примерно одному кейфрейму в секунду при 24 fps. Занятые пكسели пропускаются. При установке frame_indices параметр игнорируется. | INT | Нет | 1-1024 |
| `keyframes` | Дополнительное содержимое для инициализации новых кейфреймов. Подключите кейфреймы из более раннего Separate (одинакового пространственного размера) или простого видео latent для копирования ближайшего кадра в каждом новом слоте (например, после временного upscale). Эти кейфреймы также денoisятся, но не закрепляются в качестве направляющих. Записанные индексы на latent кейфреймов игнорируются, если не установлен frame_indices. Имеет эффект только при начале сэмплинга ниже sigma 1. | LATENT | Нет | N/A |
| `frame_indices` | Дополнительные пكسель кадры. Оставьте пустым, чтобы разместить из interval_frames на текущем канвасе. При установке этот список является размещением (подключенные кейфреймы соответствуют в порядке). Последний кадр допускается; кадр 0 не допускается (он уже является отдельным токеном). | STRING | Нет | N/A |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное условие с добавленным вниманием к кейфреймам. | CONDITIONING |
| `negative` | Отрицательное условие с добавленным вниманием к кейфреймам. | CONDITIONING |
| `latent` | Видео latent с добавленными кейфреймами на T. | LATENT |

## Примечания

- Параметр `interval_frames` определяет интервал кейфреймов в видео. Высокое значение приводит к меньшему количеству кейфреймов и более низкой частоте кадров.
- Вход `keyframes` позволяет вам инициализировать новые кейфреймы с существующими кейфреймами или видео latent. Если предоставлено, эти кейфреймы будут денoisироваться и добавляться к видео latent.
- Параметр `frame_indices` позволяет вам specify точные пكسель кадры, где должны быть размещены кейфреймы. При установке параметр `interval_frames` игнорируется.
- Выводы `positive` и `negative` содержат условие с добавленным вниманием к кейфреймам, которое можно использовать для дальнейшей обработки или анализа.
- Вывод `latent` содержит видео latent с добавленными кейфреймами на T, который можно использовать для дальнейшей обработки или анализа.
