# LTXVAddGeneratedKeyframes

```markdown
# LTXV 추가된 키 프레임

## 개요

LTXV 추가된 키 프레임 노드는 비디오 레이턴에 키 프레임을 추가합니다. 각 키 프레임은 단일 픽셀 프레임을 범위로 한 토큰 레이턴 프레임을 나타내며, 비디오와 함께 데노이즈되지만 디코딩된 출력의 일부는 아닙니다. 배치는 `interval_frames` 매개변수에 의해 결정되며, 이 매개변수는 자동 배치를 위한 픽셀 프레임 스타일을 지정합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `positive` | 키 프레임이 부착된 긍정적인 조건부. | CONDITIONING | 예 | N/A |
| `negative` | 키 프레임이 부착된 부정적인 조건부. | CONDITIONING | 예 | N/A |
| `vae` | 레이턴 스케일 팩터를 읽기 위해 사용됩니다. | VAE | 예 | N/A |
| `latent` | 키 프레임과 함께 생성할 5D 비디오 레이턴. Concat AV 레이턴 전에 추가합니다. | LATENT | 예 | N/A |
| `interval_frames` | 자동 배치를 위한 픽셀 프레임 스타일. 기본 값 24는 24 fps에서 한 키 프레임 당 초로 설정됩니다. 점유된 픽셀은 건너뜁니다. `frame_indices`가 설정되었을 때 무시됩니다. | INT | 아님 | 1-1024 |
| `keyframes` | 새 키 프레임을 초기화하기 위해 사용할 선택 사항 내용. 이전 Separate (같은 공간 크기)에서 키 프레임을 연결하거나, 평범한 비디오 레이턴을 연결하여 각 새 슬롯에서 가장 가까운 프레임을 복사합니다 (예: 시간 확대 후). 이들은 여전히 데노이즈되지만 가이드로 고정되지 않습니다. 키 프레임 레이턴에 기록된 인덱스는 `frame_indices`가 설정되지 않았을 때 무시됩니다. 샘플링이 sigma 1 이하로 시작할 때만 효과가 있습니다. | LATENT | 아님 | N/A |
| `frame_indices` | 선택 사항 픽셀 프레임 인덱스. 현재 캔버스에서 `interval_frames`에 의해 배치할 때 빈 값으로 두세요. 설정되었을 때, 이 목록은 배치입니다 (연결된 키 프레임은 순서대로 일치됩니다). 마지막 프레임은 허용됩니다; 프레임 0은 아닙니다 (그것은 독립된 토큰입니다). | STRING | 아님 | N/A |

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `positive` | 생성된 키 프레임 주의를 부착한 긍정적인 조건부. | CONDITIONING |
| `negative` | 생성된 키 프레임 주의를 부착한 부정적인 조건부. | CONDITIONING |
| `latent` | 생성된 키 프레임이 추가된 T에 비디오 레이턴. | LATENT |

## 주의사항

- `interval_frames` 매개변수는 비디오에서 키 프레임의 간격을 결정합니다. 높은 값은 키 프레임이 적고 프레임 레이트가 낮아집니다.
- `keyframes` 입력은 기존 키 프레임이나 비디오 레이턴으로 새 키 프레임을 초기화할 수 있도록 합니다. 제공되면, 이 키 프레임은 데노이즈되고 비디오 레이턴에 추가됩니다.
- `frame_indices` 매개변수는 키 프레임이 배치되는 정확한 픽셀 프레임 인덱스를 지정할 수 있습니다. 제공되면, `interval_frames` 매개변수는 무시됩니다.
- `positive`과 `negative` 출력은 생성된 키 프레임 주의를 부착한 조건부를 포함하며, 이는 추가 처리나 분석에 사용할 수 있습니다.
- `latent` 출력은 생성된 키 프레임이 추가된 비디오 레이턴을 포함하며, 추가 처리나 분석에 사용할 수 있습니다.
```
