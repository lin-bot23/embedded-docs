# LTXVAddGeneratedKeyframes

## 概要

LTXV Add Generated Keyframes ノードは、ビデオのラテンシティに詳細なキーフレームを追加します。各キーフレームは、単一のピクセルフレームを跨ぐトークンのラテンシティフレームを表し、ビデオとともにデノイズされますが、デコードされた出力の一部ではありません。配置は interval_frames パラメータによって決定され、自動配置のためのピクセルフレームのストライドを指定します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|------------|------|----------|------|-------|
| `positive` | キーフレームに付加されるポジティブな条件付け | CONDITIONING | はい | N/A |
| `negative` | キーフレームに付加されるネガティブな条件付け | CONDITIONING | はい | N/A |
| `vae` | ラテンシティスケールファクターを読み取るためにのみ使用 | VAE | はい | N/A |
| `latent` | キーフレームとともに生成するために使用される、プラインな5Dビデオラテンシティ | LATENT | はい | N/A |
| `interval_frames` | 自动配置のためのピクセルフレームのストライド | INT | いいえ | 1-1024 |
| `keyframes` | 新しいキーフレームに初期化するためにオプションのコンテンツ | LATENT | いいえ | N/A |
| `frame_indices` | オプションのピクセルフレームインデックス | STRING | いいえ | N/A |

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `positive` | 生成されたキーフレームのアテンションが付加されたポジティブな条件付け | CONDITIONING |
| `negative` | 生成されたキーフレームのアテンションが付加されたネガティブな条件付け | CONDITIONING |
| `latent` | 生成されたキーフレームが T に追加されたビデオラテンシティ | LATENT |

## 注意事項

- `interval_frames` パラメータは、ビデオ内のキーフレームのスペーシングを決定します。高い値はキーフレームが少なくなり、フレームレートが低くなります。
- `keyframes` 入力は、既存のキーフレームやビデオラテンシティで新しいキーフレームを初期化するために使用できます。提供された場合、これらのキーフレームはデノイズされ、ビデオラテンシティに追加されます。
- `frame_indices` パラメータは、キーフレームが配置される正確なピクセルフレームインデックスを指定するために使用できます。提供された場合、`interval_frames` パラメータは無視されます。
- `positive` と `negative` 出力は、生成されたキーフレームのアテンションが付加された条件付けを含み、さらなる処理や分析に使用できます。
- `latent` 出力は、生成されたキーフレームが T に追加されたビデオラテンシティを含み、さらなる処理や分析に使用できます。
