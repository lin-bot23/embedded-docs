# Предпросмотр любого

PreviewAny преобразует любое входное значение в читаемый текст, чтобы вы могли его просмотреть. Строки передаются без изменений, числа и логические значения преобразуются в обычный текст, а остальные типы данных сериализуются в JSON, когда это возможно (в случае неудачи сериализации используется их обычное строковое представление). Итоговый текст отображается в пользовательском интерфейсе, а также возвращается как строковый вывод для дальнейшей обработки.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `source` | Принимает любой тип входных данных для отображения в предпросмотре. Если значение не задано, в предпросмотре отображается 'None'. | ANY | Да | Любой тип данных |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `result` | Входное значение, преобразованное в текстовый формат. Этот же текст также отображается в пользовательском интерфейсе. | STRING |
