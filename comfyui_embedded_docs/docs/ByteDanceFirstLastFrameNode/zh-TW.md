## 記錄

- `model` 參數決定了影片生成過程的功能和限制。
- `prompt` 必須具有創意和清晰性，因為它將引導影片的生成。
- `first_frame` 和 `last_frame` 圖片應該代表期望的影片內容。
- `resolution` 和 `aspect_ratio` 參數將影響最終輸出影片的質量和尺寸。
- `duration` 參數設定了影片的長度，最小為 3 秒，最大為 12 秒。
- `seed` 參數為選擇性，可用於確保影片生成過程的可重複性。
