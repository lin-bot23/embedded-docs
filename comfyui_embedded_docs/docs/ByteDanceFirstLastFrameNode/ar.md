# تحويل الإطار الأول-الأخير من ByteDance إلى فيديو

يولّد هذا العقدة فيديو باستخدام موجه نصي مع صورتي الإطار الأول والأخير. تأخذ وصفك والإطارين الرئيسيين لإنشاء تسلسل فيديو كامل ينتقل بينهما. توفر العقدة خيارات متنوعة للتحكم في دقة الفيديو ونسبة الأبعاد والمدة وغيرها من معاملات التوليد.

## المدخلات

| المعامل | الوصف | نوع البيانات | إلزامي | النطاق |
| --- | --- | --- | --- | --- |
| `النموذج` | النموذج المستخدم لتوليد الفيديو (الافتراضي: `"seedance-1-5-pro-251215"`). | COMBO | نعم | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `المطالبة النصية` | الموجّه النصي المستخدم لتوليد الفيديو. يجب ألا يكون فارغًا. | STRING | نعم | - |
| `الإطار_الأول` | الإطار الأول المستخدم في الفيديو. يجب أن تتراوح أبعاده بين 300x300 و6000x6000 بكسل، مع نسبة أبعاد بين 0.4 و2.5. | IMAGE | نعم | - |
| `الإطار_الأخير` | الإطار الأخير المستخدم في الفيديو. يجب أن تتراوح أبعاده بين 300x300 و6000x6000 بكسل، مع نسبة أبعاد بين 0.4 و2.5. | IMAGE | نعم | - |
| `الدقة` | دقة الفيديو الناتج. | COMBO | نعم | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبة_الجانب` | نسبة الأبعاد للفيديو الناتج. | COMBO | نعم | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `المدة` | مدة الفيديو الناتج بالثواني. عند استخدام `seedance-1-5-pro-251215`، تكون المدة الدنيا 4 ثوانٍ. (الافتراضي: 5) | INT | نعم | 3 - 12 |
| `البذرة` | البذرة المستخدمة في التوليد. (الافتراضي: 0) | INT | لا | 0 - 2147483647 |
| `الكاميرا_ثابتة` | يحدد ما إذا كان سيتم تثبيت الكاميرا. تضيف المنصة تعليمة لتثبيت الكاميرا إلى الموجّه الخاص بك، ولكنها لا تضمن التأثير الفعلي. (الافتراضي: False) | BOOLEAN | لا | - |
| `علامة_مائية` | ما إذا كان سيتم إضافة علامة مائية "منشأ بالذكاء الاصطناعي" إلى الفيديو. (الافتراضي: False) | BOOLEAN | لا | - |
| `توليد الصوت` | يتم تجاهل هذا المعامل لأي نموذج باستثناء `seedance-1-5-pro-251215`. (الافتراضي: False) | BOOLEAN | لا | - |

**ملاحظة:** بالنسبة لنموذج `seedance-1-5-pro-251215`، يجب أن تكون مدة `duration` 4 ثوانٍ أو أكثر. يجب أن تكون كل من `first_frame` و`last_frame` بين 300x300 و6000x6000 بكسل وأن تكون نسبة الأبعاد بين 0.4 و2.5.
