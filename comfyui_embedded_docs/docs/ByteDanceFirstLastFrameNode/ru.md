# ByteDance - Преобразование первого-последнего кадра в видео

Этот узел генерирует видео на основе текстового запроса и изображений первого и последнего кадров. Он принимает ваше описание и два ключевых кадра для создания полной видеопоследовательности с переходом между ними. Узел предоставляет различные опции для управления разрешением видео, соотношением сторон, длительностью и другими параметрами генерации.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `модель` | Модель, используемая для генерации видео (по умолчанию: `"seedance-1-5-pro-251215"`). | COMBO | Да | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `промпт` | Текстовый запрос, используемый для генерации видео. Не должен быть пустым. | STRING | Да | - |
| `first_frame` | Первый кадр, используемый для видео. Должен иметь размер от 300x300 до 6000x6000 пикселей и соотношение сторон от 0.4 до 2.5. | IMAGE | Да | - |
| `last_frame` | Последний кадр, используемый для видео. Должен иметь размер от 300x300 до 6000x6000 пикселей и соотношение сторон от 0.4 до 2.5. | IMAGE | Да | - |
| `resolution` | Разрешение выходного видео. | COMBO | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. | COMBO | Да | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | Длительность выходного видео в секундах. При использовании `seedance-1-5-pro-251215` минимальная длительность составляет 4 секунды. (по умолчанию: 5) | INT | Да | 3 - 12 |
| `seed` | Сид для генерации. (по умолчанию: 0) | INT | Нет | 0 - 2147483647 |
| `camera_fixed` | Указывает, нужно ли фиксировать камеру. Платформа добавляет инструкцию зафиксировать камеру к вашему запросу, но не гарантирует фактический эффект. (по умолчанию: False) | BOOLEAN | Нет | - |
| `watermark` | Определяет, нужно ли добавлять водяной знак «AI generated» на видео. (по умолчанию: False) | BOOLEAN | Нет | - |
| `generate_audio` | Этот параметр игнорируется для всех моделей, кроме `seedance-1-5-pro-251215`. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Для модели `seedance-1-5-pro-251215` параметр `duration` должен быть не менее 4 секунд. Как `first_frame`, так и `last_frame` должны иметь размер от 300x300 до 6000x6000 пикселей и соотношение сторон от 0.4 до 2.5.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл. | VIDEO |
