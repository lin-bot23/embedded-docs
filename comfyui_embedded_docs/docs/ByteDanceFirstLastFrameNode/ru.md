# ByteDance First-Last-Frame to Video

Этот узел генерирует видео с использованием текстового запроса и первых и последних кадров изображения. Он создает плавный переход между двумя кадрами, что в результате создает целую последовательность видео. Узел предлагает множество опций для настройки разрешения видео, соотношения сторон, продолжительности и дополнительных параметров генерации.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `модель` | Модель, которую использовать для генерации видео. Выберите из доступных вариантов (по умолчанию: `"seedance-1-5-pro-251215"`). | КОМБО | Да | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `промпт` | Текстовый запрос, используемый для генерации видео. Этот запрос не должен содержать специфических параметров, таких как разрешение, соотношение сторон, продолжительность, seed, camerafixed или watermark. | STRING | Да | - |
| `first_frame` | Первый кадр, который будет использоваться для видео. Изображение должно быть между 300x300 и 6000x6000 пикселей и иметь соотношение сторон между 0.4 и 2.5. | IMAGE | Да | - |
| `last_frame` | Последний кадр, который будет использоваться для видео. Изображение должно быть между 300x300 и 6000x6000 пикселей и иметь соотношение сторон между 0.4 и 2.5. | IMAGE | Да | - |
| `resolution` | Разрешение выходного видео. Выберите из доступных вариантов (по умолчанию: `"480p"`). | КОМБО | Да | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `aspect_ratio` | Соотношение сторон выходного видео. Выберите из доступных вариантов (по умолчанию: `"adaptive"`). | КОМБО | Да | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `duration` | Продолжительность выходного видео в секундах (по умолчанию: 5). Для модели `seedance-1-5-pro-251215` минимальная поддерживаемая продолжительность составляет 4 секунды. | INT | Да | 3 - 12 |
| `seed` | Seed, который использовать для генерации (по умолчанию: 0). Этот параметр опционален. | INT | Нет | 0 - 2147483647 |
| `camera_fixed` | Определяет, следует ли фиксировать камеру в видео. Платформа добавляет инструкцию для фиксации камеры к вашему запросу, но фактический эффект не гарантируется (по умолчанию: False). | BOOLEAN | Нет | - |
| `watermark` | Определяет, следует ли добавлять водяной знак "AI generated" к видео (по умолчанию: False). | BOOLEAN | Нет | - |
| `generate_audio` | Этот параметр игнорируется для всех моделей, кроме `seedance-1-5-pro-251215` (по умолчанию: False). | BOOLEAN | Нет | - |

## Выходы

| Название выходного параметра | Описание | Тип данных |
|-------------|-------------|-----------|
| `output` | Генерируемый файл видео. | VIDEO |

## Примечания

- Параметр `model` определяет возможности и ограничения процесса генерации видео.
- Запрос `prompt` должен быть креативным и ясным, так как он будет направлять процесс генерации видео.
- Изображения `first_frame` и `last_frame` должны быть代表性 для желаемого контента видео.
- Параметры `resolution` и `aspect_ratio` будут влиять на качество и размеры конечного выходного видео.
- Параметр `duration` устанавливает продолжительность видео, с минимальным значением 3 секунды и максимальным значением 12 секунд.
- Параметр `seed` опционален и может быть использован для повторяемости процесса генерации видео.
- Параметр `camera_fixed` является продвинутым параметром и может не всегда давать ожидаемый эффект.
- Параметр `watermark` может быть использован для добавления водяного знака к видео, указывающего, что оно было сгенерировано AI.
- Параметр `generate_audio` в настоящее время игнорируется для всех моделей, кроме `seedance-1-5-pro-251215`.
