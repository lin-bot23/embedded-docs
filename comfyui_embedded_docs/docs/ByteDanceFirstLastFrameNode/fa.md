# تبدیل اولین و آخرین فریم به ویدیو

این گره ویدیویی‌ای تولید می‌کند که از یک پیام متنی و اولین و آخرین فریم یک تصویر استفاده می‌کند. این گره انتقال بدون شکاف بین دو فریم را ایجاد می‌کند و در نتیجه یک توالی کامل از ویدیو را تولید می‌کند. این گره مجموعه‌ای از گزینه‌ها را برای شخصی‌سازی رزولوشن، نسبت ابعاد، مدت زمان و پارامترهای اضافی تولید ارائه می‌دهد.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مدل` | مدل استفاده‌شده برای تولید ویدیو. از گزینه‌های موجود انتخاب کنید (پیش‌فرض: `"seedance-1-5-pro-251215"`). | COMBO | بله | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `پرامپت` | پیام متنی استفاده‌شده برای تولید ویدیو. این پیام نباید شامل پارامترهای خاصی مانند رزولوشن، نسبت ابعاد، مدت زمان، seed، camerafixed یا watermark باشد. | STRING | بله | - |
| `اولین فریم` | فریم اول استفاده‌شده برای ویدیو. تصویر باید بین 300x300 و 6000x6000 پیکسل باشد و نسبت ابعاد بین 0.4 و 2.5 داشته باشد. | IMAGE | بله | - |

| `واترمارک` | مشخص می‌کند که آیا باید علامت آبی "AI generated" به ویدیو اضافه شود یا خیر (پیش‌فرض: False). | BOOLEAN | خیر | - |

## یادداشت‌ها

- پارامتر `model` قابلیت‌ها و محدودیت‌های فرآیند تولید ویدیو را تعیین می‌کند.
- پیام `prompt` باید خلاقانه و واضح باشد، زیرا آن به تولید ویدیو راهنمایی می‌کند.
- تصاویر `first_frame` و `last_frame` باید نمونه‌ای از محتوای مورد انتظار ویدیو باشند.
- پارامترهای `resolution` و `aspect_ratio` بر کیفیت و ابعاد نهایی ویدیوی خروجی تأثیر می‌گذارند.
- پارامتر `duration` مدت زمان ویدیو را تنظیم می‌کند، با حداقل 3 ثانیه و حداکثر 12 ثانیه.
- پارامتر `seed` اختیاری است و می‌تواند برای تکرارپذیری فرآیند تولید ویدیو استفاده شود.
- پارامتر `camera_fixed` یک گزینه پیشرفته است که ممکن است همیشه تأثیر مورد انتظار را داشته باشد.
- پارامتر `watermark` می‌تواند برای اضافه کردن علامت آبی "AI generated" به ویدیو استفاده شود، نشان‌دهنده اینکه ویدیو توسط یک AI تولید شده است.
- پارامتر `generate_audio` در حال حاضر برای تمام مدل‌ها به جز `seedance-1-5-pro-251215` نادیده گرفته می‌شود.
