# تبدیل اولین و آخرین فریم به ویدیو ByteDance

این گره ویدیویی را با استفاده از یک پرامپت متنی همراه با تصاویر فریم اول و آخر تولید می‌کند. توضیح شما و دو فریم کلیدی را می‌گیرد تا یک توالی ویدیویی کامل ایجاد کند که بین آن‌ها انتقال برقرار می‌شود. این گره گزینه‌های متنوعی برای کنترل رزولوشن، نسبت تصویر، مدت‌زمان و سایر پارامترهای تولید ویدیو فراهم می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `مدل` | مدلی که برای تولید ویدیو استفاده می‌شود (پیش‌فرض: `"seedance-1-5-pro-251215"`). | COMBO | بله | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `پرامپت` | پرامپت متنی مورد استفاده برای تولید ویدیو. نباید خالی باشد. | STRING | بله | - |
| `اولین فریم` | فریم اولی که برای ویدیو استفاده می‌شود. باید بین 300x300 و 6000x6000 پیکسل باشد و نسبت تصویر آن بین 0.4 و 2.5 قرار گیرد. | IMAGE | بله | - |
| `آخرین فریم` | فریم آخری که برای ویدیو استفاده می‌شود. باید بین 300x300 و 6000x6000 پیکسل باشد و نسبت تصویر آن بین 0.4 و 2.5 قرار گیرد. | IMAGE | بله | - |
| `وضوح تصویر` | رزولوشن ویدیوی خروجی. | COMBO | بله | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `نسبت تصویر` | نسبت تصویر ویدیوی خروجی. | COMBO | بله | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `مدت زمان` | مدت‌زمان ویدیوی خروجی بر حسب ثانیه. هنگام استفاده از `seedance-1-5-pro-251215`، حداقل مدت‌زمان 4 ثانیه است. (پیش‌فرض: 5) | INT | بله | 3 - 12 |
| `seed` | مقدار seed برای استفاده در تولید. (پیش‌فرض: 0) | INT | خیر | 0 - 2147483647 |
| `ثابت بودن دوربین` | مشخص می‌کند که آیا دوربین ثابت باشد یا نه. پلتفرم دستوری برای ثابت نگه داشتن دوربین به پرامپت شما اضافه می‌کند، اما اثر واقعی آن را تضمین نمی‌کند. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `واترمارک` | اینکه آیا واترمارک «AI generated» به ویدیو اضافه شود یا نه. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `تولید صدا` | این پارامتر برای هر مدلی به‌جز `seedance-1-5-pro-251215` نادیده گرفته می‌شود. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**توجه:** برای مدل `seedance-1-5-pro-251215`، مقدار `duration` باید 4 ثانیه یا بیشتر باشد. هر دو `first_frame` و `last_frame` باید بین 300x300 و 6000x6000 پیکسل باشند و نسبت تصویر آن‌ها بین 0.4 و 2.5 باشد.
