# ByteDance 最初-最後フレームから動画生成

このノードは、テキストプロンプトと最初と最後のフレーム画像を使用して動画を生成します。入力された説明文と2つのキーフレーム画像を基に、それらの間を遷移する動画シーケンスを生成します。また、動画の解像度、アスペクト比、長さ、その他の生成パラメータを制御するためのさまざまなオプションも提供します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `モデル` | 動画生成に使用するモデルです（デフォルト: `"seedance-1-5-pro-251215"`）。 | COMBO | はい | `"seedance-1-5-pro-251215"`<br>`"seedance-1-0-pro-250528"` |
| `プロンプト` | 動画の生成に使用するテキストプロンプトです。空にすることはできません。 | STRING | はい | - |
| `最初のフレーム` | 動画の最初のフレームとして使用する画像です。画像サイズは300x300〜6000x6000ピクセル、アスペクト比は0.4〜2.5の範囲内である必要があります。 | IMAGE | はい | - |
| `最後のフレーム` | 動画の最後のフレームとして使用する画像です。画像サイズは300x300〜6000x6000ピクセル、アスペクト比は0.4〜2.5の範囲内である必要があります。 | IMAGE | はい | - |
| `解像度` | 出力動画の解像度です。 | COMBO | はい | `"480p"`<br>`"720p"`<br>`"1080p"` |
| `アスペクト比` | 出力動画のアスペクト比です。 | COMBO | はい | `"adaptive"`<br>`"16:9"`<br>`"4:3"`<br>`"1:1"`<br>`"3:4"`<br>`"9:16"`<br>`"21:9"` |
| `再生時間` | 出力動画の長さ（秒）です。`seedance-1-5-pro-251215` を使用する場合、最短時間は4秒です。（デフォルト: 5） | INT | はい | 3 - 12 |
| `シード` | 生成に使用するシード値です（デフォルト: 0）。 | INT | いいえ | 0 - 2147483647 |
| `カメラ固定` | カメラを固定するかどうかを指定します。プラットフォームはプロンプトにカメラを固定する指示を追加しますが、実際の効果は保証されません。（デフォルト: False） | BOOLEAN | いいえ | - |
| `ウォーターマーク` | 動画に「AI generated」の透かしを追加するかどうかを指定します。（デフォルト: False） | BOOLEAN | いいえ | - |
| `generate_audio` | このパラメータは、`seedance-1-5-pro-251215` 以外のモデルでは無視されます。（デフォルト: False） | BOOLEAN | いいえ | - |

**注：** `seedance-1-5-pro-251215` モデルの場合、`duration` は4秒以上である必要があります。また、`first_frame` と `last_frame` はどちらも300x300〜6000x6000ピクセルの範囲内で、アスペクト比が0.4〜2.5の範囲内である必要があります。

| --- | --- | --- |
| `output` | 生成された動画ファイルです。 | VIDEO |
