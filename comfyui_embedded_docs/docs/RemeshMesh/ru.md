# Ремешинг сетки (узкополосный DC)

Remesh Mesh перестраивает сетку с чистой равномерной тесселяцией путем выборки узкополосного поля расстояний вокруг исходной поверхности и извлечения ее с помощью Dual Contouring. Это нормализует неупорядоченную, немногообразную или самопересекающуюся топологию и предназначено для запуска перед Decimate Mesh для достижения точного количества граней. Обработка выполняется на активном вычислительном устройстве, и выходная сетка остается сваренной.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `mesh` | Входная сетка для перестройки. | MESH | Да | — |
| `resolution` | Разрешение воксельной сетки (плотность выходной сетки). 256 ~ 100 тыс. граней, 512 ~ 1 млн. Для точного количества граней дополнительно используйте Decimate Mesh. (по умолчанию: 512) | INT | Да | 32 - 2048 |
| `sign_mode` | Режим извлечения поверхности. «udf» устойчив к неупорядоченным/немногообразным входным данным; «sdf» создает чистую единую поверхность с восстановлением острых особенностей QEF (функции квадратичной ошибки), но требует согласованной ориентации граней. Выбор режима отображает соответствующие подпараметры. (по умолчанию: «udf») | DYNAMIC_COMBO | Да | "udf"<br>"sdf" |
| `band` | Ширина узкой полосы в воксельных единицах. В режиме UDF также смещает поверхность. (дополнительно, по умолчанию: 1.0) | FLOAT | Да | 0.5 - 4.0 |
| `project_back` | Линейно интерполирует вершины к исходной поверхности (0 = чистый DC, 1 = привязка к поверхности). (дополнительно, по умолчанию: 0.0) | FLOAT | Да | 0.0 - 1.0 |
| `fix_poles` | Схлопывание пар вершин с валентностью 3 (артефакт T-образного соединения DC). (дополнительно, по умолчанию: false) | BOOLEAN | Да | true / false |
| `smooth_iters` | Итерации сглаживания Таубина (0 = выкл.). 2–3 очищают ступенчатые артефакты DC; более высокие значения чрезмерно сглаживают ребра QEF. (по умолчанию: 0) | INT | Да | 0 - 20 |
| `drop_small_components` | Отбрасывает компоненты, размер которых меньше этой доли от количества граней самого большого компонента. 0 отключает. (дополнительно, по умолчанию: 0.01) | FLOAT | Да | 0.0 - 0.5 |
| `precluster_max_verts` | Ограничивает количество вершин на входе до выполнения запросов поля; входные данные, превышающие это значение, сначала кластерно прореживаются до него. Предотвращает нехватку памяти (OOM) на больших сетках. (дополнительно, по умолчанию: 20 000 000) | INT | Да | 0 - 100,000,000 |

### Входы режима «udf»

Эти параметры появляются, когда для `sign_mode` установлено значение `"udf"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qef` | Размещение двойных вершин QEF (функции квадратичной ошибки) для более острых ребер. (по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_inverted_components` | Отбрасывает замкнутые компоненты с внутренней нормалью (отрицательный объем) — внутренняя оболочка UDF. (по умолчанию: false) | BOOLEAN | Нет | true / false |
| `drop_enclosed_components` | Отбрасывает компоненты внутри bbox самого большого компонента, которые не проходят лучевую проверку попадания в сетку. Отключите для допустимых вложенных частей. (по умолчанию: false) | BOOLEAN | Нет | true / false |

### Входы режима «sdf»

Эти параметры появляются, когда для `sign_mode` установлено значение `"sdf"`.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `qef` | Размещение двойных вершин QEF (функции квадратичной ошибки) (восстанавливает острые особенности) вместо центроида пересечения ребра. (по умолчанию: true) | BOOLEAN | Нет | true / false |
| `manifold` | Метод Manifold Dual Contouring: 1–4 двойных вершин на воксель для случаев с несколькими листами. Медленнее. (по умолчанию: false) | BOOLEAN | Нет | true / false |

Примечание. Параметр `qef` имеет разные значения по умолчанию в зависимости от выбранного режима — false в режиме «udf», true в режиме «sdf». Когда `precluster_max_verts` больше 0 и входная сетка содержит больше вершин, чем это значение, сетка кластерно прореживается до этого целевого значения перед запросами поля. После обработки узел отображает изменение количества граней от входа к выходу (например, "faces: 1.23M → 200K (-84%)").

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `mesh` | Перестроенная сетка с равномерной тесселяцией и сваренной топологией. Вершинные цвета сохраняются, если они присутствуют на входе; UV, нормали и касательные не переносятся. | MESH |
