# مش‌بندی مجدد مش (DC باند باریک)

گره Remesh Mesh یک مش را با یک شبکه‌بندی تمیز و یکنواخت بازسازی می‌کند؛ این کار با نمونه‌برداری از یک میدان فاصله باند باریک در اطراف سطح اصلی و استخراج آن با الگوریتم Dual Contouring انجام می‌شود. این عمل توپولوژی‌های نامرتب، non-manifold یا خود-متقاطع را نرمال‌سازی می‌کند و برای اجرا قبل از گره Decimate Mesh طراحی شده است تا به تعداد وجه دقیق برسید. پردازش روی دستگاه محاسباتی فعال انجام می‌شود و مش خروجی به صورت جوش‌خورده باقی می‌ماند.

## ورودی‌ها

### ورودی‌های مشترک

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مش` | مش ورودی برای بازسازی مش. | MESH | بله | — |
| `تفکیک‌پذیری` | وضوح شبکه وکسل (تراکم خروجی). ۲۵۶ ~ ۱۰۰ هزار وجه، ۵۱۲ ~ ۱ میلیون. برای تعداد وجه دقیق، پس از آن از Decimate Mesh استفاده کنید. (پیش‌فرض: ۵۱۲) | INT | بله | 32 - 2048 |
| `sign_mode` | حالت استخراج سطح. "udf" برای ورودی‌های نامرتب/non-manifold مقاوم است؛ "sdf" یک سطح tunggal تمیز با بازیابی ویژگی‌های تیز QEF (تابع خطای درجه دوم) تولید می‌کند، اما به جهت‌دهی سازگار نیاز دارد. انتخاب یک حالت، زیر-گزینه‌های خاص آن را آشکار می‌کند. (پیش‌فرض: "udf") | DYNAMIC_COMBO | بله | "udf"<br>"sdf" |
| `باند` | عرض باند باریک بر حسب واحد وکسل. در حالت UDF سطح را نیز جابه‌جا می‌کند. (پیشرفته، پیش‌فرض: ۱.۰) | FLOAT | بله | 0.5 - 4.0 |
| `project_back` | درون‌یابی خطی رأس‌ها به سمت سطح اصلی (۰ = DC خالص، ۱ = منطبق شده). (پیشرفته، پیش‌فرض: ۰.۰) | FLOAT | بله | 0.0 - 1.0 |
| `fix_poles` | فروپاشی جفت رأس‌های با درجه ۳ (ناهنجاری اتصال T در DC). (پیشرفته، پیش‌فرض: false) | BOOLEAN | بله | true / false |
| `smooth_iters` | تکرارهای هموارسازی Taubin (۰ = خاموش). ۲-۳ ناهنجاری‌های پله‌ای DC را پاک می‌کند؛ مقادیر بالاتر لبه‌های QEF را بیش‌ازحد هموار می‌کند. (پیش‌فرض: ۰) | INT | بله | 0 - 20 |
| `drop_small_components` | حذف مؤلفه‌های زیر این کسر از تعداد وجه بزرگ‌ترین مؤلفه. ۰ غیرفعال می‌کند. (پیشرفته، پیش‌فرض: ۰.۰۱) | FLOAT | بله | 0.0 - 0.5 |
| `precluster_max_verts` | محدود کردن تعداد رأس ورودی قبل از پرس‌وجوهای میدان؛ ورودی‌های بالاتر از این مقدار ابتدا به آن خوشه‌بندی و کاهش می‌یابند. از OOM روی مش‌های بزرگ جلوگیری می‌کند. (پیشرفته، پیش‌فرض: 20,000,000) | INT | بله | 0 - 100,000,000 |

### ورودی‌های حالت "udf"

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی `"udf"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | قرارگیری رأس دوگانه QEF (تابع خطای درجه دوم) برای لبه‌های تیزتر. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_inverted_components` | حذف مؤلفه‌های بسته با نرمال inward (حجم منفی) — پوسته داخلی UDF. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |
| `drop_enclosed_components` | حذف مؤلفه‌های داخل کادر محدودکننده (bbox) بزرگ‌ترین مؤلفه که در پرتو‌افکنی نقطه-در-مش شکست می‌خورند. برای قطعات تو در تو معتبر غیرفعال کنید. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |

### ورودی‌های حالت "sdf"

این پارامترها زمانی ظاهر می‌شوند که `sign_mode` روی `"sdf"` تنظیم شده باشد.

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `qef` | قرارگیری رأس دوگانه QEF (تابع خطای درجه دوم) (بازیابی ویژگی‌های تیز) در مقابل مرکز ثقل تقاطع لبه. (پیش‌فرض: true) | BOOLEAN | خیر | true / false |
| `manifold` | Dual Contouring منیفولد: ۱-۴ رأس دوگانه/وکسل برای موارد چند-ورقه‌ای. کندتر. (پیش‌فرض: false) | BOOLEAN | خیر | true / false |

نکته: گزینه `qef` بسته به حالت انتخاب‌شده پیش‌فرض متفاوتی دارد — در حالت "udf" false، در حالت "sdf" true. وقتی `precluster_max_verts` بزرگ‌تر از ۰ باشد و مش ورودی رأس‌های بیشتری از این مقدار داشته باشد، مش قبل از پرس‌وجوهای میدان به آن هدف کاهش خوشه‌ای می‌یابد. پس از پردازش، گره تغییر تعداد وجه از ورودی به خروجی را روی گره نمایش می‌دهد (مثلاً، "faces: 1.23M → 200K (-84%)").
