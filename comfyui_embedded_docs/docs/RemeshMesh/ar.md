# إعادة تشكيل الشبكة (DC للنطاق الضيق)

`Remesh Mesh` يعيد بناء شبكةٍ بتقسيم نظيف وموحّد عبر أخذ عينات من حقل مسافة ضيّق النطاق حول السطح الأصلي واستخراجه بتقنية Dual Contouring. يعمل ذلك على تطبيع الطوبولوجيا المعقّدة أو غير المانيفولد (non-manifold) أو ذاتية التقاطع، وهو مصمَّم ليُشغَّل قبل عقدة Decimate Mesh للوصول إلى عدد وجوه دقيق. تتم المعالجة على جهاز الحوسبة النشط، وتبقى الشبكة الناتجة ملحومة.

## المدخلات

### المدخلات العامة

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `mesh` | الشبكة المُدخلة لإعادة بنائها. | MESH | نعم | — |
| `resolution` | دقة شبكة الفوكسل (كثافة الناتج). 256 تعطي ~100 ألف وجه، و512 تعطي ~1 مليون وجه. للحصول على عدد وجوه دقيق، اتبع ذلك باستخدام عقدة Decimate Mesh. (الافتراضي: 512) | INT | نعم | 32 - 2048 |
| `sign_mode` | وضع استخراج السطح. الوضع `"udf"` قوي على المدخلات المعقّدة/غير المانيفولد؛ وينتج الوضع `"sdf"` سطحًا واحدًا نظيفًا مع استرداد الميزات الحادة بواسطة QEF (دالة الخطأ التربيعي)، لكنه يتطلب اتجاه لفٍّ متسقًا. اختيار أحد الوضعين يُظهر خياراته الفرعية المحددة. (الافتراضي: `"udf"`) | DYNAMIC_COMBO | نعم | `"udf"`<br>`"sdf"` |
| `band` | عرض النطاق الضيّق بوحدات الفوكسل. في وضع UDF يعمل أيضًا على إزاحة السطح. (متقدم، الافتراضي: 1.0) | FLOAT | نعم | 0.5 - 4.0 |
| `project_back` | استيفاء خطي للقمم باتجاه السطح الأصلي (0 = DC خالص، 1 = منطبقة على السطح). (متقدم، الافتراضي: 0.0) | FLOAT | نعم | 0.0 - 1.0 |
| `fix_poles` | طيّ أزواج القمم ذات الرتبة 3 (أثر DC لالتقاء T). (متقدم، الافتراضي: false) | BOOLEAN | نعم | true / false |
| `smooth_iters` | تكرارات تنعيم Taubin (0 = معطّل). 2-3 تزيل الآثار الشبيهة بالسلالم الناتجة عن DC؛ والقيم الأعلى تُفرط في تنعيم حواف QEF. (الافتراضي: 0) | INT | نعم | 0 - 20 |
| `drop_small_components` | إسقاط المكوّنات التي تقل عن هذا الكسر من عدد وجوه أكبر مكوّن. القيمة 0 تعطيل. (متقدم، الافتراضي: 0.01) | FLOAT | نعم | 0.0 - 0.5 |
| `precluster_max_verts` | تحديد أقصى عدد للقمم المُدخلة قبل استعلامات المجال؛ المدخلات التي تتجاوز هذا الحد تُختزل إلى ذلك الهدف أولاً عبر الاختصال العنقودي (cluster-decimation). يمنع نفاد الذاكرة (OOM) على الشبكات الضخمة. (متقدم، الافتراضي: 20,000,000) | INT | نعم | 0 - 100,000,000 |

### مدخلات وضع `"udf"`

تظهر هذه المعاملات عندما يتم تعيين `sign_mode` إلى `"udf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | وضع القمم المزدوجة بتقنية QEF (دالة الخطأ التربيعي) للحصول على حواف أكثر حدة. (الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_inverted_components` | إسقاط المكوّنات المغلقة ذات الاتجاه الطبيعي الداخلي (حجم سالب) — أي الغلاف الداخلي لـ UDF. (الافتراضي: false) | BOOLEAN | لا | true / false |
| `drop_enclosed_components` | إسقاط المكوّنات الواقعة داخل الصندوق المحيط (bbox) لأكبر مكوّن والتي تفشل في اختبار الشعاع لتحديد نقطة داخل الشبكة (point-in-mesh). عطّل هذا الخيار بالنسبة للأجزاء المتداخلة الشرعية. (الافتراضي: false) | BOOLEAN | لا | true / false |

### مدخلات وضع `"sdf"`

تظهر هذه المعاملات عندما يتم تعيين `sign_mode` إلى `"sdf"`.

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `qef` | وضع القمم المزدوجة عبر QEF (دالة الخطأ التربيعي) (يستعيد الميزات الحادة) بدلاً من النقطة المركزية لعبور الحافة. (الافتراضي: true) | BOOLEAN | لا | true / false |
| `manifold` | استخلاف ثنائي مانيفولد (Manifold Dual Contouring): من 1 إلى 4 قمم مزدوجة لكل فوكسل في الحالات متعددة الأسطح. أبطأ. (الافتراضي: false) | BOOLEAN | لا | true / false |

ملاحظة: لخيار `qef` قيمة افتراضية مختلفة حسب الوضع المحدد—false في وضع `"udf"` وtrue في وضع `"sdf"`. عندما يكون `precluster_max_verts` أكبر من 0 وكانت الشبكة المُدخلة تحتوي على قمم أكثر من هذه القيمة، تُختزل الشبكة عنقوديًا إلى ذلك الهدف قبل استعلامات المجال. بعد المعالجة، تعرض العقدة مقدار التغيّر في عدد الوجوه من الإدخال إلى الإخراج على العقدة نفسها (على سبيل المثال: "faces: 1.23M → 200K (-84%)").
