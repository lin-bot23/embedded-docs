# LTXVGeneratedKeyframesToGuides

```markdown
# Преобразование Генерируемых Кейфреймов в Руководства

## Обзор

Нод LTXV Generated Keyframes to Guides привязывает генерируемые кейфреймы с более раннего этапа в виде замороженных изображений-руководств на более позднем канвасе. Он декодирует кейфреймы как отдельные кадры, изменяет их размер по мере необходимости и записывает их с шумовой маской 0, чтобы предотвратить дальнейшее降噪. Записанные индексы масштабируются с канваса, на котором они были созданы, до целевого канваса, и вы можете переопределить индексы кадров, чтобы явно установить позиции.

## Входы

| Параметр                 | Описание                                                                 | Тип данных | Обязателен | Диапазон |
|---------------------------|-----------------------------------------------------------------------------|-----------|----------|-------|
| `positive`                | Положительное условие с привязанными кейфреймами в виде изображений-руководств. | CONDITIONING | Да      |       |
| `negative`                | Отрицательное условие с привязанными кейфреймами в виде изображений-руководств. | CONDITIONING | Да      |       |
| `vae`                     | Модель VAE, которую нужно использовать для декодирования кейфреймов.         | MODEL      | Да      |       |
| `latent`                  | Целевое видео latent, к которому добавляются руководства, например, временно увеличенное. | LATENT     | Да      |       |
| `keyframes`               | Вывод кейфреймов LTXV Separate Generated Keyframes, который содержит индекс кадра пикселя, в котором был создан каждый кейфрейм. | LATENT     | Да      |       |
| `strength`                | Сила руководства. 1.0 создает жесткую привязку; значения ниже ослабляют ее. | FLOAT      | Да      | 0.0 - 10.0 |
| `override_frame_indices` | Опционально — привязать на эти пиксельные кадры вместо записанных (или масштабированных) позиций. Предоставьте один индекс на каждый кейфрейм. Оставьте пустым, чтобы повторно использовать записанные позиции или масштабировать их, если целевой канвас имеет другое количество кадров (например, после временного увеличения в 2 раза). | STRING    | Нет       |       |

## Выводы

| Название вывода | Описание                                                                 | Тип данных |
|-------------|-----------------------------------------------------------------------------|-----------|
| `positive`  | Положительное условие с привязанными кейфреймами в виде изображений-руководств. | CONDITIONING |
| `negative`  | Отрицательное условие с привязанными кейфреймами в виде изображений-руководств. | CONDITIONING |
| `latent`    | Целевое видео latent с добавленными кейфреймами в виде замороженных руководств. | LATENT     |

## Примечания

- Параметр `strength` контролирует, насколько сильно кейфреймы привязываются в виде руководств. Значение 1.0 создает жесткую привязку, а значения ниже ослабляют ее.
- Параметр `override_frame_indices` позволяет указать точные пиксельные кадры, на которых должны быть привязаны кейфреймы. Если он оставлен пустым, нод будет использовать записанные позиции или масштабировать их, если необходимо.
- Нод предполагает, что latent `keyframes` содержит индекс кадра пикселя для каждого кейфрейма. Если это не так, нод вызовет ошибку `ValueError`.
- Нод поддерживает только размер пачки 1. Каждое руководство кодируется из одного изображения, поэтому оно не может отличаться между элементами пачки.
- Нод вызовет ошибку `ValueError`, если тензор `samples` в входе `latent` не является 5D-тензором или если размер пачки не равен 1.
- Нод вызовет ошибку `ValueError`, если тензор `samples` в входе `keyframes` не является 5D-тензором или если размер пачки не равен 1.
- Нод вызовет ошибку `ValueError`, если форма тензора `samples` в входе `keyframes` не соответствует форме тензора `samples` в входе `latent` после изменения размера.
- Нод вызовет ошибку `ValueError`, если параметр `strength` выходит за пределы диапазона 0.0 до 10.0.
- Нод вызовет ошибку `ValueError`, если параметр `override_frame_indices` не является списком целых чисел, разделенных запятыми, или если количество индексов не соответствует количеству кейфреймов.
- Нод вызовет ошибку `ValueError`, если какие-либо индексы в параметре `override_frame_indices` выходят за пределы диапазона 1 до количества пиксельных кадров в целевом канвасе.
- Нод вызовет ошибку `ValueError`, если максимальный индекс в параметре `override_frame_indices` превышает количество пиксельных кадров в целевом канвасе.
```
