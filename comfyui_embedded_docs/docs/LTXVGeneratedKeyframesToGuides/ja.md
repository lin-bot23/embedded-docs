# LTXVGeneratedKeyframesToGuides

## 概要

LTXV 生成キーフレームをガイドにノードは、前のステージから生成されたキーフレームを後のキャンバス上に凍結した画像ガイドとしてピン留めします。キーフレームを独立したフレームとしてデコードし、必要に応じてリサイズし、ノイズをさらに除去しないように 0 のノイズマスクで書き込みます。記録されたインデックスは、生成されたキャンバスからターゲットキャンバスにスケールされ、フレームインデックスを明示的に設定するためにオーバーライドできます。

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-------------|-----------------------------------------------------------------------------|-----------|----------|-------|
| `ポジティブ` | キーフレームを画像ガイドとしてピン留めされたポジティブコンディショニング | CONDITIONING | はい |       |
| `ネガティブ` | キーフレームを画像ガイドとしてピン留めされたネガティブコンディショニング | CONDITIONING | はい |       |
| `vae` | キーフレームをデコードするために使用する VAE モデル | MODEL | はい |       |
| `潜在` | キーフレームを追加するターゲットビデオのラテンシティ | LATENT | はい |       |

## 注意事項

- `strength` パラメータは、キーフレームがガイドとしてどれだけ強くピン留めされるかを制御します。1.0 の値はハードピンを作成し、低い値はピン留めを緩めます。
- `override_frame_indices` パラメータは、キーフレームがピン留めされる正確なピクセルフレームを指定するのに使用されます。空のままにすると、記録された位置を使用するか、必要に応じてスケールします。
- ノードは、`keyframes` ラテンシティが各キーフレームのピクセルフレームインデックスを含むと仮定します。これがそうでない場合、ノードは `ValueError` を発生させます。
- ノードはバッチサイズ 1 をサポートしています。各ガイドは 1 つの画像からエンコードされるため、バッチ要素間で異なることはできません。
- `latent` 入力の `samples` テンソルが 5D テンソルでない場合またはバッチサイズが 1 でない場合、ノードは `ValueError` を発生させます。
- `keyframes` 入力の `samples` テンソルが 5D テンソルでない場合またはバッチサイズが 1 でない場合、ノードは `ValueError` を発生させます。
- `keyframes` 入力の `samples` テンソルの `samples` テンソルの形状がリサイズ後に `latent` 入力の `samples` テンソルの形状と一致しない場合、ノードは `ValueError` を発生させます。
- `strength` パラメータが 0.0 から 10.0 の範囲外にある場合、ノードは `ValueError` を発生させます。
- `override_frame_indices` パラメータがカンマ区切りの整数リストでない場合またはインデックスの数がキーフレームの数と一致しない場合、ノードは `ValueError` を発生させます。
- `override_frame_indices` パラメータのインデックスのいずれかが 1 からターゲットキャンバスのピクセルフレームの数までの範囲外にある場合、ノードは `ValueError` を発生させます。
- `override_frame_indices` パラメータの最大インデックスがターゲットキャンバスのピクセルフレームの数を超える場合、ノードは `ValueError` を発生させます。
