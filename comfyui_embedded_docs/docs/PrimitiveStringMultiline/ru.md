# Строка (многострочная)

Узел Text (Multiline) предоставляет многострочное текстовое поле для ввода и передачи строковых значений в рамках вашего рабочего процесса. Он принимает текст, который может занимать несколько строк, и выводит то же строковое значение без изменений. Этот узел полезен, когда необходимо предоставить более длинное текстовое содержимое или форматированный многострочный текст.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `значение` | Входное текстовое значение, которое может занимать несколько строк | STRING | Да | N/A |

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | То же строковое значение, которое было подано на вход | STRING |
