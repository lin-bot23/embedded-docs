# Chaîne (multiligne)

Le nœud Text (Multiline) fournit un champ de saisie de texte multiligne pour permettre la saisie et la transmission de valeurs de chaîne dans votre flux de travail. Il accepte un texte qui peut s'étendre sur plusieurs lignes et produit la même valeur de chaîne sans modification. Ce nœud est utile lorsque vous devez fournir un contenu textuel plus long ou un texte multiligne formaté.

## Entrées

| Paramètre | Description | Type de données | Requis | Plage |
| --- | --- | --- | --- | --- |
| `value` | La valeur de texte d'entrée pouvant s'étendre sur plusieurs lignes | STRING | Oui | N/A |

## Sorties

| Nom de sortie | Description | Type de données |
| --- | --- | --- |
| `output` | La même valeur de chaîne fournie en entrée | STRING |
