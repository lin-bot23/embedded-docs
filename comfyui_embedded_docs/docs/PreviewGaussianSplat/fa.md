# پیش‌نمایش Splat

گره PreviewGaussianSplat یک فایل gaussian splat سه‌بعدی را در پنجره پیش‌نمایش نمایش می‌دهد بدون اینکه آن را در پوشه خروجی ComfyUI ذخیره کند. این گره یک فایل مدل سه‌بعدی را در فرمت‌های مختلف gaussian splat پذیرش می‌کند، یک نسخه موقت برای پیش‌نمایش ذخیره می‌کند و داده‌های مدل را برای پردازش بیشتر در گردش کار عبور می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | یک فایل سه‌بعدی gaussian splat. | FILE3D | بله | splat<br>ply<br>spz<br>ksplat |
| `model_3d_info` | اطلاعات فراداده اختیاری درباره مدل سه‌بعدی. هنگامی که متصل نباشد، گره از اطلاعات مدل موجود در `viewport_state` استفاده می‌کند. | LOAD3DMODELINFO | خیر | - |
| `viewport_state` | وضعیت فعلی viewport سه‌بعدی، شامل اطلاعات دوربین و مدل. | LOAD3D | بله | - |
| `camera_info` | اطلاعات دوربین اختیاری برای پیش‌نمایش. هنگامی که متصل نباشد، گره از اطلاعات دوربین موجود در `viewport_state` استفاده می‌کند. | LOAD3DCAMERA | خیر | - |
| `width` | عرض رندر پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |
| `height` | ارتفاع رندر پیش‌نمایش بر حسب پیکسل (پیش‌فرض: 1024). | INT | بله | 1 تا 4096 |

توجه: هنگامی که `camera_info` یا `model_3d_info` ارائه نمی‌شوند، گره به اطلاعات دوربین و مدل ذخیره‌شده در `viewport_state` مراجعه می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_3d` | فایل gaussian splat سه‌بعدی ورودی، بدون تغییر عبور داده می‌شود. | FILE3D |
| `model_3d_info` | اطلاعات فراداده درباره مدل سه‌بعدی، είτε از ورودی یا استخراج‌شده از وضعیت viewport. | LOAD3DMODELINFO |
| `camera_info` | اطلاعات دوربین برای پیش‌نمایش، είτε از ورودی یا استخراج‌شده از وضعیت viewport. | LOAD3DCAMERA |
| `width` | عرض رندر پیش‌نمایش. | INT |
| `height` | ارتفاع رندر پیش‌نمایش. | INT |
