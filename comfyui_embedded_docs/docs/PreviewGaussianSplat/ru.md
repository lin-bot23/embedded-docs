# Предпросмотр Splat

Узел PreviewGaussianSplat отображает трёхмерный файл гауссова сплата в окне предпросмотра без сохранения в выходной каталог ComfyUI. Он принимает файл 3D-модели в различных форматах гауссова сплата, сохраняет временную копию для предпросмотра и передаёт данные модели дальше для дальнейшей обработки в рабочем процессе.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_3d` | Трёхмерный файл гауссова сплата. | FILE3D | Да | splat<br>ply<br>spz<br>ksplat |
| `model_3d_info` | Необязательные метаданные о 3D-модели. Если не подключено, узел использует информацию о модели из `viewport_state`. | LOAD3DMODELINFO | Нет | - |
| `viewport_state` | Текущее состояние 3D-области просмотра, включая информацию о камере и модели. | LOAD3D | Да | - |
| `camera_info` | Необязательная информация о камере для предпросмотра. Если не подключено, узел использует информацию о камере из `viewport_state`. | LOAD3DCAMERA | Нет | - |
| `width` | Ширина рендера предпросмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |
| `height` | Высота рендера предпросмотра в пикселях (по умолчанию: 1024). | INT | Да | 1 до 4096 |

Примечание: если `camera_info` или `model_3d_info` не заданы, узел использует информацию о камере и модели, сохранённую в `viewport_state`.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Входной трёхмерный файл гауссова сплата, переданный без изменений. | FILE3D |
| `model_3d_info` | Метаданные о 3D-модели: либо из входных данных, либо полученные из состояния области просмотра. | LOAD3DMODELINFO |
| `camera_info` | Информация о камере для предпросмотра: либо из входных данных, либо полученная из состояния области просмотра. | LOAD3DCAMERA |
| `width` | Ширина рендера предпросмотра. | INT |
| `height` | Высота рендера предпросмотра. | INT |
