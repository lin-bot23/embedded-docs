# Получить размер изображения

GetImageSize считывает входное изображение и возвращает его ширину, высоту и размер пакета. Узел также отображает эти измеренные значения непосредственно в интерфейсе узла.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Входное изображение, из которого извлекаются ширина, высота и размер пакета | IMAGE | Да | - |

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `width` | Ширина входного изображения в пикселях | INT |
| `height` | Высота входного изображения в пикселях | INT |
| `batch_size` | Количество изображений, содержащихся во входном пакете | INT |
