# الحصول على حجم الصورة

GetImageSize تقرأ صورة الإدخال وتُرجع عرضها وارتفاعها وحجم الدفعة. كما تعرض العقدة هذه القيم المُقاسة مباشرةً على واجهتها.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|---------|-------|---------------|-------|--------|
| `صورة` | صورة الإدخال التي يُستخرج منها العرض والارتفاع وحجم الدفعة | IMAGE | نعم | - |

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------|--------------|
| `العرض` | عرض صورة الإدخال بالبكسل | INT |
| `الارتفاع` | ارتفاع صورة الإدخال بالبكسل | INT |
| `حجم الدفعة` | عدد الصور الموجودة في دفعة الإدخال | INT |
