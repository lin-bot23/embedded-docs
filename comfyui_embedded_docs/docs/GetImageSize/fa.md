# دریافت ابعاد تصویر

گره GetImageSize یک تصویر ورودی را خوانده و عرض، ارتفاع و اندازه دسته‌ی آن را خروجی می‌دهد. این گره همچنین مقادیر اندازه‌گیری شده را مستقیماً روی رابط کاربری گره نمایش می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image` | تصویر ورودی که عرض، ارتفاع و اندازه دسته از آن استخراج می‌شود | IMAGE | بله | - |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `width` | عرض تصویر ورودی بر حسب پیکسل | INT |
| `height` | ارتفاع تصویر ورودی بر حسب پیکسل | INT |
| `batch_size` | تعداد تصاویر موجود در دسته‌ی ورودی | INT |

> این مستند با هوش مصنوعی تهیه شده است. اگر خطایی دیدید یا پیشنهادی برای بهبود دارید، خوشحال می‌شویم مشارکت کنید! [ویرایش در GitHub](https://github.com/Comfy-Org/embedded-docs/blob/main/comfyui_embedded_docs/docs/GetImageSize/fa.md)
