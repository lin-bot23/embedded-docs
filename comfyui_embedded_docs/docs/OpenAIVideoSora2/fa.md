# OpenAI Sora - ویدیو

گره OpenAIVideoSora2 با استفاده از مدل‌های Sora شرکت OpenAI ویدیو تولید می‌کند. این گره محتوای ویدیویی را بر اساس یک متن دستور و یک تصویر مرجع ورودی اختیاری ایجاد می‌کند و سپس ویدیوی تولید شده را به عنوان خروجی ارائه می‌دهد. این گره بسته به مدل انتخابی، از مدت‌زمان‌ها و رزولوشن‌های مختلف ویدیو پشتیبانی می‌کند.

**اطلاعیه منسوخ شدن:** شرکت OpenAI سرویس‌دهی API نسخه Sora v2 را در سپتامبر 2026 متوقف خواهد کرد. این گره در آن زمان از ComfyUI حذف خواهد شد.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
| --- | --- | --- | --- | --- |
| `model` | مدل OpenAI Sora مورد استفاده برای تولید ویدیو (پیش‌فرض: "sora-2") | COMBO | بله | "sora-2"<br>"sora-2-pro" |
| `prompt` | متن راهنما؛ در صورت وجود تصویر ورودی می‌تواند خالی باشد (پیش‌فرض: خالی) | STRING | بله | - |
| `size` | رزولوشن ویدیوی تولید شده (پیش‌فرض: "1280x720") | COMBO | بله | "720x1280"<br>"1280x720"<br>"1024x1792"<br>"1792x1024" |
| `duration` | مدت‌زمان ویدیوی تولید شده به ثانیه (پیش‌فرض: 8) | COMBO | بله | 4<br>8<br>12 |
| `image` | تصویر مرجع ورودی اختیاری مورد استفاده برای تولید ویدیو (تناسب، کاراکتر، مرجع صحنه و غیره)؛ تنها یک تصویر پشتیبانی می‌شود | IMAGE | خیر | - |
| `seed` | مقدار Seed برای تعیین اینکه آیا گره باید مجدد اجرا شود؛ نتایج واقعی بدون در نظر گرفتن Seed غیرقطعی هستند (پیش‌فرض: 0) | INT | خیر | 0 تا 2147483647 |

**محدودیت‌ها و قیدها:**

- مدل "sora-2" تنها از رزولوشن‌های "720x1280" و "1280x720" پشتیبانی می‌کند؛ گزینه‌های "1024x1792" و "1792x1024" فقط با مدل "sora-2-pro" معتبر هستند
- هنگامی که یک تصویر متصل می‌شود، باید دقیقاً حاوی یک تصویر باشد؛ اتصال بیش از یک تصویر باعث خطا می‌شود
- نتایج بدون در نظر گرفتن مقدار Seed غیرقطعی هستند
