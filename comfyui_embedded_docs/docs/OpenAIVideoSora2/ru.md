# OpenAI Sora - Видео

Узел OpenAIVideoSora2 генерирует видео с использованием моделей OpenAI Sora. Он создает видеоконтент на основе текстового запроса и необязательного входного эталонного изображения, затем выдает сгенерированное видео в качестве результата. Узел поддерживает различные длительности и разрешения видео в зависимости от выбранной модели.

**Уведомление об устаревании:** OpenAI прекратит обслуживание API Sora v2 в сентябре 2026 года. Этот узел будет удален из ComfyUI к тому времени.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `model` | Модель OpenAI Sora, используемая для генерации видео (по умолчанию: "sora-2") | COMBO | Да | "sora-2"<br>"sora-2-pro" |
| `prompt` | Направляющий текст; может быть пустым, если присутствует входное изображение (по умолчанию: пусто) | STRING | Да | - |
| `size` | Разрешение генерируемого видео (по умолчанию: "1280x720") | COMBO | Да | "720x1280"<br>"1280x720"<br>"1024x1792"<br>"1792x1024" |
| `duration` | Длительность генерируемого видео в секундах (по умолчанию: 8) | COMBO | Да | 4<br>8<br>12 |
| `image` | Необязательное входное изображение-референс, используемое для генерации видео (референс для подгонки, персонажа, сцены и т. д.); поддерживается только одно изображение | IMAGE | Нет | - |
| `seed` | Сид, определяющий, должен ли узел перезапускаться; фактические результаты недетерминированы независимо от сида (по умолчанию: 0) | INT | Нет | от 0 до 2147483647 |

**Ограничения и лимиты:**

- Модель "sora-2" поддерживает только разрешения "720x1280" и "1280x720"; опции "1024x1792" и "1792x1024" допустимы только с моделью "sora-2-pro"
- При подключении изображения оно должно содержать ровно одно изображение; подключение более одного изображения вызывает ошибку
- Результаты недетерминированы независимо от значения сида

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Сгенерированный видеофайл от OpenAI Sora | VIDEO |
