# LTXVAddGuide

گره LTXVAddGuide برای افزودن راهنمایی‌های conditionning به توالی‌های latent از طریق کدگذاری تصاویر یا ویدئوهای ورودی و جایگذاری آن‌ها به عنوان فریم‌های کلیدی در داده‌های conditionning طراحی شده است. این گره ورودی‌ها را از طریق یک انکودر VAE پردازش کرده و از لاتنت‌های کدگذاری شده برای conditionning توالی‌های latent ویدئویی استفاده می‌کند. این گره امکان تعیین شماره فریم برای شروع conditionning را فراهم کرده و قدرت تأثیر conditionning را تنظیم می‌کند. این گره همچنین از ماسک‌های فضایی پیکسلی برای conditionning منطقه‌ای و پشتیبانی از پارامترهای IC-LoRA برای تنظیمات خاص guide processing برخوردار است.

## بررسی کلی

گره LTXVAddGuide تصاویر یا ویدئوهای ورودی را کدگذاری کرده و آن‌ها را از طریق یک انکودر VAE پردازش می‌کند و از لاتنت‌های کدگذاری شده برای conditionning توالی‌های latent ویدئویی استفاده می‌کند. این گره امکان تعیین شماره فریم برای شروع conditionning را فراهم کرده و قدرت تأثیر conditionning را تنظیم می‌کند. این گره همچنین از ماسک‌های فضایی پیکسلی برای conditionning منطقه‌ای و پشتیبانی از پارامترهای IC-LoRA برای تنظیمات خاص guide processing برخوردار است.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `مثبت` | ورودی conditionning مثبت که با راهنمایی فریم‌های کلیدی به‌روزرسانی می‌شود | CONDITIONING | بله | - |
| `منفی` | ورودی conditionning منفی که با راهنمایی فریم‌های کلیدی به‌روزرسانی می‌شود | CONDITIONING | بله | - |
| `vae` | مدل VAE استفاده شده برای کدگذاری فریم‌های ورودی تصویر/ویدئو | VAE | بله | - |
| `latent` | توالی latent ورودی که فریم‌های conditionning را دریافت خواهد کرد | LATENT | بله | - |
| `تصویر` | تصویر یا ویدئویی که برای conditionning توالی ویدئویی latent استفاده می‌شود. باید 8*n + 1 فریم داشته باشد. اگر ویدئو 8*n + 1 فریم ندارد، به نزدیک‌ترین 8*n + 1 فریم بریده می‌شود. | IMAGE | بله | - |
| `اندیس فریم` | شماره فریم برای شروع conditionning. برای تصاویر یا ویدئوهای تک‌فریم یا با 1-8 فریم، هر مقدار frame_idx قابل پذیرش است. برای ویدئوهای با 9+ فریم، frame_idx باید قابل تقسیم بر 8 باشد، در غیر این صورت به نزدیک‌ترین چندگانه 8 به پایین گردانده می‌شود. مقادیر منفی از پایان ویدئو شمارش می‌شوند. (پیش‌فرض: 0) | INT | بله | -9999 تا 9999 |
| `شدت` | قدرت تأثیر conditionning، جایی که 1.0 conditionning کامل و 0.0 هیچ conditionning اعمال نمی‌کند (پیش‌فرض: 1.0) | FLOAT | بله | 0.0 تا 10.0 |
| `attention_mask` | ماسک فضایی پیکسلی اختیاری. تأثیر conditionning منطقه‌ای را از طریق self-attention کنترل می‌کند، که توسط قدرت ضرب می‌شود. | MASK | خیر | - |
| `iclora_parameters` | پارامترهای اختیاری IC-LoRA از گره Get IC-LoRA Parameters. برای تنظیم guide processing به صورت مورد نیاز توسط برخی IC-LoRAs (مثلاً آن‌هایی با reference_downscale_factor > 1) استفاده می‌شود. هنگام پیوند، هر LTXVAddGuide فقط پارامترهایی را که به آن متصل شده‌اند استفاده می‌کند. | IC_LORA_PARAMETERS | خیر | - |

**نکته:** تصویر یا ویدئو ورودی باید تعداد فریم‌ها را بر اساس الگوی 8*n + 1 داشته باشد (مثلاً 1، 9، 17، 25 فریم). اگر ورودی از این الگو خارج شود، به نزدیک‌ترین تعداد فریم معتبر بریده می‌شود.

**نکته در مورد `iclora_parameters`:** هنگام استفاده از پارامترهای IC-LoRA با reference_downscale_factor بیشتر از 1، ابعاد فضایی لاتنت (عرض و ارتفاع) باید قابل تقسیم بر این فاکتور باشند. این گره خطایی را ایجاد خواهد کرد اگر این شرط برقرار نباشد.
