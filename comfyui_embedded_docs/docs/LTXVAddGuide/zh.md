# LTXVAddGuide

LTXVAddGuide 节点旨在通过编码输入图像或视频，并将它们作为关键帧纳入条件数据中，为潜在序列添加视频条件指导。它通过 VAE 编码器处理输入，并在指定帧位置战略性地放置生成的潜在，同时更新正负条件以包含关键帧信息。节点处理帧对齐约束，并允许控制条件影响的强度。

## 概述

LTXVAddGuide 节点编码输入图像或视频，通过 VAE 编码器处理它们，并使用编码的潜在来条件化潜在视频序列。它允许指定一个帧索引以开始条件化，并调整条件影响的强度。节点还支持可选的像素空间空间掩码，以实现区域化条件影响，并可以处理 IC-LoRA 参数以进行特定的引导处理调整。
