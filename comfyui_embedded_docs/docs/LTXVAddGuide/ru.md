# LTXVAddGuide

Узел LTXVAddGuide добавляет управляющее видеокондиционирование к последовательностям скрытых представлений (latent), кодируя входные изображения или видео и встраивая их в данные кондиционирования в качестве ключевых кадров. Он обрабатывает входные данные через VAE-энкодер и стратегически размещает полученные скрытые представления в указанных позициях кадров, обновляя при этом как позитивное, так и негативное кондиционирование информацией о ключевых кадрах. Узел обрабатывает ограничения выравнивания кадров и позволяет контролировать силу влияния кондиционирования.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `положительный` | Позитивное кондиционирование, которое будет изменено с помощью ключевых кадров управления | CONDITIONING | Да | - |
| `отрицательный` | Негативное кондиционирование, которое будет изменено с помощью ключевых кадров управления | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входных кадров изображения/видео | VAE | Да | - |
| `скрытое пространство` | Входная последовательность скрытых представлений, которая получит кадры кондиционирования | LATENT | Да | - |
| `изображение` | Изображение или видео, используемое для кондиционирования скрытого видео. Должно содержать кадры в количестве 8*n + 1. Если видео содержит не 8*n + 1 кадров, оно будет обрезано до ближайшего количества кадров вида 8*n + 1. | IMAGE | Да | - |
| `индекс кадра` | Индекс кадра, с которого начинается кондиционирование. Для одиночных изображений или видео с 1–8 кадрами допустимо любое значение `frame_idx`. Для видео с 9+ кадрами `frame_idx` должен делиться на 8, иначе он будет округлён вниз до ближайшего кратного 8. Отрицательные значения отсчитываются от конца видео. (по умолчанию: 0) | INT | Да | -9999 до 9999 |
| `сила` | Сила влияния кондиционирования, где 1.0 применяет полное кондиционирование, а 0.0 — не применяет кондиционирование (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 10.0 |
| `attention_mask` | Необязательная пространственная маска в пространстве пикселей. Управляет влиянием кондиционирования на отдельные области через механизм самовнимания, умножается на `strength`. | MASK | Нет | - |
| `iclora_parameters` | Необязательные параметры IC-LoRA из узла Get IC-LoRA Parameters. Используются для настройки обработки управления в соответствии с требованиями определённых IC-LoRA (например, тех, у которых `reference_downscale_factor` > 1). При последовательном соединении каждый узел LTXVAddGuide использует только подключённые к нему параметры. | IC_LORA_PARAMETERS | Нет | - |

**Примечание:** Входное изображение/видео должно иметь количество кадров, следующее шаблону 8*n + 1 (например, 1, 9, 17, 25 кадров). Если входные данные превышают этот шаблон, они будут автоматически обрезаны до ближайшего допустимого количества кадров.

**Примечание об `iclora_parameters`:** При использовании параметров IC-LoRA с `reference_downscale_factor` больше 1 пространственные размеры скрытого представления (ширина и высота) должны быть кратны этому коэффициенту. Узел выдаст ошибку, если это условие не выполнено.

**Примечание:** Закодированные кадры управления должны помещаться в последовательность скрытого представления в выбранной позиции кадра. Если обработанные кадры превышают длину последовательности скрытого представления, узел выдаёт ошибку.

**Примечание:** Добавление управления к скрытому представлению, объединяющему аудио- и видеоканалы, не поддерживается и вызовет ошибку.
