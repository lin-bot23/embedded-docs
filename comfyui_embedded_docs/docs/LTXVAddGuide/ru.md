# LTXVAddGuide

Узел LTXVAddGuide предназначен для добавления видео-условного руководства к латентным последовательностям, кодируя входные изображения или видео и инкорпорируя полученные ключевые кадры в данные условного руководства. Он обрабатывает входные данные через энкoder VAE и стратегически размещает полученные латенты в указанных позициях кадров, обновляя как положительное, так и отрицательное условное руководство с информацией о ключевых кадрах. Узел обрабатывает ограничения по выравниванию кадров и позволяет контролировать силу влияния условного руководства.

## Обзор

Узел LTXVAddGuide кодирует входные изображения или видео, обрабатывает их через энкoder VAE и использует закодированные латенты для условного руководства латентной видео-последовательности. Он позволяет указать индекс кадра для начала условного руководства и регулирует силу влияния условного руководства. Узел также поддерживает опциональные пространственные маски для каждого региона влияния условного руководства и может обрабатывать параметры IC-LoRA для специфических настроек обработки руководства.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `положительный` | Положительное условное руководство, которое будет изменено с помощью ключевых кадров | CONDITIONING | Да | - |
| `отрицательный` | Отрицательное условное руководство, которое будет изменено с помощью ключевых кадров | CONDITIONING | Да | - |
| `vae` | Модель VAE, используемая для кодирования входных кадров изображения/видео | VAE | Да | - |
| `скрытое пространство` | Входная латентная последовательность, которая получит кадры условного руководства | LATENT | Да | - |
| `изображение` | Изображение или видео, которое-conditioning latent video. Должно быть 8*n + 1 кадров. Если видео не содержит 8*n + 1 кадров, оно будет обрезано до ближайших 8*n + 1 кадров. | IMAGE | Да | - |
| `индекс кадра` | Индекс кадра для начала условного руководства. Для единичных изображений или видео с 1-8 кадрами любое значение frame_idx приемлемо. Для видео с 9+ кадрами frame_idx должно быть делителем 8, в противном случае оно будет округлено вниз до ближайшего кратного 8. Отрицательные значения считаются от конца видео. (по умолчанию: 0) | INT | Да | -9999 до 9999 |
| `сила` | Сила влияния условного руководства, где 1.0 означает полное кондиционирование, а 0.0 — его отсутствие (по умолчанию: 1.0) | FLOAT | Да | 0.0 до 10.0 |
| `attention_mask` | Опциональная пространственная маска для пиксельной области. Управляет влиянием условного руководства для каждого региона через само-внимание, умноженное на силу. | MASK | Нет | - |
| `iclora_parameters` | Опциональные параметры IC-LoRA из узла Get IC-LoRA Parameters. Используются для настройки обработки руководства по требованию некоторых IC-LoRAs (например, тех, у которых reference_downscale_factor > 1). При цепном подключении каждый узел LTXVAddGuide использует только параметры, подключенные к нему. | IC_LORA_PARAMETERS | Нет | - |

**Заметка:** Входное изображение/видео должно иметь количество кадров, соответствующее шаблону 8*n + 1 (например, 1, 9, 17, 25 кадров). Если вход превышает этот шаблон, он будет автоматически обрезан до ближайшего действительного количества кадров.

**Заметка о `iclora_parameters`:** При использовании параметров IC-LoRA с `reference_downscale_factor` больше 1, пространственные размеры латент (ширина и высота) должны быть делителями этого фактора. Узел будет выдавать ошибку, если это условие не выполняется.

## Выходы

| Название выходного параметра | Описание | Тип данных |
|-------------|-------------|-----------|
| `положительный` | Положительное условное руководство, обновленное с информацией о ключевых кадрах | CONDITIONING |
| `отрицательный` | Отрицательное условное руководство, обновленное с информацией о ключевых кадрах | CONDITIONING |
| `скрытое пространство` | Латентная последовательность с инкорпорированными кадрами условного руководства и обновленным маской шума | LATENT |
