# LTXV 가이드 추가

LTXVAddGuide 노드는 입력 이미지 또는 비디오를 인코딩하고 이를 키프레임으로 컨디셔닝 데이터에 통합하여 잠재 시퀀스에 비디오 컨디셔닝 가이드를 추가합니다. 이 노드는 입력을 VAE 인코더로 처리하고, 결과로 생성된 잠재(latent) 표현을 지정된 프레임 위치에 배치하며, 키프레임 정보로 포지티브 및 네거티브 컨디셔닝을 업데이트합니다. 또한 이 노드는 프레임 정렬 제약 조건을 처리하고 컨디셔닝 영향의 강도를 제어할 수 있게 합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
| --- | --- | --- | --- | --- |
| `긍정 조건` | 키프레임 가이드에 의해 수정될 포지티브 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `부정 조건` | 키프레임 가이드에 의해 수정될 네거티브 컨디셔닝 입력입니다. | CONDITIONING | 예 | - |
| `vae` | 입력 이미지/비디오 프레임을 인코딩하는 데 사용되는 VAE 모델입니다. | VAE | 예 | - |
| `잠재 비디오` | 컨디셔닝 프레임을 전달받을 입력 잠재 시퀀스입니다. | LATENT | 예 | - |
| `이미지` | 잠재 비디오를 컨디셔닝하는 데 사용할 이미지 또는 비디오입니다. 프레임 수는 8*n + 1이어야 합니다. 비디오의 프레임 수가 8*n + 1이 아닌 경우 가장 가까운 8*n + 1 프레임 수로 잘립니다. | IMAGE | 예 | - |
| `프레임 번호` | 컨디셔닝을 시작할 프레임 인덱스입니다. 단일 프레임 이미지 또는 1~8프레임 비디오에서는 `frame_idx` 값이 무엇이든 허용됩니다. 9프레임 이상의 비디오에서는 `frame_idx`가 8로 나누어 떨어져야 하며, 그렇지 않으면 가장 가까운 8의 배수로 내림됩니다. 음수 값은 비디오의 끝에서부터 계산됩니다. (기본값: 0) | INT | 예 | -9999 to 9999 |
| `강도` | 컨디셔닝 영향의 강도입니다. 1.0은 컨디셔닝을 완전히 적용하고 0.0은 컨디셔닝을 적용하지 않습니다. (기본값: 1.0) | FLOAT | 예 | 0.0 to 10.0 |
| `attention_mask` | 픽셀 공간에서 정의되는 선택적 공간 마스크입니다. 자기 어텐션(self-attention)을 통해 영역별 컨디셔닝 영향을 제어하며, `strength` 값에 곱해집니다. | MASK | 아니요 | - |
| `iclora_parameters` | Get IC-LoRA Parameters 노드에서 얻은 선택적 IC-LoRA 매개변수입니다. 특정 IC-LoRA(예: `reference_downscale_factor`가 1보다 큰 IC-LoRA)에서 요구하는 가이드 처리를 조정하는 데 사용됩니다. 연결(체이닝) 시 각 LTXVAddGuide 노드는 자신에게 연결된 매개변수만 사용합니다. | IC_LORA_PARAMETERS | 아니요 | - |

**참고:** 입력 이미지/비디오의 프레임 수는 8*n + 1 패턴(예: 1, 9, 17, 25프레임)을 따라야 합니다. 입력이 이 패턴을 벗어나면 가장 가까운 유효 프레임 수로 자동으로 잘립니다.

**`iclora_parameters` 관련 참고:** `reference_downscale_factor`가 1보다 큰 IC-LoRA 매개변수를 사용하는 경우 잠재 표현의 공간 차원(너비 및 높이)이 해당 인자로 나누어 떨어져야 합니다. 이 조건이 충족되지 않으면 노드에서 오류가 발생합니다.

**참고:** 인코딩된 가이드 프레임은 선택한 프레임 위치에서 잠재 시퀀스 길이 안에 맞아야 합니다. 컨디셔닝된 프레임이 잠재 시퀀스의 길이를 초과하면 노드에서 오류가 발생합니다.

**참고:** 오디오 및 비디오 채널이 결합된 잠재에 가이드를 추가하는 것은 지원되지 않으며, 오류가 발생합니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `긍정 조건` | 키프레임 가이드 정보로 업데이트된 포지티브 컨디셔닝입니다. | CONDITIONING |
| `부정 조건` | 키프레임 가이드 정보로 업데이트된 네거티브 컨디셔닝입니다. | CONDITIONING |
| `잠재 비디오` | 컨디셔닝 프레임과 업데이트된 노이즈 마스크가 통합된 잠재 시퀀스입니다. | LATENT |
