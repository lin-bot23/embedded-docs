# LTXV 가이드 추가

```markdown
# LTXVAddGuide 노드 가이드

LTXVAddGuide 노드는 입력 이미지나 비디오를 인코딩하여 latent 시퀀스에 비디오 조건 설정 지침을 추가하는 데 사용됩니다. 이 노드는 입력을 VAE 인코더를 통해 처리하고, 인코딩된 latent을 사용하여 latent 비디오 시퀀스를 조건 설정합니다. 조건 설정을 시작할 프레임 인덱스를 지정할 수 있으며, 조건 설정의 영향력을 조절할 수 있습니다. 노드는 프레임 정렬 제약을 처리하고, 지역별 조건 설정 영향력을 제어할 수 있는 옵션적 픽셀 공간 공간 마스크를 지원합니다. 또한, 특정 가이드 처리 조정을 필요로 하는 IC-LoRA 매개변수를 처리할 수 있습니다.

## 개요

LTXVAddGuide 노드는 입력 이미지나 비디오를 인코딩하고, VAE 인코더를 통해 처리한 인코딩된 latent을 사용하여 latent 비디오 시퀀스를 조건 설정합니다. 조건 설정을 시작할 프레임 인덱스를 지정할 수 있으며, 조건 설정의 영향력을 조절할 수 있습니다. 노드는 옵션적 픽셀 공간 공간 마스크를 통해 지역별 조건 설정 영향력을 제어할 수 있으며, IC-LoRA 매개변수를 처리할 수 있습니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `긍정 조건` | 조건 설정 입력을 키 프레임 지침으로 수정할 수 있는 긍정적인 조건 설정 | CONDITIONING | 예 | - |
| `부정 조건` | 키 프레임 지침으로 수정할 수 있는 부정적인 조건 설정 | CONDITIONING | 예 | - |
| `vae` | 입력 이미지/비디오 프레임을 인코딩하는 데 사용되는 VAE 모델 | VAE | 예 | - |
| `잠재 비디오` | 조건 설정 프레임을 포함하여 조정할 수 있는 입력 latent 시퀀스 | LATENT | 예 | - |
| `이미지` | latent 비디오에 조건 설정할 이미지나 비디오. 8*n + 1 프레임이어야 합니다. 비디오가 8*n + 1 프레임이 아니면 가장 가까운 8*n + 1 프레임으로 자르됩니다. | IMAGE | 예 | - |
| `프레임 번호` | 조건 설정을 시작할 프레임 인덱스. 단일 프레임 이미지나 1-8 프레임의 비디오에서는 어떤 frame_idx 값도 가능합니다. 9+ 프레임의 비디오에서는 frame_idx가 8로 나누어 떨어지는 값이어야 하며, 아니라면 가장 가까운 8의 배수로 내림됩니다. 음수 값은 비디오의 끝에서부터 세어집니다. (기본: 0) | INT | 예 | -9999 ~ 9999 |
| `강도` | 조건 설정의 영향력을 조절하는 강도, 1.0은 전체 조건 설정을 적용하고 0.0은 조건 설정을 적용하지 않습니다. (기본: 1.0) | FLOAT | 예 | 0.0 ~ 10.0 |
| `attention_mask` | 선택적 픽셀 공간 공간 마스크. self-attention을 통해 지역별 조건 설정 영향력을 제어하고, 강도로 곱합니다. | MASK | 아님 | - |
| `iclora_parameters` | Get IC-LoRA Parameters 노드에서 가져온 선택적 IC-LoRA 매개변수. 특정 IC-LoRAs(예: reference_downscale_factor가 1보다 큰 IC-LoRAs)에 필요한 가이드 처리 조정을 위해 사용됩니다. 연결 시, 각 LTXVAddGuide는 연결된 매개변수 만 사용합니다. | IC_LORA_PARAMETERS | 아님 | - |

**주의:** 입력 이미지/비디오는 8*n + 1 패턴에 따른 프레임 수를 가지어야 합니다(예: 1, 9, 17, 25 프레임). 입력이 이 패턴을 초과하면 자동으로 가장 가까운 유효한 프레임 수로 자르됩니다.

**`iclora_parameters`에 대한 주의사항:** `reference_downscale_factor`가 1보다 큰 IC-LoRA 매개변수를 사용할 때, latent 공간적 크기(너비와 높이)는 해당 팩터로 나누어 떨어져야 합니다. 이 조건이 충족되지 않으면 노드는 오류를 발생시킵니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `긍정 조건` | 키 프레임 지침 정보로 업데이트된 긍정적인 조건 설정 | CONDITIONING |
| `부정 조건` | 키 프레임 지침 정보로 업데이트된 부정적인 조건 설정 | CONDITIONING |
| `잠재 비디오` | 조건 설정 프레임을 포함하여 조정된 noise 마스크를 포함한 latent 시퀀스 | LATENT |
```

위의 문서는 소스 코드를 기반으로 작성되었으며 다음과 같은 업데이트를 포함하고 있습니다:

- `frame_idx` 매개변수는 비디오가 9+ 프레임일 때 `frame_idx`가 8로 나누어 떨어져야 하는 제약을 포함하는 툴팁을 포함합니다.
- `iclora_parameters` 매개변수는 latent 공간적 크기가 `reference_downscale_factor`로 나누어 떨어져야 하는 요구사항에 대한 주의사항을 포함합니다.
- 개요 섹션은 노드의 기능을 소스 코드에 기반하여 업데이트했습니다.
