# LTXV 添加引導

LTXVAddGuide 節點設計用於將視頻條件化指導添加到潛在序列中，透過編碼輸入圖像或視頻，並將其作為關鍵幀編入條件數據。它通過 VAE 编碼器處理輸入，並在指定的幀位置策略性地放置結果潛在值，同時更新正負條件以包含關鍵幀信息。此節點處理幀對齊約束，並允許控制條件影響的強度。

## 概述

LTXVAddGuide 節點編碼輸入圖像或視頻，通過 VAE 编碼器處理它們，並使用編碼的潛在值來條件化潛在視頻序列。它允許指定一個幀索引以開始條件化，並調整條件影響的強度。此節點還支持選擇性像素空間空間掩罩以進行每區域條件影響，並可處理 IC-LoRA 參數以進行特定的指導處理調整。
