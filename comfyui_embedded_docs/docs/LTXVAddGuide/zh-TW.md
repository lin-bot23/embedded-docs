# LTXV 添加引導

LTXVAddGuide 節點透過編碼輸入的圖像或影片，並將其作為關鍵影格整合到條件資料中，為潛在序列加入影片條件引導。它會透過 VAE 編碼器處理輸入，並將產生的潛在資料策略性地放置在指定的影格位置，同時以關鍵影格資訊更新正向與負向條件。此節點會處理影格對齊限制，並允許控制條件影響的強度。

## 輸入
| 參數 | 描述 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `正向` | 將以關鍵影格引導進行修改的正向條件輸入 | CONDITIONING | 是 | - |
| `負向` | 將以關鍵影格引導進行修改的負向條件輸入 | CONDITIONING | 是 | - |
| `vae` | 用於編碼輸入圖像/影片影格的 VAE 模型 | VAE | 是 | - |
| `潛在空間` | 將接收條件影格的輸入潛在序列 | LATENT | 是 | - |
| `影像` | 用於對潛在影片進行條件化的圖像或影片。必須為 8*n + 1 個影格。如果影片並非 8*n + 1 個影格，則會自動裁切至最接近的有效影格數 | IMAGE | 是 | - |
| `起始幀索引` | 開始進行條件化的影格索引。對於單影格圖像或 1-8 個影格的影片，任何 `frame_idx` 值皆可接受。對於 9 個影格以上的影片，`frame_idx` 必須能被 8 整除，否則會向下取整至最接近的 8 的倍數。負值會從影片末尾開始倒數計算。（預設值：0） | INT | 是 | -9999至9999 |
| `強度` | 條件影響的強度，1.0 表示完全套用條件化，0.0 表示不套用條件化（預設值：1.0） | FLOAT | 是 | 0.0至10.0 |
| `注意力遮罩` | 選用的像素空間空間遮罩。透過自注意力控制每個區域的條件化影響，並與 `strength` 相乘 | MASK | 否 | - |
| `iclora_parameters` | 選用的 IC-LoRA 參數，來自 Get IC-LoRA Parameters 節點。用於依照特定 IC-LoRA（例如具有 `reference_downscale_factor` > 1 的 IC-LoRA）的需求調整引導處理。當串接使用時，每個 LTXVAddGuide 只會使用與其連接的參數 | IC_LORA_PARAMETERS | 否 | - |

**注意：** 輸入的圖像/影片必須具有符合 8*n + 1 模式的影格數量（例如 1、9、17、25 個影格）。如果輸入未符合此模式，則會自動裁切至最接近的有效影格數。

**關於 `iclora_parameters` 的注意事項：** 當使用的 IC-LoRA 參數具有大於 1 的 `reference_downscale_factor` 時，潛在空間的空間維度（寬度和高度）必須能被該因子整除。若不符合此條件，節點將引發錯誤。

**注意：** 編碼後的引導影格必須能容納於選定影格位置所在的潛在序列中。如果條件化的影格超過潛在序列的長度，節點將引發錯誤。

**注意：** 不支援在結合了音訊與視訊通道的潛在資料上加入引導，否則將引發錯誤。
