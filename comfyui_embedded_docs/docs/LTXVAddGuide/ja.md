# LTXVAddGuide

LTXVAddGuide ノードは、入力画像またはビデオをエンコードし、それらをキーフレームとしてコンディショニングデータに組み込むことで、潜在シーケンスにビデオコンディショニングガイダンスを追加します。このノードは、入力を VAE エンコーダーで処理し、結果として得られる潜在表現を指定されたフレーム位置に戦略的に配置するとともに、キーフレーム情報でポジティブコンディショニングとネガティブコンディショニングの両方を更新します。また、ノードはフレームの位置合わせ制約を処理し、コンディショニングの影響の強さを制御できます。

**注記：** 入力画像/ビデオは、8*n + 1 パターン（例: 1、9、17、25 フレーム）のフレーム数に従う必要があります。入力がこのパターンを超える場合、最も近い有効なフレーム数に自動的にクロップされます。

**`iclora_parameters` に関する注記：** `reference_downscale_factor` が 1 より大きい IC-LoRA パラメータを使用する場合、潜在表現の空間次元（幅と高さ）はその係数で割り切れる必要があります。この条件を満たさない場合、ノードはエラーを発生させます。

**注記：** エンコードされたガイドフレームは、選択したフレーム位置で潜在シーケンス内に収まる必要があります。コンディショニングされたフレームが潜在シーケンスの長さを超える場合、ノードはエラーを発生させます。

**注記：** オーディオチャンネルとビデオチャンネルを組み合わせた潜在表現にガイドを追加することはサポートされておらず、エラーが発生します。
