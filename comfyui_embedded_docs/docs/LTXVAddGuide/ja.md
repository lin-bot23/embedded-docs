# LTXVAddGuide

LTXVAddGuide ノードは、入力画像や動画をエンコードし、それらを鍵桜として条件データに組み込むことで、潜在シークエンスにビデオ条件ガイドを追加するために設計されています。VAE エンコーダを通じて入力を処理し、結果として得られた潜在値を指定されたフレーム位置に配置し、ポジティブおよびネガティブの条件を鍵桜情報で更新します。ノードはフレームアライメント制約を処理し、条件影響の強さを制御する機能を提供します。

## 概要

LTXVAddGuide ノードは、入力画像や動画をエンコードし、VAE エンコーダを通じて処理し、エンコードされた潜在値を使用して潜在ビデオシークエンスを条件付けます。条件を開始するフレームインデックスを指定する機能があり、条件影響の強さを調整できます。ノードは、地域ごとの条件影響を制御するためにオプションのピクセル空間空間マスクをサポートし、特定のガイド処理調整に必要な IC-LoRA パラメータを処理できます。
