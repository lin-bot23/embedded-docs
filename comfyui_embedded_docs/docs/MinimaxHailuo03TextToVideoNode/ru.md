# MiniMax H3: Текст в видео

Этот узел генерирует видео по текстовому запросу с помощью семейства моделей MiniMax H3: MiniMax H3, MiniMax H3 Max и MiniMax H3 Max Turbo. Вы выбираете модель, вводите текстовый запрос и настраиваете такие параметры, как разрешение, соотношение сторон и длительность. Узел отправляет запрос к API MiniMax, ожидает завершения задачи генерации и возвращает полученное видео.

## Входы

### Общие входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `model` | Модель для генерации видео (по умолчанию: «MiniMax H3»). При выборе модели также отображаются её собственные параметры, описанные в разделах ниже. | DYNAMIC_COMBO | Да | "MiniMax H3"<br>"MiniMax H3 Max"<br>"MiniMax H3 Max Turbo" |
| `seed` | Случайное зерно (seed). Одинаковые запросы с одним и тем же зерном дают похожие, но не гарантированно идентичные результаты (по умолчанию: 42). | INT | Да | от 0 до 4294967295 |
| `watermark` | Определяет, нужно ли добавлять на видео водяной знак AIGC (по умолчанию: false). При включении поддерживается только модель «MiniMax H3». | BOOLEAN | Нет | true<br>false |

### Входы MiniMax H3

Эти параметры появляются при выборе модели «MiniMax H3».

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt` | Текстовый запрос для генерации видео. Должен содержать хотя бы один непробельный символ. | STRING | Да | Любой текст |
| `resolution` | Разрешение выходного видео. | COMBO | Да | "768P"<br>"2K" |
| `ratio` | Соотношение сторон выходного видео (по умолчанию: «16:9»). | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | Длительность выходного видео в секундах (от 4 до 15) (по умолчанию: 5). | INT | Да | от 4 до 15 |

### Входы MiniMax H3 Max и MiniMax H3 Max Turbo

Эти параметры являются общими для моделей «MiniMax H3 Max» и «MiniMax H3 Max Turbo» и появляются при выборе любой из них.

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|---|---|---|---|---|
| `prompt` | Текстовый запрос для генерации видео. Должен содержать хотя бы один непробельный символ и может иметь длину до 50 000 символов. | STRING | Да | до 50000 символов |
| `resolution` | Разрешение выходного видео (по умолчанию: «768P»). | COMBO | Да | "480P"<br>"768P" |
| `ratio` | Соотношение сторон выходного видео (по умолчанию: «16:9»). | COMBO | Да | "16:9"<br>"4:3"<br>"1:1"<br>"3:4"<br>"9:16"<br>"21:9" |
| `duration` | Длительность выходного видео в секундах (от 5 до 15) (по умолчанию: 5). | INT | Да | от 5 до 15 |
| `prompt_expansion_mode` | Объём усилий, затрачиваемых на переписывание запроса перед генерацией (по умолчанию: «balanced»). | COMBO | Да | "balanced"<br>"quality" |

### Примечания

- Для всех моделей запрос должен содержать хотя бы один непробельный символ.
- Параметр `watermark` поддерживается только моделью «MiniMax H3». Его включение с моделями «MiniMax H3 Max» или «MiniMax H3 Max Turbo» приводит к ошибке.
- Модели «MiniMax H3 Max» и «MiniMax H3 Max Turbo» ограничивают длину запроса до 50 000 символов.
- Ограничения по разрешению и длительности зависят от выбранной модели: «MiniMax H3» поддерживает разрешения «768P» и «2K» и видео длительностью 4–15 секунд, а «MiniMax H3 Max» и «MiniMax H3 Max Turbo» поддерживают разрешения «480P» и «768P» и видео длительностью 5–15 секунд.
- Ориентировочная цена, отображаемая для этого узла, рассчитывается на основе выбранной модели, разрешения и длительности.
