# Переключатель

Узел Switch выбирает один из двух возможных входов на основе логического условия. Когда `switch` включён (true), он передаёт вход `on_true` на выход; когда выключен (false), он передаёт `on_false`. Вычисляется только выбранная ветвь, поэтому другой вход может быть не подключён.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `переключатель` | Логическое условие, определяющее, какой вход будет передан на выход. Когда включено (true), выбирается вход `on_true`. Когда выключено (false), выбирается вход `on_false`. | BOOLEAN | Да |  |
| `если_ложь` | Данные, которые передаются на выход, когда `switch` выключен (false). Этот вход требуется только тогда, когда `switch` равен false. | MATCH_TYPE | Нет |  |
| `если_истина` | Данные, которые передаются на выход, когда `switch` включён (true). Этот вход требуется только тогда, когда `switch` равен true. | MATCH_TYPE | Нет |  |

**Примечание о требованиях к входам:** Входы `on_false` и `on_true` являются условно обязательными. Узел запрашивает вход `on_true` только когда `switch` равен true, а вход `on_false` — только когда `switch` равен false. Оба входа должны иметь один и тот же тип данных, который должен совпадать с типом данных на выходе. Если выбранный вход не подключён, узел не возвращает никакого значения.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `выход` | Выбранные данные. Это значение из входа `on_true`, когда `switch` равен true, или значение из входа `on_false`, когда `switch` равен false. | MATCH_TYPE |
