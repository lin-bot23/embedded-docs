# سوئیچ

گره Switch بر اساس یک شرط بولی، بین دو ورودی ممکن انتخاب می‌کند. وقتی `switch` فعال باشد (true)، ورودی `on_true` را به خروجی منتقل می‌کند؛ وقتی غیرفعال باشد (false)، ورودی `on_false` را منتقل می‌کند. فقط شاخه انتخاب‌شده ارزیابی می‌شود، بنابراین نیازی به اتصال ورودی دیگر نیست.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `switch` | یک شرط بولی که تعیین می‌کند کدام ورودی عبور داده شود. وقتی فعال باشد (true)، ورودی `on_true` انتخاب می‌شود. وقتی غیرفعال باشد (false)، ورودی `on_false` انتخاب می‌شود. | BOOLEAN | بله | |
| `on_false` | داده‌ای که وقتی `switch` غیرفعال است (false) به خروجی منتقل می‌شود. این ورودی فقط زمانی که `switch` false باشد الزامی است. | MATCH_TYPE | خیر | |
| `on_true` | داده‌ای که وقتی `switch` فعال است (true) به خروجی منتقل می‌شود. این ورودی فقط زمانی که `switch` true باشد الزامی است. | MATCH_TYPE | خیر | |

**توضیح درباره الزامات ورودی:** ورودی‌های `on_false` و `on_true` به صورت شرطی الزامی هستند. گره ورودی `on_true` را فقط زمانی که `switch` true است درخواست می‌کند، و ورودی `on_false` را فقط زمانی که `switch` false است. هر دو ورودی باید از یک نوع داده باشند و باید با نوع داده خروجی مطابقت داشته باشند. اگر ورودی انتخاب‌شده متصل نباشد، گره هیچ مقداری خروجی نمی‌دهد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `output` | داده انتخاب‌شده. این مقدار از ورودی `on_true` است وقتی `switch` true باشد، یا مقدار از ورودی `on_false` است وقتی `switch` false باشد. | MATCH_TYPE |
