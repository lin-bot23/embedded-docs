# Tripo: چندنما به مدل

این گره با استفاده از API Tripo به صورت همزمان مدل‌های سه‌بعدی تولید می‌کند و تا چهار تصویر از نمای‌های مختلف یک شیء (روبرو، چپ، پشت، راست) را پردازش می‌کند. برای ساخت مدل سه‌بعدی، به یک تصویر روبرو و حداقل یک نمای اضافی (چپ، پشت یا راست) نیاز دارد. بافت (Texture)، متریال PBR، کیفیت هندسه و فرمت خروجی را می‌توان از طریق این گره کنترل کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر نمای روبروی شیء. | IMAGE | بله | - |
| `تصویر چپ` | تصویر نمای چپ شیء. | IMAGE | خیر | - |
| `تصویر پشت` | تصویر نمای پشت شیء. | IMAGE | خیر | - |
| `تصویر راست` | تصویر نمای راست شیء. | IMAGE | خیر | - |
| `نسخه مدل` | نسخه مدل مورد استفاده برای تولید. | COMBO | خیر | گزینه‌های متعدد موجود است |
| `جهت` | تنظیم جهت‌گیری برای مدل سه‌بعدی (پیش‌فرض: `"default"`). | COMBO | خیر | گزینه‌های متعدد موجود است |
| `تکسچر` | تولید نقشه‌های بافت. غیرفعال کردن آن هندسه خام را برگردانده و pbr را نادیده می‌گیرد. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، متالیک، زبری، نرمال). نیازمند texture است. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `بذر مدل` | seed تصادفی برای تولید مدل (پیش‌فرض: 42). | INT | خیر | 0 تا 2,147,483,647 |
| `بذر تکسچر` | seed تصادفی برای تولید بافت (پیش‌فرض: 42). | INT | خیر | 0 تا 2,147,483,647 |
| `کیفیت تکسچر` | سطح کیفیت برای تولید بافت (پیش‌فرض: `"standard"`). `"detailed"` = بافت‌های HD، `"extreme"` = بافت‌های Ultra 8K. | COMBO | خیر | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `تراز تکسچر` | روش مورد استفاده برای هم‌تراز کردن بافت‌ها با مدل (پیش‌فرض: `"original_image"`). | COMBO | خیر | `"original_image"`<br>`"geometry"` |
| `محدودیت وجه` | حداکثر تعداد وجه‌ها (faces). مقدار -1 به Tripo اجازه می‌دهد به صورت تطبیقی انتخاب کند (حدود 1.4M وجه در v3.x استاندارد، 2M در detailed). Tripo به صورت پنهان محدود می‌کند: v2.5 در 500,000، مش‌های quad در 150,000. (پیش‌فرض: -1) | INT | خیر | -1 تا 2,000,000 |
| `چهارضلعی` | خروجی مش Quad. Tripo مش‌های quad را به صورت FBX تحویل می‌دهد، بنابراین نتیجه در خروجی FBX قرار می‌گیرد و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `کیفیت هندسه` | سطح کیفیت برای تولید هندسه (پیش‌فرض: `"standard"`). | COMBO | خیر | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | مش Low-poly با توپولوژی تمیز به سبک دست‌ساز (500-20,000 وجه، quad 500-10,000). بهترین گزینه برای سوژه‌های ساده؛ موارد پیچیده ممکن است شکست بخورند. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `auto_size` | مقیاس‌دهی مدل‌های دارای بافت به اندازه واقعی آن‌ها در جهان واقعی بر حسب متر. Tripo اندازه را به عنوان transform صحنه مدل ذخیره کرده و هنگام تبدیل، ریگ‌ شدن یا ری‌تارگت شدن مدل آن را تثبیت می‌کند؛ بدون بافت نادیده گرفته می‌شود. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**توجه:** تصویر روبرو (`image`) همیشه الزامی است و حداقل یکی از `image_left`، `image_back` یا `image_right` نیز باید ارائه شود. غیرفعال کردن `texture` به صورت خودکار `pbr` را نیز غیرفعال می‌کند، زیرا `pbr` نیازمند بافت است. هنگامی که `smart_low_poly` فعال است و `face_limit` روی -1 تنظیم نشده باشد، `face_limit` باید برای مش‌های مثلثی بین 500 تا 20,000 و برای مش‌های quad بین 500 تا 10,000 باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | مسیر فایل یا شناسه برای مدل سه‌بعدی تولید شده (فقط برای سازگاری معکوس). | STRING |
| `شناسه وظیفه مدل` | شناسه وظیفه برای ردیابی فرآیند تولید مدل. | MODEL_TASK_ID |
| `GLB` | فایل مدل سه‌بعدی تولید شده در فرمت GLB. هنگامی که `quad` فعال باشد خالی است. | FILE3DGLB |
| `FBX` | فایل مدل سه‌بعدی تولید شده در فرمت FBX. فقط زمانی که `quad` فعال باشد پر می‌شود. | FILE3DFBX |
