# Tripo: چندنما به مدل

این گره با استفاده از API سرویس Tripo و پردازش حداکثر چهار تصویر که نماهای مختلف یک شیء را نشان می‌دهند (جلو، چپ، پشت، راست)، مدل‌های سه‌بعدی را به‌صورت همزمان تولید می‌کند. برای ساخت مدل سه‌بعدی، به یک تصویر جلو و حداقل یک نمای دیگر (چپ، پشت یا راست) نیاز دارد. بافت، متریال PBR، کیفیت هندسه و قالب خروجی را می‌توان از این گره کنترل کرد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصویر` | تصویر نمای جلوی شیء. | IMAGE | بله | - |
| `تصویر چپ` | تصویر نمای چپ شیء. | IMAGE | خیر | - |
| `تصویر پشت` | تصویر نمای پشت شیء. | IMAGE | خیر | - |
| `تصویر راست` | تصویر نمای راست شیء. | IMAGE | خیر | - |
| `نسخه مدل` | نسخه مدل مورد استفاده برای تولید. | COMBO | خیر | گزینه‌های متعدد در دسترس است |
| `جهت` | تنظیم جهت‌گیری مدل سه‌بعدی (پیش‌فرض: `"default"`). | COMBO | خیر | گزینه‌های متعدد در دسترس است |
| `تکسچر` | نقشه‌های بافت را تولید می‌کند. حالت خاموش، هندسه بدون بافت برمی‌گرداند و `pbr` را نادیده می‌گیرد. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `PBR` | نقشه‌های متریال PBR (رنگ پایه، فلزیت، زبری، نرمال). نیازمند `texture` است. (پیش‌فرض: True) | BOOLEAN | خیر | - |
| `بذر مدل` | بذر تصادفی برای تولید مدل (پیش‌فرض: 42). | INT | خیر | 0 to 2,147,483,647 |
| `بذر تکسچر` | بذر تصادفی برای تولید بافت (پیش‌فرض: 42). | INT | خیر | 0 to 2,147,483,647 |
| `کیفیت تکسچر` | سطح کیفیت برای تولید بافت (پیش‌فرض: `"standard"`). `"detailed"` = بافت‌های HD، `"extreme"` = بافت‌های 8K Ultra. | COMBO | خیر | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `تراز تکسچر` | روش استفاده‌شده برای هم‌ترازی بافت‌ها با مدل (پیش‌فرض: `"original_image"`). | COMBO | خیر | `"original_image"`<br>`"geometry"` |
| `محدودیت وجه` | حداکثر تعداد وجه. مقدار -1 باعث می‌شود Tripo به‌صورت تطبیقی انتخاب کند (حدود 1.4M وجه در v3.x استاندارد، 2M در حالت detailed). Tripo بی‌سروصدا محدود می‌کند: v2.5 در 500,000، مش‌های چهارضلعی در 150,000. (پیش‌فرض: -1) | INT | خیر | -1 to 2,000,000 |
| `چهارضلعی` | خروجی مش چهارضلعی. Tripo مش‌های چهارضلعی را به‌صورت FBX ارائه می‌دهد، بنابراین نتیجه روی خروجی FBX می‌آید و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `کیفیت هندسه` | سطح کیفیت برای تولید هندسه (پیش‌فرض: `"standard"`). | COMBO | خیر | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | مش کم‌پالیگان با توپولوژی تمیز و به سبک دست‌ساز (500 تا 20,000 وجه، چهارضلعی 500 تا 10,000). برای سوژه‌های ساده بهترین است؛ ممکن است سوژه‌های پیچیده شکست بخورند. (پیش‌فرض: False) | BOOLEAN | خیر | - |
| `auto_size` | مدل‌های دارای بافت را به اندازه واقعی‌شان بر حسب متر مقیاس‌دهی می‌کند. Tripo اندازه را به‌عنوان ترنسفورم صحنه مدل ذخیره می‌کند و زمانی که مدل تبدیل، ریگ یا ریتارگت می‌شود آن را اعمال می‌کند؛ بدون بافت نادیده گرفته می‌شود. (پیش‌فرض: False) | BOOLEAN | خیر | - |

**توجه:** تصویر جلو (`image`) همیشه الزامی است و حداقل یکی از `image_left`، `image_back` یا `image_right` نیز باید ارائه شود. خاموش کردن `texture` به‌طور خودکار `pbr` را نیز خاموش می‌کند، زیرا `pbr` به بافت نیاز دارد. وقتی `smart_low_poly` فعال است و `face_limit` روی -1 باقی نمانده باشد، `face_limit` باید برای مش‌های مثلثی بین 500 و 20,000 یا برای مش‌های چهارضلعی بین 500 و 10,000 باشد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `فایل مدل` | مسیر فایل یا شناسه مدل سه‌بعدی تولیدشده (فقط برای سازگاری با نسخه‌های قبلی). | STRING |
| `شناسه وظیفه مدل` | شناسه وظیفه برای پیگیری فرایند تولید مدل. | MODEL_TASK_ID |
| `GLB` | فایل مدل سه‌بعدی تولیدشده در قالب GLB. هنگام فعال بودن `quad` خالی است. | FILE3DGLB |
| `FBX` | فایل مدل سه‌بعدی تولیدشده در قالب FBX. فقط زمانی پر می‌شود که `quad` فعال باشد. | FILE3DFBX |
