# Tripo: متعدد المناظر إلى نموذج

ينشئ هذا العقد نماذج ثلاثية الأبعاد بشكل متزامن باستخدام واجهة برمجة تطبيقات Tripo، عبر معالجة ما يصل إلى أربع صور تعرض زوايا مختلفة لكائن ما (الأمام، اليسار، الخلف، اليمين). يتطلب صورة أمامية وواحدة على الأقل من الزوايا الإضافية (اليسار أو الخلف أو اليمين) لبناء النموذج ثلاثي الأبعاد. يمكن التحكم من العقد في النسيج ومواد PBR وجودة الهندسة وتنسيق الإخراج.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `image` | صورة العرض الأمامي للكائن. | IMAGE | نعم | - |
| `image_left` | صورة العرض الأيسر للكائن. | IMAGE | لا | - |
| `image_back` | صورة العرض الخلفي للكائن. | IMAGE | لا | - |
| `image_right` | صورة العرض الأيمن للكائن. | IMAGE | لا | - |
| `model_version` | إصدار النموذج المستخدم في التوليد. | COMBO | لا | خيارات متعددة متاحة |
| `orientation` | إعداد الاتجاه للنموذج ثلاثي الأبعاد (الافتراضي: `"default"`). | COMBO | لا | خيارات متعددة متاحة |
| `texture` | توليد خرائط النسيج. إيقاف التشغيل يُرجع هندسة مجردة ويتجاهل pbr. (الافتراضي: True) | BOOLEAN | لا | - |
| `pbr` | خرائط مواد PBR (اللون الأساسي، والمعدنية، والخشونة، والاتجاهات العمودية). يتطلب تفعيل النسيج. (الافتراضي: True) | BOOLEAN | لا | - |
| `model_seed` | بذرة عشوائية لتوليد النموذج (الافتراضي: 42). | INT | لا | 0 إلى 2,147,483,647 |
| `texture_seed` | بذرة عشوائية لتوليد النسيج (الافتراضي: 42). | INT | لا | 0 إلى 2,147,483,647 |
| `texture_quality` | مستوى الجودة لتوليد النسيج (الافتراضي: `"standard"`). `"detailed"` = نسيج عالي الدقة، `"extreme"` = نسيج فائق الدقة 8K. | COMBO | لا | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `texture_alignment` | الطريقة المستخدمة لمحاذاة النسيج على النموذج (الافتراضي: `"original_image"`). | COMBO | لا | `"original_image"`<br>`"geometry"` |
| `face_limit` | الحد الأقصى لعدد الوجوه. القيمة -1 تتيح لـ Tripo الاختيار التكيفي (حوالي 1.4 مليون وجه على إصدار v3.x القياسي، و2 مليون على الإصدار المفصّل). يقيّد Tripo القيمة بصمت: v2.5 عند 500,000، والشبكات الرباعية عند 150,000. (الافتراضي: -1) | INT | لا | -1 إلى 2,000,000 |
| `quad` | إخراج شبكة رباعية الأضلاع. يسلّم Tripo الشبكات الرباعية بصيغة FBX، لذا تصل النتيجة على مخرج FBX ويبقى مخرج GLB فارغًا. (الافتراضي: False) | BOOLEAN | لا | - |
| `geometry_quality` | مستوى الجودة لتوليد الهندسة (الافتراضي: `"standard"`). | COMBO | لا | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | شبكة منخفضة المضلعات بتوبولوجيا نظيفة بأسلوب يدوي الصنع (500-20,000 وجه، والرباعية 500-10,000). الأنسب للمواضيع البسيطة؛ وقد تفشل المعقدة منها. (الافتراضي: False) | BOOLEAN | لا | - |
| `auto_size` | تغيير حجم النماذج المزودة بنسيج إلى حجمها الحقيقي بالأمتار. يخزّن Tripo الحجم كتحويل مشهد للنموذج ويُدمجه عند تحويل النموذج أو تجهيزه بالهيكل أو إعادة توجيهه؛ ويُتجاهل هذا الخيار بدون نسيج. (الافتراضي: False) | BOOLEAN | لا | - |

**ملاحظة:** الصورة الأمامية (`image`) مطلوبة دائمًا، ويجب أيضًا توفير واحدة على الأقل من `image_left` أو `image_back` أو `image_right`. إيقاف `texture` يوقِف `pbr` تلقائيًا أيضًا، لأن `pbr` يتطلب النسيج. عند تفعيل `smart_low_poly` وعدم ترك `face_limit` على -1، يجب أن تكون قيمة `face_limit` بين 500 و20,000 للشبكات المثلثية، أو بين 500 و10,000 للشبكات الرباعية.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | مسار الملف أو معرّف النموذج ثلاثي الأبعاد المُولَّد (للتوافق مع الإصدارات السابقة فقط). | STRING |
| `model task_id` | معرّف المهمة لتتبّع عملية توليد النموذج. | MODEL_TASK_ID |
| `GLB` | ملف النموذج ثلاثي الأبعاد المُولَّد بصيغة GLB. يكون فارغًا عند تفعيل `quad`. | FILE3DGLB |
| `FBX` | ملف النموذج ثلاثي الأبعاد المُولَّد بصيغة FBX. لا يُملأ إلا عند تفعيل `quad`. | FILE3DFBX |
