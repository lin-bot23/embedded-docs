# Tripo: متعدد المناظر إلى نموذج

تولّد هذه العقدة نماذج ثلاثية الأبعاد بشكل متزامن باستخدام Tripo API من خلال معالجة ما يصل إلى أربع صور تُظهر زوايا مختلفة لجسم (أمامي، يسار، خلفي، يمين). وتتطلب صورة أمامية وواحدة إضافية على الأقل (يسار أو خلف أو يمين) لبناء النموذج ثلاثي الأبعاد. يمكن التحكم في النسيج ومادة PBR وجودة الهندسة وصيغة الإخراج من العقدة.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصورة` | صورة المنظر الأمامي للجسم. | IMAGE | نعم | - |
| `الصورة اليسرى` | صورة المنظر الأيسر للجسم. | IMAGE | لا | - |
| `الصورة الخلفية` | صورة المنظر الخلفي للجسم. | IMAGE | لا | - |
| `الصورة اليمنى` | صورة المنظر الأيمن للجسم. | IMAGE | لا | - |
| `إصدار_النموذج` | إصدار النموذج المستخدم في التوليد. | COMBO | لا | خيارات متعددة متاحة |
| `التوجيه` | إعداد اتجاه النموذج ثلاثي الأبعاد (الافتراضي: `"default"`). | COMBO | لا | خيارات متعددة متاحة |
| `الملمس` | توليد خرائط النسيج. عند الإيقاف، يتم إرجاع هندسة خام ويُتجاهل `pbr`. (الافتراضي: True) | BOOLEAN | لا | - |
| `PBR` | خرائط مادة PBR (اللون الأساسي، المعدنية، الخشونة، خريطة normal). يتطلب `texture`. (الافتراضي: True) | BOOLEAN | لا | - |
| `بذرة_النموذج` | بذرة عشوائية لتوليد النموذج (الافتراضي: 42). | INT | لا | 0 to 2,147,483,647 |
| `بذرة_الملمس` | بذرة عشوائية لتوليد النسيج (الافتراضي: 42). | INT | لا | 0 to 2,147,483,647 |
| `جودة_الملمس` | مستوى الجودة لتوليد النسيج (الافتراضي: `"standard"`). `"detailed"` = خرائط نسيج HD، `"extreme"` = خرائط نسيج 8K Ultra. | COMBO | لا | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `محاذاة_الملمس` | الطريقة المستخدمة لمحاذاة النسيج مع النموذج (الافتراضي: `"original_image"`). | COMBO | لا | `"original_image"`<br>`"geometry"` |
| `حد_الوجه` | الحد الأقصى لعدد الأوجه. القيمة -1 تتيح لـ Tripo الاختيار التكيفي (حوالي 1.4M وجه في v3.x standard، و2M في detailed). يقوم Tripo بالقص بصمت: v2.5 عند 500,000، والشبكات الرباعية عند 150,000. (الافتراضي: -1) | INT | لا | -1 to 2,000,000 |
| `رباعي` | إخراج شبكة رباعية. يسلّم Tripo الشبكات الرباعية بصيغة FBX، لذا تصل النتيجة عبر مخرج `FBX` ويبقى مخرج `GLB` فارغًا. (الافتراضي: False) | BOOLEAN | لا | - |
| `جودة الهندسة` | مستوى الجودة لتوليد الهندسة (الافتراضي: `"standard"`). | COMBO | لا | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | شبكة low-poly ذات طوبولوجيا نظيفة بأسلوب مصنوع يدويًا (500-20,000 وجه، وquad 500-10,000). الأفضل للأجسام البسيطة؛ قد تفشل الأجسام المعقدة. (الافتراضي: False) | BOOLEAN | لا | - |
| `auto_size` | تحجيم النماذج المزوّدة بنسيج إلى حجمها الواقعي بالأمتار. يخزّن Tripo الحجم كتحويل مشهد النموذج ويدمجه عند تحويل النموذج أو تجهيزه هيكليًا أو إعادة استهدافه؛ يُتجاهل دون `texture`. (الافتراضي: False) | BOOLEAN | لا | - |

**ملاحظة:** الصورة الأمامية (`image`) مطلوبة دائمًا، ويجب أيضًا توفير واحدة على الأقل من `image_left` أو `image_back` أو `image_right`. يؤدي إيقاف `texture` إلى إيقاف `pbr` تلقائيًا أيضًا، لأن `pbr` يتطلب `texture`. عند تمكين `smart_low_poly` وعدم ترك `face_limit` على القيمة -1، يجب أن تكون قيمة `face_limit` بين 500 و20,000 للشبكات المثلثية أو بين 500 و10,000 للشبكات الرباعية.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `ملف النموذج` | مسار الملف أو معرّف النموذج ثلاثي الأبعاد المولّد (للتوافق الرجعي فقط). | STRING |
| `معرّف مهمة النموذج` | معرّف المهمة لتتبع عملية توليد النموذج. | MODEL_TASK_ID |
| `GLB` | ملف النموذج ثلاثي الأبعاد المولّد بصيغة GLB. فارغ عند تمكين `quad`. | FILE3DGLB |
| `FBX` | ملف النموذج ثلاثي الأبعاد المولّد بصيغة FBX. يُملأ فقط عند تمكين `quad`. | FILE3DFBX |
