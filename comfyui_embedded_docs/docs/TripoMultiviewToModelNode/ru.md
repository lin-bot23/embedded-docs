# Tripo: Мультивью в модель

Этот узел синхронно генерирует 3D-модели с помощью API Tripo, обрабатывая до четырёх изображений, показывающих объект с разных видов (спереди, слева, сзади, справа). Для построения 3D-модели требуются изображение вида спереди и как минимум один дополнительный вид (слева, сзади или справа). Текстуру, PBR-материал, качество геометрии и выходной формат можно настроить в узле.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение объекта спереди. | IMAGE | Да | - |
| `image_left` | Изображение объекта слева. | IMAGE | Нет | - |
| `image_back` | Изображение объекта сзади. | IMAGE | Нет | - |
| `image_right` | Изображение объекта справа. | IMAGE | Нет | - |
| `версия_модели` | Версия модели, используемая для генерации. | COMBO | Нет | Доступно несколько вариантов |
| `ориентация` | Настройка ориентации 3D-модели (по умолчанию: `"default"`). | COMBO | Нет | Доступно несколько вариантов |
| `текстура` | Генерировать текстурные карты. При выключении возвращается только геометрия, а pbr игнорируется. (по умолчанию: True) | BOOLEAN | Нет | - |
| `PBR` | Карты PBR-материала (базовый цвет, металличность, шероховатость, нормали). Требуется текстура. (по умолчанию: True) | BOOLEAN | Нет | - |
| `сид_модели` | Случайное зерно для генерации модели (по умолчанию: 42). | INT | Нет | от 0 до 2,147,483,647 |
| `сид_текстуры` | Случайное зерно для генерации текстуры (по умолчанию: 42). | INT | Нет | от 0 до 2,147,483,647 |
| `качество_текстуры` | Уровень качества генерации текстуры (по умолчанию: `"standard"`). `"detailed"` = HD-текстуры, `"extreme"` = 8K Ultra-текстуры. | COMBO | Нет | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `выравнивание_текстуры` | Метод, используемый для выравнивания текстур относительно модели (по умолчанию: `"original_image"`). | COMBO | Нет | `"original_image"`<br>`"geometry"` |
| `лимит_лиц` | Максимальное количество граней. -1 позволяет Tripo выбрать адаптивно (около 1,4 млн граней в v3.x standard, 2 млн в detailed). Tripo ограничивает без предупреждения: v2.5 — 500,000, quad-меши — 150,000. (по умолчанию: -1) | INT | Нет | от -1 до 2,000,000 |
| `квад` | Вывод quad-меша. Tripo поставляет quad-меши в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остаётся пустым. (по умолчанию: False) | BOOLEAN | Нет | - |
| `качество геометрии` | Уровень качества генерации геометрии (по умолчанию: `"standard"`). | COMBO | Нет | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | Низкополигональный меш с чистой топологией в ручном стиле (500-20,000 граней, quad 500-10,000). Лучше всего подходит для простых объектов; сложные могут не сгенерироваться. (по умолчанию: False) | BOOLEAN | Нет | - |
| `auto_size` | Масштабировать модели с текстурами до их реального размера в метрах. Tripo сохраняет размер как трансформацию сцены модели и запекает его при конвертации, риггинге или ретаргетинге модели; игнорируется без текстуры. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Изображение спереди (`image`) всегда обязательно, и также должно быть предоставлено хотя бы одно из `image_left`, `image_back` или `image_right`. Выключение `texture` автоматически выключает и `pbr`, так как `pbr` требует текстуру. Когда `smart_low_poly` включён и `face_limit` не оставлен равным -1, `face_limit` должен быть от 500 до 20,000 для треугольных мешей или от 500 до 10,000 для quad-мешей.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Путь к файлу или идентификатор сгенерированной 3D-модели (только для обратной совместимости). | STRING |
| `task_id модели` | Идентификатор задачи для отслеживания процесса генерации модели. | MODEL_TASK_ID |
| `GLB` | Сгенерированный файл 3D-модели в формате GLB. Пустой, когда `quad` включён. | FILE3DGLB |
| `FBX` | Сгенерированный файл 3D-модели в формате FBX. Заполняется только когда `quad` включён. | FILE3DFBX |
