# Tripo: Мультивью в модель

Этот узел синхронно генерирует 3D-модели с помощью API Tripo, обрабатывая до четырех изображений, показывающих различные виды объекта (спереди, слева, сзади, справа). Для создания 3D-модели требуется изображение спереди и как минимум один дополнительный вид (слева, сзади или справа). Текстура, PBR-материал, качество геометрии и формат вывода могут управляться через узел.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image` | Изображение объекта спереди. | IMAGE | Да | - |
| `image_left` | Изображение объекта слева. | IMAGE | Нет | - |
| `image_back` | Изображение объекта сзади. | IMAGE | Нет | - |
| `image_right` | Изображение объекта справа. | IMAGE | Нет | - |
| `версия_модели` | Версия модели, используемая для генерации. | COMBO | Нет | Доступно несколько вариантов |
| `ориентация` | Настройка ориентации для 3D-модели (по умолчанию: `"default"`). | COMBO | Нет | Доступно несколько вариантов |
| `текстура` | Создавать карты текстур. При значении Off возвращается только геометрия, а pbr игнорируется. (по умолчанию: True) | BOOLEAN | Нет | - |
| `PBR` | PBR-карты материалов (основной цвет, металличность, шероховатость, нормали). Требует текстуру. (по умолчанию: True) | BOOLEAN | Нет | - |
| `сид_модели` | Случайный seed для генерации модели (по умолчанию: 42). | INT | Нет | от 0 до 2 147 483 647 |
| `сид_текстуры` | Случайный seed для генерации текстуры (по умолчанию: 42). | INT | Нет | от 0 до 2 147 483 647 |
| `качество_текстуры` | Уровень качества генерации текстур (по умолчанию: `"standard"`). `"detailed"` — HD-текстуры, `"extreme"` — текстуры 8K Ultra. | COMBO | Нет | `"standard"`<br>`"detailed"`<br>`"extreme"` |
| `выравнивание_текстуры` | Метод выравнивания текстур на модели (по умолчанию: `"original_image"`). | COMBO | Нет | `"original_image"`<br>`"geometry"` |
| `лимит_лиц` | Максимальное количество полигонов. -1 позволяет Tripo выбирать адаптивно (примерно 1,4 млн полигонов для стандартного качества v3.x, 2 млн для детального). Tripo незаметно ограничивает: v2.5 до 500 000, quad-сетки до 150 000. (по умолчанию: -1) | INT | Нет | от -1 до 2 000 000 |
| `квад` | Вывод quad-сетки. Tripo поставляет quad-сетки в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остаётся пустым. (по умолчанию: False) | BOOLEAN | Нет | - |
| `качество геометрии` | Уровень качества генерации геометрии (по умолчанию: `"standard"`). | COMBO | Нет | `"standard"`<br>`"detailed"` |
| `smart_low_poly` | Низкополигональная сетка с чистой топологией в стиле ручной работы (500–20 000 полигонов, для quad 500–10 000). Лучше всего подходит для простых объектов; сложные могут не получиться. (по умолчанию: False) | BOOLEAN | Нет | - |
| `auto_size` | Масштабировать текстурированные модели до их реального размера в метрах. Tripo сохраняет размер как трансформацию сцены модели и запекает его при конвертации, риггинге или ретаргетинге; без текстуры игнорируется. (по умолчанию: False) | BOOLEAN | Нет | - |

**Примечание:** Изображение спереди (`image`) требуется всегда, а также должно быть указано хотя бы одно из `image_left`, `image_back` или `image_right`. Отключение `texture` автоматически отключает и `pbr`, поскольку `pbr` требует текстуру. Когда `smart_low_poly` включён и `face_limit` не равен -1, `face_limit` должен быть от 500 до 20 000 для треугольных сеток или от 500 до 10 000 для четырёхугольных сеток.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `файл модели` | Путь к файлу или идентификатор сгенерированной 3D-модели (только для обратной совместимости). | STRING |
| `task_id модели` | Идентификатор задачи для отслеживания процесса генерации модели. | MODEL_TASK_ID |
| `GLB` | Файл сгенерированной 3D-модели в формате GLB. Пуст, когда включён `quad`. | FILE3DGLB |
| `FBX` | Файл сгенерированной 3D-модели в формате FBX. Заполняется только при включённом `quad`. | FILE3DFBX |
