# LTXVAddLatentGuide

## Обзор

Нод ЛТХВ Добавление латентного гида привязывает уже закодированный латентный код в качестве гида, что позволяет использовать гид, вышедший из более ранней стадии, а не изображение. Этот нод избегает vòng tri回路 VAE декодирования/кодирования и может расширить гида, имеющего меньшие размеры в пространстве, на спарсgrid для покрытия целевого канваса.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `positive` | Положительное условное вхождение. | CONDITIONING | Да | Не определено |
| `negative` | Отрицательное условное вхождение. | CONDITIONING | Да | Не определено |
| `vae` | Модель VAE, которую нужно использовать. | MODEL | Да | Не определено |
| `latent` | Целевое видео латентный код, на который привязывается гид. | LATENT | Да | Не определено |
| `guiding_latent` | Латентный код гида. Его пространственный размер должен делиться размером целевого кода на одинаковое целое число по обеим осям; равный размер привязывает его так, как есть, размер в половину рассматривается как x2 IC-LoRA эталонный гид. | LATENT | Да | Не определено |
| `latent_idx` | Индекс кадра латентного кода, с которого начинается гид, учитываемый в кадрах латентного кода, а не в кадрах пикселей. Отрицательные значения помещают гид на кадры до начала латентного кода, не учитывая обратного отсчета от его конца. | INT | Да | -9999 до 9999 |
| `strength` | Ограничено до 1.0. Расширенный гид помечает свои позиции заполнения с помощью отрицательного маскирования денoise, чтобы модель их отбросила; значения выше 1.0 приведут к отрицательным позициям сохраняемых позиций и весь гид будет отброшен. Увеличивайте за пределами 1.0 с помощью attention_mask. | FLOAT | Да | 0.0 до 1.0, шаг 0.01 |
| `attention_mask` | Опциональный пространственный маска в пространственной области. Контролирует влияние условного вхождения на каждую область через само-внимание, умноженное на силу. | MASK | Нет | Не определено |

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `positive` | Положительное условное выход. | CONDITIONING |
| `negative` | Отрицательное условное выход. | CONDITIONING |
| `latent` | Латентный выход с примененным гидом. | LATENT |

## Примечания

- Пространственный размер `guiding_latent` должен делиться размером `latent` на одинаковое целое число по обеим осям.
- Параметр `latent_idx` позволяет точно разместить гид в кадрах латентного кода.
- Параметр `strength` контролирует интенсивность гида, значения выше 1.0 требуют использования `attention_mask`, чтобы избежать отрицательных позиций.
- Параметр `attention_mask` опционален, но может быть использован для тонкой настройки влияния гида в конкретных областях изображения.
