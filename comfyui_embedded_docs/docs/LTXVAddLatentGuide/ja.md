# LTXVAddLatentGuide

## 概要

LTXV アドダー・ラテンガイドノードは、既にエンコードされたラテンをガイドとしてピン留め、以前のステージから出てくるガイドを使用するようにします。このノードはVAEのデコード/エンコードのラウンドトリップを避け、空間的に小さいガイドをスパースグリッドに拡張してターゲットキャンバスをカバーすることができます。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|------------|------|----------|------|-------|
| `positive` | 正の条件入力。 | CONDITIONING | はい | なし |
| `negative` | 負の条件入力。 | CONDITIONING | はい | なし |
| `vae` | 使用するVAEモデル。 | MODEL | はい | なし |
| `latent` | ガイドがピン留めされるターゲットビデオのラテン。 | LATENT | はい | なし |
| `guiding_latent` | ガイドラテン。その空間サイズは、ターゲットのサイズを両軸で同じ完全数で割ることが必要です；同じサイズでピン留めするとそのまま、半分のサイズはx2 IC-LoRA参照として扱われます。 | LATENT | はい | なし |
| `latent_idx` | ガイドを開始するラテンフレームインデックス、ラテンフレームで数えられます（ピクセルフレームではありません）。負の値はラテン開始前にガイドを配置し、ラテンの終わりからは数えられません。 | INT | はい | -9999 から 9999 |
| `strength` | 1.0でカップリングされます。拡張されたガイドはパディング位置を負のノイズマスクでマークし、モデルがそれらをドロップします；1.0を超える値では保持される位置が負の値になるため、全体のガイドがドロップされます。1.0を超える場合は、attention_maskを使用して拡大してください。 | FLOAT | はい | 0.0 から 1.0、ステップ 0.01 |
| `attention_mask` | オプションのピクセル空間の空間マスク。self-attentionを通じて各領域の条件影響を制御し、強度に乗算されます。 | MASK | いいえ | なし |

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `positive` | 正の条件出力。 | CONDITIONING |
| `negative` | 負の条件出力。 | CONDITIONING |
| `latent` | ガイドが適用されたラテン出力。 | LATENT |

## 注意事項

- `guiding_latent`の空間サイズは、`latent`のサイズを両軸で同じ完全数で割ることが必要です。
- `latent_idx`パラメータは、ラテンフレーム内のガイドの正確な配置を可能にします。
- `strength`パラメータは、ガイドの強度を制御し、1.0を超える値では`attention_mask`を使用して負の位置を避ける必要があります。
- `attention_mask`パラメータはオプションですが、画像の特定の領域におけるガイドの影響を微調整するために使用できます。
