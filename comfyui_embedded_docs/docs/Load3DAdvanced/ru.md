# Загрузить 3D (расширено)

Узел Load 3D (Advanced) загружает файл 3D-модели из каталога `input/3d` ComfyUI и предоставляет данные модели вместе с размещением модели и информацией о камере, сохранёнными в состоянии окна просмотра 3D-просмотрщика. Он поддерживает распространённые форматы 3D-файлов и позволяет задавать ширину и высоту рендеринга окна просмотра в пикселях. Это экспериментальный узел.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_file` | Файл 3D-модели для загрузки. Выберите «none», чтобы пропустить загрузку файла модели. | COMBO | Да | `"none"`<br>Доступные файлы 3D-моделей в каталоге `input/3d` |
| `viewport_state` | Текущее состояние окна просмотра, содержащее информацию о камере и модели из 3D-просмотрщика. | LOAD3D | Да | - |
| `width` | Ширина рендеринга окна просмотра в пикселях (по умолчанию: 1024). | INT | Да | Min: 1<br>Max: 4096<br>Default: 1024<br>Step: 1 |
| `height` | Высота рендеринга окна просмотра в пикселях (по умолчанию: 1024). | INT | Да | Min: 1<br>Max: 4096<br>Default: 1024<br>Step: 1 |

**Примечания по параметрам:**
- Параметр `model_file` перечисляет только файлы со следующими расширениями: .gltf, .glb, .obj, .fbx, .stl
- Файлы должны быть размещены в каталоге `input/3d` вашей установки ComfyUI; подпапки также включаются в поиск, а пути к файлам отображаются относительно каталога `input`
- Если `model_file` имеет значение «none», данные модели не загружаются, и выход `model_3d` будет пустым
- Если для `model_file` указан несуществующий файл, узел возвращает ошибку валидации: «Invalid 3D model file: {model_file}»

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_3d` | Загруженный файл 3D-модели (glb/obj/stl/и т. д.). Пусто, если файл модели не был выбран. | FILE3DANY |
| `model_3d_info` | Размещение каждой модели в сцене: позиция, поворот и масштаб (мировая система координат с осью Y вверх). | LOAD3DMODELINFO |
| `camera_info` | Информация о камере окна просмотра: позиция, целевая точка обзора, зум и тип. | LOAD3DCAMERA |
| `width` | Ширина рендеринга окна просмотра в пикселях. | INT |
| `height` | Высота рендеринга окна просмотра в пикселях. | INT |
