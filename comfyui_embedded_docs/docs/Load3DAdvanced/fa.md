# بارگذاری ۳بعدی (پیشرفته)

گره Load 3D (Advanced) یک فایل مدل سه‌بعدی را از پوشه `input/3d` در ComfyUI بارگذاری می‌کند و داده‌های مدل را همراه با اطلاعات قرارگیری مدل و دوربین که در وضعیت ویوپورت نمایشگر سه‌بعدی ثبت شده‌اند، ارائه می‌دهد. این گره از قالب‌های رایج فایل سه‌بعدی پشتیبانی می‌کند و به شما امکان می‌دهد عرض و ارتفاع رندر ویوپورت را برحسب پیکسل تنظیم کنید. این گره آزمایشی است.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | بازه |
|-----------|-------------|-----------|----------|-------|
| `model_file` | فایل مدل سه‌بعدی برای بارگذاری. برای صرف‌نظر کردن از بارگذاری فایل مدل، "none" را انتخاب کنید. | COMBO | بله | `"none"`<br>فایل‌های مدل سه‌بعدی موجود در پوشه `input/3d` |
| `viewport_state` | وضعیت کنونی ویوپورت که شامل اطلاعات دوربین و مدل از نمایشگر سه‌بعدی است. | LOAD3D | بله | - |
| `عرض` | عرض رندر ویوپورت برحسب پیکسل (پیش‌فرض: 1024). | INT | بله | حداقل: 1<br>حداکثر: 4096<br>پیش‌فرض: 1024<br>گام: 1 |
| `ارتفاع` | ارتفاع رندر ویوپورت برحسب پیکسل (پیش‌فرض: 1024). | INT | بله | حداقل: 1<br>حداکثر: 4096<br>پیش‌فرض: 1024<br>گام: 1 |

**نکاتی درباره پارامترها:**
- پارامتر `model_file` فقط فایل‌هایی با پسوندهای زیر را فهرست می‌کند: .gltf, .glb, .obj, .fbx, .stl
- فایل‌ها باید در پوشه `input/3d` در نصب ComfyUI شما قرار گیرند؛ زیرپوشه‌ها نیز جست‌وجو می‌شوند و مسیر فایل‌ها نسبت به پوشه input نمایش داده می‌شود
- اگر `model_file` برابر "none" باشد، هیچ داده مدلی بارگذاری نمی‌شود و خروجی `model_3d` خالی خواهد بود
- اگر `model_file` روی فایلی تنظیم شود که وجود ندارد، گره یک خطای اعتبارسنجی برمی‌گرداند: "Invalid 3D model file: {model_file}"

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `مدل ۳بعدی` | فایل مدل سه‌بعدی بارگذاری‌شده (glb/obj/stl/etc.). اگر هیچ فایل مدلی انتخاب نشده باشد، خالی است. | FILE3DANY |
| `اطلاعات مدل ۳بعدی` | قرارگیری هر مدل در صحنه: موقعیت، چرخش و مقیاس (فضای جهانی با محور Y رو به بالا). | LOAD3DMODELINFO |
| `اطلاعات دوربین` | اطلاعات دوربین ویوپورت: موقعیت، هدف نگاه، بزرگ‌نمایی و نوع. | LOAD3DCAMERA |
| `عرض` | عرض رندر ویوپورت برحسب پیکسل. | INT |
| `ارتفاع` | ارتفاع رندر ویوپورت برحسب پیکسل. | INT |
