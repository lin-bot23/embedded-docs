# 3D読み込み（詳細）

Load 3D (Advanced) ノードは、ComfyUI の `input/3d` ディレクトリから 3D モデルファイルを読み込み、3D ビューアのビューポート状態で取得されたモデル配置とカメラ情報とともにモデルデータを提供します。一般的な 3D ファイル形式に対応しており、ビューポートのレンダリング幅と高さをピクセル単位で設定できます。このノードは実験的です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|-------------|-----------|----------|-------|
| `model_file` | 読み込む 3D モデルファイル。モデルファイルの読み込みをスキップするには "none" を選択します。 | COMBO | はい | `"none"`<br>`input/3d` ディレクトリ内の利用可能な 3D モデルファイル |
| `viewport_state` | 3D ビューアからのカメラ情報とモデル情報を含む現在のビューポート状態。 | LOAD3D | はい | - |
| `width` | ビューポートのレンダリング幅（ピクセル単位、デフォルト: 1024）。 | INT | はい | Min: 1<br>Max: 4096<br>Default: 1024<br>Step: 1 |
| `height` | ビューポートのレンダリング高さ（ピクセル単位、デフォルト: 1024）。 | INT | はい | Min: 1<br>Max: 4096<br>Default: 1024<br>Step: 1 |

**パラメータに関する注記:**
- `model_file` パラメータには、次の拡張子を持つファイルのみが一覧表示されます：.gltf、.glb、.obj、.fbx、.stl
- ファイルは ComfyUI インストール先の `input/3d` ディレクトリに配置する必要があります。サブフォルダも検索され、ファイルパスは入力ディレクトリからの相対パスで表示されます。
- `model_file` が "none" の場合、モデルデータは読み込まれず、`model_3d` 出力は空になります。
- `model_file` が存在しないファイルに設定されている場合、ノードは検証エラー「Invalid 3D model file: {model_file}」を返します。

## 出力

| 出力名 | 説明 | データ型 |
|-------------|-------------|-----------|
| `model_3d` | 読み込まれた 3D モデルファイル（glb/obj/stl など）。モデルファイルが選択されていない場合は空です。 | FILE3DANY |
| `model_3d_info` | シーン内の各モデルの配置：位置、回転、スケール（Y アップのワールド空間）。 | LOAD3DMODELINFO |
| `camera_info` | ビューポートのカメラ情報：位置、注視ターゲット、ズーム、タイプ。 | LOAD3DCAMERA |
| `width` | ビューポートのレンダリング幅（ピクセル単位）。 | INT |
| `height` | ビューポートのレンダリング高さ（ピクセル単位）。 | INT |
