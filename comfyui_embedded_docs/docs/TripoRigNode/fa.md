# Tripo: ریگ مدل

این گره یک مدل سه‌بعدی Tripo موجود را دریافت کرده و نسخه‌ای استخوان‌بندی شده (rigged) از آن ایجاد می‌کند؛ به این معنی که مدل دارای اسکلت می‌شود تا بتوان آن را انیمیت کرد. شما شناسه وظیفه (Task ID) مدل مورد نظر برای استخوان‌بندی را ارائه می‌دهید، نسخه Rig، نوع اسکلت، سبک نام‌گذاری استخوان‌ها و فرمت فایل خروجی را انتخاب می‌کنید و گره وظیفه را به Tripo ارسال می‌کند، تا پایان آن صبر می‌کند و سپس نتیجه دانلود شده را باز می‌گرداند.

## ورودی‌ها

| Parameter | Description | Data Type | Required | Range |
|-----------|-------------|-----------|----------|-------|
| `original_model_task_id` | شناسه وظیفه مدل سه‌بعدی اصلی که باید استخوان‌بندی شود. این معمولاً شناسه‌ای است که توسط یک گره تولید مدل Tripo قبلی ایجاد شده است. | MODEL_TASK_ID | بله | - |
| `model_version` | نسخه مدل Rig برای استفاده. v1.0: فقط شخصیت‌های انسان‌نما (دوپا)، بیش از ۹۰ پیش‌فرض انیمیشن. v2.5: موجودات غیر انسان‌نما (چهارپا، شش‌پا، هشت‌پا، پرنده، مارگونه، آبزی). پیش‌فرض: `v1.0-20240301`. | COMBO | خیر | "v1.0-20240301"<br>"v2.5-20260210" |
| `rig_type` | نوع اسکلت. "auto" ابتدا بررسی Rig رایگان Tripo را اجرا کرده و از نوع توصیه‌شده استفاده می‌کند. سایر مقادیر یک نوع اسکلت خاص را اعمال می‌کنند، مانند biped برای شخصیت‌های انسان‌نما. پیش‌فرض: "auto". | COMBO | خیر | "auto"<br>"biped"<br>"quadruped"<br>"hexapod"<br>"octopod"<br>"avian"<br>"serpentine"<br>"aquatic" |
| `spec` | طرح نام‌گذاری استخوان‌ها: بومی Tripo یا سازگار با Mixamo. Tripo نمی‌تواند پیش‌فرض‌های انیمیشن خود را روی یک rig نسخه v1.0 که با spec مدل mixamo ساخته شده است مجدد هدف‌گذاری کند؛ برای گره Tripo: Retarget rigged model از tripo استفاده کنید. پیش‌فرض: "tripo". | COMBO | خیر | "tripo"<br>"mixamo" |
| `out_format` | فرمت فایل خروجی؛ نتیجه در خروجی مربوطه دریافت می‌شود. پیش‌فرض: "glb". | COMBO | خیر | "glb"<br>"fbx" |

**توجه:** نسخه مدل v1.0 (`v1.0-20240301`) فقط از اسکلت‌های biped پشتیبانی می‌کند. اگر یک `rig_type` غیر biped با این نسخه استفاده شود، گره خطا ایجاد کرده و دستور می‌دهد به جای آن از `v2.5-20260210` استفاده کنید.

**توجه:** هنگامی که `rig_type` برابر با "auto" است، Tripo ابتدا بررسی می‌کند که آیا مدل را می‌توان استخوان‌بندی کرد یا خیر و نوع اسکلت توصیه‌شده را انتخاب می‌کند. اگر Tripo گزارش دهد که مدل قابلیت استخوان‌بندی ندارد، گره با خطا مواجه می‌شود.

## خروجی‌ها

| Output Name | Description | Data Type |
|-------------|-------------|-----------|
| `model_file` | فایل مدل سه‌بعدی استخوان‌بندی شده تولید شده. فقط برای سازگاری معکوس نگهداری شده است. | STRING |
| `rig task_id` | شناسه وظیفه برای ردیابی فرآیند تولید Rig. | RIG_TASK_ID |
| `GLB` | مدل استخوان‌بندی شده به صورت فایل سه‌بعدی GLB. وقتی `out_format` برابر با "glb" باشد پر می‌شود. | FILE3DGLB |
| `FBX` | مدل استخوان‌بندی شده به صورت فایل سه‌بعدی FBX. وقتی `out_format` برابر با "fbx" باشد پر می‌شود. | FILE3DFBX |
