# Tripo: Риггинг модели

Этот узел берёт существующую 3D-модель Tripo и создаёт её риггированную версию, то есть модель получает скелет, чтобы её можно было анимировать. Вы указываете идентификатор задачи (task ID) модели, которую нужно оснастить скелетом, выбираете версию рига, тип скелета, стиль именования костей и формат выходного файла. Узел отправляет задание в Tripo, ожидает его завершения и возвращает загруженный результат.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Допустимые значения |
|-----------|-------------|-----------|----------|---------------------|
| `original_model_task_id` | Идентификатор задачи исходной 3D-модели, которую нужно оснастить скелетом. Обычно это идентификатор, полученный от более раннего узла генерации моделей Tripo. | MODEL_TASK_ID | Да | - |
| `model_version` | Версия рига для использования. v1.0: только человекоподобные (biped) персонажи, 90+ анимационных пресетов. v2.5: нечеловекоподобные существа (quadruped — четвероногие, hexapod — шестиногие, octopod — восьминогие, avian — птицы, serpentine — змееподобные, aquatic — водные). По умолчанию: `v1.0-20240301`. | COMBO | Нет | "v1.0-20240301"<br>"v2.5-20260210" |
| `rig_type` | Тип скелета. "auto" сначала запускает бесплатную проверку рига Tripo и использует рекомендуемый тип. Остальные значения принудительно задают конкретный тип скелета, например biped для человекоподобных персонажей. По умолчанию: "auto". | COMBO | Нет | "auto"<br>"biped"<br>"quadruped"<br>"hexapod"<br>"octopod"<br>"avian"<br>"serpentine"<br>"aquatic" |
| `spec` | Схема именования костей: собственная схема Tripo или совместимая с Mixamo. Tripo не может перенести свои анимационные пресеты на риг v1.0, созданный со спецификацией mixamo; для узла Tripo: Retarget rigged model используйте значение tripo. По умолчанию: "tripo". | COMBO | Нет | "tripo"<br>"mixamo" |
| `out_format` | Формат выходного файла; результат поступает на соответствующий выход. По умолчанию: "glb". | COMBO | Нет | "glb"<br>"fbx" |

**Примечание:** Версия модели v1.0 (`v1.0-20240301`) поддерживает только скелеты biped. Если с этой версией используется `rig_type`, отличный от biped, узел выдаст ошибку и предложит использовать `v2.5-20260210`.

**Примечание:** Когда `rig_type` имеет значение "auto", Tripo сначала проверяет, можно ли оснастить модель скелетом, и выбирает рекомендуемый тип скелета. Если Tripo сообщает, что модель не может быть оснащена скелетом, узел завершается с ошибкой.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Сгенерированный файл 3D-модели с ригом. Сохранён только для обратной совместимости. | STRING |
| `rig task_id` | Идентификатор задания (task ID) для отслеживания процесса создания рига. | RIG_TASK_ID |
| `GLB` | Модель с ригом в формате GLB 3D. Заполняется, когда `out_format` имеет значение "glb". | FILE3DGLB |
| `FBX` | Модель с ригом в формате FBX 3D. Заполняется, когда `out_format` имеет значение "fbx". | FILE3DFBX |
