# ImageYUVToRGB

Узел ImageYUVToRGB преобразует изображения из цветового пространства YUV в цветовое пространство RGB. Он принимает три отдельных входных изображения, представляющих компоненты Y (яркость), U (синяя проекция) и V (красная проекция), и объединяет их в одно изображение RGB.

## Входы

| Параметр | Описание | Тип данных | Обязательность | Диапазон |
| --- | --- | --- | --- | --- |
| `Y` | Входное изображение компонента Y (яркость) | IMAGE | Да | - |
| `U` | Входное изображение компонента U (синяя проекция) | IMAGE | Да | - |
| `V` | Входное изображение компонента V (красная проекция) | IMAGE | Да | - |

**Примечание:** Все три входных изображения (Y, U и V) должны подаваться вместе и иметь совместимые размеры для корректного преобразования.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `output` | Преобразованное изображение RGB | IMAGE |
