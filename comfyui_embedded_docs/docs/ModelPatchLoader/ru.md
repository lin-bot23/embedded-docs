# ModelPatchLoader

Узел **ModelPatchLoader** загружает файл патча модели из папки `model_patches` и подготавливает его к использованию в рабочем процессе. Узел автоматически определяет тип патча, содержащегося в файле, создаёт соответствующую архитектуру, загружает сохранённые веса и заключает всё в обёртку ModelPatcher, чтобы патч можно было применять к другим моделям. Он поддерживает множество специализированных форматов патчей, включая дополнительные ветви ControlNet, модели эмбеддеров признаков, адаптеры и подобные модули.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название` | Имя файла патча модели, загружаемого из каталога model_patches. Выберите один из доступных файлов патчей из списка. | COMBO | Да | Динамически генерируемый список всех файлов патчей модели, найденных в папке `model_patches` |

Примечание: этот узел помечен как экспериментальный. Тип патча определяется автоматически из содержимого файла, поэтому ручной выбор типа не требуется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL_PATCH` | Загруженный патч модели в обёртке ModelPatcher, готовый к применению к модели в рабочем процессе | MODEL_PATCH |
