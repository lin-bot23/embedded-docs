# ModelPatchLoader

Узел ModelPatchLoader загружает файл патча модели из папки `model_patches` и подготавливает его к использованию в рабочем процессе. Он автоматически определяет тип патча, содержащегося в файле, создаёт соответствующую архитектуру, загружает сохранённые веса и упаковывает всё в патчер модели, чтобы его можно было применить к другим моделям. Поддерживаются многие специализированные форматы патчей, включая дополнительные ветви ControlNet, модели эмбеддеров признаков, адаптеры и аналогичные модули.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
| --- | --- | --- | --- | --- |
| `название` | Имя файла патча модели для загрузки из каталога model_patches. Выберите один из доступных файлов патчей из списка. | COMBO | Да | Динамически генерируемый список всех файлов патчей моделей, найденных в папке model_patches |

Примечание: этот узел помечен как экспериментальный. Тип патча определяется автоматически по содержимому файла, поэтому ручной выбор типа не требуется.

## Выходы

| Имя выхода | Описание | Тип данных |
| --- | --- | --- |
| `MODEL_PATCH` | Загруженный патч модели, упакованный в ModelPatcher, готовый к применению к модели в рабочем процессе | MODEL_PATCH |
