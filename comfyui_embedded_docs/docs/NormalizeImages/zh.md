# 归一化图像颜色

此节点通过数学归一化过程调整输入图像的像素值。它从每个像素中减去指定的均值值，然后将结果除以指定的标准差。这是准备图像数据以供其他机器学习模型使用的一种常见预处理步骤。如果输入图像有 alpha 通道，则 alpha 通道将保持不变，以保留透明度。

## 概述

归一化图像节点通过根据均值和标准差调整像素值来归一化输入图像的颜色。此过程在应用机器学习算法之前标准化图像数据非常有用。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
|-----------|-------------|-----------|----------|-------|
| `image`   | 要归一化的输入图像。 | 图像 | 是 | - |
| `平均` | 归一化的均值值。 | 浮点数 | 否 | 0.0 - 1.0（默认：0.5） |
| `标准差` | 归一化的标准差。 | 浮点数 | 否 | 0.001 - 1.0（默认：0.5） |

`mean` 和 `std` 参数用于归一化输入图像的像素值。这两个参数的默认值都设置为 0.5，这是归一化中常用的选择。

## 输出

| 输出名称 | 描述 | 数据类型 |
|-------------|-------------|-----------|
| `图像`     | 应用归一化过程后的结果图像。 | 图像 |

归一化图像节点的输出是归一化后的图像。像素值根据指定的均值和标准差进行调整，并且（如果存在）alpha 通道被保留。

## 注意

归一化图像节点设计用于处理任何批次的图像大小，使其适用于批量处理任务。
