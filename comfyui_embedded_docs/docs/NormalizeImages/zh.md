# 规格化图像

此节点通过数学归一化过程调整输入图像的像素值。它从每个像素中减去指定的均值，然后将结果除以指定的标准差。这是为其他机器学习模型准备图像数据的常见预处理步骤。如果输入图像带有透明通道，透明通道将原样保留，以保持透明度。

## 输入

| 参数 | 描述 | 数据类型 | 必需 | 范围 |
| --- | --- | --- | --- | --- |
| `image` | 要归一化的输入图像。 | IMAGE | 是 | - |
| `平均` | 归一化的均值（默认值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `标准差` | 归一化的标准差（默认值：0.5）。 | FLOAT | 否 | 0.001 - 1.0 |
