# Нормализовать изображения

```markdown
# Normalize Image Colors

Этот узел корректирует значения пикселей входного изображения с помощью математического процесса нормализации. Из каждого пикселя вычитается заданное среднее значение, а затем результат делится на заданное стандартное отклонение. Это является стандартным шагом предобработки данных для подготовки изображений к использованию в других машинных обучающих моделях. Если входное изображение имеет канал альфа, канал альфа передается без изменений, что сохраняет прозрачность.

## Обзор

Узел Normalize Images нормализует цвета входного изображения, корректируя значения его пикселей на основе среднего значения и стандартного отклонения. Этот процесс полезен для стандартизации данных изображений перед применением машинных обучающих алгоритмов.

## Входы

| Параметр | Описание | Тип данных | Обязателен | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `image`   | Входное изображение, которое необходимо нормализовать. | ИЗОБРАЖЕНИЕ | Да | - |
| `среднее` | Среднее значение для нормализации. | ФЛОАТ | Нет | 0.0 - 1.0 (по умолчанию: 0.5) |
| `стандартное отклонение` | Стандартное отклонение для нормализации. | ФЛОАТ | Нет | 0.001 - 1.0 (по умолчанию: 0.5) |

Параметры `mean` и `std` используются для нормализации значений пикселей входного изображения. Значения по умолчанию для обоих параметров установлены в 0.5, что является распространенным выбором для нормализации.

## Выходы

| Название выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `изображения`     | Результат изображения после применения процесса нормализации. | ИЗОБРАЖЕНИЕ |

Выход узла Normalize Images является нормализованным изображением. Значения пикселей корректируются в соответствии с заданным средним значением и стандартным отклонением, и канал альфа (если он присутствует) сохраняется.

## Примечание

Узел Normalize Images спроектирован для обработки любого объема изображений, что делает его подходящим для задач пакетной обработки.
```
