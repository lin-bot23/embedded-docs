# 이미지 정규화

이 노드는 수학적 정규화 과정을 사용하여 입력 이미지의 픽셀 값进行调整합니다. 각 픽셀에서 지정된 평균 값을 뺄 후, 결과를 지정된 표준 편차로 나눕니다. 이 과정은 이미지 데이터를 다른 기계 학습 모델에 적용하기 전에 표준화하는 데 일반적인 전처리 단계입니다. 입력 이미지가 알파 채널이 있으면, 알파 채널은 변경되지 않고 투명성이 유지됩니다.

## 개요

Normalize Images 노드는 평균과 표준 편차에 기반하여 입력 이미지의 색상을 정규화하여, 기계 학습 알고리즘에 적용하기 전에 이미지 데이터를 표준화하는 데 유용합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `image`   | 정규화할 입력 이미지. | IMAGE | 예 | - |
| `평균값` | 정규화에 사용할 평균 값. | FLOAT | 아님 | 0.0 - 1.0 (기본: 0.5) |
| `표준편차` | 정규화에 사용할 표준 편차. | FLOAT | 아님 | 0.001 - 1.0 (기본: 0.5) |

`mean`과 `std` 매개변수는 입력 이미지의 픽셀 값을 정규화하는 데 사용됩니다. 두 매개변수의 기본 값은 모두 0.5로 설정되어 있으며, 이는 정규화에 일반적으로 사용되는 값입니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `이미지`     | 정규화 과정이 적용된 결과 이미지. | IMAGE |

Normalize Images 노드의 출력은 정규화된 이미지입니다. 픽셀 값은 지정된 평균과 표준 편차에 따라 조정되며, 알파 채널(만약 존재하면)은 유지됩니다.

## 주의사항

Normalize Images 노드는 어떤 배치 크기의 이미지를 처리할 수 있어, 배치 처리 작업에 적합합니다.
