# 이미지 정규화

이 노드는 수학적 정규화 과정을 통해 입력 이미지의 픽셀 값을 조정합니다. 지정된 평균값을 각 픽셀에서 뺀 다음, 그 결과를 지정된 표준 편차로 나눕니다. 이는 다른 기계 학습 모델을 위해 이미지 데이터를 준비하는 일반적인 전처리 단계입니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 | 범위 |
| --- | --- | --- | --- | --- |
| `image` | 정규화할 입력 이미지입니다. | IMAGE | 예 | - |
| `평균값` | 정규화에 사용할 평균값입니다(기본값: 0.5). | FLOAT | 아니요 | 0.0 - 1.0 |
| `표준편차` | 정규화에 사용할 표준 편차입니다(기본값: 0.5). | FLOAT | 아니요 | 0.001 - 1.0 |

참고: 입력 이미지에 알파(투명도) 채널이 포함된 경우, 알파 채널은 정규화되지 않습니다. 알파는 색상이 아닌 투명도를 저장하므로 출력에서 변경되지 않은 상태로 유지됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
| --- | --- | --- |
| `이미지` | 정규화 과정이 적용된 결과 이미지입니다. | IMAGE |
