# 標準化圖片

此節點透過數學正規化過程調整輸入影像的像素值。它會從每個像素減去指定的平均值，再將結果除以指定的標準差。這是常見的前處理步驟，用於將影像資料準備給其他機器學習模型使用。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
| --- | --- | --- | --- | --- |
| `image` | 要進行正規化的輸入影像。 | IMAGE | 是 | - |
| `平均值` | 正規化所使用的平均值（預設值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `標準差` | 正規化所使用的標準差（預設值：0.5）。 | FLOAT | 否 | 0.001 - 1.0 |

注意：當輸入影像包含 alpha（透明度）通道時，alpha 通道不會被正規化。它會保持不變地保留在輸出中，因為 alpha 儲存的是透明度而非色彩。

## 輸出

| 輸出名稱 | 說明 | 資料類型 |
| --- | --- | --- |
| `圖片` | 套用正規化過程後所得到的影像。 | IMAGE |
