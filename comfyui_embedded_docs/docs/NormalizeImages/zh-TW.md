# 標準化圖片

此節點透過數學正規化過程調整輸入影像的像素值。它會從每個像素減去指定的平均值，然後將結果除以指定的標準差。這是為其他機器學習模型準備影像資料時常見的預處理步驟。如果輸入影像帶有透明通道，透明通道將原樣保留，以保持透明度。

## 輸入

| 參數 | 說明 | 資料類型 | 必填 | 範圍 |
| --- | --- | --- | --- | --- |
| `image` | 要正規化的輸入影像。 | IMAGE | 是 | - |
| `平均值` | 正規化的平均值（預設值：0.5）。 | FLOAT | 否 | 0.0 - 1.0 |
| `標準差` | 正規化的標準差（預設值：0.5）。 | FLOAT | 否 | 0.001 - 1.0 |

## 輸出
