# نرمال‌سازی تصاویر

این گره مقادیر پیکسل‌های یک تصویر ورودی را با استفاده از یک فرایند نرمال‌سازی ریاضی تنظیم می‌کند. یک مقدار میانگین مشخص را از هر پیکسل کم می‌کند و سپس نتیجه را بر یک انحراف معیار مشخص تقسیم می‌کند. این یک گام پیش‌پردازش رایج برای آماده‌سازی داده‌های تصویری جهت استفاده در سایر مدل‌های یادگیری ماشین است.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | تصویر ورودی برای نرمال‌سازی. | IMAGE | بله | - |
| `mean` | مقدار میانگین برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.0 - 1.0 |
| `std` | انحراف معیار برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.001 - 1.0 |

توجه: هنگامی که تصویر ورودی شامل کانال آلفا (شفافیت) باشد، کانال آلفا نرمال‌سازی نمی‌شود. در خروجی بدون تغییر باقی می‌ماند، زیرا آلفا نشان‌دهنده شفافیت است نه رنگ.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `images` | تصویر حاصل پس از اعمال فرایند نرمال‌سازی. | IMAGE |
