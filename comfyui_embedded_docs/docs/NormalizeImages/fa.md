# نرمال‌سازی تصاویر

این گره مقادیر پیکسل‌های یک تصویر ورودی را با استفاده از یک فرآیند نرمال‌سازی ریاضی تنظیم می‌کند. میانگین مشخصی را از هر پیکسل کم کرده و سپس نتیجه را بر انحراف معیار مشخصی تقسیم می‌کند. این یک مرحله پیش‌پردازش رایج برای آماده‌سازی داده‌های تصویری برای سایر مدل‌های یادگیری ماشین است. اگر تصویر ورودی کانال آلفا داشته باشد، کانال آلفا بدون تغییر منتقل می‌شود تا شفافیت حفظ شود.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
| --- | --- | --- | --- | --- |
| `image` | تصویر ورودی که باید نرمال‌سازی شود. | IMAGE | بله | - |
| `mean` | مقدار میانگین برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.0 - 1.0 |
| `std` | انحراف معیار برای نرمال‌سازی (پیش‌فرض: 0.5). | FLOAT | خیر | 0.001 - 1.0 |

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
| --- | --- | --- |
| `images` | تصویر حاصل پس از اعمال فرآیند نرمال‌سازی. | IMAGE |
