# نرمال‌سازی تصاویر

این گره تصویرهای ورودی را با استفاده از یک فرآیند تنظیم ریاضی تنظیم می‌کند. از هر پیکسل مقدار معینی از میانگین کم می‌کند و سپس نتیجه را بر معیار استاندارد تقسیم می‌کند. این یک مرحله پیش‌پردازش متداول است که برای آماده‌سازی داده‌های تصویر برای مدل‌های یادگیری ماشین استفاده می‌شود. اگر تصویر ورودی کانال آلفا (شفافیت) داشته باشد، کانال آلفا بدون تغییر عبور داده می‌شود تا شفافیت حفظ شود.

## بررسی کلی

گره تنظیم رنگ‌های تصویر، رنگ‌های یک تصویر ورودی را با تنظیم پیکسل‌های آن بر اساس میانگین و معیار استاندارد تنظیم می‌کند. این فرآیند برای استانداردسازی داده‌های تصویر قبل از اعمال الگوریتم‌های یادگیری ماشین مفید است.

## ورودی‌ها

| پارامتر | توضیح | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `image`   | تصویر ورودی که باید تنظیم شود. | IMAGE | بله | - |
| `mean`    | مقدار میانگین برای تنظیم. | FLOAT | خیر | 0.0 - 1.0 (پیش‌فرض: 0.5) |
| `std`     | معیار استاندارد برای تنظیم. | FLOAT | خیر | 0.001 - 1.0 (پیش‌فرض: 0.5) |

پارامترهای `mean` و `std` برای تنظیم پیکسل‌های تصویر ورودی استفاده می‌شوند. مقادیر پیش‌فرض هر دو پارامتر به 0.5 تنظیم شده‌اند که یک انتخاب متداول برای تنظیم است.

## خروجی‌ها

| نام خروجی | توضیح | نوع داده |
|-------------|-------------|-----------|
| `images`     | تصویر نتیجه‌ای که پس از اعمال فرآیند تنظیم، به دست آمده است. | IMAGE |

خروجی گره تنظیم رنگ‌های تصویر، تصویر تنظیم شده است. پیکسل‌ها بر اساس میانگین و معیار استاندارد مشخص شده تنظیم می‌شوند و کانال آلفا (اگر موجود باشد) حفظ می‌شود.

## یادداشت

گره تنظیم رنگ‌های تصویر برای هر اندازه‌ای از مجموعه تصاویر قابل مدیریت است، بنابراین برای وظایف پردازش دسته‌ای مناسب است.
