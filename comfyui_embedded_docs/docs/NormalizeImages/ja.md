# 画像を正規化

このノードは、数理的な正規化プロセスを使用して、入力画像のピクセル値を調整します。各ピクセルから指定された平均値を差し引き、その結果を指定された標準偏差で割ります。これは、他の機械学習モデル向けに画像データを準備するための一般的な前処理手順です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
| --- | --- | --- | --- | --- |
| `image` | 正規化する入力画像です。 | IMAGE | はい | - |
| `平均値` | 正規化に使用する平均値です（デフォルト：0.5）。 | FLOAT | いいえ | 0.0 - 1.0 |
| `標準偏差` | 正規化に使用する標準偏差です（デフォルト：0.5）。 | FLOAT | いいえ | 0.001 - 1.0 |

注：入力画像にアルファ（透明度）チャンネルが含まれる場合、そのアルファチャンネルは正規化されません。アルファは色ではなく透明度を格納するため、出力では変更されずに維持されます。

## 出力

| 出力名 | 説明 | データ型 |
| --- | --- | --- |
| `画像` | 正規化プロセスが適用された後の結果画像です。 | IMAGE |
