# 画像を正規化

このノードは、数学的な正規化プロセスを使用して入力画像のピクセル値を調整します。各ピクセルから指定された平均値を引いた後、結果を指定された標準偏差で除算します。これは、他の機械学習モデルに画像データを準備するための一般的な前処理ステップです。入力画像にアルファチャンネルがある場合、アルファチャンネルは変更せずに通過し、透明性が保たれます。

## 概要

Normalize Images ノードは、平均値と標準偏差に基づいて入力画像のピクセル値を調整することで、画像の色を正規化します。このプロセスは、機械学習アルゴリズムに画像データを標準化する際に有用です。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 范囲 |
|------------|------|----------|------|-------|
| `image`    | 正規化する入力画像。 | IMAGE | はい | - |
| `平均値` | 正規化の平均値。 | FLOAT | いいえ | 0.0 - 1.0 (デフォルト: 0.5) |
| `標準偏差` | 正規化の標準偏差。 | FLOAT | いいえ | 0.001 - 1.0 (デフォルト: 0.5) |

`mean`と`std`パラメータは、入力画像のピクセル値を正規化するために使用されます。両方のパラメータのデフォルト値は0.5に設定されており、これは正規化の一般的な選択です。

## 出力

| 出力名 | 説明 | データ型 |
|--------|------|----------|
| `画像`| 正規化プロセスが適用された後の結果画像。 | IMAGE |

Normalize Images ノードの出力は、正規化された画像です。ピクセル値は指定された平均値と標準偏差に応じて調整され、アルファチャンネル（存在する場合）は保たれます。

## 注意

Normalize Images ノードは、画像のバッチサイズに関係なく処理できるように設計されており、バッチ処理タスクに適しています。
