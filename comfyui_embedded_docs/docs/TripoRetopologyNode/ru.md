# Tripo: Ретопология

Tripo: Retopology принимает высокополигональную 3D-модель, созданную предыдущим узлом Tripo, и перестраивает её в низкополигональную версию с чистой топологией. Он отправляет модель в сервис ретопологии Tripo, ожидает завершения задачи, затем скачивает готовую модель и предоставляет её ID задачи для использования другими узлами Tripo.

## Входы

| Параметр | Описание | Тип данных | Обязательный | Диапазон |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | ID задачи исходной высокополигональной модели. Принимает ID задачи модели из узла генерации Tripo или ID задачи сегмента из Tripo: Segment Model. | STRING | Да | ID задачи Tripo |
| `face_limit` | Целевое количество граней: 500–20 000 треугольников или 500–10 000 четырёхугольников. Значение -1 позволяет Tripo выбрать самостоятельно. (по умолчанию: -1) | INT | Да | -1 (автоматически)<br>500–20 000 (треугольники)<br>500–10 000 (четырёхугольники) |
| `quad` | Вывод четырёхугольной сетки. Tripo поставляет четырёхугольные сетки в формате FBX, поэтому результат появляется на выходе FBX, а выход GLB остаётся пустым. (по умолчанию: False) | BOOLEAN | Да | True<br>False (по умолчанию) |
| `bake` | Запечь исходные текстуры на низкополигональной сетке. (по умолчанию: True) | BOOLEAN | Нет | True (по умолчанию)<br>False |
| `part_names` | Имена частей через запятую из Tripo: Segment Model. Пустое значение обрабатывает всю модель. (по умолчанию: "") | STRING | Нет | Имена частей модели или пусто |

Примечание: Если для `face_limit` задано значение -1, Tripo автоматически определяет количество граней. Если `quad` включён, максимальное ограничение граней составляет 10 000 четырёхугольников вместо 20 000 треугольников, а результат предоставляется в формате FBX (выход GLB остаётся пустым). Если `part_names` пустое, обрабатывается вся модель. Если `face_limit` имеет значение, отличное от -1, и выходит за пределы допустимого диапазона, узел выдаёт ошибку.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|-------------|-----------|
| `model_file` | Обратносовместимый выход, который идентифицирует завершённый файл модели. В более новых рабочих процессах следует использовать выходы GLB или FBX. | STRING |
| `model task_id` | ID задачи завершённого результата ретопологии. Может быть передан другим узлам Tripo для ссылки на эту модель. | STRING |
| `GLB` | Ретопологизированная низкополигональная модель в формате GLB. Пусто, если `quad` включён. | GLB FILE |
| `FBX` | Ретопологизированная низкополигональная модель в формате FBX. Заполняется только если `quad` включён. | FBX FILE |
