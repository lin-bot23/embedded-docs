# Tripo: بازتوپولوژی

Tripo: Retopology یک مدل سه‌بعدی پرجزئیات (high-poly) را که توسط یک گره Tripo قبلی تولید شده است می‌گیرد و آن را به‌صورت نسخه‌ای کم‌جزئیات (low-poly) با توپولوژی تمیز بازسازی می‌کند. این گره مدل را به سرویس ریتاپولوژی Tripo ارسال می‌کند، منتظر می‌ماند تا وظیفه تمام شود، سپس مدل تکمیل‌شده را دانلود می‌کند و شناسه وظیفه (task ID) آن را برای استفاده در سایر گره‌های Tripo ارائه می‌دهد.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | شناسه وظیفه مدل منبع پرجزئیات. یک شناسه وظیفه مدل از یک گره تولید Tripo یا شناسه وظیفه قطعه از Tripo: Segment Model را می‌پذیرد. | STRING | بله | شناسه وظیفه Tripo |
| `face_limit` | تعداد وجه هدف: 500 تا 20,000 مثلث یا 500 تا 10,000 چهارضلعی. مقدار -1 باعث می‌شود Tripo خودش انتخاب کند. (پیش‌فرض: -1) | INT | بله | -1 (خودکار)<br>500 تا 20,000 (مثلث)<br>500 تا 10,000 (چهارضلعی) |
| `quad` | خروجی مش چهارضلعی. Tripo مش‌های چهارضلعی را به‌صورت FBX ارائه می‌دهد، بنابراین نتیجه از خروجی FBX می‌آید و خروجی GLB خالی می‌ماند. (پیش‌فرض: False) | BOOLEAN | بله | True<br>False (پیش‌فرض) |
| `bake` | بافت‌های منبع را روی مش کم‌جزئیات بیک کن. (پیش‌فرض: True) | BOOLEAN | خیر | True (پیش‌فرض)<br>False |
| `part_names` | نام‌های قطعه جداشده با کاما از Tripo: Segment Model. مقدار خالی کل مدل را پردازش می‌کند. (پیش‌فرض: "") | STRING | خیر | نام‌های قطعه مدل یا خالی |

توجه: وقتی `face_limit` روی -1 تنظیم شود، Tripo تعداد وجه را به‌صورت خودکار تعیین می‌کند. وقتی `quad` فعال باشد، حداکثر محدودیت وجه 10,000 چهارضلعی به‌جای 20,000 مثلث است و نتیجه به‌صورت FBX ارائه می‌شود (خروجی GLB خالی می‌ماند). وقتی `part_names` خالی باشد، کل مدل پردازش می‌شود. اگر `face_limit` مقداری غیر از -1 باشد و خارج از محدوده مجاز قرار گیرد، گره خطا ایجاد می‌کند.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `model_file` | خروجی سازگار با نسخه‌های قبلی که فایل مدل تکمیل‌شده را مشخص می‌کند. گردش‌کارهای جدیدتر باید به‌جای آن از خروجی‌های GLB یا FBX استفاده کنند. | STRING |
| `task_id مدل` | شناسه وظیفه نتیجه نهایی ریتاپولوژی. می‌تواند به سایر گره‌های Tripo برای ارجاع به این مدل پاس داده شود. | STRING |
| `GLB` | مدل کم‌جزئیات ریتاپولوژی‌شده در قالب GLB. وقتی `quad` فعال باشد خالی است. | GLB FILE |
| `FBX` | مدل کم‌جزئیات ریتاپولوژی‌شده در قالب FBX. فقط زمانی پر می‌شود که `quad` فعال باشد. | FBX FILE |
