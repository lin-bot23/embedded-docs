# Tripo: إعادة بناء الطوبولوجيا

Tripo: Retopology يأخذ نموذجًا ثلاثي الأبعاد عالي الدقة (high-poly) تم إنشاؤه بواسطة عقدة Tripo سابقة، ويعيد بناءه كنسخة منخفضة الدقة (low-poly) ذات طوبولوجيا نظيفة. يرسل النموذج إلى خدمة إعادة الطوبولوجيا من Tripo، وينتظر اكتمال المهمة، ثم ينزّل النموذج النهائي ويكشف عن معرّف المهمة الخاص به لاستخدامه بواسطة عقد Tripo الأخرى.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `model_task_id` | معرّف مهمة النموذج المصدر عالي الدقة. يقبل معرّف مهمة نموذج من عقدة توليد Tripo أو معرّف مهمة تجزئة من Tripo: Segment Model. | STRING | نعم | Tripo task ID |
| `face_limit` | عدد الأوجه المستهدف: 500-20,000 مثلث أو 500-10,000 رباعي. -1 يجعل Tripo تختار. (الافتراضي: -1) | INT | نعم | -1 (automatic)<br>500 to 20,000 (triangles)<br>500 to 10,000 (quads) |
| `quad` | إخراج شبكة رباعية. تقدّم Tripo الشبكات الرباعية بصيغة FBX، لذلك تصل النتيجة عبر مخرج FBX ويبقى مخرج GLB فارغًا. (الافتراضي: False) | BOOLEAN | نعم | True<br>False (default) |
| `bake` | دمج خامات المصدر على الشبكة منخفضة الدقة. (الافتراضي: True) | BOOLEAN | لا | True (default)<br>False |
| `part_names` | أسماء الأجزاء مفصولة بفواصل من Tripo: Segment Model. فارغ يعالج النموذج كاملًا. (الافتراضي: "") | STRING | لا | Model part names or empty |

ملاحظة: عندما يتم ضبط `face_limit` على -1، يحدد Tripo عدد الأوجه تلقائيًا. عند تمكين `quad`، يكون الحد الأقصى للأوجه 10,000 رباعي بدلًا من 20,000 مثلث، وتُقدَّم النتيجة بصيغة FBX (يبقى مخرج GLB فارغًا). عندما يكون `part_names` فارغًا، تتم معالجة النموذج كاملًا. إذا كانت قيمة `face_limit` أي شيء غير -1 وتقع خارج النطاق المسموح به، فإن العقدة تُطلق خطأً.

## المخرجات

| اسم المخرج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `model_file` | مخرج متوافق مع الإصدارات السابقة يحدد ملف النموذج المكتمل. يجب أن تستخدم سير العمل الأحدث مخارج GLB أو FBX بدلًا منه. | STRING |
| `معرّف مهمة النموذج` | معرّف مهمة نتيجة إعادة الطوبولوجيا المكتملة. يمكن تمريره إلى عقد Tripo الأخرى للإشارة إلى هذا النموذج. | STRING |
| `GLB` | النموذج منخفض الدقة المعاد طوبولوجيًا بصيغة GLB. فارغ عند تمكين `quad`. | GLB FILE |
| `FBX` | النموذج منخفض الدقة المعاد طوبولوجيًا بصيغة FBX. يُملأ فقط عند تمكين `quad`. | FBX FILE |
