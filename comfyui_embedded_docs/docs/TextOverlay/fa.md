# افزودن متن به تصویر

این گره متن را روی یک تصویر یا دسته‌ای از تصاویر رسم می‌کند. یک لایه‌ی متنی با اندازه قلم، رنگ، موقعیت عمودی، ترازبندی افقی و حاشیه سیاه اختیاری قابل تنظیم می‌سازد، سپس لایه را روی تصاویر اصلی ترکیب می‌کند.

## ورودی‌ها

| پارامتر | توضیحات | نوع داده | الزامی | محدوده |
|-----------|-------------|-----------|----------|-------|
| `تصاویر` | تصویر ورودی یا دسته‌ای از تصاویر برای رسم متن روی آن‌ها | IMAGE | بله | |
| `متن` | متنی که روی تصویر قرار می‌گیرد (پیش‌فرض: ""). از چند خط پشتیبانی می‌کند: توالی‌های فرار `\n` و `\t` به خط جدید و تب تبدیل می‌شوند، و خطوط بلند به‌طور خودکار برای جا شدن در عرض تصویر شکسته می‌شوند. | STRING | بله | |
| `اندازه فونت` | اندازه قلم به‌صورت درصدی از ارتفاع تصویر (پیش‌فرض: 5.0) | FLOAT | بله | 0.5 تا 50.0 (گام 0.5) |
| `رنگ` | رنگ متن (پیش‌فرض: "#ffffff") | STRING | بله | |
| `موقعیت` | موقعیت عمودی متن روی تصویر (پیش‌فرض: "top") | COMBO | بله | "top"<br>"bottom" |
| `تراز` | ترازبندی افقی متن (پیش‌فرض: "left") | COMBO | بله | "left"<br>"center"<br>"right" |
| `حاشیه` | رسم یک حاشیه سیاه دور متن (پیش‌فرض: True) | BOOLEAN | بله | |

توجه: اگر `text` خالی باشد یا فقط فاصله سفید داشته باشد، گره تصاویر ورودی را بدون تغییر برمی‌گرداند. لایه‌ی متنی یک‌بار رندر می‌شود و روی هر تصویر در دسته اعمال می‌گردد.

## خروجی‌ها

| نام خروجی | توضیحات | نوع داده |
|-------------|-------------|-----------|
| `تصاویر` | تصاویر ورودی با لایه‌ی متنی ترکیب‌شده روی آن‌ها | IMAGE |
