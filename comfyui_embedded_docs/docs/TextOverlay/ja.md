# テキストオーバーレイを描画

このノードは、画像または画像のバッチの上にテキストを描画します。フォントサイズ、色、垂直位置、水平揃え、および任意の黒い輪郭を設定できるテキストオーバーレイを構築し、そのオーバーレイを元の画像に合成します。

## 入力

| パラメータ | 説明 | データ型 | 必須 | 範囲 |
|-----------|------|----------|------|------|
| `画像` | テキストを描画する対象となる入力画像、または画像のバッチです。 | IMAGE | はい | |
| `テキスト` | 画像にオーバーレイするテキストです（デフォルト: ""）。複数行に対応しており、`\n` エスケープシーケンスは改行に、`\t` はタブに変換されます。長い行は画像の幅に収まるように自動的に折り返されます。 | STRING | はい | |
| `フォントサイズ` | 画像の高さに対するパーセントで指定するフォントサイズです（デフォルト: 5.0）。 | FLOAT | はい | 0.5〜50.0 (ステップ 0.5) |
| `色` | テキストの色です（デフォルト: "#ffffff"）。 | STRING | はい | |
| `位置` | 画像上でのテキストの垂直位置です（デフォルト: "top"）。 | COMBO | はい | "top"<br>"bottom" |
| `整列` | テキストの水平揃えです（デフォルト: "left"）。 | COMBO | はい | "left"<br>"center"<br>"right" |
| `アウトライン` | テキストの周囲に黒い輪郭を描画するかどうかを指定します（デフォルト: True）。 | BOOLEAN | はい | |

注：`text` が空、または空白のみの場合は、このノードは入力画像を変更せずにそのまま返します。テキストオーバーレイは1回だけ描画され、バッチ内のすべての画像に適用されます。

## 出力

| 出力名 | 説明 | データ型 |
|---------|------|----------|
| `画像` | テキストオーバーレイが合成された入力画像です。 | IMAGE |
