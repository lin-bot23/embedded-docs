# 텍스트 오버레이 그리기

이 노드는 이미지 또는 이미지 배치 위에 텍스트를 그립니다. 구성 가능한 글꼴 크기, 색상, 세로 위치, 가로 정렬 및 선택적 검은색 윤곽선을 사용하여 텍스트 오버레이를 만든 다음, 원본 이미지 위에 해당 오버레이를 합성합니다.

## 입력

| 매개변수 | 설명 | 데이터 타입 | 필수 여부 | 범위 |
|-----------|-------------|-----------|----------|-------|
| `images` | 텍스트를 그릴 입력 이미지 또는 이미지 배치입니다. | IMAGE | 예 | |
| `text` | 이미지에 표시할 텍스트입니다(기본값: ""). 여러 줄을 지원하며, `\n` 및 `\t` 이스케이프 시퀀스는 줄바꿈과 탭으로 변환되고, 긴 줄은 이미지 너비에 맞게 자동으로 줄바꿈됩니다. | STRING | 예 | |
| `font_size` | 이미지 높이의 백분율로 표시되는 글꼴 크기입니다(기본값: 5.0). | FLOAT | 예 | 0.5~50.0 (단계 0.5) |
| `color` | 텍스트의 색상입니다(기본값: "#ffffff"). | STRING | 예 | |
| `position` | 이미지에서 텍스트의 세로 위치입니다(기본값: "top"). | COMBO | 예 | "top"<br>"bottom" |
| `align` | 텍스트의 가로 정렬입니다(기본값: "left"). | COMBO | 예 | "left"<br>"center"<br>"right" |
| `outline` | 텍스트 주위에 검은색 윤곽선을 그립니다(기본값: True). | BOOLEAN | 예 | |

참고: `text`가 비어 있거나 공백만 포함된 경우, 노드는 입력 이미지를 변경하지 않고 반환합니다. 텍스트 오버레이는 한 번 렌더링되어 배치의 모든 이미지에 적용됩니다.

## 출력

| 출력 이름 | 설명 | 데이터 타입 |
|-------------|-------------|-----------|
| `images` | 텍스트 오버레이가 합성된 입력 이미지입니다. | IMAGE |
