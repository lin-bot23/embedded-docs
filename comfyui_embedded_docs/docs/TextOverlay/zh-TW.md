# 繪製文字覆蓋

此節點會在圖片或圖片批次上繪製文字。它會建立一個可設定的文字疊加層，包含字型大小、顏色、垂直位置、水平對齊，以及可選的黑色外框，然後將疊加層合成到原始圖片上。

## 輸入

| 參數 | 說明 | 資料類型 | 必要 | 範圍 |
|-----------|-------------|-----------|----------|-------|
| `圖片` | 要繪製文字的輸入圖片或圖片批次 | IMAGE | 是 | |
| `文字` | 要疊加在圖片上的文字（預設：""）。支援多行：`\n` 和 `\t` 跳脫序列會轉換為換行和跳位字元，長行會自動換行以符合圖片寬度。 | STRING | 是 | |
| `字型大小` | 字型大小，以圖片高度的百分比表示（預設：5.0） | FLOAT | 是 | 0.5 至 50.0（間距 0.5） |
| `顏色` | 文字顏色（預設："#ffffff"） | STRING | 是 | |
| `位置` | 文字在圖片上的垂直位置（預設："top"） | COMBO | 是 | "top"<br>"bottom" |
| `對齊` | 文字的水平對齊方式（預設："left"） | COMBO | 是 | "left"<br>"center"<br>"right" |
| `外框` | 在文字周圍繪製黑色外框（預設：True） | BOOLEAN | 是 | |

注意：如果 `text` 為空或僅包含空白字元，此節點會直接回傳輸入圖片而不做任何變更。文字疊加層只會渲染一次，並套用到批次中的每一張圖片。

## 輸出

| 輸出名 | 說明 | 資料類型 |
|-------------|-------------|-----------|
| `圖片` | 已將文字疊加層合成在上方的輸入圖片 | IMAGE |
