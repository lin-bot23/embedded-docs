# Наложение текста

Этот узел рисует текст поверх изображения или пакета изображений. Он создает текстовое наложение с настраиваемым размером шрифта, цветом, вертикальным положением, горизонтальным выравниванием и опциональной черной обводкой, а затем объединяет наложение с исходными изображениями.

## Входы

| Параметр | Описание | Тип данных | Обязательно | Диапазон |
|----------|----------|------------|-------------|----------|
| `изображения` | Входное изображение или пакет изображений, на которых нужно нарисовать текст | IMAGE | Да | |
| `текст` | Текст для наложения на изображение (по умолчанию: ""). Поддерживает несколько строк: escape-последовательности `\n` и `\t` преобразуются в переводы строк и табуляцию, а длинные строки автоматически переносятся, чтобы поместиться в ширину изображения. | STRING | Да | |
| `размер_шрифта` | Размер шрифта в процентах от высоты изображения (по умолчанию: 5.0) | FLOAT | Да | от 0.5 до 50.0 (шаг 0.5) |
| `цвет` | Цвет текста (по умолчанию: "#ffffff") | STRING | Да | |
| `позиция` | Вертикальное положение текста на изображении (по умолчанию: "top") | COMBO | Да | "top"<br>"bottom" |
| `выравнивание` | Горизонтальное выравнивание текста (по умолчанию: "left") | COMBO | Да | "left"<br>"center"<br>"right" |
| `контур` | Рисовать чёрную обводку вокруг текста (по умолчанию: True) | BOOLEAN | Да | |

Примечание: Если параметр `text` пуст или содержит только пробельные символы, узел возвращает входные изображения без изменений. Текстовое наложение отрисовывается один раз и применяется к каждому изображению в пакете.

## Выходы

| Имя выхода | Описание | Тип данных |
|-------------|----------|------------|
| `изображения` | Входные изображения с текстовым наложением поверх | IMAGE |
