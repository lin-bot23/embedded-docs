# إضافة نص على الصورة

هذا العقد يرسم نصًا فوق صورة أو دفعة من الصور. ينشئ تراكبًا نصيًا بحجم خط قابل للضبط، ولون، وموضع رأسي، ومحاذاة أفقية، ومخطط أسود اختياري، ثم يُركّب التراكب على الصور الأصلية.

## المدخلات

| المعامل | الوصف | نوع البيانات | مطلوب | النطاق |
|-----------|-------------|-----------|----------|-------|
| `الصور` | صورة الإدخال أو دفعة الصور التي سيُرسَم النص عليها | IMAGE | نعم | |
| `النص` | النص الذي سيُركَّب على الصورة (الافتراضي: ""). يدعم عدة أسطر: يتم تحويل تسلسلي الهروب `\n` و `\t` إلى أسطر جديدة وتبويبات، كما تُلتفّ الأسطر الطويلة تلقائيًا لتناسب عرض الصورة. | STRING | نعم | |
| `حجم الخط` | حجم الخط كنسبة مئوية من ارتفاع الصورة (الافتراضي: 5.0) | FLOAT | نعم | 0.5 إلى 50.0 (الخطوة 0.5) |
| `اللون` | لون النص (الافتراضي: "#ffffff") | STRING | نعم | |
| `الموضع` | الموضع الرأسي للنص على الصورة (الافتراضي: "top") | COMBO | نعم | "top"<br>"bottom" |
| `محاذاة` | المحاذاة الأفقية للنص (الافتراضي: "left") | COMBO | نعم | "left"<br>"center"<br>"right" |
| `حد خارجي` | رسم مخطط أسود حول النص (الافتراضي: True) | BOOLEAN | نعم | |

ملاحظة: إذا كان `text` فارغًا أو يحتوي على مسافات بيضاء فقط، تُرجع العقدة صور الإدخال دون تغيير. يُولَّد التراكب النصي مرة واحدة ويُطبَّق على كل صورة في الدفعة.

## المخرجات

| اسم المخرَج | الوصف | نوع البيانات |
|-------------|-------------|-----------|
| `الصور` | صور الإدخال مع التراكب النصي المُركَّب فوقها | IMAGE |
